New Research Preview 2026-04-05

Claude Code Ultraplan

3월 31일 소스코드 유출에서 피처 플래그로 발견됐던 Ultraplan이 정식 공개됐습니다. 터미널과 클라우드 브라우저를 연결하는 비동기 계획 도구로, 아직 체인지로그에는 없고 Research Preview 상태입니다.

🖥️
비동기 계획
터미널에서 시작하면 클라우드 세션이 플랜을 짜는 동안 터미널은 자유롭습니다.
💬
브라우저 리뷰
구간 선택 → 인라인 코멘트 → 이모지 반응 → 아웃라인 사이드바로 섹션 이동.
🔁
반복 개선
수정 요청하면 Claude가 반영한 새 버전을 내놓습니다. 만족할 때까지 반복 가능.
⚡
두 가지 실행
클라우드에서 바로 구현하거나, 터미널로 플랜을 받아 로컬에서 실행 선택.

🔄 동작 방식

Ultraplan 전체 흐름

터미널에서 계획을 시작하면, 클라우드의 Claude Code on the web 세션이 받아서 플랜을 작성합니다. 그 동안 터미널은 비어 있어서 다른 작업을 할 수 있습니다.

플랜이 완성되면 브라우저에서 리뷰합니다. 특정 구간을 선택해서 인라인 코멘트를 달고, 이모지 반응을 붙이고, 아웃라인 사이드바로 섹션 간 이동하면서 검토합니다. 수정을 요청하면 Claude가 반영한 새 버전을 내놓습니다. 만족할 때까지 반복 가능합니다.

▶ 실행 방법 (세 가지)

  • 방법 1
    /ultraplan 명령어 + 프롬프트
  • 방법 2
    일반 프롬프트에 "ultraplan"이라는 단어 포함
  • 방법 3
    로컬 플랜 완료 후 "클라우드로 보내서 다듬기" 선택
$ /ultraplan auth 서비스를 세션에서 JWT로 마이그레이션해줘

◇ 터미널 상태 표시

◇ ultraplan — 코드베이스 분석하고 플랜 작성 중.
◇ ultraplan needs your input — 확인할 게 있음. 브라우저 열어서 답해야 함.
◆ ultraplan ready — 플랜 완성. 브라우저에서 리뷰 가능.
◆ 속이 빈 다이아몬드(◇)는 진행 중, 속이 찬 다이아몬드(◆)는 완료 상태입니다. 터미널 자체는 계속 사용할 수 있습니다.

✅ 플랜 승인 후 선택지

선택 1
클라우드에서 바로 실행
"Approve Claude's plan and start coding"을 누르면 같은 클라우드 세션에서 구현이 시작됩니다. 끝나면 diff를 보고 PR을 만들 수 있습니다.
선택 2
터미널로 다시 보내기
"Approve plan and teleport back to terminal"을 누르면 플랜이 로컬 터미널로 내려옵니다. 클라우드 세션은 아카이브되고, 병렬 실행은 불가능합니다.
터미널로 돌아왔을 때 세 가지 옵션
  • ① 현재 대화에 플랜 주입
  • ② 새 세션으로 시작
  • ③ 파일로 저장 후 나중에 실행

🔍 유출본과 정식 버전 비교

항목 유출 당시 (3월 31일) 정식 공개
기본 구조 Opus가 클라우드에서 최대 30분 사고 동일 (Opus, 클라우드 세션)
로컬 전송 __ULTRAPLAN_TELEPORT_LOCAL__ 센티넬 값으로 전송 동일 구조 위에 UI 추가
리뷰 인터페이스 언급 없음 인라인 코멘트, 이모지 반응, 아웃라인 사이드바 추가
구간별 피드백 없음 특정 구간 선택 → 코멘트 가능
체인지로그 등재 피처 플래그만 존재 아직 없음, Research Preview
◆ 정식 버전은 유출에서 발견된 구조 위에 브라우저 리뷰 인터페이스를 올린 것입니다. 터미널에서는 불가능했던 "구간별 피드백"이 핵심 추가 기능입니다.
