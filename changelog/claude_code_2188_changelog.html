01 NEW FEATURES

새 기능

3가지 새로운 기능이 추가되었습니다.

🖥️
NEW · 터미널
CLAUDE_CODE_NO_FLICKER=1 — 깜빡임 없는 터미널 렌더링
환경변수 CLAUDE_CODE_NO_FLICKER=1을 설정하면 alt-screen(대체 화면) 렌더링이 활성화됩니다. 가상 스크롤백(virtual scrollback)과 함께 작동해 터미널 출력 시 발생하던 화면 깜빡임이 근본적으로 해소됩니다.
bash 
export CLAUDE_CODE_NO_FLICKER=1
claude  # 이제 깜빡임 없이 렌더링됨
🔔
NEW · 훅
PermissionDenied 훅 — 거부된 명령 자동 재시도
auto mode에서 명령이 거부된 후 실행되는 PermissionDenied 훅이 추가되었습니다. 훅이 {retry: true}를 반환하면 모델이 자동으로 재시도합니다. 허용 정책을 동적으로 조정하거나 로그를 남기는 등 다양하게 활용할 수 있습니다.
🤖
NEW · 에이전트
이름 지정 서브에이전트 @ 멘션 자동완성
이름이 지정된 서브에이전트(named subagent)가 @ 멘션 자동완성 목록에 표시됩니다. [@]my-agent처럼 입력하면 즉시 해당 에이전트를 호출할 수 있어 에이전트 전환이 훨씬 빠릅니다.
02 IMPROVEMENTS

개선

기존 기능의 사용성과 일관성이 개선되었습니다.

📋
IMPROVE · 권한
거부된 명령어 알림 + /permissions Recent 탭
auto mode에서 거부된 명령어가 이제 알림(notification)으로 표시됩니다. 또한 /permissions의 Recent 탭에서 어떤 명령이 언제 거부됐는지 추적할 수 있습니다.
💭
IMPROVE · 설정
thinking 요약 기본 비활성화
thinking(추론 과정) 요약이 기본적으로 비활성화되었습니다. 다시 켜려면 설정에서 showThinkingSummaries: true로 변경하세요.
settings.json 
{
  "showThinkingSummaries": true  // thinking 요약 다시 보기
}
⚙️
IMPROVE · 환경변수
/env 설정이 PowerShell 도구에도 적용
/env로 설정한 환경변수가 이전에는 Bash 도구에만 반영되었으나, 이제 PowerShell 도구에도 적용됩니다. Windows 환경에서 환경변수가 누락되는 문제가 해소됩니다.
03 BUG FIXES

버그 수정

4개의 버그가 수정되었습니다. 특히 긴 세션 성능과 Windows 호환성이 개선됩니다.

가장 큰 변화
긴 세션에서 프롬프트 캐시가 점점 풀리던 문제가 수정되었습니다. 장시간 작업 시 토큰 비용이 크게 줄어들 것으로 기대됩니다.
🗃️
FIX · 캐시
긴 세션 프롬프트 캐시 풀림 수정
도구 스키마(tool schema) 바이트가 변경될 때 프롬프트 캐시(prompt cache)가 풀리던 문제를 수정했습니다. 캐시가 유지되면 API 요청 시 이전 맥락을 재전송하지 않아도 되므로, 장시간 세션에서 토큰 비용과 응답 속도가 크게 개선됩니다.
📊
FIX · 스키마
StructuredOutput 스키마 캐시 버그 — 50% 실패율 해결
여러 스키마를 사용하는 워크플로우에서 약 50% 실패율을 보이던 StructuredOutput 스키마 캐시 버그가 해결되었습니다. 복잡한 멀티 스키마 파이프라인이 안정적으로 동작합니다.
📄
FIX · CLAUDE.md
중첩 CLAUDE.md 수십 번 재주입 문제 수정
긴 세션에서 중첩된 CLAUDE.md 파일이 수십 번 반복 주입되어 컨텍스트 윈도우를 낭비하던 문제를 수정했습니다. 각 CLAUDE.md는 한 번만 주입됩니다.
🪟
FIX · Windows
Windows CRLF 이중 적용 및 trailing spaces 손실 수정
Windows에서 Edit/Write 도구가 CRLF 줄바꿈을 두 번 적용하고, 마크다운의 줄바꿈(trailing spaces, 두 칸 공백)을 잘라내던 문제를 수정했습니다. Windows 환경에서 파일 편집 결과가 의도한 대로 저장됩니다.
