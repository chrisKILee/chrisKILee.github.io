2.1.110 핵심 업데이트

6가지 핵심 변화

화면 안정성, 자리비움 알림, 키보드 재정의, 스크롤 제어, 편집기 연동, 세션 복구까지 — 장시간 사용자를 위한 변화들.

🖥️
/tui — 전체화면 플리커 없는 렌더링
같은 대화 세션 안에서 즉시 전환. tmux·iTerm2 같은 멀티플렉서 환경에서 화면 깜빡임(flicker)이 사라집니다.
/tui fullscreen
🔔
푸시 알림 — 자리 비우고 기다리기
Remote Control + "Push when Claude decides" 설정 시 Claude가 판단해서 완료 시점에 모바일로 알림을 전송합니다.
Remote Control 활성화 필요
⌨️
Ctrl+O 역할 재정의
Ctrl+O는 이제 verbose transcript 토글만 담당. Focus 뷰 전환은 새로 추가된 /focus 명령어로 분리되었습니다.
Ctrl+O · /focus
📜
자동 스크롤 끄기
긴 응답 출력 중 위쪽 내용을 읽고 싶을 때 화면이 계속 내려가는 문제 해결. fullscreen 모드에서 autoScrollEnabled로 제어합니다.
config: autoScrollEnabled: false
✏️
외부 편집기 연동 개선
Ctrl+G로 편집기 열릴 때 Claude의 마지막 응답이 주석으로 삽입됩니다. /config 활성화 필요. 명령어 인젝션 보안도 강화됐습니다.
Ctrl+G + /config 옵션 활성화
🔄
--resume / --continue 복구 강화
예약된 작업(scheduled tasks)이 남아있는 세션을 복구할 때 작업이 그대로 살아납니다. 비정상 종료 시 이름·컬러도 보존됩니다.
--resume · --continue

Quick Start Guide

바로 써먹는 활용 가이드

4단계로 2.1.110의 핵심 기능을 즉시 적용할 수 있습니다.

1
전체화면 플리커 없는 렌더링 켜기
터미널에서 Claude Code 실행 후 /tui fullscreen 입력. 같은 대화에서 즉시 전환됩니다. 설정 파일에 tui 값을 저장하면 매번 자동 적용.
2
자동 스크롤 비활성화 (fullscreen 한정)
/config에서 autoScrollEnabled를 false로 설정. 이제 긴 응답 출력 중에도 위쪽 내용을 자유롭게 스크롤할 수 있습니다.
3
외부 편집기에 Claude 응답 주석 삽입 켜기
/config에서 관련 옵션 활성화 후 Ctrl+G로 편집기를 열면 Claude의 마지막 응답이 주석으로 함께 삽입됩니다.
4
세션 복구로 작업 이어받기
claude --resume 또는 claude --continue로 이전 세션을 복구하면 예약된 작업(scheduled tasks)까지 그대로 살아납니다. 비정상 종료 후에도 이름과 컬러가 보존됩니다.
bash — /tui 및 자동 스크롤 
# 전체화면 플리커 없는 렌더링 전환
/tui fullscreen

# 자동 스크롤 끄기 (fullscreen 모드)
# /config 에서 설정 또는 settings.json에 추가
"autoScrollEnabled": false
bash — 세션 복구 
# 마지막 세션 이어서 복구 (예약 작업 포함)
claude --resume

# 특정 세션 ID로 복구
claude --resume <session-id>

# 이전 대화 계속하기
claude --continue
bash — 2.1.111 effort 슬라이더 
# 인터랙티브 슬라이더 (인자 없이 호출)
/effort
# → 화살표키로 low / medium / high / xhigh / max 선택
# → Enter로 확정

# 또는 직접 지정
/effort xhigh
⚠️
Ctrl+O / Ctrl+U 변경 주의 2.1.110부터 Ctrl+O는 verbose transcript 전용. 2.1.111부터 Ctrl+U는 전체 버퍼 삭제(이전엔 라인 시작까지만). 기존 습관과 다를 수 있으니 확인하세요.
