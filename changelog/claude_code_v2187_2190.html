단일 버그 수정 릴리즈 — 멀티 에이전트 협업(Cowork) 안정성 개선

  • FIX
    Cowork Dispatch 메시지 미전달 문제 수정
    Cowork 기능 사용 시 에이전트 간 메시지가 전달되지 않던 버그를 수정했습니다. 여러 에이전트를 동시에 운용하는 병렬 워크플로우에서 메시지 손실이 발생하던 문제입니다.
유저 가치

Cowork 기능은 Claude Code 내에서 여러 AI 에이전트를 동시에 실행해 대형 태스크를 병렬로 처리하는 기능입니다. 이번 수정으로 에이전트 간 커뮤니케이션이 안정화되어, 복잡한 멀티 에이전트 자동화 파이프라인을 신뢰할 수 있게 되었습니다.

주요 Hooks/자동화 업데이트

2026년 3–4월

Headless 파이프라인 제어, MCP 연결 최적화, 수십 가지 안정성 수정 포함

신규 기능 하이라이트
"defer" 권한 결정 (PreToolUse Hooks)
Headless 세션에서 특정 도구 호출 시 실행을 일시중단하고, -p --resume으로 재개할 수 있습니다. 자동화 파이프라인에 사람이 개입하는 체크포인트를 만들 수 있습니다.
PermissionDenied Hook + retry
Auto 모드에서 도구 실행이 거부될 때 발동하는 새 훅입니다. 훅에서 {"retry": true}를 반환하면 모델이 재시도합니다. 맥락에 따라 동적으로 권한을 조정하는 스마트 자동화가 가능합니다.
MCP_CONNECTION_NONBLOCKING=true
-p 모드(헤드리스)에서 MCP 연결 대기를 건너뜁니다. MCP 서버가 느리거나 불필요할 때 빠른 실행을 보장합니다. 서버 연결 타임아웃도 5초로 단축되었습니다.
Named 서브에이전트 @ 자동완성
프롬프트 입력 시 @를 입력하면 등록된 서브에이전트 이름이 자동완성 목록에 나타납니다. 파일과 에이전트를 함께 검색할 수 있습니다.
Auto 모드 거부 명령 → /permissions Recent
거부된 명령이 알림으로 표시되고 /permissions → Recent 탭에서 확인 가능합니다. r 키로 즉시 재시도할 수 있어 자동화 워크플로우 디버깅이 쉬워졌습니다.
CLAUDE_CODE_NO_FLICKER=1
alt-screen 렌더링 시 화면 깜빡임을 제거합니다. 가상 스크롤백을 사용하며 tmux 사용자에게 특히 효과적입니다. export CLAUDE_CODE_NO_FLICKER=1으로 활성화합니다.
Defer 훅 활용 패턴

PreToolUse 훅에서 위험한 명령(rm, deploy 등)을 감지하면 "decision": "defer"를 반환합니다. CI 파이프라인이 멈추고 담당자가 검토 후 claude -p --resume SESSION_ID로 재개합니다. 완전 자동화와 인간 감독을 결합하는 안전한 자동화 패턴입니다.

# PreToolUse 훅 예시 (hooks.json) { "hooks": { "PreToolUse": [{ "matcher": "Bash", "hooks": [{ "type": "command", "command": "check-risky-cmd.sh" }] }] } } # check-risky-cmd.sh — 위험 명령 감지 시 defer if echo "$TOOL_INPUT" | grep -qE 'rm -rf|DROP TABLE|kubectl delete'; then echo '{"decision": "defer", "reason": "위험 명령 — 사람이 검토 필요"}' fi # 나중에 재개 claude -p --resume SESSION_ID "승인됨, 계속 진행해줘"

/powerup 대화형 학습 도입

2026년 4월

Claude Code 기능을 인터랙티브 레슨으로 학습하는 /powerup 명령어 추가

/powerup — 대화형 Claude Code 학습
Claude Code 기능을 애니메이션 데모와 함께 단계별로 가르쳐주는 대화형 레슨 시스템입니다. 새로 입문하는 팀원이나 고급 기능을 익히고 싶은 유저에게 적합합니다.
CLAUDE_CODE_PLUGIN_KEEP_MARKETPLACE_ON_FAILURE
플러그인 마켓플레이스의 git pull이 실패해도 기존 캐시를 유지합니다. 오프라인 환경이나 불안정한 네트워크에서 플러그인이 갑자기 사라지는 상황을 방지합니다.
  • NEW
    /powerup 명령어
    /powerup을 실행하면 Claude Code의 주요 기능(Hooks, MCP, 서브에이전트 등)을 애니메이션 데모로 학습할 수 있습니다. 각 레슨은 실제 사용 예시를 포함하고 있어 즉시 응용 가능합니다.
  • IMP
    플러그인 마켓플레이스 캐시 유지 옵션
    환경변수 CLAUDE_CODE_PLUGIN_KEEP_MARKETPLACE_ON_FAILURE=true를 설정하면 마켓플레이스 업데이트 실패 시 기존 캐시를 보존합니다. 기업 환경에서 유용합니다.
활용 팁 — /powerup

/powerup은 단순 도움말이 아닌 대화형 레슨입니다. 신규 입사자 온보딩, 팀 내 Claude Code 워크숍, 혹은 특정 기능(예: Hooks)을 집중적으로 익히고 싶을 때 활용하세요. 기존 /help보다 훨씬 직관적이고 실용적인 학습 경험을 제공합니다.
