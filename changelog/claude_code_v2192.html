🧙Bedrock 셋업 마법사 New

AWS Bedrock 설정, 이제 물어보면서 해줍니다

AWS Bedrock을 통해 Claude Code를 쓰려면 인증 방식, 리전, 자격 증명, 모델 고정까지 설정할 게 여러 개입니다. 지금까지는 문서를 보면서 하나하나 환경변수를 세팅해야 했습니다.

이번에 로그인 화면에서 "3rd-party platform"을 선택하면 인터랙티브 셋업 마법사가 뜹니다. AWS 인증 방식을 고르고, 리전을 설정하고, 자격 증명을 검증하고, 사용할 모델까지 단계별로 안내받을 수 있습니다.

Bedrock 셋업 마법사 진행 흐름

◆ 이전에는 AWS_REGION, AWS_ACCESS_KEY_ID, ANTHROPIC_BEDROCK_BASE_URL 등 환경변수를 문서를 보며 직접 입력해야 했습니다. 마법사가 이 과정을 인터랙티브하게 대체합니다.

💰비용 분석 강화 Improvement

비용을 모델별로 쪼개서 볼 수 있습니다

구독 사용자를 위한 변경입니다. /cost를 실행하면 이제 어떤 모델에서 토큰을 얼마나 썼는지, 캐시가 얼마나 적중했는지까지 분리해서 보여줍니다. "Opus에서 비용이 많이 나오는지, Sonnet에서 나오는지" 한눈에 파악할 수 있습니다.

프롬프트 캐시 만료 힌트 (Pro 플랜)

Pro 플랜 사용자는 세션에 돌아왔을 때, 프롬프트 캐시가 만료된 상태면 "다음 턴에 캐시 없이 보낼 토큰이 대략 얼마"라는 힌트가 하단에 뜹니다. 비용 감각을 잡는 데 도움이 됩니다.

★ /powerup(v2.1.90에서 추가)과 /cost를 함께 써보세요. 세션 내 비용 흐름을 체계적으로 파악할 수 있습니다.

🔒엔터프라이즈 보안 강화 New

forceRemoteSettingsRefresh 정책 추가

회사에서 Claude Code를 관리할 때, 원격 정책을 서버에서 내려받아 적용하는 구조인데요. forceRemoteSettingsRefresh 설정을 켜면 시작 시 반드시 최신 정책을 받아오고, 실패하면 아예 실행이 안 됩니다.

"정책을 못 받으면 차라리 막아라"는 뜻입니다. 캐시된 오래된 정책으로 돌아가는 것을 허용하지 않겠다는, 보안이 엄격한 조직을 위한 옵션입니다.

Linux 샌드박스 강화

Linux 샌드박스도 강화되어, npm과 네이티브 빌드 모두에서 유닉스 소켓 차단이 복원됐습니다. 이전 버전에서 누락됐던 보안 경계를 복구한 수정입니다.

🐛버그 수정 Fix

  • #1
    tmux 서브에이전트 영구 실패 수정 — 오래 작업하다 tmux 창을 닫거나 번호를 바꾸면, 이후부터 서브에이전트를 띄울 때 "Could not determine pane count" 에러가 나면서 영구적으로 실패하던 문제가 수정됐습니다. tmux에서 에이전트 팀을 돌리는 분들한테 꽤 뼈아팠을 버그입니다.
  • #2
    스트리밍 중 도구 입력값 JSON 파싱 오류 수정 — 스트리밍 중 도구 입력값이 JSON 문자열로 넘어와서 검증에 실패하던 문제 수정. 간헐적으로 도구 호출이 깨지던 원인 중 하나였습니다.
  • #3
    확장 사고 중 공백 텍스트 블록 API 에러 수정 — 확장 사고(extended thinking) 과정에서 공백만 있는 텍스트 블록이 생기면 API 400 에러가 나던 문제 수정.
  • #4
    자동 파일럿 중 숫자 키 피드백 설문 오발 수정 — 자동 파일럿이나 연속 프롬프트에서 숫자 키를 누르면 피드백 설문이 의도치 않게 제출되던 문제 수정.
  • #5
    전체 화면 모드 스크롤 버그 수정 — 전체 화면 모드에서 같은 메시지가 두 군데에 동시에 표시되던 스크롤 버그 수정. iTerm2, Ghostty 등에서 발생했습니다.
  • #6
    /clear 힌트 토큰 수 오표시 수정 — "토큰을 아끼려면 /clear 하세요" 힌트가 현재 컨텍스트가 아니라 누적 세션 토큰을 보여주던 문제 수정.
  • #7
    플러그인 MCP 서버 connecting 상태 멈춤 수정 — 플러그인 MCP 서버가 인증 안 된 claude.ai 커넥터와 중복될 때 "connecting" 상태에서 멈추던 문제 수정.
  • #8
    Write 도구 diff 계산 60% 성능 향상 — 큰 파일의 Write 도구 diff 계산이 60% 빨라졌습니다. 탭이나 &, $ 같은 특수문자가 많은 파일에서 특히 차이가 큽니다.
  • #9
    Homebrew 업데이트 안내 채널 분기 — Homebrew로 설치한 분들은 업데이트 안내가 설치 채널에 맞게 표시됩니다. claude-code는 stable, claude-code@latest는 latest.

✦기타 변경사항

  • /release-notes 인터랙티브 피커 — 버전을 직접 골라볼 수 있는 인터랙티브 피커로 바뀌었습니다.
  • Remote Control 세션 이름 자동 생성 — 호스트네임 기반으로 자동 생성됩니다. 예: myhost-graceful-unicorn. --remote-control-session-name-prefix로 접두사를 바꿀 수도 있습니다.
  • /tag, /vim 명령어 삭제 — 두 명령어가 제거됐습니다. vim 모드 전환은 /config → Editor mode에서 하면 됩니다.
  • 멀티라인 Ctrl+E 커서 버그 수정 — 멀티라인 프롬프트에서 줄 끝에 커서가 있을 때 Ctrl+E를 누르면 다음 줄 끝으로 튀던 문제 수정.
