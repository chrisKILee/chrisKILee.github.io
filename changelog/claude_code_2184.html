Windows
PowerShell 도구 (opt-in 프리뷰)
Windows에서 Bash 대신 PowerShell을 Claude Code 도구로 직접 사용할 수 있습니다. 현재 opt-in 프리뷰 단계. 자세한 내용: docs/en/tools-reference#powershell-tool
UX
75분 자리 비움 후 /clear 제안
세션이 75분 이상 유휴 상태였다가 재개되면 /clear를 권유하는 팝업이 나타납니다. 낡은 컨텍스트에 토큰을 낭비하지 않도록 유도하는 기능입니다.
paths: YAML 리스트
스킬·룰 paths: 프론트매터에 YAML 리스트 문법 지원
Rules와 Skills의 paths: 프론트매터에 glob 패턴을 YAML 리스트 형태로 여러 개 선언할 수 있습니다. 기존 단일 문자열 방식 대신 다중 경로 패턴을 깔끔하게 관리할 수 있습니다.
MCP
MCP 도구 설명 · 서버 안내문 2KB 제한
MCP 도구 설명과 서버 instructions가 최대 2KB로 제한됩니다. OpenAPI 기반 MCP 서버가 컨텍스트 윈도우를 과도하게 차지하던 문제를 해소합니다.
MCP
MCP 서버 중복 제거 (로컬 설정 우선)
로컬 설정과 claude.ai 커넥터 모두에 동일하게 설정된 MCP 서버가 있으면 자동으로 중복 제거됩니다. 로컬 설정이 우선권을 가집니다.
UX
백그라운드 Bash 작업 정지 시 45초 후 알림
백그라운드에서 실행 중인 Bash 작업이 인터랙티브 프롬프트에서 멈춰 있는 것 같으면 약 45초 후에 알림을 표시합니다.
Hook
TaskCreated 훅 추가
TaskCreate 도구로 태스크가 생성될 때 발동하는 TaskCreated 훅이 추가되었습니다.
WorktreeCreate Hook
WorktreeCreate 훅에 type: "http" 지원
WorktreeCreate 훅이 type: "http"를 지원합니다. 응답 JSON의 hookSpecificOutput.worktreePath로 생성된 워크트리 경로를 반환할 수 있습니다.
Enterprise
allowedChannelPlugins 관리 설정 추가
팀/엔터프라이즈 관리자가 채널 플러그인 허용 목록을 정의할 수 있는 allowedChannelPlugins 설정이 추가되었습니다.
디버깅
API 요청에 x-client-request-id 헤더 추가
모든 API 요청에 x-client-request-id 헤더가 포함되어 타임아웃 등 이슈 디버깅 시 요청 추적이 쉬워집니다.
딥링크
딥링크가 선호 터미널에서 열림
claude-cli:// 딥링크가 감지 순서상 맨 처음 터미널이 아닌 사용자가 선호하는 터미널에서 열립니다.
스트리밍
CLAUDE_STREAM_IDLE_TIMEOUT_MS 환경변수
스트리밍 유휴 와치독 임계값을 환경변수로 설정할 수 있습니다 (기본값 90초).
3rd Party
ANTHROPIC_DEFAULT_*_MODEL_SUPPORTS 환경변수
Bedrock, Vertex, Foundry 등 써드파티 프로바이더용 고정 모델의 effort/thinking 능력 감지를 오버라이드하는 환경변수가 추가됩니다.
🔵 개선 Improvements 10개
표시
1M+ 토큰 "1.5m" 표기
100만 이상의 토큰 수가 1512.6k 대신 1.5m으로 표시됩니다. 대용량 컨텍스트를 한눈에 파악하기 쉬워집니다.
캐싱
ToolSearch 활성화 시에도 시스템 프롬프트 캐싱 동작
ToolSearch가 활성화된 상태, 즉 MCP 도구를 사용하는 경우에도 글로벌 시스템 프롬프트 캐싱이 정상 동작합니다. 캐시 적중률이 향상됩니다.
시작속도
인터랙티브 시작 약 30ms 단축
setup()을 슬래시 커맨드·에이전트 로딩과 병렬로 실행하여 인터랙티브 시작이 약 30ms 빨라졌습니다.
시작속도
MCP 서버 시작 시 REPL 즉시 렌더링
claude "prompt" 실행 시 MCP 서버가 모두 연결될 때까지 기다리지 않고 REPL이 즉시 렌더링됩니다.
캐싱
p90 프롬프트 캐시 적중률 향상
내부 최적화를 통해 p90 프롬프트 캐시 적중률이 개선되었습니다.
Windows
Windows 드라이브 루트 위험 제거 감지 개선
C:\, C:\Windows 등 Windows 드라이브 루트의 위험한 제거 명령을 더 정확하게 감지합니다.
스크롤
긴 세션에서 스크롤 최상단 리셋 감소
메시지 창이 컴팩션 및 그룹 변경에 영향을 받지 않도록 개선되어 긴 세션에서 불필요하게 스크롤이 맨 위로 이동하는 현상이 줄어듭니다.
렌더링
애니메이션 도구 진행 상황 플리커 감소
뷰포트 위로 스크롤될 때 애니메이션 도구 진행 바가 깜빡이는 현상이 감소했습니다.
VSCode
사용량 비율 및 리셋 시간 경고 배너
VSCode 확장에서 사용량 비율과 리셋 시간을 보여주는 속도 제한 경고 배너가 추가되었습니다.
통계
통계 스크린샷 (Ctrl+S) 16배 빨라짐
/stats에서 Ctrl+S로 찍는 스크린샷이 모든 빌드에서 동작하며 16배 빨라졌습니다.
🟠 버그 수정 Bug Fixes 19개
음성
Push-to-talk 키 누를 때 문자가 입력창에 새어들던 문제
음성 모드에서 push-to-talk 키를 누르고 있을 때 문자가 텍스트 입력창에 입력되거나 트랜스크립트가 잘못된 위치에 삽입되던 문제가 해결되었습니다.
CJK 입력
IME 조합 창이 커서를 따라가지 않던 문제
네이티브 터미널 커서가 텍스트 입력 캐럿을 추적하지 않아 한국어·일본어·중국어 IME 조합 창이 올바른 위치에 렌더링되지 않던 문제가 수정되었습니다.
Git
Scalar/GVFS 부분 클론 저장소에서 시작 시 대량 blob 다운로드
Scalar 또는 GVFS 같은 부분 클론(partial clone) 저장소에서 Claude Code를 시작할 때 불필요한 대량 blob 다운로드가 발생하던 시작 성능 문제가 수정되었습니다.
macOS
macOS에서 산발적 "Not logged in" 오류
macOS 키체인 일시적 읽기 실패로 인해 발생하던 "Not logged in" 오류가 수정되었습니다.
탐색
푸터 항목에 포커스 시 위/아래 화살표 키 응답 없는 문제
푸터 항목이 포커스된 상태에서 위/아래 화살표 키가 반응하지 않던 문제가 수정되었습니다.
콜드 스타트
핵심 도구가 bypass 없이 지연되어 Edit/Write 실패하던 문제
콜드 스타트 시 핵심 도구들이 bypass 활성화 없이 지연될 수 있는 경쟁 조건으로 인해 Edit/Write가 InputValidationError로 실패하던 문제가 수정되었습니다.
키보드
Ctrl+U (kill-to-line-start)가 줄 경계에서 no-op이던 문제
멀티라인 입력에서 줄 경계에 있을 때 Ctrl+U가 아무 작동도 하지 않아, 반복 입력으로 여러 줄을 지울 수 없던 문제가 수정되었습니다.
키바인딩
기본 코드 바인딩 null-해제 시 코드 대기 모드 진입하던 문제
예를 들어 "ctrl+x ctrl+k": null로 기본 코드 바인딩을 해제해도 ctrl+x가 여전히 코드 대기 모드로 진입하던 문제가 수정되었습니다.
마우스
트랜스크립트 검색 입력에 마우스 이벤트가 "mouse" 텍스트로 삽입되던 문제
마우스 이벤트가 트랜스크립트 검색 입력에 리터럴 "mouse" 텍스트로 삽입되던 문제가 수정되었습니다.
워크플로우
--json-schema 세션과 서브에이전트 간 API 400 오류
외부 세션이 --json-schema를 사용하고 서브에이전트도 스키마를 지정할 때 API 400 오류가 발생하던 문제가 수정되었습니다.
렌더링
일부 터미널에서 사용자 메시지 버블의 이모지 배경 누락
특정 터미널에서 사용자 메시지 버블 내 이모지 뒤의 배경색이 누락되던 문제가 수정되었습니다.
권한
Edit(.claude) allow 규칙이 세션 동안 유지되지 않던 문제
Edit(.claude) allow 규칙이 있는 사용자에게 "이 세션 동안 설정 편집 허용" 옵션이 적용되지 않던 문제가 수정되었습니다.
첨부파일
대용량 편집 파일 첨부 스니펫 생성 시 hang
대용량 편집 파일에 대한 첨부 스니펫을 생성할 때 프로그램이 응답하지 않던 문제가 수정되었습니다.
MCP
서버 재연결 시 도구/리소스 캐시 누수
MCP 서버가 재연결될 때 도구/리소스 캐시가 누수되던 문제가 수정되었습니다.
링크
issue/PR 참조 링크 조건 변경
이슈/PR 참조가 owner/repo#123 형식으로 작성된 경우에만 클릭 가능한 링크가 됩니다. 기존에 자동 링크되던 단순 #123 형식은 더 이상 링크로 처리되지 않습니다.
슬래시 커맨드
현재 인증 설정에서 사용 불가 슬래시 커맨드 숨김
/voice, /mobile, /chrome, /upgrade 등 현재 설정에서 사용 불가한 슬래시 커맨드들이 목록에서 숨겨집니다.
스크롤
스크롤 중 스트리밍 시 오래된 콘텐츠가 보이던 문제
스트리밍 중 위로 스크롤할 때 오래된 콘텐츠가 비쳐 보이던 문제가 수정되었습니다.
터미널

Ghostty, Kitty, WezTerm 등 Kitty 키보드 프로토콜을 지원하는 터미널에서 Claude Code 종료 후 enhanced keyboard mode가 해제되지 않아 Ctrl+C, Ctrl+D가 작동하지 않던 문제가 수정되었습니다.
VSCode
