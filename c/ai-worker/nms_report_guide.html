AI-Worker 과제 완료

NMS 데이터, 이제
30분 안에 보고서로

매달 1~2일씩 걸리던 네트워크 현황 보고서 작성을 AI가 자동화했습니다. 웹에서 기간과 암호만 입력하면, 장비 성능·트래픽·수량 리포트가 즉시 생성됩니다.

기존 방식
NMS 수동 조회 → Excel 가공
장비성능, 트래픽, 수량을 각각 참조해 직접 정리
1 ~ 2일
→
자동화 이후
웹에서 기간 입력 → 자동 리포트
Python 스크립트가 NMS DB에 접속해 4종 리포트 즉시 생성
30분 이내

왜 만들었나요?

기존 보고서 작성 방식의 한계에서 출발했습니다

📋
반복적인 수작업
네트워크 현황 보고 때마다 NMS 시스템에서 장비 성능, 트래픽, 장비 수량, 종류별 세부 수량을 각각 조회해 Excel로 옮겨 가공해야 했습니다.
⏱️
1~2일 소요
단순한 현황 정리 작업에 매번 하루 이상의 시간이 소요되어, 담당자가 다른 업무에 집중하기 어려운 구조였습니다.
🤖
AI로 해결
Gemini·ChatGPT를 활용해 Python 자동화 스크립트를 작성하고, NMS DB에서 직접 데이터를 조회해 웹 리포트로 자동 생성하는 방식으로 전환했습니다.

주요 기능

4종 리포트를 하나의 웹 화면에서 확인할 수 있습니다

🖥️
장비 성능 리포트
NMS에 등록된 네트워크 장비의 CPU·메모리·가용성 등 성능 지표를 지정한 기간 동안 자동으로 집계해 보여줍니다.
자동 집계
📡
회선 트래픽 리포트
계열사별 회선 트래픽을 트리 구조로 정리해, 어느 구간에서 트래픽이 집중되는지 한눈에 파악할 수 있습니다.
트리 구조
📊
계열사별 장비 종류 수량
각 계열사가 보유한 장비의 종류별 수량을 자동으로 집계해 현황표 형태로 제공합니다.
현황 집계
🔍
계열사별 장비 종류 세부 수량
장비 종류별 수량에서 더 나아가, 세부 기종·모델별 수량까지 드릴다운해 확인할 수 있습니다.
세부 내역
🔐
웹 기반 입력 화면
별도 프로그램 설치 없이 브라우저에서 암호와 조회 기간만 입력하면 리포트 생성이 시작됩니다.
브라우저 접속
📑
4종 리포트 동시 생성
한 번의 실행으로 4가지 리포트가 동시에 생성되며, 상단 탭 메뉴로 각 리포트를 빠르게 전환할 수 있습니다.
탭 전환

어떻게 사용하나요?

브라우저를 열고 단 3단계면 완성입니다

Step 01
🌐
웹 서버 실행
담당자가 Python 스크립트를 실행하면 웹 서버가 자동으로 시작되고 브라우저가 열립니다.
Step 02
🔑
암호 및 기간 입력
웹 화면에서 접속 암호와 조회 시작·종료일을 입력합니다. (예: 20260101 ~ 20260131)
Step 03
⚡
리포트 자동 생성
NMS 데이터베이스에 자동 접속해 4종 리포트를 동시에 수집하고 화면에 출력합니다.
Step 04
📋
탭 메뉴로 확인
메인·장비성능·회선트래픽·수량·세부수량·보고서 탭을 클릭해 각 리포트를 바로 확인합니다.

어떻게 발전해 왔나요?

1차 시도부터 최종 버전까지, 6단계 반복 개선의 기록입니다

Ver 1 · 260205
PDF 파일로 저장 — 장비 성능과 트래픽을 별도 스크립트로 분리해 PDF 형태로 첫 결과물을 생성했습니다.
Ver 2 · 260206
웹으로 전환 — 두 스크립트를 하나로 합치고, Flask 웹 서버로 브라우저에서 바로 확인할 수 있도록 개선했습니다.
Ver 3 · 260212
계열사별 장비 종류 수량 추가 — HTML 리포트 형식으로 전환하고, 계열사별 장비 종류 수량 탭을 추가했습니다.
Ver 4 · 260220
트리 구조 개선 — 회선 트래픽 화면에서 계열사명을 트리 구조로 재구성해 가독성을 높였습니다.
Ver 5 · 260224
세부 수량 탭 추가 — 계열사별 장비 종류 세부 수량 탭을 추가하여 4종 리포트 체계가 완성되었습니다.
최종 Ver 6 · 260306
웹 입력 화면으로 완전 전환 — 암호와 조회 기간을 웹에서 직접 입력하는 방식으로 변경하고, 장비 성능 화면을 개선해 최종 버전을 완성했습니다.
