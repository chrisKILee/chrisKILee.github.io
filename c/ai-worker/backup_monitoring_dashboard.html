화면 안내
주요 화면 미리보기
실제 대시보드 화면을 통해 기능을 확인하세요. 이미지를 클릭하면 크게 볼 수 있습니다.
01
로그인 화면
회사 계정(@vntgcorp.com)으로 Google 로그인. 별도 계정 발급 없이 기존 사내 계정으로 바로 접속합니다.
02
메인 대시보드
전체 백업 성공·경고·실패 현황을 KPI 카드와 차트로 한눈에 파악. 회사별 성공률 비교와 스토리지 추이도 함께 확인합니다.
03
백업 목록 > 백업 작업 목록
날짜별로 255개 백업 작업의 상태를 조회합니다. 회사·상태·키워드 필터로 원하는 항목을 빠르게 찾고, 일괄 확인 처리도 가능합니다.
04
백업 목록 > Ansible 원본 로그
Oracle RMAN, NetVault, RapidRecovery 등 이기종 백업 솔루션의 원본 로그를 한 화면에서 통합 조회합니다.
05
백업 목록 > 백업일지
일일 백업일지가 자동 생성됩니다. HTML 복사 기능으로 결재문서에 서식 그대로 붙여넣기 가능. 점검자 정보도 자동 입력됩니다.
06
백업 목록 > 시스템 매핑 관리
백업 작업명과 시스템(서버)을 연결하는 매핑 정보를 관리합니다. 올바른 회사·서버 분류를 위해 관리자가 직접 설정합니다.
07
서비스 > 서비스 모델 현황
18개 자회사별 백업 장비 계약 현황을 한눈에 확인. 계약 보존 기간과 실제 보관일을 자동 비교하여 SLA 준수 여부를 시각적으로 표시합니다.
08
서비스 > 백업 용량 계산기
서버 사양과 보존 기간을 입력하면 필요한 백업 저장 용량을 자동으로 계산합니다. 신규 장비 도입 시 용량 산정에 활용합니다.
09
서비스 > 월간 보고서 관리
월별 백업 현황 보고서를 자동 생성합니다. 경영진 보고나 감사 대응 시 즉시 활용할 수 있는 형태로 제공됩니다.
10
관리 > Veeam 서버 설정
Veeam 백업 서버 연결 정보를 등록하고 관리합니다. 다중 Veeam 서버를 등록하여 지사별 백업 서버를 통합 관리할 수 있습니다.
11
관리 > 알림 설정
백업 실패 시 Google Chat으로 즉시 알림을 보낼 웹훅 주소와 알림 조건을 설정합니다. 팀 채널에 자동으로 장애 메시지가 전송됩니다.
12
관리 > 서비스 모델 유형 관리
백업 유형, 서버 분류 등 드롭다운 항목을 관리자가 직접 추가·수정합니다. 새로운 서버 분류 기준이 생길 때 코드 수정 없이 바로 반영됩니다.

FAQ
자주 묻는 질문
사용 중 궁금한 점을 정리했습니다.
대시보드는 어떻게 접속하나요?
사내 네트워크(VPN 포함)에 연결된 상태에서 http://backup.infra.vntgcorp.com 으로 접속합니다. @vntgcorp.com 도메인의 회사 Google 계정으로 로그인하면 됩니다. 별도 소프트웨어 설치 없이 웹 브라우저(Chrome 권장)로 이용 가능합니다.
어떤 권한이 있어야 하나요?
접근 권한은 4단계로 구분됩니다. Admin(전체 관리), Manager(관리 + 확인), User(확인 처리), Viewer(조회 전용)이며, 플랫폼인프라팀에서 적절한 권한을 부여합니다. 처음 접속 시에는 Viewer 권한으로 시작하여 필요에 따라 상향 요청하시면 됩니다.
백업 데이터는 얼마나 자주 업데이트되나요?
Veeam 백업 작업 상태는 Veeam REST API를 통해 자동으로 수집됩니다. Oracle RMAN, NetVault, RapidRecovery 등 이기종 백업 솔루션의 로그는 Ansible 인프라를 통해 정해진 일정에 따라 자동 수집됩니다. 구체적인 수집 주기는 플랫폼인프라팀에 문의해 주세요.
AI 분석은 어떻게 활용하나요?
메인 대시보드의 AI 분석 위젯에서 Gemini AI가 오늘의 전체 백업 현황을 분석한 요약과 권장 조치를 확인할 수 있습니다. 이를 참고 자료로 활용하되, 중요한 판단은 원본 데이터와 함께 전문가가 최종 확인하는 것을 권장합니다.
백업이 실패했을 때 어떻게 해야 하나요?
Google Chat 알림을 수신하거나 대시보드에서 실패 항목을 발견한 경우, 해당 작업을 클릭하여 상세 로그를 확인합니다. AI 분석 내용을 참고하여 조치하거나, 해결이 어려울 경우 플랫폼인프라팀에 문의해 주세요.
백업일지는 결재문서에 어떻게 사용하나요?
백업 목록 메뉴의 '백업일지' 화면에서 원하는 날짜를 선택하고 'HTML 복사' 버튼을 클릭합니다. 클립보드에 복사된 내용을 결재문서(그룹웨어, 워드 등)에 Ctrl+V로 붙여넣으면 서식이 그대로 유지된 상태로 삽입됩니다.
