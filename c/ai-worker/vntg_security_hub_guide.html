💾 설치 방법

1

설치 파일 수령

담당자로부터 VNTG_Security_Hub_Setup.exe 파일을 전달받습니다.

2

설치 실행

다운로드한 .exe 파일을 더블클릭하여 설치 마법사를 실행합니다. 안내에 따라 다음(Next)을 눌러 설치를 완료합니다.

3

앱 실행

바탕화면 또는 시작 메뉴에서 VNTG Security Hub 아이콘을 클릭해 앱을 실행합니다.

4

바로 사용 시작

별도 로그인 없이 메인 화면에서 바로 원하는 기능을 선택해 사용합니다.

ℹ️ Windows Defender 또는 백신 프로그램에서 경고가 뜰 경우, 추가 정보 → 실행을 선택하면 정상적으로 설치됩니다.

🤖 AI 정보보안 규정 Q&A

🤖

AI 정보보안 규정 Q&A

정보보안 규정에 대한 질문을 입력하면 AI가 관련 문서를 검색하여 답변합니다.

1 질문 입력
›
2 AI 문서 검색
›
3 AI 답변 확인
›
4 관련 문서 내용 확인
1
질문 입력

하단 입력창에 궁금한 정보보안 규정 내용을 자연어로 입력하고 전송합니다.
예) "외부 USB 사용은 허용되나요?", "개인정보 처리 기준이 뭔가요?"

2
AI 답변 확인

AI가 관련 정보보안 규정 문서를 검색한 후 요약된 답변을 제공합니다.

3
관련 문서 내용 확인

답변과 함께 참조된 규정 문서의 해당 조항 내용이 함께 표시됩니다.

💡 구체적인 상황을 포함해 질문할수록 더 정확한 답변을 받을 수 있습니다.

📧 악성메일 분석

📧

악성메일 분석

수상한 이메일을 EML 파일로 저장한 후 앱에 업로드하면 위협 여부를 분석합니다.

1 메일 EML 저장
›
2 파일 업로드
›
3 분석 실행
›
4 결과 확인
1
EML 파일 저장

수상한 메일을 이메일 클라이언트에서 .eml 파일로 저장(다운로드)합니다.
Outlook: 파일 → 다른 이름으로 저장 → 파일 형식: Outlook 메시지 형식

2
앱에서 파일 업로드

VNTG Security Hub 앱에서 악성메일 분석 메뉴를 선택하고, 저장한 .eml 파일을 업로드합니다.

3
분석 실행

업로드 후 분석 버튼을 클릭하면 AI가 메일 헤더, 본문, 링크, 첨부파일 등을 종합 분석합니다.

4
분석 결과 확인

위협 여부 및 위험 요소에 대한 분석 결과를 확인합니다.

⚠️ 악성 의심 메일의 링크를 클릭하거나 첨부파일을 열지 마세요. 반드시 EML 파일로 저장 후 앱을 통해 분석하세요.
