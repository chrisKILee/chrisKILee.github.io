2. 조직별 미션 및 역할

2.1 플랫폼서비스실

Terroir 플랫폼과 전사 서비스의 안정적 기반을 제공한다 (Run & Operate)

능동적 플랫폼 서비스 제공

플랫폼인프라팀

  • Terroir 운영 Kubernetes 클러스터 운영, GitOps 배포 환경
  • 클라우드 GCP MSP, 하이브리드(IDC+GCP), FinOps
  • 관측성 Grafana LGTM 스택 기반 통합 관측
  • 시스템/NW IDC 운영, DB 성능 관리, 네트워크 전환

플랫폼정보보호팀

  • SECaaS 중앙 집중형 보안 서비스 전환
  • 보안 기준 Group S-MSB(Security Minimum Baseline) 제정
  • DevSecOps CI/CD 보안 통합, 취약점 스캐닝 자동화
  • 인증 ISMS, ISO27001/27017 유지

2.2 서비스개발실

솔루션을 개발하고 제품화를 추진하며 기술 역량을 제공한다 (Apply & Deliver)

데이터포지팀

  • 현장 데이터 제조 설비 데이터 수집 표준화, 자동화
  • Edge 엣지 컴퓨팅 기반 실시간 처리 고도화
  • 플랫폼 팩토리 to 전체 데이터 플랫폼 연결 구축
  • 제품화 DataForge Web 기능, SLA 수립 (대외 사업)

서비스개발팀

  • 프로젝트 세아M&S MES 등 On-time Delivery
  • 리더십 PM/PL 역량 향상, 영역별 전문가 육성
  • 전환 Terroir 기반 Multi-Stack 기술 대응 (PoC)
  • AI AI-Assisted Dev(Cursor, Copilot) 활용 강화

2.3 R&D실

차세대 기술을 연구하고 Terroir 플랫폼을 설계/구축한다 (Research & Build)

R&D 직속

Enabling Team 역할

  • 기술 연구 클라우드 네이티브 기술 검증, 신기술 PoC
  • Enabling 전사 기술 표준 정의, 아키텍처 가이드라인

플랫폼개발팀

  • Framwork Terroir 코어 개발 (NestJS, Nx)
  • IDP Backstage 기반 개발자 포털 구축
  • CI/CD GitOps 파이프라인 설계, 배포 자동화
  • SDD Spec-Driven Development 방법론 개발

4. 실/팀 간 시너지 매트릭스

R&D실 ↔ 플랫폼서비스실

Build → Run 연속성

R&D 설계/구축 후 즉시 운영 이관으로 기술 이전 비용 최소화

IDP + 인프라

Self-Service 단일 포털 제공 (개발~배포~모니터링)

보안 내재화

DevSecOps 자동화를 통해 보안의 개발 프로세스 내재화

R&D실 ↔ 서비스개발실

Terroir 프레임워크

프로젝트 적용 및 현장 피드백 루프로 품질 향상

SDD 확산

AI 도구 현장 실천, 활용률 90% 달성 목표

DataForge

End-to-End 데이터 플랫폼 자동화 연결

플랫폼서비스실 ↔ 서비스개발실

인프라 ↔ 프로젝트

환경 구축 시간 단축으로 개발 집중도 향상

모니터링 ↔ 운영

통합 관측으로 장애 감지 시간 80% 단축
