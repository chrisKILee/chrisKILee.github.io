사내 AI(RAG) 구현 기술 가이드

단순한 챗봇을 넘어, 기업 내부 데이터를 AI 모델이 이해할 수 있는 숫자 배열(Vector)로 변환하고 프롬프트 템플릿을 통해 정교한 답변을 생성하는 과정을 탐험해보세요.

01. 토큰 (Token)

AI가 문장을 읽는 '글자 조각' 단위입니다. 모델마다 처리 가능한 최대 토큰량이 정해져 있습니다.

02. 청크 (Chunk)

AI 모델의 성능과 효율을 위해 문서를 적절한 크기로 자른 텍스트 덩어리입니다.

03. 벡터 DB (Vector DB)

텍스트를 숫자 배열(Vector)로 변환하여 저장하고 의미 기반으로 검색하는 창고입니다.

04. 템플릿 (Template)

검색된 정보와 질문을 합쳐 AI에게 전달하는 '작업 지시서'입니다. 결과 형식을 고정합니다.

1 AI 모델 기반의 청킹(Chunking) 시뮬레이션

청크의 크기는 사람이 임의로 정하기도 하지만, 궁극적으로는 Embedding AI 모델의 Context Window(토큰 제한)가 결정합니다. 너무 크면 핵심 정보가 희석되고, 너무 작으면 문맥이 끊어집니다.

작은 조각 (빠른 검색) 40 Tokens 큰 조각 (풍부한 문맥)

AI 모델의 텍스트 조각화(Chunking) 결과

2 벡터 DB와 숫자 배열(Numerical Array)

AI는 텍스트를 직접 비교하지 않습니다. 모든 청크는 AI 모델(Embedding)을 거쳐 수천 개의 실수 배열(Array)로 바뀝니다. 벡터 DB는 이 숫자들 사이의 '거리'를 계산하여 유사도를 판별합니다.

실제 저장 형태 (Vector Data)
[ 0.142, -0.091, 0.882, 0.314, -0.551, 0.229, 0.004, -0.118, 0.672, -0.421, 0.901, 0.124, ... ]
* 각 청크는 모델에 따라 보통 768차원 또는 1536차원의 배열로 변환됩니다.

3 질의 응답 및 템플릿(Template) 제어

프롬프트 템플릿 (Prompt Template)
당신은 사내 지식 도우미입니다.
다음 [지식 청크]를 참고하여 답변하세요.
답변은 반드시 JSON 형식으로 리턴하세요.
{
  "answer": "내용",
  "source": "청크 ID"
}
[지식 청크]: {context}
AI Final Response
● 처리 완료
질문을 입력하고 버튼을 눌러주세요.

본 시뮬레이션은 사내 AI(RAG) 구현 시의 핵심 로직인 모델 기반 청킹 -> 벡터 변환 -> 템플릿 응답 과정을 교육하기 위해 제작되었습니다.
