01 Beta 핵심

Beta의 단 한 줄 증명점

화려한 기능보다 이 흐름이 끊김 없이 돌아가는 것이 Beta의 기준입니다.

"한 팀이 IDP에서 새 서비스를 만들어 dev 환경에 배포하고,
기본 관측성으로 상태를 확인할 수 있다." — Beta Release Letter, 이광일 (R&D실장)
플랫폼 철학
Terroir는 레시피(프레임워크)가 아니라 잘 갖춰진 주방입니다. 힘든 준비는 플랫폼이, 재미있는 개발은 개발자가.
🎯
프로젝트 원클릭 생성

VNTG IDP(Backstage)에서 Frontend / Backend / DB 포함 프로젝트를 원클릭으로 생성. 인프라 요청 없이 즉시 시작.

Backstage · Scaffolding
⚙️
자동 배포 (GKE)

코드 머지 시 GitHub Actions → Sommelier → ArgoCD 파이프라인이 GCP(GKE) 환경에 자동 배포.

CI/CD · ArgoCD · Sommelier
🔗
서비스 URL 자동 안내

배포 완료 즉시 Backstage에서 서비스 URL이 자동으로 표시됩니다. (Alpha 주요 피드백 반영)

Alpha 피드백 반영
📊
기본 관측성

로그·메트릭을 Grafana(LGTM 스택)에서 통합 조회. Self-healing + Auto-scaling 지원.

Grafana · LGTM

Vinification과 Élevage 프로젝트가 Terroir 환경에서 본격 진행됩니다. 레거시 서비스의 현대화 작업이 Terroir 위에서 시작됩니다.
