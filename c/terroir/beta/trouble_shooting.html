TS-1 common not found

증상:

## 예시 ##

Command "jest" not found, node_modules 없음

~/rnd-nx (TS-1) $ npx prisma generate
/bin/sh: prisma: command not found

~/rnd-nx (TS-1) $ npx tsc --version
/bin/sh: tsc: command not found

~/rnd-nx (TS-1) $ npx eslint .
/bin/sh: eslint: command not found

원인: 에러가 발생한 패키지가 미설치하여 발생한 에러

해결: 해당 Repository의 루트에서 pnpm install 실행 (약 30초)

원인:

  • 마이그레이션을 실행하지 않음

  • DB를 새로 만들었는데 migrate deploy를 안 함

  • 다른 환경의 DB를 바라보고 있음

해결:

  • DB 기준으로 schema.prisma 만들 SQL 생성

    • pnpm -F db-postgres db:migrate-diff

  • DB 접속해서 SQL 실행

  `@unique` or add a multi field criterion with `@@id([])` or `@@unique([])` to the model.

  13 |

  17 | }

  Validation Error Count: 1

  Prisma CLI Version : 5.22.0

  model Post {
