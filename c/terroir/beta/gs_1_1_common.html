Getting Started 1-1단계: 사전준비 (공통)

Terroir 가이드 문서 (Beta) · R&D실

1. VNTG-CORP 저장소 접근

해당링크: https://github.com/VntgCorp

github 로그인 뒤에 위 링크의 저장소에 접근이 가능해야합니다.

저장소에 접속되하여 아래와 같은 화면이 보이지 않는다면 권한이 없는것 입니다.

문의: Terroir 무엇이든 물어보살 구글 챗(링크)

권한이 없다면 아래를 순서를 따라 진행해주세요

  1. 아래 Form 에 정보를 넣어주세요

github 권한 요청 구글폼(링크)

  1. 폼에 넣은 정보는 플랫폼개발팀에서 수시로 확인하여 업데이트합니다. 만약 조금 더 빠르게 진행하고 싶다면 Google chat 에서 권한 요청을 해주세요

Terroir 무엇이든 물어보살 구글 챗(링크)

안녕하세요 {팀 이름} 의 {이름} 입니다.
github 권한 부탁드립니다 🙏

2. GitHub 설정 및 인증

  1. GitHub 2차 인증 설정
    GitHub에 로그인 후 게정 Setting 메뉴에서 Password and authentication 메뉴(https://github.com/settings/security )로 들어갑니다.


2. 해당 메뉴에서 2FA 항목에서 Enable two-factor authentication 버튼을 클릭합니다.


3. SMS 인증으로 진행을 합니다.
(다른 방식의 2차 인증을 적용하시려면 GitHub Authentication 참고하시기 바랍니다.)


4. 조직 GitHub 담당자가 보낸 초대 메일을 확인합니다.
(메일 제목)

(메일 내용): Join@VntgCorp 버튼 클릭 하여 가입 진행을 하시면 됩니다.
