Getting Started 4-2단계: 배포 관리 (기존 배포에서 환경 설정 변경)

Terroir 가이드 문서 (Beta) · R&D실

이미 배포된 상황에서 환경 설정 변경

운영 중인 앱의 환경변수 / 리소스 / Port 등을 변경하는 시나리오입니다.

ℹ️ 안내

💡 DB 는 이 시나리오에서 변경할 수 없습니다.
DB 계정/이름 등을 바꿔야 한다면 [가이드] DB 접근방법 (DBeaver) 를 통해 접근 후, 수동 변경 하셔야 합니다.

Step 1 — 변경 대상 앱의 환경 설정 진입

프로젝트 상세 화면에서 변경할 앱(BE 또는 FE)의 환경 설정 버튼을 클릭합니다.

Step 2 — 값 변경 + 적용

수정할 항목을 변경한 뒤 적용을 누릅니다.

  • BE: 변경값이 저장만 됩니다. 실제 적용은 다음 배포 시점에 일어납니다.

    • 즉시 변경을 원할 경우 플랫폼개발팀에 요청 해 주시면 됩니다.

    • 리소스, containerPort 변경의 경우에는 즉시 반영 됩니다.

  • FE: 적용 즉시 이미지 빌드가 트리거됩니다 (시나리오 1 Step 4 참고). 빌드 완료까지 대기해야 다음 단계 진행 가능.

Step 3 — 재배포

상단 우측의 배포 버튼을 클릭하여 재배포합니다.

  • 배포 버튼을 누르지 않더라도 일정 시간이 지난 뒤에 자동으로 반영이 됩니다.

  • 조금이라도 빨리 반영하고 싶을 경우 사용해주세요.

Step 4 — 변경 결과 확인

  • 배포 상태 Synced + Healthy

  • 변경된 환경변수가 실제 앱 동작에 반영 됐는지 (서비스 URL 호출 또는 Grafana 로그) 확인
