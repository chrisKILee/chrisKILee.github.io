pnpm

  1. 터미널에서 아래 명령어 실행

brew install pnpm

https://pnpm.io/ko/installation

nx-cli

  1. 터미널에서 아래 명령어 실행

pnpm setup
source ~/.bashrc  # 또는 ~/.zshrc

1번 방법이 안될 시 아래 실행

# 1. 전역 bin 디렉토리 설정
pnpm config set global-bin-dir ~/.local/share/pnpm

# 2. 쉘 설정 파일에 PATH 추가 (예: ~/.zshrc)
export PNPM_HOME="$HOME/.local/share/pnpm"
export PATH="$PNPM_HOME:$PATH"

# 3. 적용
source ~/.zshrc

git

  1. Git 설치

  • brew install git

  1. Git config 설정

  • 터미널에서 아래 명령어 진행

git config --global user.name "Your Name"         // Your Name에 본인 이름
git config --global user.email "you@company.com"  // you@company.com에 본인 이메일

git 공식: https://git-scm.com/install/
