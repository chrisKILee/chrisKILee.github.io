Getting Started 3단계: SDD로 개발하기

Terroir 가이드 문서 (Beta) · R&D실

SDD란?

SDD(Spec-Driven Development, 명세 기반 개발)는 코드를 직접 작성하는 대신, 자연어로 작성된 명세(Spec)를 기반으로 AI가 코드를 생성하는 개발 방법론입니다. 개발자는 코드를 리뷰하는 대신 의도(스펙)를 리뷰하며,
PRD → SPEC → PLAN → TASK → CODE 순서의 파이프라인으로 진행합니다.

ℹ️ 안내

플랫폼개발팀의 SDD가 궁금하다면? 링크

1. (필수) https://github.com/VntgCorp 에 개인 계정 등록

[가이드] Getting Started 1-1단계: 사전준비 (공통) 내용 참고

2.(https://github.com/VntgCorp 연동되어 있으면 Skip) Github의 VntgCorp 개인 계정 연동 필수

  • 터미널에서 아래 명령어 실행

    • gh auth login

      • 만약 github cli가 미설치되어있다면 해당 링크에서 설치 https://cli.github.com/

    • 본인에게 맞는 방법 선택 : HTTPS or SSH

3. Github 연동 확인

터미널에서 아래 명령어로 연결 필수
  - gh auth status 또는
  - git ls-remote https://github.com/VntgCorp/terroir-claude-plugin.git

4. terroir-claude-plugin 설치 & 실행

1. 터미널에서 claude code 실행

2. /plugin marketplace add VntgCorp/terroir-claude-plugin

3. /plugin install terroir-sdd-flow@terroir-claude-plugin

4. Install for you (user scope) 선택

5. /reload-plugins

6. /sdd-classify 실행하여 SDD을 이용한 개발을 시작하시면 됩니다.
