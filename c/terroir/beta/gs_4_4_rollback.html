Getting Started 4-4단계: 배포 관리 (롤백)

Terroir 가이드 문서 (Beta) · R&D실

배포 롤백 — 이전 버전으로 되돌리기

배포 후 문제가 발생하여 이전 배포 버전으로 되돌리는 시나리오입니다.

Step 1 — 롤백 실행

프로젝트 상세 화면 상단 우측에서 롤백 버튼을 클릭합니다. (배포 버튼 옆에 위치합니다.)

확인 다이얼로그에서 롤백 대상 앱 목록과 이전 버전 정보를 확인한 뒤, 롤백 버튼을 클릭하면 롤백이 시작됩니다.

📝 참고

⚠️ 주의

DB 는 롤백 대상이 아닙니다 — 데이터베이스 스키마나 데이터는 롤백되지 않습니다.

Step 2 — 롤백 버전 선택

롤백하려는 대상 버전을 확인합니다.

📝 참고

롤백 버전에 다른 프로젝트가 표기 될 수 있습니다.

버전에서 자신의 프로젝트가 맞는지 확인해주세요.

Step 3 — 롤백 버전 상세 확인

본문 내용을 보고 롤백 하려는 버전의 상세 내용을 확인합니다.

롤백 하려는 버전이 맞다면 다음 버튼을 클릭합니다.

Step 4 — 롤백 검토

롤백하려는 대상 버전을 검토 합니다.

맞다면 하단에 프로젝트명을 입력 후 롤백을 실행합니다.

Step 5 — 확인

롤백이 된 배포 상태를 확인합니다.

  • 롤백을 한 이후부터는 OutOfSync 상태가 됩니다.

  • 롤백이 진행중이므로 Progressing 상태입니다. 해당 버전에 문제가 없다면 곧 Healthy로 변경됩니다.

Step 6 — 버전 최신화

📝 참고

롤백을 실시한 경우, 자동으로 최신 버전으로 갱신되지 않습니다.

수동으로 배포를 하셔야 합니다.

다시 버전을 최신화 하기 위해 수동으로 배포 버튼을 클릭합니다.
