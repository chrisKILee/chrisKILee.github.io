02 SDD 이해하기

SDD가 뭔가요?

SDD(Spec-Driven Development, 명세 기반 개발)는 Terroir 개발의 핵심 방법론입니다. 코드를 직접 작성하는 대신, 자연어 명세를 먼저 작성하고 AI가 코드를 만들어줍니다.

코드를 짜는 시대에서
의도를 정의하는 시대로

PRD → SPEC → PLAN → TASK → CODE ✨

기존 방식은 개발자가 코드를 직접 작성하고, 팀원이 리뷰합니다. 빠르게 만들기 어렵고, 비개발자는 참여하기 힘들었습니다.

SDD 방식은 "무엇을 만들지"를 자연어로 명세합니다. AI(Claude Code)가 SPEC을 읽고 코드를 생성하므로, 개발자는 코드가 아닌 의도를 리뷰합니다.

💡 Terroir IDP와 SDD의 관계
Terroir IDP는 개발 플랫폼 자체로, SDD를 강제하지 않습니다.
다만 AI로 개발하고 싶다면 R&D실은 SDD 방식을 권장합니다. 막막하다면, R&D실이 Terroir와 함께 출시한 SDD 도구를 별도 설치해서 시작할 수 있습니다. 3단계 가이드에서 설치 방법과 전체 흐름을 확인하세요.
