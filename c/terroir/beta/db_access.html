DB 접근 방법 (DBeaver)

Terroir 가이드 문서 (Beta) · R&D실

CD를 통해 GKE에 배포된 자신의 서버의 DB에 접근하는 방법을 가이드 합니다.
이 문서에서는 로컬에 설치된 DBeaver를 사용합니다.

사전 준비

항목

설명

DBeaver 설치

https://dbeaver.io/download/ 에서 Community Edition 다운로드 및 설치

사내망 접속

vntg 사내망에서만 접근 가능합니다.

1. Terroir IDP에서 DB 정보 확인

Terroir IDP의 배포관리에서 자신의 프로젝트의 DB 접속 정보를 확인합니다.

2. DBeaver에서 새 연결 생성

  1. DBeaver를 실행합니다.

  2. 좌측 상단의 플러그 아이콘(🔌) 또는 메뉴 Database > New Database Connection 을 클릭합니다.

  1. PostgreSQL 을 선택하고 Next 를 클릭합니다.

3. 연결 정보 입력

1.에서 확인한 연결 정보를 입력합니다:

  • DB Host

  • DB 이름

  • User

  • Password

4. 연결 테스트 및 완료

  1. 좌측 하단의 Test Connection 버튼을 클릭합니다.

  2. "Connected" 메시지가 표시되면 정상입니다.

  1. Finish 를 클릭하여 연결을 저장합니다.

최초 연결 시 PostgreSQL JDBC 드라이버 다운로드 팝업이 뜰 수 있습니다. Download 를 클릭하여 설치합니다.

5. DB 탐색

연결이 완료되면 좌측 Database Navigator 패널에서:

  • Databases > {{project db}} > Schemas > public > Tables 경로로 테이블 목록을 확인할 수 있습니다.
