DB 운영 가이드 — Prisma 개념

Terroir 가이드 문서 (Beta) · R&D실

1. Prisma 기초

1.1 Prisma란?

TypeScript/Node.js용 ORM. SQL 대신 TypeScript로 DB를 다룰 수 있게 해줍니다.

Schema 정의  →  Migration 관리  →  TypeScript Client로 쿼리

1.2 핵심 개념

Schema — DB 구조를 정의하는 파일 (*.prisma)

model User {
  id        Int      @id @default(autoincrement())
  email     String   @unique
  createdAt DateTime @default(now())
}

Migration — schema 변경사항을 SQL 파일로 관리

이 프로젝트는 prisma migrate 체계 대신 직접 SQL 방식을 사용합니다. prisma/manual-migrations/디렉토리에 보관한다.

prisma/manual-migrations/
  20260413120000_init/
    migration.sql       ← 이 SQL을 직접 DB에 실행
  20260414090000_add_phone/
    migration.sql

_prisma_migrations 테이블은 생성되지 않습니다. 적용 이력은 Git으로 관리합니다.

Client — schema 기반으로 자동 생성되는 타입 안전한 쿼리 클라이언트

const user = await prisma.user.findMany(); // 자동 완성 + 타입 추론

1.3 주요 명령어

명령어 (예시)

용도

pnpm -F db-postgres db:migrate-diff

schema와 DB 간 차이를 SQL로 출력. SQL 초안 생성에 사용

pnpm -F db-postgres db:generate

schema 기반으로 TypeScript Client 재생성

migrate dev / migrate deploy는 사용하지 않습니다. 이 프로젝트는 SQL을 직접 실행하는 방식을 채택했습니다.

2. 이 프로젝트의 Prisma 구조

2.1 파일 위치

projects/<project-name>/
└── db-postgres/                  ← Prisma 전용 라이브러리
    └── src/api-server-db/prisma/
        ├── schema.prisma         ← DB 연결 + Client 설정 (SSoT)
        ├── app.prisma            ← 모델 정의 (여기에 테이블 작성)
        ├── libs.prisma           ← 공통 모델
        └── manual-migrations/   ← 실행한 SQL 파일 (Git 관리)
            └── <timestamp>_<name>/
                └── migration.sql

schema.prisma와 app.prisma가 분리되어 있습니다.
테이블(모델) 추가/수정은 app.prisma에 합니다.
Prisma는 같은 폴더의 *.prisma 파일을 자동으로 합쳐서 처리합니다.

schema.prisma는 SSoT(Single Source of Truth)입니다.
prisma migrate diff는 이 파일을 기준으로 현재 DB 상태와 차이를 계산합니다.
DB 변경 후에는 반드시 app.prisma를 실제 DB와 동기화된 상태로 유지합니다.
