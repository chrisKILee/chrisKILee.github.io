2. WSL2 설치

 

2.1 버전 확인

윈도우 키 → 검색 → “Windows Powershell” 실행 후 하기 명령어 기입

winver

Windows OS 버전 정보 확인

2.2 CPU 가상화 활성화

작업 관리자 → 성능 → CPU → 가상화: 사용

2.3 충돌 소프트웨어 확인

  • Hyper-V 비활성화된 구버전 Docker 있으면 제거 권장

2.4 설치 준비 (wsl 확인)

윈도우 키 → 검색 → "windows 기능 켜기/끄기" 실행 → "Linux용 Windows 하위 시스템" 기능을 활성화

적용 후 반드시 재부팅 수행

2.5 wsl 설치

윈도우 키 → 검색 → "Windows Powershell" 관리자 모드로 실행

  • 하기 명령어 순차적으로 실행 

wsl --set-default-version 2
wsl --install -d Ubuntu-24.04

이후 입력 프롬프트가 나올 때, Username 과 password에 대한 입력 실행

  • 설치 시, 아래와 같은 에러가 밸상하면 https://changun516.tistory.com/m/215 접속해서 진행

  • default 설정

exit
wsl --set-default Ubuntu-24.04

  • 하기 명령어로 설치 확인 ( 하기 스크린샷은 22.02 버전 예시임)

3.WSL2 환경 설정

 

3.1 WSL2 기본 환경 설정

프레임워크 사용을 위한 기본 환경 설정 파일을 함

도구

버전

Node.js

v22.17.0

패키지 매니저

pnpm

pnpm

v10.14.0

윈도우 키 → 검색 → “cmd” 실행 후 하기 명령어를 통해 접속

wsl

  • wsl 홈 디렉토리로 이동

    • (시작 경로가 “/mnt” 로 시작하는 경우 문제가 발생)

cd ~

  • 업데이트 및 필수 파일 설치 

sudo apt update
sudo apt install -y \
  curl \
  git \
  ca-certificates \
  build-essential

  • nvm 설치 

curl -fsSL https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
source ~/.nvm/nvm.sh

  • Node.js 설치

nvm install 22.17.0
nvm use 22.17.0
nvm alias default 22.17.0

node -v 명령어를 통해 버전 확인 가능

  • Corepack 활성화

corepack enable

  • pnpm 설치

corepack prepare pnpm@10.14.0 --activate
pnpm setup
source ~/.bashrc

pnpm -v 명령어를 통해 버전 확인 가능

  • nx-cli 설치

pnpm add -g nx

  • Git config 설정

  • 터미널에서 아래 명령어 진행

git config --global user.name "Your Name"         // Your Name에 본인 이름
git config --global user.email "you@company.com"  // you@company.com에 본인 이메일

4. VScode 설정

 

4.1. VSCode에서 WSL 디렉토리 사용

  • Vscode에서 [wsl] 검색하여 extension 설치

VSCode에서 wsl 경로에 접근하는 방법

  1. WSL 직접 열기

WSL 직접 열기

  1. VSCode 실행

Ctrl + Shift + P (명령어 팔레트 열기 )

“Connect to WSL” 입력 후 클릭

  1. 프로젝트 이동

좌측 상단 Explore 아이콘 클릭 후 “Open Folder”를 이용하여, 원하는 디렉토리로 이동하여 사용

5. Rancher Desktop 추가 설정

 

설치 후 “Rancher Desktop 실행”

  • 실행 후 좌측 하단 “Preferences” 클릭

  • WSL 클릭 후, 사용할 wsl 버전 체크 후, apply 클릭

    • apply 이후, 설정을 위해 3~5분 정도 소요될 수 있음.
