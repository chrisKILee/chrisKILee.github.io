OpenAI Codex CLI
터미널 코딩 에이전트

Codex는 OpenAI의 코딩 에이전트로, 터미널에서 대화형으로 코드를 읽고 수정하고 명령을 실행한다. ChatGPT 계정으로 로그인해 바로 쓰거나 API 키로도 동작하며, IDE·웹·데스크톱 버전과 연결된다.

공식 문서 → GitHub
01 / INSTALL

설치 & 인증

npm·Homebrew·설치 스크립트 중 택일. 설치 후 codex 한 줄로 시작한다.

bash
# npm (전역)
npm install -g @openai/codex

# Homebrew
brew install --cask codex

# 설치 스크립트 (Mac/Linux)
curl -fsSL https://chatgpt.com/codex/install.sh | sh

# 시작
codex
인증 — codex 실행 후 "Sign in with ChatGPT"가 권장 방식이며 Plus·Pro·Business·Edu·Enterprise 플랜과 통합된다. 또는 OPENAI_API_KEY 환경변수로 API 키 인증도 가능하다.
02 / MODES

대화형 vs 비대화(exec)

Codex는 터미널 UI로 대화하며 작업하거나, exec 서브명령으로 스크립트·자동화에 비대화로 끼워 넣을 수 있다.

그림 1 · codex(대화형 TUI) ↔ codex exec(비대화 자동화)
03 / FEATURES

핵심 기능

💬

대화형 TUI

codex로 터미널 UI 진입. 자연어로 작업을 지시하고 편집·명령 실행을 승인한다.

🤖

모델 전환

세션 안에서 /model로 모델 변경 및 추론 강도(reasoning) 조정.

🔌

MCP 지원

Model Context Protocol로 서드파티 도구·컨텍스트를 Codex에 연결.

🛡️

승인 모드

Codex가 파일을 편집하거나 명령을 실행하기 전, 사용자 편의 수준에 맞는 승인 모드를 선택.

🧩

IDE 통합

VS Code·Cursor·Windsurf에서 사용. 웹 버전(chatgpt.com/codex)은 클라우드 에이전트.

⚙️

설정 파일

~/.codex/config.toml로 기본 모델·승인 정책·MCP 서버 등을 구성.

04 / USAGE

실전 사용법

bash
# 대화형 세션
codex

# 작업 지시와 함께 시작
codex "refactor utils.py and add unit tests"

# 비대화 실행 (스크립트/CI)
codex exec "run the test suite and summarize failures"

# 데스크톱 앱
codex app
⚠️ 승인·샌드박스 — Codex는 파일 쓰기/명령 실행 범위를 제어하는 승인 모드와 샌드박스를 제공한다. 자동 실행 범위를 넓힐수록 편하지만 위험도 커지므로, 신뢰할 수 있는 작업에만 넓은 권한을 부여한다. 정확한 플래그/정책 값은 공식 CLI 레퍼런스를 확인하세요.
05 / CONFIG

설정 (config.toml)

전역 설정은 ~/.codex/config.toml에 둔다. 기본 모델·MCP 서버 등을 선언.

~/.codex/config.toml
# 예시 (실제 키/값은 공식 Config Reference 참조)
model = "gpt-5-codex"

# MCP 서버 등록
[mcp_servers.filesystem]
command = "npx"
args = ["-y", "@modelcontextprotocol/server-filesystem", "."]
설정 키의 전체 목록과 환경변수는 공식 문서의 Config Basics / Advanced Config / Config Reference, 그리고 MCP 페이지를 참고하세요.
