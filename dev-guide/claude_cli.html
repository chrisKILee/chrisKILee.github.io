Claude Code CLI 가이드 2026-06-14
⌘ AI CODING CLI · #1

터미널에서 코딩하는
Claude Code 완전 가이드

Claude Code는 코드베이스를 읽고, 파일을 수정하고, 명령을 실행하고, 개발 도구와 통합되는 에이전트형 코딩 도구다. 터미널·IDE·데스크톱 앱·브라우저에서 동작한다. 이 페이지는 터미널 CLI를 기준으로 설치부터 실전 활용까지 정리한다.

공식 문서 → code.claude.com
01 / INSTALL

설치 & 시작

네이티브 설치 스크립트가 권장 방법이며, 백그라운드 자동 업데이트를 지원한다. Homebrew·WinGet도 가능하다.

bash
# macOS / Linux / WSL (네이티브 설치, 권장)
curl -fsSL https://claude.ai/install.sh | bash

# Windows PowerShell
irm https://claude.ai/install.ps1 | iex

# Homebrew
brew install --cask claude-code

# WinGet
winget install Anthropic.ClaudeCode
bash
# 프로젝트로 이동해 실행 — 최초 실행 시 로그인 안내
cd your-project
claude
최초 실행 시 로그인 프롬프트가 뜬다. 대부분의 환경은 Claude 구독 또는 Anthropic Console 계정이 필요하며, 터미널 CLI와 VS Code는 서드파티 프로바이더도 지원한다.
02 / HOW IT WORKS

에이전트 루프

Claude Code는 단순 자동완성이 아니라, 코드베이스를 읽고 계획을 세우고 도구를 사용해 작업을 끝까지 수행하는 에이전트다.

그림 1 · 이해 → 계획 → 실행 → 검증의 에이전트 루프
03 / FEATURES

핵심 기능

모든 표면(터미널·IDE·데스크톱·웹)이 같은 엔진을 쓰므로 CLAUDE.md·설정·MCP 서버가 어디서든 동일하게 동작한다.

📝

CLAUDE.md 메모리

프로젝트 루트에 두면 매 세션 시작 시 읽는다. 코딩 표준·아키텍처·리뷰 체크리스트를 명시. 작업하며 자동 메모리도 축적.

⚡

스킬 (슬래시 명령)

반복 워크플로우를 패키지화. /review-pr, /deploy-staging처럼 팀이 공유.

🔌

MCP

Model Context Protocol로 Google Drive·Jira·Slack·커스텀 도구 연결.

🪝

훅 (Hooks)

액션 전후로 셸 명령 실행. 편집 후 자동 포맷, 커밋 전 린트 등.

👥

서브에이전트

여러 에이전트가 작업을 분담. 리드 에이전트가 조율·병합. 병렬 세션은 Agent View로 관찰.

⛓️

파이프 & 스크립트

Unix 철학. 로그를 파이프로 넣거나 CI에서 실행, 다른 도구와 체이닝.

04 / USAGE

실전 사용법

대화형으로 쓰거나, 헤드리스(-p)로 파이프·CI에 끼워 넣는다.

bash
# 자연어로 작업 지시
claude "write tests for the auth module, run them, and fix any failures"

# 변경사항 커밋
claude "commit my changes with a descriptive message"

# 헤드리스(-p): 로그 분석 후 Slack 알림
tail -200 app.log | claude -p "Slack me if you see any anomalies"

# 변경된 파일만 보안 리뷰
git diff main --name-only | claude -p "review these changed files for security issues"
💡 Plan 모드 먼저. 복잡한 작업은 먼저 계획을 세우게 한 뒤 실행시키면 결과 품질이 크게 오른다. 작업은 작게 쪼갤수록 좋다.
05 / IN-SESSION

세션 안에서 자주 쓰는 것들

대화 세션 안에서 입력하는 대표 명령. 전체는 공식 CLI 레퍼런스를 참고.

명령 / 동작설명
claude대화형 세션 시작
claude -p "..."헤드리스(비대화) 1회 실행 — 파이프·CI용
/schedule반복 작업(Routines) 생성
/loop세션 안에서 프롬프트를 주기적으로 반복(폴링)
/desktop현재 터미널 세션을 데스크톱 앱으로 핸드오프(시각 diff)
claude --teleport웹/iOS에서 시작한 장기 작업을 터미널로 가져오기
설정은 /settings 및 Settings 문서 참조. CI/CD는 GitHub Actions·GitLab CI/CD, 자동 PR 리뷰는 GitHub Code Review와 통합된다.
