Dev Guide · 생산성 도구

Snipaste 매뉴얼

스크린샷 · 붙여넣기 · 이미지 주석을 하나로 묶은 가벼운 화면 캡처 도구. 캡처부터 부유 윈도우 붙여넣기까지, 단축키 중심으로 정리한 사용 가이드.

난이도 · 입문 플랫폼 · Win / macOS / Linux 라이선스 · 무료 + PRO 업데이트 · 2026-06-17

개요

Snipaste(스니페이스트)는 강력하면서도 쉬운 스니핑(캡처), 페이스트(붙여넣기), 이미지 주석 기능을 제공하는 화면 캡처 유틸리티입니다. 단순한 스크린샷 도구를 넘어, 클립보드의 내용을 화면 위 최상위 부유 윈도우로 띄워 생산성을 끌어올리는 "붙여넣기" 기능이 가장 큰 차별점입니다.

✂️

Snip — 캡처

UI 요소를 자동 감지하고, 픽셀 단위로 영역·커서를 제어. 캡처 히스토리 리플레이까지 지원.

🖍️

Annotate — 주석

사각형·화살표·펜·텍스트·모자이크·블러 등으로 캡처 직후 바로 마킹.

📌

Paste — 붙여넣기

클립보드의 이미지·텍스트·색상을 화면 위 최상위 윈도우로 띄워 참고용으로 고정.

한 줄 요약 F1 로 캡처 → 바로 주석 → F3 로 클립보드를 화면 위에 핀(pin). 이 세 동작이 Snipaste의 전부이자 핵심입니다.

설치 · 플랫폼

Snipaste는 Windows · macOS · Linux 전 플랫폼을 지원합니다. 개인 사용은 무료이며, 고급 기능은 PRO 라이선스로 잠금 해제됩니다.

플랫폼지원 형태설치 방법

무료 vs PRO

구분내용
무료개인 사용. 캡처 · 주석 · 붙여넣기 핵심 기능 전부 포함
PRO스크롤(긴) 영역 보조, 텍스트 인식(OCR), 주석 재편집, 이미지 그룹·배경 모드, 단축키 완전 커스터마이징 등
참고 · 가격 가격 정책은 버전·스토어·지역에 따라 다릅니다. 정확한 금액과 비즈니스 라이선스 조건은 공식 사이트(snipaste.com) 및 PRO 안내(docs.snipaste.com/pro)에서 확인하세요.

핵심 개념 — 캡처에서 핀까지

Snipaste의 작업 흐름은 캡처 → 주석 → 출력/붙여넣기의 세 단계로 이어집니다. 캡처 직후 곧바로 주석을 달 수 있고, 결과물은 클립보드 복사·파일 저장은 물론 화면 위 부유 윈도우로 띄울 수도 있습니다.

Snip — 화면 캡처

기본 단축키 F1 또는 트레이 아이콘 클릭으로 캡처를 시작합니다. 마우스를 올리면 창·버튼 같은 UI 요소를 자동으로 감지해 영역을 잡아줍니다.

1

캡처 시작

F1 을 누르면 화면이 캡처 모드로 전환됩니다. 마우스를 움직이면 Snipaste가 윈도우/요소 경계를 자동 감지합니다.

2

감지 단위 전환

Tab 으로 "윈도우 감지 ↔ 요소(컨트롤) 감지"를 전환합니다. PRO에서는 마우스 스크롤로 부모/자식 요소 계층을 오갈 수 있습니다.

3

확정 또는 취소

영역을 정한 뒤 Enter 로 클립보드에 복사하고 종료, Esc 또는 우클릭으로 취소합니다.

Paste — 붙여넣기

Snipaste의 시그니처 기능입니다. F3 을 누르면 클립보드의 내용(이미지·텍스트·색상 등)이 화면 위 최상위 부유 윈도우로 떠오릅니다. 다른 화면을 보면서 참고 이미지를 옆에 띄워두거나, 디자인 시안을 화면에 겹쳐 픽셀을 맞추는 식으로 활용합니다.

PRO 기능

무료판으로도 핵심 캡처·주석·붙여넣기는 충분합니다. PRO는 다음과 같은 고급 워크플로우를 더합니다.

영역PRO 추가 기능
SnipSuper-snip(Win+드래그), 요소 계층 스크롤 감지, 영역 크기 직접 입력, 캡처 새로고침(F5), 취소분 포함 전체 히스토리
Paste이미지 자르기, 다중 선택(Ctrl+클릭), 그룹 관리, 배경 모드(투명/체스판), 브라우저 이미지 직접 드래그, 파일로 직접 복사
Annotate주석 재편집, 드래그 가능한 컬러 버튼, 주석별 색 기억, 확대/축소 주석
텍스트 인식OCR 텍스트 추출, QR/바코드 디코딩

주의 PRO 기능의 정확한 범위와 활성화 조건은 버전에 따라 달라질 수 있습니다. 위 목록은 공식 안내 기준이며, 도입 전 docs.snipaste.com/pro 에서 최신 내용을 확인하세요.

활용 시나리오

A

캡처 + 즉시 주석 → 공유

F1 캡처 → Space 로 페인트 바 → 화살표·텍스트로 마킹 → Ctrl+C 복사 후 채팅에 붙여넣기.

B

참고 이미지 핀 — 디자인 대조

시안을 복사한 뒤 F3 으로 화면 위에 띄우고, Ctrl+스크롤로 투명도를 낮춰 실제 구현 화면과 픽셀 단위로 겹쳐 비교.

C

색상 추출 — CSS 작업

F1 후 Alt 확대경으로 픽셀 확인 → Shift 로 Hex 전환 → C 로 색상값 복사해 스타일시트에 붙여넣기.

D

여러 컷 정렬 — 비교 작업

여러 화면을 F3 으로 동시에 띄운 뒤 Shift+드래그로 자동 정렬해 나란히 배치.

팁 · 문제 해결

단축키가 안 먹어요 hotkey conflict
다른 프로그램(게임 오버레이, 캡처 도구 등)이 F1/F3 을 선점했을 수 있습니다. 환경설정 → 단축키에서 다른 키로 재지정하세요.
요소 자동 감지가 부정확해요 UI detection
Tab 으로 윈도우/요소 감지를 전환하고, 그래도 어긋나면 드래그로 직접 영역을 그린 뒤 화살표 키로 1px씩 보정하세요.
핀한 창을 실수로 닫았어요 restore
닫기 전 Ctrl+S 로 저장하는 습관을, 또는 캡처 시 빠른 저장 폴더(Ctrl+Shift+S)를 활용하세요.
캡처에 마우스 커서가 같이 찍혀요 cursor
캡처 모드에서 ` (백틱) 으로 커서 포함/제외를 토글합니다.
