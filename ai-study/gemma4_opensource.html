Gemma 4, 오픈소스 맞아?

구글 표현으로는 "our most intelligent open models to date"입니다. 라이선스는 Apache 2.0이라고 명시했고, 모델 weights는 Hugging Face, Kaggle, Ollama에서 내려받을 수 있습니다.

Apache 2.0은 상업적 활용 제약이 적고, 온프렘(사내 서버)이든 클라우드든 원하는 환경에서 돌릴 수 있다는 의미입니다. 적어도 라이선스 기준으로는 "예"라고 답해도 무리가 없는 출시였습니다.

✦

오픈소스 vs 오픈 웨이트: "오픈소스"는 엄밀히 학습 데이터·코드까지 공개를 의미하지만, Google은 "open model"이라는 표현을 썼습니다. weights 공개 + Apache 2.0 라이선스 기준으로는 사실상 오픈소스에 준하는 수준입니다.

모델 라인업 — 4종 패밀리

Gemma 4는 "큰 모델 하나"가 아니라 하드웨어에 따라 고를 수 있는 패밀리로 출시됐습니다. 이 점이 사람들이 좋아한 핵심 이유입니다. 클라우드 데모가 아니라 실제 배포 단위로 생각할 수 있으니까요.

모델 타입 컨텍스트 타깃 환경 특이사항
E2B Efficient 128K 모바일, Edge 오디오 입력 지원

26B MoE MoE 256K 로컬 PC, 워크스테이션 Mixture of Experts 구조

MoE(Mixture of Experts)란? 입력마다 전체 파라미터 중 일부만 활성화하는 구조입니다. 전체 파라미터 수는 크지만 실제 연산량은 적어 속도와 효율이 높습니다.

핵심 기능 4가지

Gemma 4가 "또 하나의 오픈 모델"과 다른 이유는 기능 조합에 있습니다. 에지 디바이스부터 에이전트 코딩까지 한 번에 커버합니다.

📱

모바일 · 온디바이스

E2B·E4B는 RAM과 배터리를 아끼는 방향으로 설계됐습니다. 폰, Raspberry Pi, Jetson Orin Nano 같은 edge 디바이스에서 오프라인으로 거의 지연 없이 실행됩니다.

🤖

에이전트 워크플로

function calling, structured JSON output, native system instructions가 기본 탑재됐습니다. 도구 호출·JSON 응답·시스템 지시를 붙여 에이전트처럼 굴리기 쉬운 구조입니다.

💻

로컬 코딩 어시스턴트

high-quality offline code 지원을 명시했습니다. 최대 256K 컨텍스트로 레포 하나 또는 긴 문서를 한 번에 넣고 처리할 수 있습니다.

🖼️

멀티모달

전 모델이 이미지·비디오 처리를 기본 지원하고, E2B·E4B는 오디오 입력도 받습니다. OCR, 차트 이해 같은 시각 작업도 강조했습니다.

에코시스템 — 첫날부터 넓게

Gemma 4는 익숙한 도구를 첫날부터 지원한다고 밝혔습니다. 새 도구를 배울 필요 없이 이미 써온 스택 위에 얹힌다는 뜻입니다.

🤗 Hugging Face ⚡ vLLM 🦙 llama.cpp 🦙 Ollama 🍎 MLX 🟢 NVIDIA NIM 📦 Kaggle

Gemma 첫 세대 이후 4억 회 이상 다운로드, 파생 모델 10만 개 이상 생성됐습니다. Gemma 4는 이 생태계 위에 얹히는 후속 모델입니다. 혼자 던져놓고 끝나는 모델이 아니라, 이미 형성된 커뮤니티가 있다는 점이 다릅니다.

💡

Ollama로 로컬 실행 예시: ollama run gemma4:27b 형태로 실행 가능합니다 (정확한 태그명은 Ollama 라이브러리 확인 필요).

🎯

결론 — 맥미니 사도 되나?

질문의 핵심은 "로컬에서 쓸 만한 오픈 모델이 생겼냐"입니다. Gemma 4 기준으로는 26B MoE 또는 31B Dense 모델이 로컬 PC·워크스테이션 타깃으로 명시됐고, 256K 컨텍스트에 코딩·에이전트 기능까지 붙었습니다.

✅

살 이유가 생긴 경우

로컬 AI 코딩 어시스턴트가 목적이라면, 26B/31B 모델이 맥미니(M4 Pro 기준)에서 충분히 돌아갑니다. 오프라인, 프라이버시, API 비용 없음이 이점입니다.

⚠️

살 이유가 아직 없는 경우

단순 챗봇 용도라면 Claude나 GPT-4o API가 여전히 품질이 높습니다. 맥미니 투자 대비 ROI는 사용 패턴에 따라 크게 달라집니다.

Gemma 4는 라이선스(Apache 2.0), 모델 크기(E2B~31B), 기능(에이전트·멀티모달·긴 컨텍스트), 생태계(Ollama·HuggingFace 첫날 지원)의 조합이 가장 큰 강점입니다. "오픈소스냐"는 라이선스 기준으로 예스(Apache 2.0), 엄밀한 정의로는 오픈 웨이트입니다.
