설치 가이드

Python 3.11 이상이 설치된 환경이면 5단계로 실행할 수 있습니다.

1
저장소 다운로드
GitHub 페이지에서 Code → Download ZIP 후 압축 해제. 또는 git 명령어 사용.
bash 
git clone https://github.com/sodam-ai/ai-news-radar.git
cd ai-news-radar
2
패키지 설치
의존성 패키지를 한 번에 설치합니다.
bash 
pip install -r requirements.txt
3
무료 API 키 발급
아래 두 곳 중 하나(또는 둘 다) 무료 키를 발급합니다. 카드 등록 불필요.
Google Gemini
aistudio.google.com/apikey
무료 1,000회/일
Groq
console.groq.com/keys
무료 14,400회/일
4
.env 파일 설정
.env.example을 복사해서 .env로 이름 변경 후 API 키를 입력합니다. API 키는 로컬에만 저장되며 GitHub에 올라가지 않습니다.
.env 
GEMINI_API_KEY=여기에_발급받은_키_입력
GROQ_API_KEY=여기에_발급받은_키_입력
5
앱 실행
웹 모드(브라우저)와 데스크탑 앱 모드 중 선택합니다.
bash 
# 웹 모드 (기본, 브라우저에서 열림)
streamlit run app.py

# 데스크탑 앱 모드
python desktop.py

# 포트 충돌 시
streamlit run app.py --server.port 7777

자주 발생하는 문제

python 명령어가 작동 안 해요
Python 재설치 시 "Add Python to PATH" 체크 필수
API 키 경고가 뜨는데요
.env 파일이 없거나 키가 입력 안 됐을 때. .env.example 복사 후 키 입력
뉴스가 나타나지 않아요
"Collect" 버튼 클릭 후 약 1분 대기 필요
포트 6601 충돌 오류
streamlit run app.py --server.port 7777
AI 기능이 작동 안 해요
.env 파일 존재 여부 및 유효한 API 키 확인

보안 & 개인정보

API 키는 로컬에만 저장
.env 파일은 .gitignore에 포함되어 GitHub에 업로드되지 않습니다. 각 사용자가 자신의 키를 직접 관리합니다.
외부 연결 최소화
RSS 피드와 선택한 AI API에만 연결됩니다. 사용자 데이터를 별도 서버로 전송하지 않습니다.
