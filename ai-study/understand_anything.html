Understand Anything은 어떤 코드베이스든 함수·파일·의존성이 노드로 연결된 대화형 지식 그래프로 바꿔줍니다. 노드를 클릭하면 "이게 무슨 일을 하는지" 쉬운 말로 풀어주고, 자연어로 질문할 수도 있습니다. Claude Code·Cursor·Codex·Gemini CLI에서 그대로 동작합니다.

🕸️ 인터랙티브 지식 그래프 🔍 자연어 질문 · 의미 검색 🧩 Claude Code 플러그인
⭐ GitHub 저장소 공식 사이트 →
01 The Problem

코드는 쌓이는데, 설명해줄 사람은 없습니다

Claude Code나 Cursor로 개발을 몰라도 직접 앱을 만드는 시대. 그런데 막상 그 코드가 어떻게 연결돼 있는지는 아무도 모릅니다. 온보딩에 몇 주가 걸리고, 한 줄을 바꾸면 어디가 깨질지 불안합니다.

핵심 아이디어
"Graphs that teach > graphs that impress" — 보기 좋은 그래프가 아니라, 가르쳐 주는 그래프를 지향합니다. 구조를 그리는 데서 멈추지 않고 각 노드가 무슨 일을 하는지 설명합니다.
02 How it works

스캔 → 매핑 → 설명, 세 단계

코드베이스를 입력하면 스캔으로 파일을 훑고, 함수·클래스·의존성을 그래프로 매핑한 뒤, 각 노드를 쉬운 말로 설명하는 가이드 투어까지 만들어 줍니다.

03 Features

무엇을 할 수 있나

그래프 탐색에서 끝나지 않습니다. 자연어 질문, 의미 기반 검색, 변경 영향 분석, 업무 흐름 단위 정리까지 슬래시 명령어로 제공합니다.

🕸️
인터랙티브 그래프 대시보드

파일·함수·클래스가 노드, 의존성이 엣지. 확대·이동하며 클릭하면 코드와 요약을 함께 봅니다.

/understand-dashboard
💬
자연어로 질문

"결제는 어디서 처리돼?" 같은 질문을 그래프 컨텍스트 위에서 자연어로 묻고 답을 받습니다.

/understand-chat
🧭
가이드 투어 · 온보딩

의존성 순서로 정렬된 학습 경로를 자동 생성. 신규 합류자가 코드를 따라 읽기 좋습니다.

/understand-onboard
🔀
변경 영향 분석 (Diff)

한 곳을 바꾸면 무엇이 영향받는지(downstream)를 시각화해 리팩토링 위험을 줄입니다.

/understand-diff
🗂️
업무 흐름(도메인) 뷰

로그인·결제·회원 관리처럼 실제 업무 단위로 코드를 묶어 보여줍니다. 비개발자 설명에 유용.

/understand-domain
📖
지식베이스 · 설명 생성

Karpathy LLM-Wiki 형식의 문서·개념 관계를 추출하고, 선택한 부분을 설명으로 풀어 줍니다.

/understand-explain · /understand-knowledge
04 Commands

슬래시 명령어

설치 후 AI 코딩 도구에서 아래 명령어로 바로 사용합니다. (명령어 목록은 실제 플러그인 기준)

명령어설명

/understand-diff변경 사항의 영향 범위(downstream)를 분석
/understand-domain코드를 업무 흐름(도메인) 단위로 묶어 보기

/understand-knowledge문서·위키 기반 지식베이스 분석

사전 확인
Claude Code가 설치돼 있어야 합니다. 아래는 공식 README 기준 설치 방법으로, 버전에 따라 변동될 수 있으니 저장소에서 최신 안내를 확인하세요.
1

claude code 
# 마켓플레이스 등록

/plugin install understand-anything
