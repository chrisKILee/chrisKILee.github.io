RTK(Rust Token Killer)는 AI 에이전트와 CLI 도구 사이에 앉아 출력을 필터링·압축해 LLM이 소비하는 토큰을 최대 90% 줄여주는 오픈소스 Rust 프록시입니다.

⭐ 31.2k GitHub Stars 🦀 Rust 구현 📜 MIT License 🔖 v0.37.2 🤖 Claude Code / Cursor / Gemini 지원
01 문제 정의

CLI 출력이 토큰을 낭비한다

AI 에이전트가 cargo test, git diff, npm install 같은 명령어를 실행할 때 raw 출력을 그대로 LLM에 넘깁니다. 이 출력에는 타임스탬프, ANSI 컬러 코드, 중복 경고, 불필요한 진행 표시줄 등 LLM이 실제로 필요로 하지 않는 노이즈가 가득합니다.

02 아키텍처

CLI 프록시 구조

RTK는 OS 셸과 LLM 에이전트 사이에 투명하게 삽입됩니다. 에이전트는 평소처럼 명령을 실행하고, RTK가 출력을 조용히 정제합니다.

05 설치 가이드

5분 안에 시작하기

RTK는 바이너리 하나로 동작합니다. 별도의 런타임이나 의존성이 필요 없습니다.

사전 요구사항
macOS, Linux, Windows(WSL2) 환경 지원. Rust 설치 불필요 — 미리 빌드된 바이너리 제공.
1
RTK 설치
원하는 방법으로 설치합니다. curl 스크립트가 가장 빠릅니다.
bash · curl 설치 
curl -fsSL https://rtk.sh | sh
bash · Homebrew (macOS) 
brew install rtk-ai/tap/rtk
2
설치 확인
설치 후 버전을 확인합니다.
bash 
rtk --version
# rtk 0.37.2
3
Claude Code와 통합
프로젝트 루트의 CLAUDE.md에 RTK 래퍼 설정을 추가합니다.
markdown · CLAUDE.md 
# RTK 설정
모든 CLI 명령은 rtk를 통해 실행하세요.
예: rtk cargo test, rtk git diff, rtk npm install
4
RTK로 명령 실행
기존 명령 앞에 rtk를 붙이기만 하면 됩니다. 출력이 자동으로 필터링됩니다.
bash 
# 기존 방식
cargo test

# RTK 적용 (4,823 → 11 토큰)
rtk cargo test

# git diff
rtk git diff HEAD~1

# npm
rtk npm install
5
전역 별칭으로 자동 적용 (선택)
셸 설정에 별칭을 추가하면 기존 명령을 바꾸지 않아도 RTK가 자동 적용됩니다.
bash · ~/.zshrc 또는 ~/.bashrc 
alias cargo='rtk cargo'
alias git='rtk git'
alias npm='rtk npm'
alias pytest='rtk pytest'
팁
별칭 방식은 기존 스크립트를 수정하지 않아도 RTK 효과를 누릴 수 있습니다. 단, 일부 스크립트에서 예상치 못한 동작이 발생할 수 있으므로 먼저 테스트하세요.
06 주요 기능

RTK가 처리하는 노이즈

RTK는 LLM에 불필요한 여섯 가지 유형의 출력 노이즈를 자동으로 제거합니다.

🎨
ANSI 컬러 코드 제거

터미널 색상 표시용 이스케이프 시퀀스(\e[31m 등)는 LLM에게 무의미한 노이즈입니다. RTK가 모두 제거합니다.

Output Cleaning
📦
중복 줄 압축

cargo test나 pytest의 반복되는 "." 진행 표시, 동일한 경고 메시지 반복을 단일 요약으로 압축합니다.

Deduplication
🚫
무관 섹션 필터링

npm install의 패키지 다운로드 진행 바, git의 remote 연결 메시지 등 결과와 무관한 섹션을 삭제합니다.

Section Filter
⏱️
타임스탬프 정규화

로그의 타임스탬프를 제거하거나 정규화해 LLM이 실제 메시지 내용에 집중하도록 합니다.

Normalization
🔇
경고 중복 억제

동일한 deprecation warning이 수십 번 반복되는 경우 첫 번째만 남기고 "N회 더 발생" 요약으로 대체합니다.

Warning Dedup
⚡
제로 지연 (인-프로세스)

Rust로 구현된 인-프로세스 필터링으로 네트워크 왕복 없이 처리합니다. 체감 지연 없음.

Performance
07 주의사항

알아두어야 할 제한

인터랙티브 명령에는 사용 불가
vim, top, htop 같이 TTY 제어가 필요한 인터랙티브 명령에는 RTK를 사용하지 마세요. 출력이 손상될 수 있습니다.
필터링 규칙 오탐 가능성
RTK의 필터링 규칙이 드물게 중요한 출력을 제거할 수 있습니다. 중요한 작업 전에는 RTK 없이 실행해 비교 확인하세요.
커스텀 필터 규칙 지원
~/.config/rtk/rules.toml에 커스텀 필터 규칙을 추가할 수 있습니다. 팀별로 맞춤화된 필터링이 가능합니다.
