Agentation이란 무엇인가?

탄생 배경 — 디자이너 개발자의 문제 인식

디자이너 출신 개발자 Benji Taylor가 AI 에이전트와 협업하면서 겪은 문제에서 출발합니다. "이 버튼 색을 바꿔줘"라고 해도 에이전트는 어떤 버튼인지 모릅니다. 스크린샷을 보내도 정확한 DOM 위치를 알기 어렵습니다. Agentation은 클릭 한 번으로 UI 요소를 어노테이션하고, 에이전트에게 CSS 셀렉터·좌표·컴포넌트 정보를 정확히 전달하는 인터페이스입니다.

시각적 어노테이션 CSS 셀렉터 자동 추출 Vibe Coding

핵심 작동 방식

React 앱에 단 하나의 컴포넌트 <Agentation />를 추가하면 됩니다. 개발 모드에서 UI 위에 오버레이가 생기고, 원하는 요소를 클릭하면 어노테이션이 생성됩니다. 어노테이션에는 요소 설명(텍스트), CSS 셀렉터, 화면 위치(x, y, width, height) 가 포함됩니다. v1은 클립보드 복사 방식, v2는 MCP 서버를 통해 에이전트가 실시간으로 어노테이션을 읽습니다.

MCP 통합 실시간 양방향
v1

수동 복사 모드

  1. 앱에 <Agentation /> 추가
  2. UI 요소 클릭 → 어노테이션 생성
  3. 설명 텍스트 입력
  4. 클립보드 복사 버튼 클릭
  5. 에이전트 채팅창에 붙여넣기
v2

MCP 실시간 모드

  1. agentation-mcp 서버 설치
  2. Claude Code에 MCP 서버 연결
  3. UI 요소 클릭 → 어노테이션 생성
  4. 에이전트가 MCP로 자동 감지
  5. Hands-Free Mode로 자동 루프 실행

v1 → v2 진화: 설치 & 활용 단계

1
기본 컴포넌트 설치 (v1 시작점)
React 프로젝트에 패키지 설치 후 개발 모드에서만 렌더링합니다.
# 패키지 설치
npm install agentation

# Next.js / React 컴포넌트에 추가
import Agentation from 'agentation'

// 개발 모드에서만 렌더링 (필수!)
{process.env.NODE_ENV === 'development' && <Agentation />}
npm install 개발 전용 렌더링
2
v1 사용: 클릭 → 어노테이션 → 복사 → 붙여넣기
브라우저에서 UI 요소 클릭 → 설명 작성 → "Copy" 버튼 → 에이전트 채팅에 붙여넣기. 에이전트는 어노테이션 JSON(셀렉터 + 좌표 + 설명)을 받아 작업합니다.
수동 복사
3
v2 MCP 서버 설치 — 에이전트에 연결
agentation-mcp 서버를 Claude Code에 연결하면 에이전트가 실시간으로 어노테이션을 읽고 쓸 수 있습니다.
# MCP 서버 패키지 설치
npm install agentation-mcp

# Claude Code에 MCP 서버 추가 (한 번만)
npx add-mcp "npx -y agentation-mcp server"
MCP 도구 목록: fetch_annotations · acknowledge · ask_followup · resolve · dismiss
4
Hands-Free Mode — 완전 자동 루프
MCP watch 모드를 활성화하면 에이전트가 새 어노테이션을 자동 감지하고, 변경 → 확인 → 피드백 수집 → 재수정 사이클을 완전 자동으로 반복합니다. 사용자는 화면을 보며 클릭만 하면 됩니다.
완전 자동화 Hands-Free

MCP 도구 상세 (v2)

도구명 역할 사용 시점
fetch_annotations 현재 어노테이션 목록 조회 에이전트가 작업 시작 시
acknowledge 어노테이션 수신 확인 작업 시작 전 확인 신호
ask_followup 추가 정보 요청 어노테이션이 불명확할 때
resolve 작업 완료 처리 변경 적용 후
dismiss 어노테이션 무시/삭제 불필요한 어노테이션 정리

왜 지금 주목받는가

🎨

Vibe Coding 시대의 인터페이스 문제

자연어만으로 UI를 지시하는 데는 한계가 있습니다. "왼쪽 상단 파란 버튼"은 모호하지만, CSS 셀렉터 #header .btn-primary는 정확합니다. Agentation은 이 갭을 메웁니다.

🔗

MCP 생태계와의 완벽한 시너지

Model Context Protocol(MCP)이 AI 에이전트 도구 생태계의 표준이 되면서, Agentation v2는 Claude Code, Cursor 등 MCP 지원 에이전트와 바로 연동됩니다. 브라우저 ↔ 에이전트 간 실시간 채널이 열립니다.

♾️

Hands-Free 자동 루프의 가능성

디자이너가 화면을 보며 클릭하면, 에이전트는 자동으로 코드를 수정하고 결과를 화면에 반영합니다. 사람이 시각적 판단을 하고, AI가 구현을 맡는 이상적인 분업이 가능해집니다.

⚠️

개발 환경 전용 — 프로덕션 노출 주의

반드시 process.env.NODE_ENV === 'development' 조건으로 렌더링을 제한하세요. Agentation 컴포넌트가 프로덕션에 노출되면 사용자에게 오버레이 UI가 보입니다. Next.js에서는 환경 변수 기반 조건부 렌더링이 자동으로 트리 쉐이킹을 적용해 번들에서도 제거됩니다.
