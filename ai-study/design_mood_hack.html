문제 정의 무드 해킹이란 실전 방법 프롬프트 참조 사이트 템플릿화 고급 팁
😩

왜 Claude Code로 만든 UI는 항상 비슷할까?

Claude Code에게 "대시보드 만들어줘"라고 하면 어김없이 나오는 디자인이 있다. 어두운 배경, 보라/청록 그라디언트, 카드 그리드, 둥근 모서리… 기능적으로는 멀쩡하지만 분위기가 항상 같다.

이유는 단순하다. Claude는 "좋은 디자인"의 평균값을 학습했기 때문에 프롬프트에 스타일 제약이 없으면 항상 그 평균으로 수렴한다. 이것을 디자인 중력(Design Gravity)이라 부른다.

🎯

평균값 수렴

제약 없는 프롬프트는 항상 학습 데이터의 평균 스타일로 수렴한다.

🔁

피드백 루프 없음

"좀 더 세련되게" 같은 주관적 피드백은 Claude가 해석할 기준이 없다.

🧱

컨텍스트 부족

원하는 디자인의 실제 코드나 수치가 없으면 레퍼런스를 만들 수 없다.

💡

무드 해킹이란?

디자인 무드 해킹(Design Mood Hacking)은 내가 좋아하는 사이트의 디자인 DNA — 색상 팔레트, 타이포그래피, 여백 패턴, 컴포넌트 스타일 — 를 체계적으로 추출해서 내 프로젝트에 이식하는 기법이다.

✦

핵심 아이디어: Claude Code에게 "이 사이트처럼 만들어줘"가 아니라, 그 사이트의 CSS 수치를 직접 분석시켜서 시스템으로 만들어 달라고 요청하는 것. 주관적 형용사 대신 객관적 숫자로 소통한다.

구분 기존 방식 무드 해킹
지시 방식 "세련되게 만들어줘" 모호 참조 URL + CSS 분석 요청 구체적
색상 Claude 기본 팔레트 참조 사이트 실제 hex 코드
타이포 Inter / sans-serif 참조 사이트 font-family + weight
여백 암묵적 판단 참조 사이트 padding/gap 수치
반복성 매번 비슷 낮음 설계서 기반 일관성 높음
⚡

실전 3단계 워크플로우

1

레퍼런스 수집 — 내가 원하는 분위기의 사이트 3~5개

눈에 꽂히는 사이트 URL을 모은다. 디자인 커뮤니티(Dribbble, Awwwards, Godly)나 평소 좋아하던 SaaS 사이트면 된다. 완전히 같은 스타일이 아니어도 괜찮다. 색상이 마음에 드는 것, 레이아웃이 마음에 드는 것, 타이포가 마음에 드는 것 을 각각 따로 골라도 좋다.

2

Claude Code로 CSS 분석 → 디자인 토큰 추출

레퍼런스 사이트 URL을 Claude Code에 주고 CSS를 분석하게 한다. 목표는 디자인 토큰 파일 하나를 만드는 것. 색상 변수, 폰트 스택, spacing scale, border-radius 패턴을 숫자로 추출한다.

3

토큰 파일을 기반으로 내 페이지 생성

추출한 디자인 토큰을 컨텍스트로 고정한 뒤 페이지를 생성 요청한다. Claude는 이제 "세련되게"가 무엇인지 수치로 알기 때문에 훨씬 원하는 방향에 가깝게 만들어준다.

📝

실전 프롬프트 예시

아래 프롬프트를 Claude Code에 그대로 복사해서 사용해도 된다.

① 디자인 토큰 추출
Claude Code 프롬프트 
아래 URL 사이트의 CSS를 분석해서 디자인 시스템 토큰을 추출해줘.
WebFetch로 가져온 뒤 다음 항목을 마크다운으로 정리해줘:

1. 배경색 & 표면색 (hex 코드)
2. 텍스트 색상 계층 (primary / muted / disabled)
3. 강조색 (accent / brand color)
4. 폰트 패밀리 & 웨이트
5. font-size 스케일 (px 단위)
6. 주요 border-radius 값
7. 주요 padding/gap spacing 값
8. 그림자 (box-shadow) 패턴
9. 트랜지션 패턴 (duration + easing)

URL: [참조할 사이트 URL]

결과는 CSS :root 변수 블록 형태로도 함께 출력해줘.
② 토큰 기반 페이지 생성
Claude Code 프롬프트 
아래 디자인 토큰을 기반으로 [페이지 설명] HTML 페이지를 만들어줘.

[디자인 토큰 — 위에서 추출한 내용 붙여넣기]

:root {
  --bg: #0f0f13;
  --surface: #18181c;
  --text: #f4f4f6;
  --text-muted: #888898;
  --accent: #6366f1;
  --radius: 12px;
  --font: 'Inter', sans-serif;
  /* ... */
}

규칙:
- 이 토큰 외의 색상은 절대 추가하지 말 것
- 인라인 스타일 금지, 모두 CSS 변수로
- 폰트는 위 스택만 사용
- 여백은 위 spacing scale 기반으로
💡

핵심 규칙: "이 토큰 외의 색상은 절대 추가하지 말 것"이 없으면 Claude가 슬금슬금 자기 취향을 섞기 시작한다. 제약을 명시적으로 걸어야 한다.

③ 여러 사이트 무드 믹싱
Claude Code 프롬프트 
세 가지 사이트의 디자인 요소를 다음과 같이 조합해서 디자인 토큰을 만들어줘:

색상 팔레트: [사이트 A URL] 에서
타이포그래피: [사이트 B URL] 에서
컴포넌트 스타일 (카드, 버튼): [사이트 C URL] 에서

각 사이트에서 해당 요소만 WebFetch로 분석하고,
충돌하는 부분은 A > B > C 우선순위로 결정해줘.
최종 :root 토큰 블록으로 통합해서 출력해줘.
🌐

분위기별 참조 사이트 목록

무드 해킹에 좋은 레퍼런스 사이트들. 목적에 맞게 골라 쓰자.

Linear
다크 + 미니멀 + 프로덕티비티 도구 느낌의 최고봉
다크 미니멀 도구
Vercel
흑백 대비 + 강한 타이포그래피 + 개발자 감성
모노크롬 개발자 타이포
Stripe
보라 그라디언트 + 정교한 그림자 + 신뢰감
그라디언트 신뢰 B2B
Notion
크림 배경 + Georgia 폰트 + 문서 편집기 느낌
라이트 문서 따뜻함
Raycast
투명 레이어 + 블러 효과 + 앱 런처 감성
글래스 macOS 블러
Craft
오프화이트 배경 + 섬세한 그림자 + 콘텐츠 집중
오프화이트 에디터 고급
Framer
다크 + 형광 강조색 + 노코드 툴 에너지
다크 형광 에너지
Loom
보라+핑크 그라디언트 + 친근함 + 비디오 도구
컬러풀 친근 B2C
⚠️

디자인 무드를 참조하는 것과 디자인을 복제하는 것은 다르다. 색상·폰트·여백 패턴은 참조해도 되지만, 아이콘·일러스트·실제 컴포넌트 코드 그대로를 가져오는 건 저작권 문제가 될 수 있다.

🗃️

추출한 무드를 템플릿으로 저장하는 법

한 번 좋은 디자인 토큰을 추출했다면, 재사용 가능한 HTML 템플릿으로 저장해두는 게 핵심이다. Claude Code의 /add-new-page 스킬처럼 템플릿 시스템을 만들어두면 다음 페이지부터는 바로 그 분위기로 시작할 수 있다.

A

DESIGN_SYSTEM.md 파일 만들기

추출한 디자인 토큰을 마크다운 파일로 저장한다. Claude Code 대화 시작 시 이 파일을 컨텍스트로 주입하면 항상 같은 분위기로 생성이 시작된다.

DESIGN_SYSTEM.md 예시
# My Design System (Linear 무드 기반)

## Colors
- Background: #0f0f13
- Surface:    #18181c
- Accent:     #6366f1 (Indigo)
- Text:       #f4f4f6
- Muted:      #888898

## Typography
- Font: Inter, -apple-system
- Scale: 12 / 13 / 14 / 16 / 20 / 24 / 32px

## Spacing
- Gap: 8 / 12 / 16 / 24 / 32 / 48px

## Components
- Border radius: 8px (small), 12px (card), 20px (pill)
- Shadow: 0 1px 3px rgba(0,0,0,0.4)
- Transition: 150ms ease
B

base-template.html 파일 만들기

CSS :root 변수, 기본 리셋, 공통 컴포넌트(카드, 버튼, 코드블럭)를 포함한 빈 HTML 파일을 템플릿으로 저장한다. 새 페이지 요청 시 이 파일을 기반으로 콘텐츠만 채우도록 지시한다.

C

Claude Code 스킬에 등록

~/.claude/skills/add-new-page/templates/ 에 my-mood.html처럼 저장하면 /add-new-page 스킬의 템플릿 목록에 추가된다. 이후 "my-mood 템플릿으로 만들어줘"라고 하면 바로 사용 가능.

🎯

고급 팁 & 흔한 실수

🎨

색상은 5개 이하로

토큰에 색상이 많을수록 Claude가 멋대로 조합한다. bg / surface / text / accent / border 5개면 충분하다.

📐

spacing scale 고정

8의 배수로 고정하자. 8 / 16 / 24 / 32 / 48 / 64. 이 외의 값은 쓰지 말라고 명시하면 여백이 일관해진다.

🔤

폰트는 Google Fonts CDN

로컬 폰트 참조는 배포 후 깨질 수 있다. Google Fonts CDN 링크를 명시적으로 지정해줘야 안정적이다.

🚫

"더 예쁘게" 금지

주관적 형용사는 쓰지 않는다. 대신 "카드 그림자를 0 4px 16px rgba(0,0,0,0.3)으로 바꿔줘"처럼 수치로 말한다.

💾

토큰 파일 먼저 확정

페이지 생성 전에 디자인 토큰을 먼저 확정하고 파일로 저장한다. 생성 중간에 바꾸면 일관성이 깨진다.

🔍

브라우저 DevTools 활용

참조 사이트에서 F12 → Computed 탭으로 실제 픽셀값을 직접 복사해서 Claude에게 주면 더 정확하다.

✦

최종 꿀팁: DESIGN_SYSTEM.md를 프로젝트 루트에 두고 CLAUDE.md에 "모든 UI 작업은 DESIGN_SYSTEM.md를 기반으로 할 것"을 추가하면 매번 프롬프트에 토큰을 붙여넣지 않아도 자동으로 적용된다.
