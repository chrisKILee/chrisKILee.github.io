🎯 왜 만들었나
기존 Diff 뷰어(Difftastic, Delta)는 단순 렌더링에 집중합니다. Hunk는 AI 에이전트가 단 주석을 코드 옆에 직접 표시하고, 에이전트가 CLI로 Hunk UI를 제어할 수 있는 양방향 구조를 제공합니다.
02 주요 기능

리뷰에 필요한 것만, 제대로

단순한 Diff 렌더링을 넘어 에이전트 협업 코드리뷰 워크플로우 전체를 터미널에서 처리합니다.

📂
멀티파일 인터랙티브 리뷰

사이드바 네비게이션으로 여러 파일 변경사항을 동시에 탐색. 파일별 추가/삭제 라인 수와 AI 주석 개수를 한눈에 확인.

💬
인라인 AI 주석

에이전트가 분석한 코드 리뷰 주석을 변경된 코드 바로 옆에 표시. 컨텍스트를 잃지 않고 피드백을 확인.

📐
반응형 레이아웃

Split(좌우 분할) / Stack(수직) / Auto 모드를 지원. 터미널 크기에 따라 자동 전환되어 좁은 화면에서도 동작.

👁️
Watch 모드

파일 또는 Git 저장소 변경사항을 실시간 감지하여 자동 리로드. AI 에이전트가 코드를 수정하면 즉시 반영.

🖱️
마우스 + 키보드 지원

클릭·스크롤 마우스 지원과 키보드 단축키를 모두 지원. Pager 모드로 파이프 입력도 처리.

🔗
Git 통합

git diff / git show 명령어를 그대로 Hunk에서 실행. Git difftool 또는 pager로 설정하면 기본 도구로 동작.

04 아키텍처

에이전트와 Hunk가 대화하는 방식

Session Broker Daemon이 에이전트와 Hunk UI 사이를 중계합니다. TUI 자동화 없이 CLI 명령으로 안전하게 제어.

05 설치 & 사용법

5분 안에 시작하기

1

설치

Node.js 18 이상 필요. npm으로 전역 설치합니다.

bash
npm i -g hunkdiff
2

기본 사용

Git 저장소에서 바로 실행합니다.

bash
# 현재 작업 변경사항 hunk diff # 최신 커밋 hunk show # 특정 커밋 hunk show HEAD~1 # 파일 간 직접 비교 hunk diff before.ts after.ts # stdin (파이프) git diff | hunk patch - # Watch 모드 (자동 리로드) hunk diff --watch

06 AI 에이전트 연동

Claude Code / Cursor와 함께 쓰기

에이전트가 코드를 작성하는 동안, Hunk는 변경사항을 실시간으로 시각화하고 주석을 인라인으로 표시합니다.

🔄 작동 원리
에이전트는 Sidecar JSON 형식으로 리뷰 주석을 생성하고, hunk session comment apply로 Hunk UI에 전달합니다. TUI를 직접 조작하지 않고 CLI 명령만 사용하므로 안정적입니다.
연동 플로우
# 1. Hunk 시작 (터미널 A) hunk diff --watch # 2. 에이전트에게 지시 (Claude Code 등) "Load the Hunk review skill and review the current diff" # 3. 에이전트가 실행하는 명령들 hunk session review --repo . --json # 변경사항 구조 파악 hunk session navigate --file src/App.tsx # 특정 파일로 이동 hunk session navigate --hunk 2 # 특정 hunk로 이동 # 4. 배치 주석 적용 (JSON stdin) echo '{ "files": [{ "path": "src/App.tsx", "hunks": [{"number": 1, "comment": "useCallback 고려해보세요"}] }] }' | hunk session comment apply --stdin
💡 Session Broker Daemon
여러 Hunk 세션을 동시에 열고 있다면 hunk daemon serve로 데몬을 실행하세요. 에이전트가 --repo <path>로 올바른 세션을 자동으로 선택합니다. 로컬 루프백만 지원하여 외부 노출 없이 안전합니다.
