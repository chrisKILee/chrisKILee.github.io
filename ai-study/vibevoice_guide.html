핵심 기술

비밀은 7.5Hz 토크나이저

초당 7.5프레임만으로 음성을 압축하는 연속 음성 토크나이저(Continuous Speech Tokenizer)가 핵심입니다. 일반적인 TTS가 초당 수백 프레임을 처리하는 것과 대조됩니다.

⚡
7.5Hz의 의미
초당 7.5프레임으로 음성을 표현합니다. 일반 오디오가 초당 수백~수천 프레임인 것에 비해 극단적으로 압축된 표현 방식입니다. 덕분에 긴 오디오도 LLM 컨텍스트 안에 담을 수 있습니다.
🧠
LLM + Diffusion 조합
LLM이 대화의 문맥과 흐름을 이해하고, Diffusion Heads가 실제 음성의 음향적 세부사항을 생성합니다. 이 두 구조의 조합이 자연스러운 억양과 화자 구분을 가능하게 합니다.
📏
Whisper와의 차이
Whisper는 30초 슬라이딩 윈도우로 긴 오디오를 잘게 잘라서 처리합니다. VibeVoice-ASR은 60분을 단일 패스로 처리해 화자 맥락이 끊기지 않습니다.

사용 방법

설치 및 실행 가이드

ASR 모델 기준. TTS는 현재 오용 방지를 위해 공식 코드가 비공개 상태입니다.

⚠️
TTS 코드 비공개 안내
VibeVoice-TTS는 딥페이크·허위정보 생성 위험을 고려해 공식 설치 가이드 및 사용 코드가 의도적으로 제거된 상태입니다. 연구 목적의 ASR은 공개되어 있습니다.
bash · 설치 
# 1. 레포지토리 클론
git clone https://github.com/microsoft/VibeVoice.git
cd VibeVoice

# 2. 의존성 설치 (NVIDIA Container 24.07 ~ 25.12 권장)
pip install -e .

# 3. 모델은 HuggingFace Hub에서 자동 다운로드됨
#    모델 ID: microsoft/VibeVoice-ASR
bash · Gradio 데모 실행 
# 브라우저 UI로 바로 테스트
python demo/vibevoice_asr_gradio_demo.py \
  --model_path microsoft/VibeVoice-ASR \
  --share

# --share 옵션: 외부 공유 URL 생성 (Gradio 터널)
bash · 오디오 파일 추론 
# 오디오 파일 직접 분석
python demo/vibevoice_asr_inference_from_file.py \
  --model_path microsoft/VibeVoice-ASR \
  --audio_files /path/to/meeting.wav

# 출력 예시:
# [00:00:00 → 00:00:15] Speaker A: 오늘 회의 시작하겠습니다.
# [00:00:16 → 00:00:42] Speaker B: 지난 주 결과부터 공유드리면...
# [00:00:43 → 00:01:20] Speaker A: 네, 좋습니다. 이어서...
python · HuggingFace Transformers v5.3+ 통합 
# HuggingFace Transformers v5.3 이상에서 공식 지원
# (2026년 3월 정식 통합 완료)
from transformers import AutoModel, AutoProcessor

processor = AutoProcessor.from_pretrained("microsoft/VibeVoice-ASR")
model = AutoModel.from_pretrained("microsoft/VibeVoice-ASR")

# Realtime 모델 (0.5B) — Colab 데모 제공
# https://huggingface.co/microsoft/VibeVoice-Realtime-0.5B
