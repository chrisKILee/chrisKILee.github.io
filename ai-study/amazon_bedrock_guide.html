Architecture

핵심 컴포넌트 구조

파운데이션 모델을 중심으로 RAG·에이전트·가드레일·AgentCore가 단일 관리형 플랫폼으로 통합됩니다.

Core Features

5가지 핵심 기능

AI 개발의 전 주기를 단일 플랫폼으로 지원합니다.

🗄️
Knowledge Bases — RAG
자체 데이터로 RAG(검색 증강 생성)를 구성합니다. Amazon S3, OpenSearch, Salesforce, ServiceNow 등 다양한 데이터 소스와 연결하면 벡터 임베딩이 자동으로 생성됩니다. 모델이 학습하지 않은 사내 문서를 기반으로 정확한 답변을 생성하고 출처 인용까지 함께 제공합니다. 정형 데이터(SQL, Neptune Analytics)도 지원합니다.
S3 · OpenSearch · Kendra 멀티모달 지원 SQL 자동 변환
🤖
Agents
단순 챗봇을 넘어 외부 API 호출, 예약 처리, 이메일 전송 등 실제 자율 작업을 수행하는 AI 에이전트를 구축합니다. 프롬프트 엔지니어링, 메모리, 모니터링, IAM 권한 관리를 자동 처리합니다.
자율 워크플로우
🛡️
Guardrails
유해 콘텐츠 최대 88% 차단, 최대 99% 정확도로 기업 보안 정책을 AI에 적용합니다. PII 필터링, 기밀 정보 유출 방지, 할루시네이션 감소를 제공합니다.
PII 필터링 할루시네이션 최소화
🔀
Bedrock Flows
노드 기반 시각적 빌더로 복잡한 AI 워크플로우를 구성합니다. 코딩 없이 멀티스텝 에이전트 파이프라인을 설계하고 테스트할 수 있습니다.
Visual Builder
📊
Model Evaluation & Routing
성능·비용·지연시간 기준으로 모델을 평가하고 최적 모델을 선택합니다. 지능형 프롬프트 라우팅으로 요청 복잡도에 따라 자동으로 최적 모델을 선택해 비용을 최대 30% 절감합니다.

Claude on AWS · Megazone Cloud 오퍼링

Claude on AWS 4가지 소비 경로

AWS Premier Partner이자 Anthropic 공식 파트너인 메가존 클라우드가 제시하는 기업 유형별 최적 Claude 도입 경로입니다.

구분 출시 시트비 EDP/PPA 데이터 경계 최적 고객
① Claude Code on Bedrock GA 없음 100% uncapped 고객 AWS 계정 내 개발자 전용 · 데이터 레지던시 필수 · 비용 최적화
② C4E on AWS Marketplace GA $20/user/월 100% (PPA 25% cap) Anthropic 호스팅 전사 AI 도입 · Chat+Code+Cowork 풀 플랫폼
③ Cowork 3P on Bedrock PREVIEW 없음 (토큰 과금) 100% uncapped 고객 AWS 계정 내 금융·의료·공공 규제 고객 · 비US 데이터 레지던시
④ Claude Platform on AWS SOON TBD TBD Anthropic (AWS 외부) Anthropic 네이티브 UX + Beta · 레지던시 무관

KEY INSIGHT

Cowork 3P on Bedrock은 C4E의 부가 옵션이 아닌 독립형 대체 배포 모드입니다. 시트 라이선스를 순수 토큰 과금으로 전환하며, 금융·의료·공공 규제 고객의 데이터 레지던시 요건을 완벽히 충족합니다. Anthropic에 프롬프트가 전송되지 않으며, CloudTrail 추론 감사로그를 지원합니다.

Enterprise Value

엔터프라이즈 Pain Point 해소

기업 AI 도입의 핵심 장벽 4가지를 Amazon Bedrock이 해소합니다.

Pain #1 — 중앙 모니터링·보안 제어 부재
세분화된 조직 단위 제어
사용자별 프롬프트 저장·감사 구성 / Bedrock Guardrails로 PII 필터링 / 개인·팀·조직 단위 모델 접근 및 사용량 제어가 가능합니다.
경쟁사 대비: 타사 대비 세분화된 제어 가능
Pain #2 — 인터넷 경유 민감 데이터 전송
완전 Private Network 구성
VPC/PrivateLink로 완전 프라이빗 네트워크 구성 / LLM Gateway를 AWS 내부 네트워크에서 운영 가능. 데이터가 인터넷을 경유하지 않습니다.
경쟁사: Cursor, GitHub Copilot 등은 인터넷 경유 필수
Pain #3 — 고정 토큰 제한으로 생산성 저하
토큰 상한 없는 Pay-As-You-Go
사용량에 따른 종량제 과금 / 비용 소진율에 따라 Opus→Sonnet→Haiku 유동 라우팅 가능. 고정 토큰 제한 없음.
경쟁사: 고정 토큰 제한 도달 시 생산성 저하
Pain #4 — 보안 인증 인프라 미비
엔터프라이즈급 보안 인증 완비
ISMS, FedRAMP High, HIPAA, DoD IL 4/5, ISO 27001/42001 지원 / AWS Enterprise Support 24/7 / 국내 금융보안원 가이드라인 준수 아키텍처 설계 가능.
특히 ISMS는 Anthropic 1P에서 미지원 — Bedrock만 충족

5가지 비용 최적화 전략

Security & Compliance

엔터프라이즈급 보안 인증

고객 데이터는 모델 학습에 사용되지 않으며, 전송 중·저장 데이터 모두 암호화됩니다. AWS IAM 및 VPC와 완벽히 연동됩니다.

ISO 27001 ISO 42001 SOC 2 Type II CSA STAR Level 2 GDPR FedRAMP High HIPAA DoD IL 4/5 ISMS (국내) 금융보안원 가이드라인

데이터 주권

고객 입력 데이터는 AI 모델 학습에 사용되지 않습니다. 선택한 AWS 리전 내에 데이터가 유지됩니다.

네트워크 격리

VPC/PrivateLink로 완전 프라이빗 네트워크 구성. 데이터가 인터넷을 경유하지 않고 AWS 내부망에서 처리됩니다.

감사 로그

AWS CloudTrail과 통합된 추론 감사 로그. Cross-Region Inference 사용 시에도 실제 처리 리전 추적이 가능합니다.
