01 서비스 개요

LazyWeb이란?

AI 코딩 도구는 코드를 빠르게 생성하지만 좋은 디자인 판단력은 없다. LazyWeb은 실제 운영 중인 앱의 검증된 UI 패턴을 AI 에이전트에 공급하는 레퍼런스 라이브러리다.

LazyWeb 작동 방식 — 전체 플로우
🖼️
디자인 레퍼런스 라이브러리

실제 운영 중인 앱 300,000+ 화면을 수집·인덱싱. 온보딩 흐름, 가격 표시, 대시보드, 체크아웃 등 카테고리별 실제 UI 패턴 즉시 검색 가능.

Core Feature
🔌
MCP 네이티브 통합

Anthropic MCP(Model Context Protocol) 기반. Claude, Cursor, Codex 등 AI 에이전트에 Bearer 토큰 한 번으로 연결. 에이전트가 UI 결정 시 자동으로 레퍼런스 참조.

Agent Integration
🖥️
Canvas 기반 탐색

실제 예시들을 Canvas에 끌어다 배치하며 여러 디자인 방향 동시 탐색. 저충실도(Low-fi)에서 고충실도(Hi-fi) 반복 설계 지원.

02 창업자 & 배경

Ali Abouelatta — Duolingo PM이 만든 이유

2026년 3월 18일 출시. 약 2.5개월의 집중 개발. AI 도구만으로 설계·개발·마케팅 전 과정을 수행한 솔로 프로젝트.

개발 동기
Duolingo에서 경쟁사 분석을 위해 수동으로 수행하던 작업들 — 앱 화면 캡처, 패턴 분류, A/B 테스트 아이디어 도출 — 을 AI로 자동화하려는 목표에서 출발. 디자인 레퍼런스 없이 AI 코딩만으로 만들어지는 UI의 품질 문제를 직접 경험.
개발 방식
AI만으로 전체 스택 개발 (설립자 혼자). 초기 Mac 앱 계획 → 웹 기반으로 피벗. 의존성 역순 개발 방식 채택 (UI 먼저 → 기능 후).

03 기술 스택 & MCP 통합

AI 에이전트 연결 방법

Anthropic MCP 표준 프로토콜 기반. Bearer 토큰을 에이전트 설정에 추가하는 것만으로 257,000+ 화면에 접근 가능.

MCP 통합 아키텍처
Claude Code에서 설정하는 방법
lazyweb.com/mcp-install 에서 설치 프롬프트 복사 → Claude Code MCP 설정에 붙여넣기 → 무료 Bearer 토큰 자동 생성
json — claude_desktop_config.json 
{
  "mcpServers": {
    "lazyweb": {
      "url": "https://mcp.lazyweb.com/sse",
      "headers": {
        "Authorization": "Bearer {YOUR_FREE_TOKEN}"
      }
    }
  }
}
주의
토큰을 공개 Git 저장소에 커밋하지 말 것. 로컬 MCP 설정 파일에서만 사용 권장.
04 사용 방법

3단계로 시작하기

공식 사이트 기준. 설치 프롬프트 복사 → AI 에이전트 연결 → 즉시 사용.

1
lazyweb.com/mcp-install 접속
공식 MCP 설치 페이지에서 자신의 AI 에이전트(Claude, Cursor, Codex)에 맞는 설치 프롬프트를 복사한다. 이 과정에서 무료 Bearer 토큰이 자동 생성된다.
2
AI 에이전트 MCP 설정에 붙여넣기
복사한 프롬프트를 Claude Code 또는 Cursor의 MCP 설정 파일에 붙여넣는다. HTTP Streaming Transport 방식으로 자동 연결된다.
bash — Claude Code에서 
# Claude Code 설정 파일 위치
~/.claude/claude_desktop_config.json

# 또는 프로젝트별 .claude/settings.json → mcpServers 섹션
3
AI 에이전트에게 UI 레퍼런스 요청
연결 후 AI 에이전트에게 "이 온보딩 화면 설계에 실제 앱 사례를 참고해줘" 같은 자연어 요청을 하면, 에이전트가 LazyWeb MCP를 통해 관련 UI 패턴을 자동으로 검색·분석해 근거 있는 제안을 생성한다.

07 한계 & 주의사항

알고 쓰기

2026년 3월 출시된 신생 서비스. 공식 한계 및 사용 시 주의할 점.

서비스 제약

  • UI/UX 영역만 지원 — 백엔드·DB·법률 분야 불가
  • 스크린샷 기반 — 동적 인터랙션·애니메이션 검증 불가
  • 데이터 수집 지연 — 최신 앱 업데이트 즉시 반영 안 될 수 있음
  • 사용자 수·매출 미공개 (신생 서비스 특성)
  • 정식 리뷰·사례 부족 (출시 2개월)

사용 시 주의

  • 디자인 직접 복제 금지 — 저작권·특허 침해 위험
  • Bearer 토큰 공개 Git 저장소 커밋 금지
  • 각 앱의 비즈니스 목표·타겟 고객 컨텍스트 별도 이해 필요
  • AI 제안도 항상 사람이 검토 후 적용
