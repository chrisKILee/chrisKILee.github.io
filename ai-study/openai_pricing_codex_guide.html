02 · 사용 한도 방식

롤링 윈도우 — Claude와 같은 구조

ChatGPT는 자정 초기화가 아닌 롤링 윈도우(sliding window) 방식. 각 메시지의 타임스탬프를 기준으로 개별 추적.

04 · Codex CLI 시작하기

설치부터 첫 태스크까지

출처: developers.openai.com/codex/cli · /quickstart · /cli/reference · github.com/openai/codex (직접 확인)

ℹ️ "Codex"라는 이름 — 현재도 사용?

OpenAI는 2022년 구 Codex 모델(code-davinci 계열)을 폐기했지만, 2025년 완전히 새로운 Codex CLI를 출시하며 같은 이름을 재사용. 구 Codex API와는 무관한 별개 제품. Rust로 작성된 오픈소스(Apache 2.0) 터미널 에이전트.

1
설치 — npm 또는 Homebrew

macOS, Windows, Linux 모두 지원. npm 전역 설치 또는 Homebrew 사용.

# npm (모든 플랫폼 — 권장)
npm install -g @openai/codex

# Homebrew (macOS)
brew install --cask codex
2
인증 — ChatGPT 계정 또는 API 키

두 가지 방식. ChatGPT 계정 연동 시 별도 API 비용 없이 구독 크레딧 사용.

# 방법 1: ChatGPT 계정 연동 (브라우저 열림, 추천)
codex
# → 로그인 후 자동 완료. Plus/Pro/Business/Edu/Enterprise 구독 크레딧 사용.

# 방법 2: API 키 직접 사용
export OPENAI_API_KEY=sk-proj-...
codex
# → platform.openai.com API 요금 별도 발생
3
첫 태스크 실행

프로젝트 디렉토리에서 실행. 자연어로 작업 지시.

# 대화형 TUI 시작
codex

# 즉시 태스크 지시
codex "이 프로젝트 구조를 설명해줘"
codex "CSV를 파싱해서 JSON으로 출력하는 Python 스크립트 작성"
codex "auth.js 의 버그를 찾아서 수정해줘"
⚠️ Git 체크포인트 필수

Codex는 코드베이스를 직접 수정함. 각 태스크 전후 git commit으로 체크포인트를 만들 것. 공식 문서 강력 권장.

4
승인 모드 선택 (--ask-for-approval)

파일 수정·명령 실행에 대한 승인 수준을 선택.

# untrusted: 모든 작업 승인 필요 (기본, 가장 안전)
codex --ask-for-approval untrusted "리팩토링해줘"

# on-request: 필요할 때만 승인
codex --ask-for-approval on-request "테스트 코드 추가"

# never: 모든 작업 자동 실행
codex --ask-for-approval never "lint 에러 전부 수정"

# --full-auto: 로컬 작업 자동화 단축키
codex --full-auto "마이그레이션 스크립트 작성"
5
유용한 CLI 플래그

자동화·CI/CD 환경에서 특히 유용한 옵션.

# 이전 세션 이어서 진행
codex --last
codex --last "이어서 타입 정의도 추가해줘"

# JSON 출력 (CI/CD 파이프라인 자동화)
codex --json "빌드 에러 수정"

# 샌드박스 설정
codex --sandbox read-only        # 읽기 전용
codex --sandbox workspace-write  # 워크스페이스 쓰기 허용

# 서브 커맨드
codex exec     # 비대화형 실행
codex resume   # 세션 재개
codex fork     # 대화 분기
codex apply    # 패치 적용

05 · Claude Code vs Codex CLI

기능 비교

설치·비용·구조적 차이를 중심으로 비교. 벤치마크 수치는 제3자 비교 사이트 기반으로 공식 수치가 아님을 명시.

항목 🟣 Claude Code 🔵 Codex CLI
구동 방식 터미널 AI 에이전트 (Anthropic) 터미널 AI 에이전트 (OpenAI, Rust 기반)
설치 npm install -g @anthropic-ai/claude-code npm install -g @openai/codex
인증 Claude.ai 계정 or Anthropic API 키 ChatGPT 계정 or OpenAI API 키
구독 포함 여부 Claude Pro 이상 포함 ChatGPT Plus 이상 포함
오픈소스 아니오 ✅ Apache 2.0 (github.com/openai/codex)
멀티 에이전트 ✅ Agent Teams — 의존성 추적, 병렬 worktree 독립 컨테이너 (에이전트 간 조율 불가)
실행 모드 인터랙티브 협업 방식 ✅ untrusted / on-request / never / full-auto
CI/CD 자동화 가능 ✅ --json 출력, SSH 환경 지원
IDE 통합 VS Code, JetBrains VS Code, Cursor, Windsurf, macOS 앱
비용 구조 구독 크레딧 기반 구독 크레딧 기반 (토큰당, API 키 시 별도)
⚠️ 성능 수치 주의

인터넷에 "Claude Code SWE-bench 87.6%", "Codex CLI 4× 토큰 효율" 등의 수치가 유통되나, 이는 제3자 비교 사이트 기반으로 공식 OpenAI/Anthropic 발표 수치가 아님. 실제 성능은 태스크·코드베이스 특성에 따라 크게 다름.
