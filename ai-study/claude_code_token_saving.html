왜 토큰이 예상보다 많이 소비되는가

Claude Opus 4.7 출시 이후 코딩 에이전트의 토큰 비용이 급증했다는 사용자 보고가 이어지고 있습니다. 원인을 찾지 못한 채 비용만 늘어나는 상황에서, 이 가이드는 실제로 토큰을 낭비하는 근본 원인을 식별하고 설정 변경만으로 해결하는 방법을 제시합니다.

⚠️

비용은 "기능"에서가 아닌 "설정"에서 새고 있다

코딩 에이전트의 토큰 소비 중 상당 부분은 실제 작업과 무관한 자동 첨부 텍스트, 장황한 도구 출력, 불필요한 외부 연결에서 발생합니다. 코드 자체를 줄이지 않아도 설정만으로 대폭 절감이 가능합니다.

토큰 낭비의 3가지 주요 원인

코딩 에이전트에서 토큰이 낭비되는 경로는 크게 세 가지입니다.

원인 설명 해결 방향
자동 첨부 텍스트 매 세션/턴마다 자동으로 삽입되는 Git 지시문, IDE 컨텍스트 등 설정에서 비활성화
긴 도구 출력 Bash 명령어 실행 결과 등이 대화 기록에 무제한으로 누적 출력 길이 상한 설정
외부 연결 웹 검색, MCP 서버, IDE 통합 등 각 호출마다 추가 토큰 발생 필요한 것만 활성화

토큰 소비 흐름

코딩 에이전트가 하나의 요청을 처리할 때 토큰이 어디서 발생하는지 시각화합니다.

Claude Code 토큰 절약 설정

Claude Code는 .claude/settings.json 또는 .claude/settings.local.json 파일과 환경변수를 통해 토큰 소비를 제어할 수 있습니다.

1. Git 지시문 비활성화

Claude Code는 기본적으로 매 세션에 Git 관련 지시문을 자동 첨부합니다. Git 작업이 주 목적이 아닌 경우 비활성화하면 매 턴마다 수백 토큰을 절감할 수 있습니다. 

# .claude/settings.json 또는 .claude/settings.local.json
{
  "includeGitInstructions": false
}

2. IDE 자동 연결 차단

IDE 통합(VS Code, JetBrains 등)이 활성화되어 있으면 에디터 컨텍스트를 자동으로 가져옵니다. 터미널 전용으로 사용할 경우 비활성화합니다. 

# .claude/settings.json
{
  "includeGitInstructions": false,
  "autoConnectIde": false
}

3. Bash 출력 길이 제한

BASH_MAX_OUTPUT_LENGTH 환경변수로 Bash 명령어 실행 결과의 최대 길이를 제한합니다. 기본값이 없거나 매우 크게 설정된 경우, 긴 로그·빌드 출력이 대화 기록에 고스란히 누적됩니다. 

# 쉘 설정 파일 (~/.zshrc, ~/.bashrc 등)에 추가
export BASH_MAX_OUTPUT_LENGTH=10000   # 문자 단위, 필요에 맞게 조정
💡

빌드 로그처럼 수만 줄이 나오는 명령어는 출력 상한 설정의 효과가 특히 큽니다. 필요한 정보만 확인하려면 tail -n 50처럼 명령어 수준에서도 제한하는 것이 좋습니다.

4. MCP 서버 선별 활성화

설치되어 있지만 사용하지 않는 MCP 서버는 등록만으로도 컨텍스트를 차지합니다. 현재 작업에 필요한 서버만 활성화하고 나머지는 비활성화합니다. 

# .claude/settings.json — 특정 MCP 서버 비활성화 예시
{
  "mcpServers": {
    "unused-server": {
      "disabled": true
    }
  }
}
ℹ️

슬래시 커맨드도 정리 대상

사용하지 않는 슬래시 커맨드(스킬)도 컨텍스트에 로드됩니다. .claude/settings.json에서 등록된 커맨드를 주기적으로 정리하면 추가 절감이 가능합니다.

Codex CLI 토큰 절약 설정

OpenAI의 Codex CLI도 설정 파일과 플래그로 토큰 소비를 제어할 수 있습니다. Claude Code와 병행 사용하는 경우 양쪽 모두 최적화하는 것이 좋습니다.

1. MCP 앱 비활성화

Codex CLI 설정 파일에서 MCP 앱을 비활성화합니다. 

# Codex 설정 파일 (codex.toml 또는 config.json)
features.apps = false

2. 웹 검색 비활성화

웹 검색은 검색 결과 전체가 토큰으로 변환되어 컨텍스트에 포함됩니다. 코드 작업 중 필요하지 않다면 비활성화합니다. 

# Codex 설정 파일
web_search = "disabled"

3. 명령어 플래그 활용

비대화형 모드에서 Codex CLI를 실행할 때 유용한 플래그입니다. 

# JSON 출력 모드 — 파싱하기 쉬운 구조화된 출력
codex --json

# 읽기 전용 샌드박스 — 불필요한 재시도 루프 방지
codex --sandbox read-only

보완 도구: claude-slim

GeekNews 댓글(dzzwe)에서 소개된 claude-slim은 "들어오는 토큰"을 등록 단계에서 줄이는 접근법입니다.

항목 내용
목적 미사용 스킬, 비대해진 CLAUDE.md 파일을 스캔하고 정리
방식 CLI 도구로 등록된 컴포넌트 중 실제로 사용되지 않는 것을 탐지
이 가이드와의 관계 이 가이드가 "설정으로 토큰 차단"이라면, claude-slim은 "등록 단계에서 불필요한 것을 제거"
⚠️

claude-slim의 정확한 설치 경로와 공식 저장소는 원문에서 확인되지 않았습니다. 사용 전 공식 채널에서 최신 정보를 확인하세요.

설정 체크리스트

아래 설정을 순서대로 적용하면 불필요한 토큰 소비를 최소화할 수 있습니다.

Claude Code

설정 방법 효과
includeGitInstructions: false settings.json 매 턴 Git 지시문 자동 첨부 차단
autoConnectIde: false settings.json IDE 컨텍스트 자동 수집 차단
BASH_MAX_OUTPUT_LENGTH 환경변수 Bash 출력 상한 설정으로 누적 차단
미사용 MCP 서버 비활성화 settings.json 불필요한 서버 컨텍스트 제거
미사용 슬래시 커맨드 정리 settings.json 로드되는 스킬 수 감소

Codex CLI

설정 방법 효과
features.apps = false 설정 파일 MCP 앱 비활성화
web_search = "disabled" 설정 파일 웹 검색 결과 토큰 제거
--sandbox read-only 플래그 불필요한 재시도 루프 방지
--json 플래그 비대화형 모드 효율 향상
