Background

Lead Story

LLM Wiki란 무엇인가 — Karpathy가 제안한 지식 축적 패턴

2026년 4월 3일, Andrej Karpathy(OpenAI 공동창업자, 전 Tesla AI 총괄)가 X(트위터)에 GitHub Gist를 공개했습니다. 새로운 앱이나 SaaS가 아닌 아이디어 파일 — Claude Code 같은 LLM 에이전트에 붙여넣기만 하면 동작하는 개념적 패턴입니다.

핵심 통찰은 RAG(검색 증강 생성)의 한계를 우회하는 방식입니다. 전통 RAG는 쿼리할 때마다 벡터를 검색해 조합하지만, LLM Wiki는 수집(ingest) 시점에 한 번만 합성하고 결과를 마크다운 페이지에 저장합니다. 지식이 페이지에 쌓이며 복리로 성장합니다.

Andrej Karpathy · GitHub Gist · 2026-04-03

Key Insight

RAG와 LLM Wiki의 핵심 차이

항목 전통 RAG LLM Wiki
합성 시점 쿼리할 때마다 수집 시 한 번
지식 축적 영구 기억상실 복리로 성장
추적 가능성 블랙박스 벡터 .md 파일로 추적
토큰 효율 매번 재계산 최대 95% 절감*

* 소규모 지식 베이스 기준 (Atlan 분석)

Architecture

LLM Wiki의 철학: 사람은 raw/ 폴더에 원본을 넣는다. LLM이 wiki/ 폴더를 소유하고 관리한다.

your-obsidian-vault/ ├── raw/ ← 불변 원본 (사람이 관리, LLM은 읽기만) │ └── topic/ │ └── 2026-04-03-article.md ├── wiki/ ← LLM이 소유하고 관리하는 지식 페이지 │ ├── sources/ ← 소스 1개당 요약 페이지 1개 자동 생성 │ ├── entities/ ← 인물, 기업, 제품, 도구 페이지 │ ├── concepts/ ← 아이디어, 프레임워크, 이론 페이지 │ ├── answers/ ← /file-answer로 저장된 Q&A 페이지 │ ├── index.md ← 에이전트가 쿼리 시 먼저 읽는 카탈로그 │ └── log.md ← 추가 전용(append-only) 작업 기록 └── CLAUDE.md ← 가장 중요! 도메인 스키마·워크플로우 규칙

Claudian Plugin — 터미널 없이 위키에 질문

핵심 도구

Obsidian Claudian — Claude Code를 사이드바로

Claudian은 Obsidian 볼트에 Claude Code를 사이드바로 임베드하는 커뮤니티 플러그인입니다. "Your vault becomes the agent's working directory" — 볼트가 에이전트의 작업 디렉토리가 되어 터미널 없이 파일 읽기/쓰기, 검색, bash 명령 실행이 가능합니다.

/query 에이전트 하네스에 대해서 알려줘 라고 입력하면 Claude가 index.md를 먼저 읽고, 관련 wiki 페이지를 탐색한 뒤 [[wikilink]] 인용과 함께 답변을 합성합니다. 답변은 다시 wiki/answers/에 저장됩니다.

GitHub: YishenTu/claudian · ⭐ 8,500 · MIT 라이선스 · 2026-04-10 기준

/query 흐름

질문 → 탐색 → 답변 → 저장

① /query "X와 Y의 관계?" ↓ ② wiki/index.md 읽기 ↓ ③ 관련 페이지 2~3개 탐색 ↓ ④ [[wikilink]] 인용 + 답변 ↓ ⑤ /file-answer 로 저장 → wiki/answers/에 축적

지식이 쌓일수록 점점 똑똑해지는 구조

How to Start — 3단계 시작 가이드

01
Karpathy Gist 열기 + Claude Code에 붙여넣기
카파시의 llm-wiki GitHub Gist를 열고, 내용을 복사해 Claude Code 또는 Claudian에 붙여넣습니다.
# Claude Code에서 "이걸 참고해서 내 볼트에 위키 만들어줘"
02
raw/ 폴더에 Obsidian 노트 넣기
기존 Obsidian 볼트의 마크다운 파일들을 raw/ 폴더에 복사합니다. 이 폴더는 LLM이 읽기만 하고 절대 수정하지 않습니다.
vault/ ├── raw/ ← 여기에 노트 복사 │ └── *.md └── wiki/ ← LLM이 자동 생성
03
Claudian 설치 + /ingest 실행
Obsidian Claudian 플러그인을 설치하고 사이드바에서 /ingest를 실행합니다. 이후 /query "질문"으로 바로 위키에 질문 가능합니다.
# Claudian 사이드바에서 /ingest # 소스 요약 + 엔티티 추출 /query "..." # 위키에 질문

알려진 한계 — 공식 출처 기반

  • 주의 1 할루시네이션 축적: LLM이 소스에 없는 내용을 추가하면 위키에 기록되고, 이후 생성 결과에도 영향을 줍니다. CLAUDE.md에 "소스에 없는 내용은 추가하지 말 것" 규칙을 명시해야 합니다.
  • 주의 2 규모 확대 시 분류 체계 한계: entities/concepts 이분법은 소규모에서 잘 작동하지만, 수천 개 노트 규모에서는 더 세밀한 그룹핑이 필요합니다. CLAUDE.md를 점진적으로 발전시켜야 합니다.
  • 주의 3 컨텍스트 윈도우 한계: Claude Sonnet 기준 ~200,000 토큰. "수백 개의 집중된 노트"까지는 직접 처리 가능하지만, 그 이상은 QMD 같은 검색 레이어 도입이 권장됩니다.
  • 주의 4 RAG와의 수렴: 대규모에서는 결국 벡터 검색 도구가 필요해지는 현상이 있습니다. Karpathy 본인도 대형 볼트에서는 QMD(RAG류) 검색 도구 사용을 권장합니다.

"153개 파일을 넣었더니 146개 소스가 요약되고, 48개 엔티티와 29개 컨셉이 자동으로 추출됐습니다. 이걸 수동으로 분류했다면 며칠이 걸렸을 작업입니다. 노트 정리가 고민이신 분들은 꼭 시도해보세요."
