Gemini CLI 에이전트 스킬 만들기

AI에게 나만의 지식과 워크플로를 가르치는 방법을 배웁니다

🎯 이 실습에서 배울 것

Gemini CLI에 나만의 지식과 워크플로를 제공하는 "에이전트 스킬"을 직접 만들어봅니다. 마치 AI에게 개인 튜터를 붙여주는 것과 같습니다!

학습 목표 3가지

✏️

1. 개인 맞춤형 에이전트 스킬 생성

나만의 SKILL.md 파일을 작성해서 Gemini가 내 선호도나 정보를 알 수 있게 합니다.

🤖

2. Gemini CLI를 활용한 스킬 쿼리

만든 스킬을 Gemini CLI에서 직접 호출하고 결과를 확인합니다.

🔥

3. Firebase 공식 에이전트 스킬로 앱 배포

Firebase가 제공하는 전문 스킬을 설치해서, Gemini가 Firebase 앱을 자동으로 만들고 배포하게 합니다.

실습 흐름 한눈에 보기

① 준비 → ② SKILL.md 작성 → ③ CLI 테스트 → ④ Firebase 스킬 → ⑤ 앱 배포

💡 초보자를 위한 사전 지식

터미널(명령줄)을 처음 사용해도 괜찮습니다. 이 가이드는 모든 명령어를 단계별로 설명합니다. Google 계정만 있으면 시작할 수 있습니다!

핵심 개념 이해

실습을 시작하기 전에, 핵심 용어들을 쉽게 이해해봅시다.

에이전트 스킬(Agent Skill)이란?

🧠

AI에게 주는 "전문 지식 패키지"

에이전트 스킬은 LLM(대형 언어 모델)에게 특정 지식과 워크플로를 제공하는 모듈입니다.

예를 들어, "내 좋아하는 색은 파란색, 음식은 피자"라는 정보를 스킬로 만들면, Gemini가 이를 기억하고 답변에 활용합니다.

🍕 피자 가게 비유로 이해하기

Gemini CLI = 피자 가게의 직원

에이전트 스킬 = 직원이 가진 레시피 북

직원(Gemini)은 기본적으로 많은 것을 알지만, 레시피 북(스킬)을 추가하면 "오늘의 특선 메뉴"처럼 특정 정보를 더 잘 알 수 있게 됩니다!

핵심 구성 요소

용어 쉬운 설명 예시
SKILL.md 스킬의 핵심 파일. AI에게 줄 정보를 마크다운으로 작성 좋아하는 색, 음식 목록
Gemini CLI 터미널에서 Gemini AI를 사용하는 도구 gemini 명령어
에이전트 스킬 SKILL.md 파일이 들어있는 폴더 하나 .agents/skills/my-skill/
포터블 스킬 다른 프로젝트에서도 재사용 가능한 완성형 스킬 Firebase 공식 스킬

SKILL.md 파일 구조

SKILL.md는 두 부분으로 구성됩니다:

--- # 1. 프론트매터(메타데이터) - AI에게 스킬을 소개하는 부분 name: my-skill-name # 스킬 이름 description: 이 스킬이 무엇을 하는지 설명 # AI가 언제 이 스킬을 써야 할지 판단 --- # 2. 본문(Knowledge) - 실제 AI에게 줄 지식 # Knowledge - **항목1:** 값1 - **항목2:** 값2

📌 폴더 위치가 중요!

스킬 폴더는 반드시 .agents/skills/ 안에 있어야 합니다. Gemini CLI가 이 경로를 자동으로 탐색합니다.

Google Cloud 프로젝트 설정

STEP 1 — Google Cloud Console 열기

브라우저에서 console.cloud.google.com을 엽니다.

상단 메뉴에서 "새 프로젝트"를 클릭해서 새 프로젝트를 만드세요.

STEP 2 — Cloud Shell 편집기 열기

Cloud Console 우상단의 >_ 아이콘을 클릭하면 Cloud Shell이 열립니다.

Cloud Shell은 브라우저 안에서 바로 터미널을 사용할 수 있는 도구입니다. 별도 설치가 필요 없어요!

# Cloud Shell 터미널에서 프로젝트 확인 gcloud config set project [YOUR_PROJECT_ID] # 프로젝트 ID 목록 확인 방법 gcloud projects list | awk '/PROJECT_ID/{print $2}'

STEP 3 — 결제 활성화

Cloud Console에서 청구 → 프로젝트 연결을 통해 결제를 활성화합니다.

💰 비용 걱정 없이!

이 실습의 예상 비용은 $1 미만입니다. 신규 사용자라면 $300 무료 체험 크레딧을 받으므로 실제로는 비용이 발생하지 않습니다.

📝 첫 번째 에이전트 스킬 만들기

이제 실제로 스킬을 만들어봅니다. 내 좋아하는 것들을 AI가 기억하게 하는 스킬입니다!

1. 작업 디렉터리 생성

Cloud Shell 터미널에서 아래 명령어를 순서대로 실행합니다:

# 1. 실습용 메인 폴더 생성 mkdir ~/agent-skills-lab # 2. 해당 폴더로 이동 cd ~/agent-skills-lab # 3. 스킬 폴더 구조 생성 (폴더 이름이 스킬 이름이 됨) mkdir -p ~/agent-skills-lab/.agents/skills/my-favorite-things

📁 디렉터리 구조 설명

agent-skills-lab/ └── .agents/ ← 숨김 폴더 (점으로 시작) └── skills/ ← 모든 스킬이 여기에 위치 └── my-favorite-things/ ← 내 스킬 폴더 └── SKILL.md ← 곧 만들 파일!

💡 mkdir -p 란?

-p 옵션은 중간 폴더가 없어도 한 번에 전체 경로를 만들어줍니다. 예를 들어 .agents와 skills 폴더가 없어도 한 번에 생성됩니다.

2. SKILL.md 파일 작성

아래 명령어로 파일을 엽니다:

cloudshell edit ~/agent-skills-lab/.agents/skills/my-favorite-things/SKILL.md

파일에 아래 내용을 붙여넣습니다:

--- name: my-favorite-things description: 내 개인 선호도(좋아하는 색, 음식, 프로그래밍 언어)를 제공합니다 --- # Knowledge # 아래 내용을 자신의 취향으로 바꿔보세요! - **Favorite Color:** Blue - **Favorite Food:** Pizza - **Favorite Programming Language:** Python

🔍 각 줄 설명

부분역할설명
--- 사이 메타데이터(프론트매터) AI가 이 스킬을 식별하고 언제 사용할지 결정하는 데 사용
name 스킬 이름 /skills 명령어로 확인할 때 표시되는 이름
description 스킬 설명 AI가 이 설명을 보고 "지금 이 스킬을 써야 하나?" 판단
# Knowledge 이하 실제 지식 데이터 AI가 읽고 답변에 활용하는 실제 정보

⚠️ 중요: 파일 저장!

Cloud Shell 편집기에서 Ctrl+S (Mac: Cmd+S)로 저장하세요. 저장하지 않으면 내용이 사라집니다.

🤖 Gemini CLI로 스킬 테스트

만든 스킬을 Gemini CLI에서 실제로 사용해봅니다!

Gemini CLI 시작하기

터미널에서 agent-skills-lab 폴더 안에 있는지 확인 후 실행합니다:

# 1. 실습 폴더로 이동 (중요! 이 폴더 안에서 실행해야 스킬이 인식됨) cd ~/agent-skills-lab # 2. Gemini CLI 시작 gemini

📌 왜 폴더 위치가 중요한가요?

Gemini CLI는 현재 폴더에서 시작해서 상위 폴더까지 .agents/skills/ 폴더를 탐색합니다. 엉뚱한 위치에서 실행하면 스킬이 보이지 않습니다!

스킬 목록 확인

Gemini CLI가 실행되면 아래 명령어로 스킬 목록을 확인합니다:

# CLI 안에서 슬래시(/) 명령어 사용 /skills

이렇게 표시되면 성공입니다:

Available skills: • my-favorite-things

스킬에 질문하기

이제 Gemini에게 내 정보를 물어봅니다:

# 질문 예시 What is my favorite color? # Gemini의 답변 예시 Based on your skills, your favorite color is Blue.

🎯 더 다양한 질문 테스트

  • What food do I like? → 좋아하는 음식 확인
  • What programming language is my favorite? → 좋아하는 언어 확인
  • Tell me about my preferences → 전체 선호도 요약

CLI 종료

/quit

🎉 축하합니다! 첫 스킬 완성!

SKILL.md 파일 하나만으로 Gemini AI가 내 정보를 기억하고 답변할 수 있게 됐습니다.

이 원리를 응용하면 회사 정책, 개발 가이드라인, 프로젝트 정보 등을 AI에게 가르칠 수 있습니다!

🔥 Firebase 공식 에이전트 스킬 설치

이제 Firebase가 만든 전문 에이전트 스킬을 설치합니다. 이 스킬을 사용하면 Gemini가 Firebase 앱을 자동으로 만들고 배포할 수 있게 됩니다!

🔥 Firebase란?

Google의 앱 개발 플랫폼. 인증(로그인), 데이터베이스, 웹 호스팅 등을 쉽게 구현할 수 있는 서비스 모음입니다. 백엔드 없이도 완성도 높은 앱을 만들 수 있어요.

1. 새 작업 폴더 생성

# todo 앱을 만들 새 폴더 생성 후 이동 mkdir ~/todo-app && cd ~/todo-app

2. Firebase 로그인

# Firebase CLI로 로그인 (브라우저 없이 인증) firebase login --no-localhost

로그인 과정:

  1. 터미널에 URL이 나타납니다 → 브라우저에서 해당 URL 접속
  2. Google 계정으로 로그인
  3. Firebase 기능 활성화 여부 묻는 프롬프트: Y 입력
  4. 사용 정보 수집 동의 여부: Y 입력
  5. 브라우저에 표시된 승인 코드를 복사 → 터미널에 붙여넣기

3. Firebase 에이전트 스킬 설치

# npx로 Firebase 공식 스킬 패키지 설치 npx skills add firebase/agent-skills

설치할 스킬을 선택하는 메뉴가 나타납니다. 아래 4개를 선택하세요:

📦 설치할 스킬 4가지

스킬 이름역할
firebase-basics Firebase 기본 개념과 설정 방법
firebase-hosting-basics 웹사이트를 Firebase에 배포하는 방법
firebase-auth-basics Google 로그인 등 인증 기능 구현 방법
firebase-firestore-enterprise-native-mode Firestore 데이터베이스 사용 방법

💡 포터블 스킬이란?

Firebase 스킬처럼 다른 사람이 만들어서 배포한 스킬을 "포터블 스킬"이라고 합니다. npx skills add 명령어로 누구나 공유하고 설치할 수 있습니다. Claude Code의 /add 명령어와 비슷한 개념!

🚀 Firebase 앱 빌드 & 배포

Firebase 에이전트 스킬을 활용해서 Gemini가 실제 웹 앱을 만들고 배포하게 합니다!

1. API 활성화 및 Firebase 프로젝트 설정

# Google Cloud API 활성화 gcloud services enable cloudresourcemanager.googleapis.com firebase.googleapis.com # 현재 Cloud 프로젝트에 Firebase 추가 firebase projects:addfirebase ${GOOGLE_CLOUD_PROJECT}

💡 ${GOOGLE_CLOUD_PROJECT} 란?

Cloud Shell이 자동으로 설정하는 환경 변수입니다. 현재 선택된 Google Cloud 프로젝트 ID가 자동으로 입력됩니다.

2. Gemini CLI 실행

# todo-app 폴더에서 Gemini CLI 시작 cd ~/todo-app gemini

3. 단계별 앱 개발 (Gemini에게 지시)

STEP 1 — 기본 HTML 페이지 만들기

Gemini CLI에 아래 프롬프트를 입력합니다:

Generate an index.html file with "Hello Firebase Hosting" and deploy using the current Google Cloud Project.

Gemini가 자동으로 HTML 파일을 만들고 Firebase Hosting에 배포합니다. 완료되면 배포 URL이 표시됩니다!

STEP 2 — Google 로그인 기능 추가

Gemini CLI에 아래 프롬프트를 입력합니다:

Generate HTML, CSS, and Javascript for a single page application using Google Sign-in with Firebase Authentication.

Firebase Authentication을 사용한 Google 로그인 기능이 자동으로 추가됩니다!

STEP 3 — Firestore DB 연동

로그인한 사용자의 할 일(Task)을 저장하는 기능을 추가합니다:

Update the application to save tasks in Cloud Firestore for signed-in users.

Cloud Firestore 데이터베이스에 할 일 목록이 저장되는 완전한 Todo 앱이 완성됩니다!

4. 최종 배포

# 완성된 앱을 Firebase Hosting에 배포 firebase deploy --only hosting

🎉 놀라운 결과!

단 3개의 프롬프트로 아래 기능을 모두 갖춘 앱이 완성됩니다:

  • ✅ 웹 호스팅 (Firebase Hosting)
  • ✅ Google 로그인 (Firebase Authentication)
  • ✅ 실시간 데이터베이스 (Cloud Firestore)

5. 정리 (선택사항)

실습이 끝난 후 불필요한 리소스를 정리하려면:

# Google Cloud 프로젝트 삭제 (모든 리소스 포함) gcloud projects delete $GOOGLE_CLOUD_PROJECT # 로컬 실습 파일 삭제 rm -rf ~/agent-skills-lab rm -rf ~/todo-app

⚠️ 프로젝트 삭제 주의

프로젝트를 삭제하면 모든 데이터와 배포된 앱이 영구적으로 삭제됩니다. 학습 목적이라면 삭제하는 것이 좋지만, 계속 사용할 앱이 있다면 삭제하지 마세요.
