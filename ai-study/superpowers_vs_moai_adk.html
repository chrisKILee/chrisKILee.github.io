Trade-offs

장점과 한계

Superpowers
💪 강점
  • ✅ 설치 마찰 제로 — 마크다운 파일, 의존성 없음
  • ✅ Anthropic 공식 마켓 등록, 플러그인 1개 명령으로 설치
  • ✅ MIT 라이선스, 완전 무료
  • ✅ 103K+ ⭐, Discord + GitHub 대형 커뮤니티
  • ✅ 자가 진화: 클로드가 새 스킬 직접 작성
  • ✅ Claude Code, Cursor, Gemini CLI, OpenCode 모두 지원
  • ✅ 45~60분 안에 Notion 클론 완성 (87% 커버리지) 검증 사례
⚠️ 한계
  • ❌ 계획 단계에서 10~20분 오버헤드
  • ❌ 간단한 스크립트나 소규모 수정엔 과함
  • ❌ 커뮤니티 운영, Anthropic 공식 엔지니어 지원 아님
  • ❌ 메모리 시스템·공유 메커니즘 미완성
MoAI-ADK
💪 강점
  • ✅ 단일 바이너리, ~5ms 시작, 의존성 없음
  • ✅ Ralph Engine: 100회 자율 에러 수정 루프
  • ✅ CG Mode: GLM 하이브리드로 비용 60~70% 절감
  • ✅ progress.md로 세션 중단 후 재개 가능
  • ✅ 18개 언어 + 9개 플랫폼 (Vercel, Supabase 등) 명시 지원
  • ✅ 9,800+ 테스트, 85~100% 내부 커버리지
⚠️ 한계
  • ❌ 27 에이전트 + 52 스킬 — 높은 러닝커브
  • ❌ Claude Code 전용 (Cursor/Gemini CLI 불가)
  • ❌ RUN 페이즈 ~180K 토큰 — 고비용
  • ❌ Opus 풀 활용에 $200/월 구독 필요
  • ❌ 한국 커뮤니티 중심, 영어권 자료 부족
Decision Guide

언제 어느 걸 써야 할까?

선택 가이드 플로우차트
⚡ Superpowers를 선택하면 좋을 때
  • →설치 없이 즉시 시작하고 싶을 때
  • →Claude Code, Cursor, Gemini CLI 등 여러 IDE 사용 시
  • →팀이 AI 개발 방법론에 처음 입문할 때
  • →스킬을 직접 커스터마이징하고 싶을 때
  • →대형 커뮤니티와 공식 지원이 중요할 때
🤖 MoAI-ADK를 선택하면 좋을 때
  • →가장 강력한 자율 품질 강제가 필요할 때
  • →Vercel, Supabase 등 플랫폼 통합 프로젝트
  • →Claude API 비용이 부담스러울 때 (CG Mode)
  • →테스트 커버리지 낮은 레거시 코드 (DDD 모드)
  • →긴 작업을 중단 후 재개해야 하는 장기 프로젝트

Bottom Line

두 도구는
경쟁 관계가 아니다

Superpowers는 방법론 플러그인이다. Claude를 "어떻게 생각하고 행동할지" 훈련시키는 규칙서. 접근성, 커뮤니티, 멀티 IDE 지원에서 압도적이다.

MoAI-ADK는 자율 개발 플랫폼이다. 개발자가 환경(하네스)을 설계하면 AI가 실행, 검증, 수정까지 자율로 처리한다. 복잡한 대규모 프로젝트에 맞는 엔터프라이즈급 도구.

💡 처음 시작한다면?
Superpowers로 시작해 방법론을 익히고, 대형 프로젝트가 생기면 MoAI-ADK 도입을 검토하는 것이 현실적인 경로.
