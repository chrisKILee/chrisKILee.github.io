03 핵심 기능

preserve_thinking — 다중턴 추론 유지

다중턴 에이전트 작업에서 이전 대화 턴의 사고 컨텍스트를 유지해 반복적 추론을 줄이고 논리 연속성을 보장하는 기능.

작동 원리
<think>...</think> 태그로 표현되는 추론 내용을 이전 메시지에서 현재 메시지로 이월한다. 복잡한 다단계 코딩 작업, 자율 에이전트에서 논리 일관성을 높이는 데 유효하다.
python 
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.qwenmodel.alibaba.com/v1"  # OpenAI-compatible endpoint
)

response = client.chat.completions.create(
    model="qwen3.6-max-preview",
    messages=[{"role": "user", "content": "Fix the bug in this repo"}],
    extra_body={
        "chat_template_kwargs": {"preserve_thinking": True}  # 추론 컨텍스트 유지
    }
)

print(response.choices[0].message.content)
