⚡ 주요 기능

📄 Oracle 로그 파싱

EXPDP_*.log 파일을 자동 분석.
날짜·시작/종료 시간·백업 용량·성공 여부를 정규식으로 추출.
EUC-KR 인코딩 자동 감지 지원.

📑 RR PDF 파싱

Rapid Recovery 백업 보고서 PDF를 pdf.js로 파싱.
CMES/PMES 키워드로 창원/포항 점검자 자동 판별.

📊 운영일지 자동 생성

파싱 결과를 5개 섹션(점검자·BACKUP·아카이브·운영사항·비고) 양식으로 조립.
좌표 기반 셀 병합 자동 계산.

📋 표 클립보드 복사

생성된 표를 버튼 한 번으로 클립보드에 복사.
Excel·이메일에 바로 붙여넣기 가능 (MS Office 호환).

🔀 지역 분기 처리

포항·창원 두 지역의 양식 차이를 자동 분기.
아카이브 관리 컬럼 수, 점검자 정보가 지역에 따라 자동 변경.

✅ 파일 유효성 검사

다른 지역 파일 혼재(CMES+PMES) 시 오류 안내.
동일 파일명 중복 업로드 방지.
