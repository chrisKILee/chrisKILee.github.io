⚡ 주요 기능

🤖 AI 의도 분류 스마트 검색

자연어 입력 → Gemini가 30개 이상 검색 모드 중 최적 선택. 신뢰도 낮으면 후보 모드 제시

📋 스마트 브리핑

결재 대기·오늘 일정·미읽은 메일·근태 현황을 1화면에 통합 요약

✍️ AI 기안서·게시글 초안

주제 입력 시 Gemini가 업무연락·기안서·게시글 HTML 초안을 자동 생성

🔍 결재·게시글 AI 요약

결재문서·게시글 본문을 Gemini가 요약 + 키포인트 추출. 복수 문서 업무 동향 분석

🌐 Google Workspace 통합 검색

Gmail·Calendar·Drive를 단일 인터페이스에서. AI가 자연어를 검색 연산자로 자동 변환

💬 가이드봇 (매뉴얼 챗봇)

FAQ·매뉴얼·팁을 챗봇 형태로 자동 응대. AI 태그 추천으로 비개발자 운영 자립화

🪟 PiP 독립 윈도우

Picture-in-Picture 모드로 기존 업무 화면 유지하며 검색 창을 독립 윈도우로 분리

📊 관리자 통계 대시보드

KPI 카드 5개 + 차트 4종. Stage별 AI 비용 절감률, 모드별 사용 빈도 실시간 추적

⚙️ 검색 모드 운영 관리

30개 이상 검색 모드를 코드 변경 없이 활성화/비활성화. 카테고리·가이드 CRUD 직접 운영

🧠 AI 활용 방식 · 기술 스택

3단계 점진적 지능화 (Progressive Intelligence)

① Stage 1 — 키워드 직접 매칭 (~100ms, AI 비용 $0) → 전체 검색의 40% 처리
② Stage 2 — 패턴 매칭 (~10ms, AI 비용 $0) → 전체 검색의 20% 처리
③ Stage 3 — Gemini AI 의도 분류 (~800ms, ~$0.001~0.003/건) → 나머지 40%만 AI 호출
