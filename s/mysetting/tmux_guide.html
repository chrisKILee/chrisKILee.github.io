터미널 안에 터미널 여러 개를 띄우고, 닫아도 프로세스가 살아있는 멀티플렉서. 세션 관리부터 창 전환, 단축키까지 한 번에 정리합니다.

2026-03-27 · MySetting

💡 tmux가 뭐야?

터미널 멀티플렉서(Terminal Multiplexer)입니다. 쉽게 말하면 두 가지 기능을 합니다:

📺
터미널 창 분할
하나의 터미널 안에서 창을 여러 개로 나눠 동시에 볼 수 있음
🔋
세션 유지 (핵심!)
터미널을 닫아도 서버가 계속 살아있음. 재접속하면 그대로 이어서 작업
💡
핵심 비유 tmux는 탭이 있는 브라우저와 비슷합니다. 창이 여러 개 열려 있어도 한 번에 하나만 보이고, 단축키로 전환합니다. 그리고 브라우저를 꺼도 탭이 사라지지 않는 마법 같은 버전이라고 생각하세요.

🔄 기본 흐름

터미널을 닫아도 tmux 세션 안의 프로세스(서버, DB 등)는 계속 실행됩니다. 다시 터미널을 열고 tmux attach하면 그대로 이어집니다.

🚀 세션 시작 & 복귀

처음 시작할 때

bash
# 프로젝트 폴더로 이동 cd ~/git/all_mighty # tmux 세션 시작 (폴더명 = 세션이름 자동 설정) /tmux on # → "all_mighty" 라는 이름으로 세션 생성

WSL/PC 재시작 후 복귀

⚠️
주의 WSL이나 PC를 재시작하면 tmux 세션이 사라집니다. /tmux on으로 새로 만들어야 합니다.
bash
# 세션이 살아있을 때 복귀 tmux attach -t all_mighty # 짧게: tmux a -t all_mighty # 세션 목록 확인 tmux ls # 세션이 없으면 새로 생성 /tmux on

세션 종료

bash
# tmux 안에서 나가기 (세션은 유지) Ctrl+B → d # detach # 세션 완전 종료 /tmux off

🪟 창 구성 & 전환

tmux는 창(window)이 여러 개 있어도 한 번에 하나만 보입니다. 탭 브라우저처럼요. 하단 상태바에서 현재 창 목록을 확인할 수 있습니다.

상태바 예시
[1] backend* [2] frontend [3] test [4] terminal ↑ * = 지금 보고 있는 창

이 프로젝트(all_mighty)의 창 구성:

1backend
NestJS API 서버 실행
npm run start 여기서!
2frontend
Next.js 개발 서버
npm run dev
3test
테스트 실행용
npm test
4terminal
일반 터미널
git, 기타 명령
✅
창 전환 방법 Ctrl+B 를 누르고 손을 뗀 다음 숫자를 누릅니다.
동시에 누르는 게 아닙니다! Ctrl+B → 손 떼기 → 2

⌨️ 단축키 전체 정리

모든 tmux 단축키는 Ctrl+B를 먼저 누르고 손을 뗀 뒤 다음 키를 누릅니다.

Ctrl+B → 숫자
창 전환
(1=backend, 2=frontend...)
Ctrl+B → w
창 목록 보기
(방향키로 선택)
Ctrl+B → d
tmux에서 나가기
(세션은 유지됨)
Ctrl+B → [
스크롤 모드
(q로 종료)
Ctrl+B → c
새 창 만들기
Ctrl+B → ,
창 이름 바꾸기
CLI 명령어설명
tmux ls실행 중인 세션 목록
tmux attach -t 이름세션에 다시 붙기
tmux kill-session -t 이름세션 강제 종료
tmux new-session -s 이름새 세션 생성

🤖 /tmux 커맨드

이 프로젝트에서는 Claude Code 스킬로 /tmux를 지원합니다.

커맨드동작
/tmux on현재 폴더명으로 세션 생성 (4개 창 자동 구성)
/tmux off현재 폴더명의 세션 종료
/tmux status현재 세션 상태 확인
ℹ️
세션 이름 자동 결정 /tmux on은 현재 디렉토리 이름을 세션 이름으로 씁니다. ~/git/all_mighty에서 실행하면 세션 이름은 all_mighty가 됩니다.

🛠️ 실전 워크플로우

매일 개발 시작할 때

bash
# 1. 터미널 열기 cd ~/git/all_mighty # 2. 세션 살아있으면 복귀, 없으면 생성 tmux attach -t all_mighty || /tmux on # 3. 1번 backend 창에서 서버 시작 # (자동으로 1번 창이 활성화됨) npm run start # DB + API + Frontend 한 번에 시작 # 4. 브라우저에서 확인 # http://localhost:3000

작업 중 창 이동

단축키 흐름
서버 로그 보다가 → Ctrl+B → 4 → terminal 창에서 git 작업 git 완료 후 → Ctrl+B → 3 → test 창에서 npm test 테스트 완료 → Ctrl+B → 1 → backend 창으로 복귀

🤖 Claude Code는 어디서 열어?

Claude Code는 tmux 밖의 별도 터미널 탭에서 엽니다. tmux 창 안에서 열면 화면이 깨지거나 단축키가 충돌할 수 있습니다.

Windows Terminal 탭 구성 권장
# 탭 1: tmux (서버 실행) tmux attach -t all_mighty ← npm run start 실행 중 # 탭 2: Claude Code cd ~/git/all_mighty && claude ← AI 작업 # 탭 3: 자유 터미널 ← git, 기타 명령
💡
Windows Terminal 탭 추가 Ctrl+Shift+T로 새 탭을 열 수 있습니다.
