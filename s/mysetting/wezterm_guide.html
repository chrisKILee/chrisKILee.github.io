🖥️ Terminal Emulator · Rust · GPU-Accelerated

WezTerm —
GPU 가속 터미널 에뮬레이터

WezTerm은 Rust로 작성된 GPU 가속 크로스 플랫폼 터미널 에뮬레이터 겸 멀티플렉서입니다. Lua 기반 설정, 빌트인 SSH 클라이언트, 탭/패널 멀티플렉싱을 하나의 도구로 제공합니다.

⚡ GPU 가속 렌더링 🔀 빌트인 멀티플렉서 🌐 SSH 클라이언트 내장 🦀 Rust 구현 🌙 Lua 설정 🔤 리거처 + 컬러 이모지
01 핵심 기능

무엇을 할 수 있나?

WezTerm이 제공하는 주요 기능들을 한눈에 파악합니다.

🔀
멀티플렉싱

로컬 및 원격 호스트의 탭·창·패널을 하나의 GUI에서 통합 관리. SSH/TLS/Unix 소켓 기반 도메인 연결을 지원하며 네트워크가 끊겨도 세션이 유지됩니다.

SSH · TLS · Unix Socket
🔤
고급 폰트 렌더링

HarfBuzz 기반 리거처(ligature), 컬러 이모지, 폰트 폴백 체인 지원. True Color(24bit)와 동적 컬러 스킴 전환이 가능합니다.

HarfBuzz · True Color
🔍
검색 가능한 스크롤백

탭당 최대 스크롤백 라인 수 설정 가능. Ctrl-Shift-F로 검색 오버레이 활성화, 정규식/대소문자 구분 모드 지원, 저장된 검색 등록 가능.

Regex · Saved Search
🐚
Shell Integration

OSC 7(현재 디렉토리), OSC 133(시멘틱 프롬프트), OSC 1337(User Vars) 지원. bash/zsh/xonsh에서 CWD 추적, 프롬프트 존 하이라이트 등 활성화.

bash · zsh · xonsh
🌐
SSH 클라이언트 내장

시스템 SSH 의존성 없이 내장 라이브러리로 SSH 연결. 새 탭/패널 생성 시 동일 SSH 세션 재사용, ~/.ssh/config 파싱 지원.

libssh · ssh_config
🖼️
그래픽 프로토콜

iTerm2 이미지 프로토콜, Kitty 그래픽 프로토콜, Sixel(실험 단계) 지원. 터미널 내에서 인라인 이미지 렌더링 가능.

iTerm2 · Kitty · Sixel

03 설치 & 시작

빠르게 시작하기

플랫폼별 설치 방법과 기본 설정 파일 위치를 확인합니다.

1
패키지 설치
플랫폼에 맞는 방법으로 설치합니다.
bash 
# macOS (Homebrew)
brew install --cask wezterm

# Ubuntu/Debian (apt)
curl -fsSL https://apt.fury.io/wez/gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/wezterm-fury.gpg
echo 'deb [signed-by=/etc/apt/keyrings/wezterm-fury.gpg] https://apt.fury.io/wez/ * *' | sudo tee /etc/apt/sources.list.d/wezterm.list
sudo apt update && sudo apt install wezterm

# Windows (winget)
winget install wez.wezterm

# Arch Linux (AUR)
yay -S wezterm
2
설정 파일 생성
홈 디렉토리에 ~/.wezterm.lua 파일을 생성합니다. 변경사항은 저장 즉시 핫 리로드됩니다.
lua 
-- ~/.wezterm.lua
local wezterm = require 'wezterm'
local config = wezterm.config_builder()

-- 폰트 설정
config.font = wezterm.font('JetBrains Mono', { weight = 'Regular' })
config.font_size = 14.0

-- 컬러 스킴
config.color_scheme = 'Tokyo Night'

-- 스크롤백 라인 수
config.scrollback_lines = 10000

-- 스크롤바 표시
config.enable_scroll_bar = true

return config
3
SSH 연결
내장 SSH 클라이언트로 원격 서버에 연결합니다. 새 탭을 열면 동일 SSH 세션을 재사용합니다.
bash 
wezterm ssh user@my-server.com
4
멀티플렉서 연결 (원격 지속 세션)
SSH 도메인을 설정하면 네트워크가 끊겨도 세션이 유지됩니다. wezterm connect로 재접속 가능합니다.
lua 
-- ~/.wezterm.lua에 SSH 도메인 추가
config.ssh_domains = {
  {
    name = 'my.server',
    remote_address = '192.168.1.100',
    username = 'wez',
  },
}

-- 접속
-- $ wezterm connect my.server

05 멀티플렉싱

tmux 없이도 영구 세션

WezTerm 멀티플렉서는 tmux/screen과 유사하지만 GUI와 완전히 통합됩니다.

tmux vs WezTerm Mux
tmux는 별도 프로세스로 동작하지만, WezTerm Mux는 터미널 에뮬레이터 내부에 통합되어 마우스, 클립보드, 스크롤백이 네이티브로 동작합니다.
🔐
SSH 도메인 (원격 멀티플렉싱)

원격 서버에 wezterm 데몬을 실행하고 SSH 채널로 연결. 네트워크가 끊겨도 세션 유지, 재접속 시 바로 복원됩니다.

bash 
wezterm connect my.server
# ~/.ssh/config 호스트는 자동 감지
wezterm connect SSHMUX:hostname
SSH Channel · Persistent
🔌
Unix 도메인 (로컬 멀티플렉싱)

Unix 소켓으로 로컬 mux 서버에 연결. 시작 시 자동 연결 설정 가능. WSL에서 Win32 GUI로 접근 가능합니다.

lua 
config.unix_domains = {{ name = 'unix' }}
config.default_gui_startup_args =
  { 'connect', 'unix' }
Unix Socket · WSL
🔒
TLS 도메인 (암호화 TCP)

TLS 암호화 TCP 연결로 원격 mux 연결. SSH 부트스트랩으로 인증서를 안전하게 배포, 이후 TCP로 직접 연결합니다.

lua 
config.tls_clients = {{
  name = 'server.name',
  remote_address = 'host:8080',
  bootstrap_via_ssh = 'host',
}}
TLS · Auto-Reconnect
06 Lua 설정

프로그래머블 설정 시스템

WezTerm 설정 파일은 Lua 스크립트입니다. 조건 분기, 함수 정의, 모듈 임포트가 모두 가능합니다.

핫 리로드
설정 파일 저장 시 WezTerm을 재시작하지 않고 즉시 변경사항이 적용됩니다.
lua — ~/.wezterm.lua 예시 
local wezterm = require 'wezterm'
local config = wezterm.config_builder()

-- 폰트 및 외관
config.font = wezterm.font_with_fallback {
  'JetBrains Mono',
  'Noto Sans CJK KR',  -- 한글 폴백
  'Noto Color Emoji',
}
config.font_size = 13.0
config.color_scheme = 'Tokyo Night'

-- 탭바 스타일
config.use_fancy_tab_bar = false
config.tab_bar_at_bottom = true

-- 스크롤백
config.scrollback_lines = 10000
config.enable_scroll_bar = true

-- 하이퍼링크 규칙 커스터마이즈
config.hyperlink_rules = wezterm.default_hyperlink_rules()
table.insert(config.hyperlink_rules, {
  regex = [[\b[Tt](\d+)\b]],
  format = 'https://jira.example.com/browse/T-$1',
})

-- 커스텀 단축키 추가
config.keys = {
  -- Ctrl-Shift-H: git 해시 검색
  {
    key = 'H',
    mods = 'SHIFT|CTRL',
    action = wezterm.action.Search { Regex = '[a-f0-9]{6,}' },
  },
  -- Ctrl-Shift-P: 패널 분할 (수직)
  {
    key = 'P',
    mods = 'SHIFT|CTRL',
    action = wezterm.action.SplitVertical { domain = 'CurrentPaneDomain' },
  },
}

-- Shell Integration: 탭 타이틀을 CWD로 업데이트
wezterm.on('user-var-changed', function(window, pane, name, value)
  local overrides = window:get_config_overrides() or {}
  if name == 'WEZTERM_PROG' then
    overrides.initial_prog = { value }
  end
  window:set_config_overrides(overrides)
end)

return config

07 CLI 명령어

터미널에서 제어하기

wezterm CLI로 스크립팅 및 자동화가 가능합니다.

명령어 설명
wezterm ssh user@host 내장 SSH 클라이언트로 원격 연결
wezterm connect domain 멀티플렉서 도메인에 연결 (SSH/TLS/Unix)
wezterm imgcat image.png 터미널에서 인라인 이미지 표시
wezterm serial /dev/ttyUSB0 시리얼 포트 연결 (Arduino 등)
wezterm serial --baud 38400 PORT 보드레이트 지정하여 시리얼 연결
wezterm ls-fonts 사용 가능한 폰트 목록 출력
wezterm show-keys 현재 설정된 단축키 전체 출력
wezterm record 터미널 세션 녹화
wezterm replay session.cast 녹화된 세션 재생
wezterm cli spawn 새 탭/패널 프로그래밍 방식으로 생성
