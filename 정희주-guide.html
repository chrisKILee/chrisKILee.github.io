⚡ 주요 기능

🔐 ITS 자동 로그인

ITS 시스템에 자동 로그인(JSESSIONID)하여 부서 처리이력 CH건을 AES 암호화 방식으로 전체 수집

📊 상세 데이터 추출

CH건별 공수·모듈·착수일·완료일·처리내용을 상세 폼 HTML 파싱으로 자동 추출, 중복 제거 후 Sheets 저장

📝 Confluence 회의록 취합

Confluence CQL로 하위 회의록 전체 검색, 담당자·일자·소요시간 파싱 후 고객커뮤니케이션 시트에 Append

📅 주간칸반 자동 동기화

담당자 15명의 주차별 건수·공수를 칸반 시트에 자동 반영, 현재 주차까지 빈칸 0 초기화

📈 월간 집계 & 차트

SAP/MES 분류 기반 요청분류·업무모듈 월간 통계표와 원형·막대 차트를 자동 생성

🖥️ KPI 대시보드 Web App

Bootstrap 5 + Chart.js 기반 6탭 SPA. URL 접근만으로 비개발자도 팀 KPI 실시간 확인 가능

🧠 AI 활용 방식 · 기술 스택

🤖 AI 활용 방식

  • ✅ 바이브코딩 — Claude·Gemini로 AppScript 전체 개발
  • ✅ 노코드 AI — Google AppScript 자동화 플랫폼
  • ❌ 런타임 AI 없음 (자동화·크롤링 중심)

🛠️ 기술 스택

  • 🔹 Google Apps Script (V8 런타임)
  • 🔹 Bootstrap 5.3 + Chart.js
  • 🔹 CryptoJS 4.1.1 (AES-ECB)
  • 🔹 Confluence REST API / ITS HTTP

🔄 자동화 흐름

ITS 로그인 → AES 암호화 요청 → CH건 수집 → 상세 추출 →
Confluence CQL → 회의록 파싱 → Google Sheets 저장 →
칸반 동기화 → 월간 집계 → Web App 대시보드 시각화
