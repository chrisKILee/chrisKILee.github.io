🛠️ 주요 기능

🎯 화면 템플릿 학습

1회만 하면 됩니다. 기준 화면에서 각 입력 필드를 클릭하면 라벨 좌표와 입력칸 오프셋이 자동 저장됩니다.

🔍 ORB 기하 정합

창이 이동하거나 배율이 달라져도 특징점 매칭으로 실제 클릭 위치를 자동 보정합니다. (Homography + Affine fallback)

🤖 Gemini Vision Fallback

정합 실패 시 Gemini Vision API가 화면을 직접 보고 라벨 위치를 추정합니다. 화면 변화에도 자동 복구.

🧠 AI 필드 매핑

비정형 Google Sheets에서 대상 필드값을 AI가 의미 기반으로 추출합니다. 복잡한 양식도 자동 파싱.

🖥️ 비개발자용 GUI

Flet 기반 GUI로 설정·학습·실행·결과 탭 제공. 툴팁 안내 포함, exe 더블클릭으로 즉시 실행.

📊 결과 검증

디버그 클릭 이미지(빨간점)와 JSON 로그로 입력 결과를 즉시 확인. 실행 이력 요약도 제공.

🧠 AI 활용 방식 · 기술 스택

🤖 런타임 AI 모델

  • ✅ Gemini Vision API — 정합 실패 시 화면 인식 fallback
  • ✅ Gemini Text API — 비정형 시트 AI 필드 매핑

  • 🔹 pyautogui — 화면 캡처 + 클릭·입력 자동화
  • 🔹 PyInstaller — exe 단일 파일 패키징

① ORB 기하 정합(비용 없음, 빠름) → 실패 시 ② Gemini Vision API(정확도 보강) → 스크롤 영역은 ③ EasyOCR(선택 적용)
