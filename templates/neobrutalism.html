두꺼운 테두리

How It Works

시작하는 방법

1

CSS 변수 선언

`:root`에 디자인 토큰을 CSS 변수로 선언합니다.

--color-primary: #FDC800;
--shadow-brutal: 4px 4px 0px #1C293C;
--border-brutal: 2px solid #1C293C;
2

brutal-card 클래스 적용

모든 카드·버튼·입력창에 `border` + `box-shadow` 패턴을 적용합니다.

border: var(--border-brutal);
box-shadow: var(--shadow-brutal);
3

hover 인터랙션 추가

translate + 더 큰 shadow로 물리적 피드백을 구현합니다.

:hover {
  transform: translate(-2px, -2px);
  box-shadow: 6px 6px 0 #1C293C;
}
