처음 만나는 LLM API — 0에서 프로덕션까지

계정 생성부터 첫 호출, 스트리밍, 도구 호출, 그리고 비용 최적화까지. 한 페이지로 끝내는 입문 가이드.

난이도 · 입문 읽기 · 18분 업데이트 · 2026.04.25 코드 · Python / TypeScript

개요

이 문서는 LLM API를 처음 다루는 개발자를 위한 핸즈온 가이드입니다. 마지막에 도달하면 다음을 할 수 있습니다.

  • API 키를 안전하게 발급·보관한다
  • SDK로 첫 응답을 받고 스트리밍을 켠다
  • 도구 호출(tool use)로 외부 함수를 연결한다
  • 토큰 단가를 보고 월 비용을 추산한다
  • RAG 한 줄 파이프라인을 만든다

TL;DR

① pip install → ② 환경변수에 키 등록 → ③ 5줄짜리 첫 호출 → ④ 스트리밍 켜기 → ⑤ 평가셋으로 검증. 기본기를 잡는 데 30분이면 충분합니다.

사전 준비

본 가이드는 Python 3.10+ 또는 Node 20+ 환경을 가정합니다. 신용카드는 결제 등록만 하고, 실 사용은 무료 크레딧 안에서 끝납니다.

설치 및 인증

키 발급은 콘솔의 API Keys → New Key에서 합니다. 발급된 값은 한 번만 보이므로, 비밀 저장소에 즉시 옮깁니다.

주의 · 키 노출 금지 깃 리포지토리, 클라이언트 사이드 JS, 공유 노트에 키를 직접 넣지 마세요. 환경 변수 또는 시크릿 매니저를 사용하세요.

Python

pip install ai-sdk
export AI_API_KEY="sk-..."

TypeScript

npm install ai-sdk
echo 'AI_API_KEY=sk-...' >> .env

첫 호출

아래는 가장 작은 단위의 호출입니다. 클라이언트를 만들고, 메시지를 보내고, 응답 텍스트를 꺼냅니다.

from ai_sdk import Client

client = Client()  # 환경변수에서 키 자동 인식
resp = client.chat.create(
    model="model-mini",
    messages=[{"role": "user", "content": "안녕, 한 줄로 자기소개해."}],
)
print(resp.text)
1

모델을 고른다

model-mini는 빠르고 저렴합니다. 깊은 추론이 필요하면 model-pro로 바꾸세요.

2

메시지 배열을 만든다

역할(role)과 내용(content)을 가진 객체들의 리스트입니다. system으로 페르소나를 고정할 수 있습니다.

3

응답을 파싱한다

resp.text는 평탄화된 텍스트, resp.choices[0]는 원본 객체.

프롬프트 작성법

“좋은 프롬프트”의 90%는 구조에서 나옵니다. 역할 → 작업 → 입력 → 출력 형식의 4-구획을 지키세요.

스트리밍 응답

대화형 UI에서는 첫 토큰까지의 지연을 줄이는 것이 핵심입니다.

for chunk in client.chat.stream(model="model-mini", messages=msgs):
    print(chunk.delta, end="", flush=True)

도구 호출 (Tool use)

모델이 직접 함수를 호출하도록 시키려면 JSON 스키마로 도구를 선언합니다.

tools = [{
  "name": "get_weather",
  "description": "도시의 현재 날씨",
  "input_schema": {
    "type": "object",
    "properties": {"city": {"type": "string"}},
    "required": ["city"],
  },
}]
resp = client.chat.create(model="model-pro", messages=msgs, tools=tools)

비용 최적화

토큰 = 돈. 다음 표는 대표 모델의 1M 토큰당 단가입니다(2026-04 기준).

모델입력 / 1M출력 / 1M특징
model-mini$0.15$0.60빠름·라이트 작업
model-base$1.00$3.00균형
model-pro$3.00$15.00심층 추론·도구 호출
경험칙 분류·요약은 mini, 멀티스텝 추론과 도구 호출은 pro. 둘을 함께 쓰는 라우팅이 비용 대비 효과가 가장 좋습니다.

레시피 — RAG 한 줄 파이프라인

문서를 임베딩하고, 질문 시 가장 가까운 K개를 가져와 프롬프트에 끼워 넣는 가장 작은 RAG입니다.

docs = [open(p).read() for p in glob("docs/*.md")]
emb = client.embed(texts=docs, model="embed-3")
def answer(q):
    q_emb = client.embed(texts=[q], model="embed-3")[0]
    top = topk(q_emb, emb, docs, k=4)
    ctx = "\n\n".join(top)
    return client.chat.create(model="model-base",
        messages=[{"role":"system","content":f"근거:\n{ctx}"},
                  {"role":"user","content":q}]).text

레시피 — 평가셋 만들기

50개의 입력·기대출력 쌍을 만들고, 각 모델의 응답을 사람·LLM 둘 다로 채점합니다. 회귀 방지의 시작.

케이스입력 요지기대 출력 형식난이도
EVAL-001약관에서 해지 조항 추출JSON {clause, page}쉬움
EVAL-014두 의견의 충돌점 요약마크다운 3줄중간
EVAL-027SQL → 자연어 설명한 단락중간
EVAL-049모순 탐지boolean + 근거어려움

문제 해결

401 Unauthorized 인증 실패
키 환경변수 누락 또는 만료. echo $AI_API_KEY로 확인.
429 Rate Limited 속도 제한
분당 요청 또는 토큰 한도 초과. 지수 백오프로 재시도하거나 티어를 올리세요.
맥락 길이 초과 context length exceeded
입력+출력 합이 모델의 컨텍스트 한도를 넘음. 청크 분할 또는 long-context 모델로 전환.

용어 사전

토큰 token
모델이 텍스트를 다루는 최소 단위. 영어 ~4자, 한국어 ~1.5자/토큰.
스트리밍 streaming
완성을 기다리지 않고 토큰이 생성되는 즉시 클라이언트로 흘려보내는 응답 모드.
도구 호출 tool / function calling
모델이 사용자 함수를 직접 호출하도록 스키마로 선언하는 기능.
임베딩 embedding
텍스트를 고정 길이 벡터로 변환한 표현. 의미적 유사도 계산에 사용.
