client = Client()
resp = route(client,
  classify="model-mini",      # 1차: 분류
  reason="model-pro",         # 2차: 추론·도구 호출
).chat("이 메일을 분류하고 적절히 답변해.")

버전 명명 규약

  • major · 호환성 깨짐. 마이그레이션 가이드 필수.
  • minor · 신기능, 호환 유지.
  • patch · 버그 수정만.
  • hotfix · 긴급 보안·회귀 수정. 평일·주말 무관 릴리스.

업그레이드 체크리스트

  • 의존성 잠금 파일 갱신 (uv lock 또는 poetry lock)
  • 마이그레이션 스크립트 ai-sdk migrate 적용
  • 스트리밍·도구 호출 e2e 테스트 1회 실행
  • 관측 대시보드의 토큰 단위 로그 활성화 확인
  • 로그에 키가 마스킹되는지 grep 으로 재확인

용어 사전

SemVer Semantic Versioning
MAJOR.MINOR.PATCH 규칙. 호환성 변화는 MAJOR 자릿수만 올린다.
Hotfix 핫픽스
릴리스 사이클 외 시점에 긴급 배포되는 수정. 보안·회귀 사고에서 주로 사용.
Migration script 마이그레이션 스크립트
코드 변경을 자동 패치하는 도구. 깨지는 변경을 가능한 한 자동으로 흡수한다.
