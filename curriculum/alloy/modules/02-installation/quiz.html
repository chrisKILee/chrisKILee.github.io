Module 02 퀴즈

설치 및 기본 설정 모듈 학습 내용을 확인합니다.

Q1. apt로 설치한 Alloy의 기본 설정 파일 경로는?

apt/rpm으로 설치한 경우 기본 설정 파일 경로는 /etc/alloy/config.alloy입니다.

Q2. Alloy에서 민감한 시크릿 값을 파일에서 읽고 로그에서 마스킹하려면?

local.file 컴포넌트에서 is_secret = true를 설정하면 해당 값이 Alloy UI와 로그에서 자동으로 마스킹됩니다.

Q3. Kubernetes에서 Alloy를 모든 노드에서 실행하려면 어떤 controller type을 사용해야 하나요?

노드 레벨 메트릭/로그 수집 에이전트는 daemonset으로 배포합니다. DaemonSet은 모든 (또는 선택된) 노드에 정확히 1개의 Pod를 실행합니다.

Q4. Alloy 설정 변경 후 재시작 없이 적용하는 HTTP API는?

curl -X POST http://localhost:12345/-/reload로 Alloy 설정을 핫 리로드합니다. SIGHUP 시그널을 보내는 것과 동일한 효과입니다.
