실습: kind 클러스터에 Alloy 배포

kind로 로컬 Kubernetes 클러스터를 만들고 Helm으로 Alloy를 배포합니다.

사전 요구사항 Docker, kind, kubectl, helm이 설치되어 있어야 합니다.

실습 1: kind 클러스터 생성

kind 클러스터 생성 
kind create cluster --name alloy-lab
kubectl cluster-info --context kind-alloy-lab
monitoring 네임스페이스 생성 
kubectl create namespace monitoring

실습 2: Helm으로 Alloy 설치

Grafana Helm 저장소 추가 
helm repo add grafana https://grafana.github.io/helm-charts
helm repo update
values.yaml 작성 
cat > values.yaml << 'EOF'
alloy:
  configMap:
    content: |
      // Alloy 자신의 메트릭 수집
      prometheus.exporter.self "alloy" {}

      prometheus.scrape "alloy_self" {
        targets    = prometheus.exporter.self.alloy.targets
        forward_to = [prometheus.remote_write.local.receiver]
      }

      // 로컬 저장 (실제 환경에서는 Mimir URL로 변경)
      prometheus.remote_write "local" {
        endpoint {
          url = "http://prometheus:9090/api/v1/write"
        }
      }

controller:
  type: daemonset

serviceAccount:
  create: true

rbac:
  create: true
EOF
Helm 설치 
helm install alloy grafana/alloy \
  --namespace monitoring \
  -f values.yaml
설치 확인 
kubectl get pods -n monitoring
kubectl logs -n monitoring -l app.kubernetes.io/name=alloy -f

실습 3: Alloy UI 포트 포워딩

포트 포워딩 
kubectl port-forward -n monitoring \
  svc/alloy 12345:12345 &
브라우저에서 확인

브라우저에서 http://localhost:12345 접속 후:

  • Graph 탭에서 컴포넌트 연결 확인
  • Components 탭에서 각 컴포넌트 상태 확인

실습 4: ConfigMap으로 설정 업데이트

# values.yaml의 설정 수정 후 Helm 업그레이드
helm upgrade alloy grafana/alloy \
  --namespace monitoring \
  -f values.yaml

# Pod 재시작 확인
kubectl rollout status daemonset/alloy -n monitoring

정리

kind delete cluster --name alloy-lab
echo "클러스터 삭제 완료"
