설치 및 기본 설정

다양한 환경에서 Alloy를 설치하고 기본 설정 구조를 이해합니다.

설치 방법 개요

방법적합한 환경난이도
apt/rpm 패키지Linux 서버, VM쉬움
Docker로컬 개발, 컨테이너 환경쉬움
Helm ChartKubernetes중간
바이너리커스텀 설치, 에어갭중간

Linux 패키지 설치

Debian/Ubuntu (apt)

# Grafana apt 저장소 추가
sudo mkdir -p /etc/apt/keyrings/
wget -q -O - https://apt.grafana.com/gpg.key | \
  gpg --dearmor | sudo tee /etc/apt/keyrings/grafana.gpg > /dev/null

echo "deb [signed-by=/etc/apt/keyrings/grafana.gpg] https://apt.grafana.com stable main" | \
  sudo tee /etc/apt/sources.list.d/grafana.list

sudo apt-get update
sudo apt-get install -y alloy

RHEL/CentOS (rpm)

sudo cat > /etc/yum.repos.d/grafana.repo << 'EOF'
[grafana]
name=grafana
baseurl=https://rpm.grafana.com
repo_gpgcheck=1
enabled=1
gpgcheck=1
gpgkey=https://rpm.grafana.com/gpg.key
sslverify=1
sslcacert=/etc/pki/tls/certs/ca-bundle.crt
EOF

sudo dnf install -y alloy

systemd 서비스 관리

# 서비스 시작/중지/상태
sudo systemctl start alloy
sudo systemctl stop alloy
sudo systemctl status alloy

# 부팅 시 자동 시작
sudo systemctl enable alloy

# 로그 확인
sudo journalctl -u alloy -f
설정 파일 위치 (apt/rpm 설치) 기본 설정 파일: /etc/alloy/config.alloy 환경 변수 파일: /etc/default/alloy (Debian) 또는 /etc/sysconfig/alloy (RHEL)

Kubernetes Helm 설치

# Grafana Helm 저장소 추가
helm repo add grafana https://grafana.github.io/helm-charts
helm repo update

# 기본 설치
helm install alloy grafana/alloy \
  --namespace monitoring \
  --create-namespace \
  -f values.yaml

values.yaml 예시

# values.yaml
alloy:
  configMap:
    content: |
      prometheus.scrape "kubernetes_pods" {
        targets = discovery.kubernetes.pods.targets
        forward_to = [prometheus.remote_write.mimir.receiver]
      }

      discovery.kubernetes "pods" {
        role = "pod"
      }

      prometheus.remote_write "mimir" {
        endpoint {
          url = "http://mimir:9009/api/v1/push"
        }
      }

controller:
  type: daemonset  # 각 노드에서 실행

serviceAccount:
  create: true

설정 파일 구조

Alloy 설정 파일은 컴포넌트 블록의 집합입니다. 단일 파일이나 디렉토리 형태 모두 지원합니다.

단일 파일

// /etc/alloy/config.alloy

// 1. 서비스 디스커버리
discovery.kubernetes "pods" {
  role = "pod"
}

// 2. 디스커버리 결과 필터링
discovery.relabel "app_pods" {
  targets = discovery.kubernetes.pods.targets
  // ... relabel 규칙
}

// 3. 메트릭 스크래핑
prometheus.scrape "pods" {
  targets    = discovery.relabel.app_pods.output
  forward_to = [prometheus.remote_write.mimir.receiver]
}

// 4. 원격 전송
prometheus.remote_write "mimir" {
  endpoint {
    url = env("MIMIR_URL")
  }
}

다중 파일 (디렉토리)

# 실행 시 디렉토리 지정
alloy run /etc/alloy/

# 디렉토리 구조
/etc/alloy/
├── metrics.alloy    # 메트릭 파이프라인
├── logs.alloy       # 로그 파이프라인
└── traces.alloy     # 트레이스 파이프라인

환경 변수와 시크릿

// env() 함수로 환경 변수 참조
prometheus.remote_write "mimir" {
  endpoint {
    url = env("REMOTE_WRITE_URL")

    basic_auth {
      username = env("REMOTE_WRITE_USER")
      password = env("REMOTE_WRITE_PASSWORD")
    }
  }
}

// local.file로 파일에서 시크릿 읽기
local.file "api_key" {
  filename  = "/etc/alloy/secrets/api-key"
  is_secret = true  // 로그에 마스킹 처리
}

prometheus.remote_write "grafana_cloud" {
  endpoint {
    url = "https://prometheus-prod.grafana.net/api/prom/push"
    basic_auth {
      username = "12345"
      password = local.file.api_key.content
    }
  }
}
주의 is_secret = true로 표시된 값은 Alloy UI와 로그에서 마스킹됩니다. API 키, 패스워드 등 민감한 값은 반드시 이 옵션을 사용하세요.

옵션설명기본값
