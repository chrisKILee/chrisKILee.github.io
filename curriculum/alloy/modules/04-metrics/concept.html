Module 04 — 개념

메트릭 수집

prometheus.scrape — 메트릭 수집의 핵심

Alloy는 Prometheus 호환 메트릭을 스크래핑하기 위해 prometheus.scrape 컴포넌트를 사용합니다.

prometheus.scrape "node" {
  targets = [
    { "__address__" = "localhost:9100", "job" = "node-exporter" },
  ]
  scrape_interval = "15s"
  scrape_timeout  = "10s"
  forward_to      = [prometheus.remote_write.mimir.receiver]
}

주요 속성

속성기본값설명
targets필수스크래핑할 타깃 목록
scrape_interval1m스크래핑 간격
scrape_timeout10s스크래핑 타임아웃
metrics_path/metrics메트릭 엔드포인트 경로
honor_labelsfalse타깃의 레이블 우선 적용 여부

prometheus.remote_write — Mimir/Cortex 전송

prometheus.remote_write "mimir" {
  endpoint {
    url = "http://mimir:9009/api/v1/push"

    // 인증
    basic_auth {
      username = env("MIMIR_USER")
      password = env("MIMIR_PASSWORD")
    }

    // 큐 설정 (대용량 환경)
    queue_config {
      capacity             = 10000
      max_shards           = 50
      min_shards           = 1
      max_samples_per_send = 2000
    }

    // 외부 레이블 (모든 메트릭에 추가)
    metadata_config {
      send = true
    }
  }

  // 전역 외부 레이블
  external_labels = {
    cluster = "prod-k8s",
    region  = "ap-northeast-2",
  }
}

prometheus.relabel — 메트릭 변환

수집된 메트릭의 레이블을 변환하거나 특정 메트릭만 필터링합니다.

prometheus.relabel "filter_and_rename" {
  targets    = prometheus.scrape.node.targets
  forward_to = [prometheus.remote_write.mimir.receiver]

  // 불필요한 메트릭 드롭 (node_cpu_guest_seconds_total 제외)
  rule {
    source_labels = ["__name__"]
    action        = "drop"
    regex         = "node_cpu_guest_seconds_total"
  }

  // 레이블 추가
  rule {
    target_label = "env"
    replacement  = "production"
  }

  // 레이블 이름 변경
  rule {
    source_labels = ["node_name"]
    target_label  = "host"
    action        = "replace"
  }
}

Kubernetes 서비스 디스커버리 전체 예시

// Node 레벨 메트릭 (Node Exporter)
discovery.kubernetes "nodes" {
  role = "node"
}

discovery.relabel "node_exporter" {
  targets = discovery.kubernetes.nodes.targets

  rule {
    replacement  = "localhost:9100"
    target_label = "__address__"
  }

  rule {
    source_labels = ["__meta_kubernetes_node_name"]
    target_label  = "node"
  }
}

prometheus.scrape "node_exporter" {
  targets         = discovery.relabel.node_exporter.output
  scrape_interval = "30s"
  forward_to      = [prometheus.remote_write.mimir.receiver]
}

prometheus.remote_write "mimir" {
  endpoint {
    url = env("MIMIR_REMOTE_WRITE_URL")
  }
  external_labels = { cluster = env("CLUSTER_NAME") }
}

내장 익스포터 (Exporters)

Alloy에는 자주 쓰이는 메트릭 익스포터가 내장되어 있습니다:

컴포넌트수집 대상
prometheus.exporter.selfAlloy 자신의 메트릭
prometheus.exporter.unixUnix 시스템 메트릭 (node_exporter 역할)
prometheus.exporter.mysqlMySQL 메트릭
prometheus.exporter.postgresPostgreSQL 메트릭
prometheus.exporter.redisRedis 메트릭
prometheus.exporter.blackboxHTTP/TCP 프로브
// Unix 시스템 메트릭 (Node Exporter 대체)
prometheus.exporter.unix "node" {
  // 수집할 콜렉터 지정
  set_collectors = ["cpu", "memory", "disk", "filesystem", "network"]
}

prometheus.scrape "unix" {
  targets    = prometheus.exporter.unix.node.targets
  forward_to = [prometheus.remote_write.mimir.receiver]
}
