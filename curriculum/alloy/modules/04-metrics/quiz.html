Module 04 — 퀴즈

메트릭 수집 학습 내용 확인

Q1. prometheus.scrape의 기본 scrape_interval은?

Alloy의 기본 scrape_interval은 1분(1m)입니다. 필요에 따라 명시적으로 설정하세요.

Q2. 메트릭 이름이 "go_gc_.*"로 시작하는 메트릭을 모두 제거하는 올바른 규칙은?

메트릭 이름은 __name__ 레이블에 저장됩니다. source_labels = ["__name__"]와 action = "drop"으로 해당 메트릭을 제거합니다.

Q3. Alloy 내장 Unix 시스템 메트릭 수집 컴포넌트는?

prometheus.exporter.unix이 Node Exporter 역할을 하는 Alloy 내장 컴포넌트입니다.
