실습: 컴포넌트 파이프라인 구성

kind 클러스터에서 Kubernetes 서비스 디스커버리와 메트릭 파이프라인을 구성합니다.

사전 요구사항 kind, kubectl, helm이 설치되어 있어야 합니다.

실습 1: kind 클러스터 생성

kind create cluster --name components-lab
kubectl cluster-info --context kind-components-lab

실습 2: 멀티 파이프라인 설정

cat > pipeline-values.yaml << 'EOF'
alloy:
  configMap:
    content: |
      // 1. Kubernetes Pod 디스커버리
      discovery.kubernetes "pods" {
        role = "pod"
      }

      // 2. 어노테이션 기반 필터링
      discovery.relabel "annotated_pods" {
        targets = discovery.kubernetes.pods.targets

        rule {
          source_labels = ["__meta_kubernetes_pod_annotation_prometheus_io_scrape"]
          action        = "keep"
          regex         = "true"
        }

        rule {
          source_labels = ["__meta_kubernetes_namespace"]
          target_label  = "namespace"
        }

        rule {
          source_labels = ["__meta_kubernetes_pod_name"]
          target_label  = "pod"
        }
      }

      // 3. Alloy 자신의 메트릭 (항상 수집)
      prometheus.exporter.self "alloy" {}

      // 4. 스크래핑
      prometheus.scrape "annotated" {
        targets    = discovery.relabel.annotated_pods.output
        forward_to = [prometheus.remote_write.local.receiver]
      }

      prometheus.scrape "alloy_self" {
        targets    = prometheus.exporter.self.alloy.targets
        forward_to = [prometheus.remote_write.local.receiver]
      }

      // 5. 원격 전송 (테스트용 — 실제로는 Mimir URL 사용)
      prometheus.remote_write "local" {
        endpoint {
          url = "http://localhost:9999/api/v1/write"
        }
      }

controller:
  type: daemonset
rbac:
  create: true
serviceAccount:
  create: true
EOF

helm repo add grafana https://grafana.github.io/helm-charts
helm repo update
helm install alloy grafana/alloy   --namespace monitoring --create-namespace   -f pipeline-values.yaml

실습 3: UI에서 파이프라인 시각화

kubectl port-forward -n monitoring svc/alloy 12345:12345 &
# 브라우저에서 http://localhost:12345 열기
# Graph 탭 → 컴포넌트 연결 그래프 확인
# Components 탭 → discovery.relabel.annotated_pods 클릭
# Exports → output targets 목록 확인

실습 4: 테스트 Pod에 어노테이션 추가

kubectl run test-app   --image=nginx   --annotations="prometheus.io/scrape=true"   --annotations="prometheus.io/port=80"

# discovery.relabel.annotated_pods exports에서 test-app이 보이는지 확인
# UI Components → discovery.relabel.annotated_pods → Exports → output
