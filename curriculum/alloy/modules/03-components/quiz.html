Module 03 퀴즈

컴포넌트와 파이프라인 학습 내용을 확인합니다.

Q1. discovery.kubernetes "pods" 컴포넌트의 outputs(타깃 목록)를 prometheus.scrape에서 참조하는 올바른 방법은?

컴포넌트 참조 형식은 [타입].[레이블].[export이름]입니다. discovery.kubernetes "pods"의 타입은 discovery.kubernetes, 레이블은 pods이므로 discovery.kubernetes.pods.targets가 올바릅니다.

Q2. relabel rule에서 action = "keep"은 어떤 동작을 하나요?

action = "keep"은 regex에 매칭되는 타깃만 남깁니다(필터링). 매칭되지 않는 타깃은 파이프라인에서 제거됩니다. 반대로 action = "drop"은 매칭되는 타깃을 제거합니다.

Q3. otelcol 컴포넌트에서 다음 컴포넌트로 데이터를 전달하는 올바른 방법은?

otelcol 컴포넌트는 output { traces/metrics/logs = [...] } 블록으로 데이터를 전달합니다. Prometheus/Loki 컴포넌트의 forward_to와 다릅니다. 두 방식을 혼동하지 마세요.

Q4. Alloy 파이프라인 구조의 특성은 무엇인가요?

Alloy 파이프라인은 DAG(Directed Acyclic Graph) 구조입니다. 컴포넌트 간 연결은 단방향이며, 순환 참조는 허용되지 않습니다. 하지만 하나의 소스에서 여러 목적지로 분기하거나, 여러 소스를 하나의 목적지로 합치는 것은 가능합니다.
