Module 05 — 퀴즈

로그 수집 학습 내용 확인

Q1. Kubernetes Pod 로그를 수집하는 Alloy 컴포넌트는?

loki.source.kubernetes가 Kubernetes Pod 로그를 수집합니다. loki.source.file은 로컬 파일 테일링, loki.source.kubernetes_events는 Kubernetes 이벤트를 수집합니다.

Q2. loki.process에서 JSON 로그에서 severity 필드를 level이라는 이름으로 추출하는 올바른 설정은?

stage.json { expressions = { [추출할이름] = "[JSON경로]" } } 형식입니다. level = "severity"는 JSON의 severity 필드 값을 "level"이라는 이름으로 추출합니다.

Q3. 로그 레이블 설계 시 반드시 피해야 하는 값은?

요청 ID, Pod IP, 사용자 ID 등 고유 값을 레이블로 사용하면 Loki 인덱스가 폭발합니다. 대신 stage.structured_metadata를 사용하면 인덱스 없이 저장할 수 있습니다.
