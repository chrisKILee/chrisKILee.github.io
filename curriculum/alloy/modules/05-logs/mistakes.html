Module 05 — 일반적인 실수

로그 수집 시 흔한 실수

실수 1: 고카디널리티 레이블

로그 레이블은 Loki 인덱스에 저장됩니다. 고유값 레이블은 인덱스를 폭발시킵니다.

// ❌ Pod IP, 요청 ID는 레이블로 절대 금지
stage.labels {
  values = {
    pod_ip    = "",  // 각 Pod마다 다른 IP — 카디널리티 폭발!
    request_id = "",
  }
}

// ✅ 구조적으로 안정된 레이블만 사용
stage.labels {
  values = {
    level     = "",   // info/warn/error
    namespace = "",
    app       = "",
  }
}

// 고유값은 구조화된 메타데이터로
stage.structured_metadata {
  values = { trace_id = "", request_id = "" }
}

실수 2: __path__ 패턴 오류

// ❌ 와일드카드 없이는 단일 파일만
loki.source.file "app" {
  targets = [{ __path__ = "/var/log/app/", job = "app" }]  // 디렉토리 → 오류
}

// ✅ 와일드카드 사용
loki.source.file "app" {
  targets = [{ __path__ = "/var/log/app/*.log", job = "app" }]
}

실수 3: stage 순서 오류

JSON 파싱 전에 labels 스테이지를 쓰면 추출된 값이 없어 레이블이 비어 있습니다.

// ❌ JSON 파싱 전에 labels 스테이지
loki.process "wrong_order" {
  stage.labels {
    values = { level = "" }  // 아직 JSON에서 level을 추출 안 함 → 빈 값
  }
  stage.json {
    expressions = { level = "severity" }
  }
}

// ✅ json 먼저, labels 나중에
loki.process "correct_order" {
  stage.json {
    expressions = { level = "severity" }  // 1단계: 추출
  }
  stage.labels {
    values = { level = "" }               // 2단계: 레이블화
  }
}
