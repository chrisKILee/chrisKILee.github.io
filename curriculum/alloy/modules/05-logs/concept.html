Module 05 — 개념

로그 수집

로그 파이프라인 개요

Alloy는 loki.* 컴포넌트 패밀리로 로그를 수집, 처리, 전달합니다.

// 전체 로그 파이프라인 예시
loki.source.file "app_logs" {
  targets    = [{ __path__ = "/var/log/app/*.log", job = "app" }]
  forward_to = [loki.process.parse_json.receiver]
}

loki.process "parse_json" {
  forward_to = [loki.write.loki.receiver]

  stage.json {
    expressions = { level = "level", msg = "message" }
  }

  stage.labels {
    values = { level = "" }
  }
}

loki.write "loki" {
  endpoint {
    url = "http://loki:3100/loki/api/v1/push"
  }
}

loki.source.* — 로그 소스

컴포넌트설명
loki.source.file로컬 파일 테일링
loki.source.kubernetesKubernetes Pod 로그 (kubelet API)
loki.source.kubernetes_eventsKubernetes 이벤트 수집
loki.source.journalsystemd journal 로그
loki.source.apiHTTP API로 로그 수신 (push 방식)
loki.source.dockerDocker 컨테이너 로그

loki.source.kubernetes — Kubernetes 로그

// Kubernetes Pod 로그 수집
loki.source.kubernetes "pods" {
  targets    = discovery.relabel.pods.output
  forward_to = [loki.process.add_labels.receiver]
}

// 모든 Pod 디스커버리
discovery.kubernetes "pods" {
  role = "pod"
}

discovery.relabel "pods" {
  targets = discovery.kubernetes.pods.targets

  // Pod 이름을 레이블로
  rule {
    source_labels = ["__meta_kubernetes_pod_name"]
    target_label  = "pod"
  }

  // 네임스페이스 레이블
  rule {
    source_labels = ["__meta_kubernetes_namespace"]
    target_label  = "namespace"
  }

  // 컨테이너 이름
  rule {
    source_labels = ["__meta_kubernetes_pod_container_name"]
    target_label  = "container"
  }
}

loki.process — 로그 처리 파이프라인

다양한 처리 스테이지를 체인으로 연결합니다:

loki.process "pipeline" {
  forward_to = [loki.write.loki.receiver]

  // JSON 파싱
  stage.json {
    expressions = {
      level     = "severity",
      message   = "msg",
      trace_id  = "traceID",
    }
  }

  // 추출된 값을 레이블로
  stage.labels {
    values = {
      level = "",    // JSON에서 추출한 level 사용
    }
  }

  // 특정 레벨 이하 로그 드롭 (debug 제외)
  stage.drop {
    expression  = ".*"
    if          = "level == \"debug\""
    drop_counter_reason = "debug_log"
  }

  // 타임스탬프 파싱
  stage.timestamp {
    source = "time"
    format = "RFC3339"
  }

  // 구조화된 메타데이터 추가
  stage.structured_metadata {
    values = { trace_id = "" }
  }
}

loki.write — Loki 전송

loki.write "loki" {
  endpoint {
    url = "http://loki:3100/loki/api/v1/push"

    // 인증 (Grafana Cloud)
    basic_auth {
      username = env("LOKI_USER")
      password = env("LOKI_API_KEY")
    }

    // 배치 설정
    batch_wait   = "1s"
    batch_size   = 1048576  // 1MB
  }

  // 외부 레이블
  external_labels = {
    cluster = "prod-k8s",
  }
}
