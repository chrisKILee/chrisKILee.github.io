Module 07 — 퀴즈

고급 기능 학습 내용 확인

Q1. Alloy 클러스터링에서 여러 인스턴스가 스크래핑 타깃을 중복 없이 분배하려면?

clustering { enabled = true }를 prometheus.scrape 블록에 추가하면 클러스터 멤버 간에 타깃이 자동으로 분배됩니다. 중복 없이 샤딩됩니다.

Q2. 프로덕션에서 Alloy를 트레이스 파이프라인으로 배포할 때 권장 controller type은?

트레이스용 Alloy는 StatefulSet으로 배포합니다. Tail-based 샘플링에는 WAL(영구 스토리지)이 필요하고, 클러스터링으로 피어 발견에 stable network identity(Pod 이름)가 필요하기 때문입니다.

Q3. remote.kubernetes.configmap 컴포넌트의 역할은?

remote.kubernetes.configmap은 Kubernetes ConfigMap에서 설정 내용을 읽어와 Alloy 파이프라인에서 동적으로 사용할 수 있게 합니다. poll_frequency로 주기적으로 갱신됩니다.
