Module 06 — 퀴즈

트레이스 수집 학습 내용 확인

Q1. Tail-based 샘플링의 주요 장점은?

Tail-based 샘플링은 트레이스가 완료된 후 전체 결과(에러 발생 여부, 지연 시간 등)를 보고 저장 여부를 결정합니다. 에러나 느린 요청은 항상 저장하고, 정상 요청은 일부만 저장하는 스마트 전략이 가능합니다.

Q2. OTLP gRPC의 기본 수신 포트는?

OTLP gRPC는 4317, OTLP HTTP는 4318이 표준 포트입니다. 9411은 Zipkin, 14250은 Jaeger gRPC, 55678은 OpenCensus입니다.

Q3. otelcol 컴포넌트에서 tracing span을 다음 컴포넌트로 전달하는 방법은?

otelcol 컴포넌트는 output { traces/metrics/logs = [...] } 블록을 사용합니다. Prometheus/Loki의 forward_to와 혼동하지 마세요.
