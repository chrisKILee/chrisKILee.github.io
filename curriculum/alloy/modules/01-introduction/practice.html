실습: Alloy 첫 파이프라인 실행

Docker로 Alloy를 실행하고 첫 번째 파이프라인을 만들어 UI를 탐색합니다.

실습 환경 Docker가 설치된 환경이 필요합니다. kind 클러스터는 Module 02에서 사용합니다. 이 실습은 Docker만으로 진행합니다.

실습 1: Docker로 Alloy 실행

작업 디렉토리 만들기 
mkdir -p ~/alloy-lab/config
cd ~/alloy-lab
최소 설정 파일 작성

config/alloy.alloy 파일을 만듭니다:

// alloy.alloy — 첫 번째 파이프라인
// 자기 자신의 메트릭을 스크래핑해서 stdout에 출력합니다

prometheus.exporter.self "alloy_metrics" {}

prometheus.scrape "self" {
  targets    = prometheus.exporter.self.alloy_metrics.targets
  forward_to = [prometheus.remote_write.stdout.receiver]
}

// stdout 출력용 (테스트 목적)
prometheus.remote_write "stdout" {
  endpoint {
    url = "http://localhost:19999/api/v1/push"
  }
}
팁 prometheus.exporter.self는 Alloy 자신의 메트릭을 expose하는 내장 컴포넌트입니다.
Docker로 실행 
docker run -d \
  --name alloy \
  -p 12345:12345 \
  -v $(pwd)/config:/etc/alloy \
  grafana/alloy:latest \
  run /etc/alloy/alloy.alloy
컨테이너 로그 확인 
docker logs alloy

다음과 같은 로그가 보이면 정상입니다:

ts=... level=info msg="Alloy started"
ts=... level=info msg="HTTP server started" addr=0.0.0.0:12345

실습 2: Alloy UI 탐색

브라우저에서 UI 열기

브라우저에서 http://localhost:12345를 엽니다.

Graph 탭 확인

상단 메뉴에서 Graph를 클릭합니다. 컴포넌트 연결 관계가 시각적으로 표시됩니다:

  • prometheus.exporter.self.alloy_metrics
  • prometheus.scrape.self
  • prometheus.remote_write.stdout
컴포넌트 상태 확인

Components 탭 클릭 → 각 컴포넌트 이름 클릭:

  • Health: healthy / unhealthy
  • Arguments: 현재 설정값
  • Exports: 컴포넌트가 내보내는 값
메트릭 엔드포인트 확인 
curl http://localhost:12345/metrics | head -20

Alloy 자신의 Prometheus 메트릭이 출력됩니다.

실습 3: 설정 파일 수정 및 핫 리로드

설정에 로그 출력 추가

config/alloy.alloy에 다음을 추가합니다:

// 로컬 파일에서 로그 읽기 (테스트용 더미)
loki.source.file "demo" {
  targets    = [{ __path__ = "/var/log/*.log", job = "demo" }]
  forward_to = [loki.write.stdout.receiver]
}

loki.write "stdout" {
  endpoint {
    url = "http://localhost:3100/loki/api/v1/push"
  }
}
핫 리로드 트리거 
# Alloy는 SIGHUP으로 설정을 리로드합니다
docker kill --signal=SIGHUP alloy

# 또는 HTTP API 사용
curl -X POST http://localhost:12345/-/reload
UI에서 새 컴포넌트 확인

브라우저 새로고침 후 Graph 탭에서 loki 컴포넌트가 추가된 것을 확인합니다.

실습 4: 설정 문법 검증

# Docker 없이 문법 검증 (alloy 바이너리가 있는 경우)
alloy fmt config/alloy.alloy    # 포맷팅
alloy validate config/alloy.alloy  # 문법 검증

# Docker로 문법 검증
docker run --rm \
  -v $(pwd)/config:/etc/alloy \
  grafana/alloy:latest \
  validate /etc/alloy/alloy.alloy

정리

docker stop alloy
docker rm alloy
