Module 01 퀴즈

Alloy 소개 모듈에서 배운 내용을 확인합니다. 선택지를 클릭하세요.

Q1. Grafana Alloy가 기반으로 하는 업스트림 프로젝트는 무엇인가요?

Grafana Alloy는 OpenTelemetry Collector를 핵심 엔진으로 사용합니다. 이를 통해 OTel 생태계의 컴포넌트를 직접 활용하면서, Grafana 스택에 특화된 기능을 추가로 제공합니다.

Q2. Alloy 설정 파일의 확장자는 무엇인가요?

Alloy 설정 파일은 .alloy 확장자를 사용합니다. HCL에서 영감을 받은 자체 설정 언어를 사용하며, YAML이 아닙니다.

Q3. Alloy UI의 기본 포트는 무엇인가요?

Alloy는 기본적으로 localhost:12345에서 웹 UI를 제공합니다. UI에서 컴포넌트 그래프 시각화, 상태 확인, 디버깅을 할 수 있습니다.

Q4. 다음 설정에서 prometheus.scrape 컴포넌트의 레이블은 무엇인가요? prometheus.scrape "node_metrics" { ... }

Alloy 컴포넌트 선언 형식은 [네임스페이스].[타입] "[레이블]"입니다. prometheus.scrape "node_metrics"에서 레이블은 node_metrics입니다. 레이블은 같은 타입의 여러 컴포넌트를 구분하는 고유 식별자입니다.

Q5. Grafana Agent에서 Alloy로 마이그레이션할 때 사용할 수 있는 도구 명령어는?

Grafana가 공식 마이그레이션 도구를 제공합니다: alloy convert --source-format=agent --output=config.alloy agent-config.yaml 이 명령어는 Grafana Agent YAML을 Alloy 설정 언어로 자동 변환합니다.
