Grafana Alloy 소개

Alloy가 무엇인지, 왜 만들어졌는지, 핵심 개념을 이해합니다.

Grafana Alloy란?

Grafana Alloy는 2024년 Grafana Labs가 Grafana Agent의 후속으로 발표한 오픈소스 관측성 데이터 파이프라인 도구입니다. OpenTelemetry Collector를 핵심 엔진으로 사용하면서, Grafana 생태계에 특화된 기능을 더한 것이 특징입니다.

왜 Alloy인가?

Grafana Agent에서 Alloy로의 전환

Grafana Agent는 2019년 등장해 유용하게 쓰였지만, 설정이 복잡하고 확장성에 한계가 있었습니다. Alloy는 이를 해결하기 위해 다음 목표로 설계되었습니다:

  • 컴포넌트 기반 — 기능을 레고처럼 조합
  • 선언적 설정 — HCL-like 언어로 데이터 흐름 명시
  • 내장 UI — 컴포넌트 그래프 시각화, 실시간 디버깅
  • 클러스터링 — 수평 확장 내장 지원
  • OTel 호환 — OpenTelemetry Collector 컴포넌트 직접 사용
중요 Grafana Agent는 2024년 deprecated(지원 종료 예정) 선언되었습니다. 신규 프로젝트는 반드시 Alloy를 사용하세요.

Alloy 설정 언어 (Alloy Syntax)

Alloy는 자체 설정 언어를 사용합니다. HCL(HashiCorp Configuration Language)에서 영감을 받았으며, .alloy 확장자를 사용합니다.

기본 구조

// 컴포넌트 선언: [네임스페이스].[타입] "[레이블]" {
//   argument = 값
// }

prometheus.scrape "node_exporter" {
  targets = [{ "__address__" = "localhost:9100" }]
  forward_to = [prometheus.remote_write.mimir.receiver]
}

prometheus.remote_write "mimir" {
  endpoint {
    url = "http://mimir:9009/api/v1/push"
  }
}

}

컴포넌트 모델 기초

Alloy의 모든 기능은 컴포넌트로 구현됩니다. 컴포넌트는 입력(arguments)을 받아 처리하고, 출력(exports)을 다른 컴포넌트로 전달합니다.

Alloy UI

Alloy는 기본적으로 localhost:12345에서 웹 UI를 제공합니다. UI에서 다음을 확인할 수 있습니다:

  • 그래프 뷰 — 컴포넌트 연결 관계를 시각화
  • 컴포넌트 상태 — 각 컴포넌트의 현재 상태와 exports 값
  • 디버깅 — 실시간 데이터 흐름 확인
팁 UI에서 특정 컴포넌트를 클릭하면 현재 인자(arguments)와 내보내는 값(exports)을 실시간으로 볼 수 있습니다. 파이프라인 디버깅에 매우 유용합니다.
