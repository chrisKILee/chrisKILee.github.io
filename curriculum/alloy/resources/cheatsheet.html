빠른 참조 치트시트

Grafana Alloy 핵심 명령어, 컴포넌트, 설정 패턴을 한눈에 확인합니다.

CLI 명령어

alloy run config.alloy 설정 파일로 Alloy 실행
alloy run /etc/alloy/ 디렉토리의 모든 .alloy 파일 실행
alloy fmt config.alloy 설정 파일 포맷팅
alloy validate config.alloy 문법 검증
alloy convert --source-format=agent Grafana Agent → Alloy 변환
curl -X POST localhost:12345/-/reload 설정 핫 리로드

주요 CLI 플래그

--server.http.listen-addr=0.0.0.0:12345 UI 바인딩 주소
--storage.path=/var/lib/alloy WAL 저장 경로
--cluster.enabled 클러스터링 활성화
--cluster.join-peers=alloy-0:12345 클러스터 피어 지정
--stability.level=public-preview 실험적 기능 활성화

메트릭 컴포넌트

prometheus.scrape Prometheus 형식 스크래핑
prometheus.remote_write Mimir/Cortex/Prometheus 전송
prometheus.relabel 메트릭 레이블 변환/필터
prometheus.exporter.unix 시스템 메트릭 (Node Exporter)
prometheus.exporter.self Alloy 자신의 메트릭
prometheus.exporter.blackbox HTTP/TCP 프로브

로그 컴포넌트

loki.source.file 로컬 파일 테일링
loki.source.kubernetes Kubernetes Pod 로그
loki.source.kubernetes_events Kubernetes 이벤트
loki.source.journal systemd journal
loki.process 로그 처리 파이프라인
loki.write Loki로 전송

트레이스 컴포넌트

otelcol.receiver.otlp OTLP gRPC/HTTP 수신 (4317/4318)
otelcol.receiver.jaeger Jaeger 형식 수신
otelcol.processor.batch 배치 처리
otelcol.processor.tail_sampling Tail-based 샘플링
otelcol.exporter.otlp OTLP로 전송 (Tempo)
otelcol.connector.spanmetrics Span → RED 메트릭 변환

디스커버리 컴포넌트

discovery.kubernetes K8s pod/node/service/endpoints
discovery.relabel 디스커버리 결과 필터/변환
discovery.file 파일 기반 서비스 디스커버리
discovery.http HTTP 기반 서비스 디스커버리

Relabel Rule Actions

keep regex 일치 타깃만 유지
drop regex 일치 타깃 제거
replace 레이블 값 치환
labelmap regex로 레이블 이름 변환
labeldrop regex 일치 레이블 삭제
labelkeep regex 일치 레이블만 유지

loki.process 스테이지

stage.json JSON 필드 추출
stage.regex 정규식으로 값 추출
stage.labels 추출된 값을 레이블로
stage.drop 조건부 로그 드롭
stage.timestamp 로그 타임스탬프 파싱
stage.structured_metadata 인덱스 없는 메타데이터 추가

설정 언어 패턴

env("VAR") 환경 변수 읽기
local.file "name" { filename = "..." } 파일에서 값 읽기
is_secret = true UI/로그에서 마스킹
clustering { enabled = true } 컴포넌트 클러스터링 활성화

Kubernetes 메타데이터 레이블 (주요)

__meta_kubernetes_namespace 네임스페이스
__meta_kubernetes_pod_name Pod 이름
__meta_kubernetes_pod_container_name 컨테이너 이름
__meta_kubernetes_pod_annotation_* Pod 어노테이션
__meta_kubernetes_pod_label_* Pod 레이블
__meta_kubernetes_node_name 노드 이름

자주 쓰는 설정 스니펫

기본 메트릭 파이프라인 (Kubernetes)

discovery.kubernetes "pods" {
  role = "pod"
}

discovery.relabel "scrape_targets" {
  targets = discovery.kubernetes.pods.targets

  rule {
    source_labels = ["__meta_kubernetes_pod_annotation_prometheus_io_scrape"]
    action        = "keep"
    regex         = "true"
  }

  rule {
    source_labels = ["__meta_kubernetes_namespace"]
    target_label  = "namespace"
  }
}

prometheus.scrape "pods" {
  targets         = discovery.relabel.scrape_targets.output
  scrape_interval = "30s"
  forward_to      = [prometheus.remote_write.mimir.receiver]
}

prometheus.remote_write "mimir" {
  endpoint {
    url = env("MIMIR_URL")
  }
  external_labels = { cluster = env("CLUSTER_NAME") }
}

기본 로그 파이프라인 (Kubernetes)

discovery.kubernetes "pods" {
  role = "pod"
}

discovery.relabel "pods" {
  targets = discovery.kubernetes.pods.targets
  rule { source_labels = ["__meta_kubernetes_namespace"]; target_label = "namespace" }
  rule { source_labels = ["__meta_kubernetes_pod_name"]; target_label = "pod" }
  rule { source_labels = ["__meta_kubernetes_pod_container_name"]; target_label = "container" }
}

loki.source.kubernetes "pods" {
  targets    = discovery.relabel.pods.output
  forward_to = [loki.process.json.receiver]
}

loki.process "json" {
  forward_to = [loki.write.loki.receiver]
  stage.json { expressions = { level = "severity" } }
  stage.labels { values = { level = "" } }
}

loki.write "loki" {
  endpoint { url = env("LOKI_URL") }
}

기본 트레이스 파이프라인

otelcol.receiver.otlp "default" {
  grpc { endpoint = "0.0.0.0:4317" }
  http { endpoint = "0.0.0.0:4318" }
  output { traces = [otelcol.processor.batch.default.input] }
}

otelcol.processor.batch "default" {
  timeout         = "5s"
  send_batch_size = 1000
  output { traces = [otelcol.processor.tail_sampling.smart.input] }
}

otelcol.processor.tail_sampling "smart" {
  decision_wait = "30s"
  policy { name = "errors"; type = "status_code"; status_code { status_codes = ["ERROR"] } }
  policy { name = "slow"; type = "latency"; latency { threshold_ms = 1000 } }
  policy { name = "sample-10"; type = "probabilistic"; probabilistic { sampling_percentage = 10 } }
  output { traces = [otelcol.exporter.otlp.tempo.input] }
}

otelcol.exporter.otlp "tempo" {
  client { endpoint = env("TEMPO_URL"); tls { insecure = true } }
}
