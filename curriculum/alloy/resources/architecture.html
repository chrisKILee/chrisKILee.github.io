메트릭 파이프라인 상세

Prometheus 메트릭 수집 파이프라인
sequenceDiagram
  participant target as 스크래핑 타깃
  participant scrape as prometheus.scrape
  participant relabel as prometheus.relabel
  participant wal as WAL (Write-Ahead Log)
  participant rw as prometheus.remote_write
  participant mimir as Mimir

  loop 매 scrape_interval
    scrape ->> target: HTTP GET /metrics
    target -->> scrape: Prometheus text format
    scrape ->> relabel: 레이블 변환/필터링 요청
    relabel -->> scrape: 처리된 메트릭
    scrape ->> wal: 메트릭 저장
  end

  loop 주기적 배치 전송
    wal ->> rw: 배치 읽기
    rw ->> mimir: HTTP POST /api/v1/push
    mimir -->> rw: 200 OK
    rw ->> wal: 전송 완료 표시
  end

  keep --> tempo
