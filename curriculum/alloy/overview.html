커리큘럼 개요

Grafana Alloy 전체 학습 경로와 선수 지식, 목표를 확인합니다.

Grafana Alloy란?

Grafana Alloy는 Grafana Labs가 2024년 공개한 오픈소스 관측성 데이터 수집기입니다. 기존 Grafana Agent를 대체하며, OpenTelemetry Collector 프레임워크 위에 구축되었습니다. 메트릭·로그·트레이스·프로파일을 단일 에이전트로 수집·처리·전달할 수 있습니다.

핵심 특징은 컴포넌트 기반 파이프라인입니다. 레고 블록처럼 컴포넌트를 연결해 데이터 흐름을 구성하고, 설정 언어(Alloy syntax)로 선언적으로 표현합니다.

팁 Module 03(컴포넌트)을 마친 후 메트릭·로그·트레이스 모듈은 병렬로 학습해도 됩니다. 각 모듈은 독립적으로 구성되어 있습니다.

모듈별 학습 목표

Module 01 — Alloy 소개

  • Grafana Alloy의 탄생 배경과 Grafana Agent와의 차이 설명
  • OpenTelemetry Collector 대비 Alloy의 추가 가치 설명
  • Alloy 설정 언어 기본 문법 작성
  • Alloy UI(웹 인터페이스) 활용

Module 02 — 설치 및 기본 설정

  • apt/rpm 패키지, Docker, Helm으로 Alloy 설치
  • 기본 설정 파일 구조 이해 및 작성
  • systemd 서비스로 Alloy 관리
  • 첫 번째 데이터 파이프라인 실행 및 검증

Module 03 — 컴포넌트 & 파이프라인

  • 컴포넌트의 arguments, exports 구조 이해
  • 컴포넌트 간 참조(reference)로 파이프라인 구성
  • 범용 컴포넌트(otelcol.*, discovery.*, local.*) 활용
  • Alloy UI에서 컴포넌트 그래프 시각화

Module 04 — 메트릭 수집

  • prometheus.scrape로 타깃 스크래핑 설정
  • discovery.kubernetes, discovery.relabel로 서비스 디스커버리
  • 메트릭 변환(prometheus.relabel), 필터링 적용
  • prometheus.remote_write로 Mimir/Cortex 전송

Module 05 — 로그 수집

  • loki.source.file, loki.source.kubernetes_events로 로그 수집
  • loki.process로 로그 파싱 및 레이블 처리
  • 구조화된 로그(JSON) 처리 파이프라인 구성
  • loki.write로 Loki 백엔드 전송

Module 06 — 트레이스 수집

  • otelcol.receiver.otlp로 OTLP 수신기 설정
  • 트레이스 처리 컴포넌트(배치, 샘플링) 적용
  • otelcol.exporter.otlp로 Tempo 전송
  • Tail-based 샘플링 전략 설계

Module 07 — 고급 기능 & 운영

  • Alloy 클러스터링으로 HA 구성
  • TLS, 인증 설정으로 보안 강화
  • 성능 튜닝 및 메모리 제한 설정
  • Kubernetes DaemonSet/Deployment 패턴으로 프로덕션 배포
