> 💻 **인터랙티브 전체 가이드(SVG 다이어그램·비교표 포함):** [Dev Guide · Codex CLI →](/dev-guide/codex_cli.html)

Codex는 OpenAI의 코딩 에이전트로, 터미널에서 대화형으로 코드를 읽고 수정하고 명령을 실행한다. ChatGPT 계정으로 로그인해 바로 쓰거나 API 키로도 동작한다.

# 설치 & 인증

```bash
# npm (전역)
npm install -g @openai/codex

# Homebrew
brew install --cask codex

# 설치 스크립트 (Mac/Linux)
curl -fsSL https://chatgpt.com/codex/install.sh | sh

# 시작
codex
```

**인증** — `codex` 실행 후 **"Sign in with ChatGPT"** 가 권장 방식이며 Plus·Pro·Business·Edu·Enterprise 플랜과 통합된다. 또는 `OPENAI_API_KEY` 환경변수로 API 키 인증도 가능하다.

# 대화형 vs 비대화(exec)

```bash
# 대화형 TUI
codex

# 작업 지시와 함께 시작
codex "refactor utils.py and add unit tests"

# 비대화 실행 (스크립트/CI)
codex exec "run the test suite and summarize failures"

# 데스크톱 앱
codex app
```

# 핵심 기능

| 기능 | 설명 |
|------|------|
| **대화형 TUI** | `codex`로 터미널 UI 진입, 편집·명령 실행을 승인 |
| **모델 전환** | 세션 안에서 `/model`로 모델 변경 및 추론 강도 조정 |
| **MCP 지원** | 서드파티 도구·컨텍스트를 Codex에 연결 |
| **승인 모드** | 파일 편집·명령 실행 전 사용자 편의 수준에 맞는 승인 모드 선택 |
| **IDE 통합** | VS Code·Cursor·Windsurf, 웹(chatgpt.com/codex)은 클라우드 에이전트 |
| **설정 파일** | `~/.codex/config.toml`로 기본 모델·승인 정책·MCP 서버 구성 |

> ⚠️ Codex는 파일 쓰기/명령 실행 범위를 제어하는 승인 모드·샌드박스를 제공한다. 자동 실행 범위를 넓힐수록 편하지만 위험도 커지므로 신뢰할 수 있는 작업에만 넓은 권한을 부여한다. 정확한 플래그/정책 값은 [공식 CLI 레퍼런스](https://developers.openai.com/codex/cli)를 확인.

# 설정 예시 (~/.codex/config.toml)

```toml
# 실제 키/값은 공식 Config Reference 참조
model = "gpt-5-codex"

# MCP 서버 등록
[mcp_servers.filesystem]
command = "npx"
args = ["-y", "@modelcontextprotocol/server-filesystem", "."]
```

# Claude Code vs Codex (요약)

| 항목 | Claude Code | Codex CLI |
|------|-------------|-----------|
| 제공사 | Anthropic | OpenAI |
| 설치 | `claude.ai/install.sh` · brew · winget | `@openai/codex` · brew · 스크립트 |
| 실행 | `claude` / `-p` | `codex` / `codex exec` |
| 인증 | Claude 구독·Console | ChatGPT 로그인·API 키 |
| 설정 | CLAUDE.md · settings | `~/.codex/config.toml` |
