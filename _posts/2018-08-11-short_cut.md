> 손이 키보드를 떠나지 않게 하는 것이 생산성의 핵심. Vim 이동·편집부터 tmux 세션, iTerm·macOS 단축키까지 모았다.

# Vi / Vim

## Navigation (이동)

- `H` `J` `K` `L` - 왼쪽 / 아래 / 위 / 오른쪽
- `w` / `b` - 다음 단어 / 이전 단어 시작
- `e` - 단어 끝
- `0` / `^` / `$` - 줄 맨 앞 / 첫 글자 / 줄 끝
- `⇧` + `G` - 문서 맨 아래
- `g` `g` - 문서 맨 위
- `:42` - 42번째 줄로 이동
- `{` / `}` - 이전 / 다음 문단
- `⌃` + `d` / `⌃` + `u` - 반 페이지 아래 / 위

## Fast Search (검색)

- `/term` - 아래로 검색
- `?term` - 위로 검색
- `n` / `⇧` + `N` - 다음 / 이전 결과
- `*` - 커서 아래 단어를 검색
- `:noh` - 검색 하이라이트 끄기

## Command mode (명령)

- `:` - 명령 모드 진입
- `:w` - 저장
- `:q` - 종료
- `:q!` - 저장 없이 종료
- `:wq` / `ZZ` - 저장 후 종료
- `:e filename` - 파일 열기
- `Esc` - 명령 모드 탈출
- `u` / `⌃` + `r` - 실행 취소 / 다시 실행

## Editor Mode (편집)

- `i` / `⇧` + `I` - 현재 위치 / 줄 맨 앞에서 삽입
- `a` / `⇧` + `A` - 뒤에서 / 줄 끝에서 삽입
- `o` / `⇧` + `O` - 아래 / 위에 새 줄
- `s` / `⇧` + `S` - 글자 / 줄 삭제 후 삽입
- `r` - 한 글자 교체
- `cw` - 단어 변경 (change word)

## 삭제 · 복사 · 붙여넣기

- `x` - 한 글자 삭제
- `dd` / `dw` / `d$` - 줄 / 단어 / 줄 끝까지 삭제(잘라내기)
- `yy` / `yw` - 줄 / 단어 복사
- `p` / `⇧` + `P` - 커서 뒤 / 앞에 붙여넣기
- `.` - 직전 명령 반복

## Advanced (중급 이상)

```vim
" 치환 (전체 파일, 확인 포함)
:%s/old/new/gc

" Visual 모드 — 블록 선택 후 편집
v        " 문자 단위 선택
⇧ + V    " 줄 단위 선택
⌃ + v    " 블록(열) 선택 → 여러 줄 동시 편집

" 마커
ma       " 현재 위치를 a 마커로 저장
`a       " a 마커로 점프

" 매크로
qa       " a 레지스터에 매크로 기록 시작
q        " 기록 종료
@a       " 매크로 실행
10@a     " 10번 반복

" 들여쓰기 / 정렬
>>  <<   " 오른쪽 / 왼쪽 들여쓰기
gg=G     " 문서 전체 자동 들여쓰기
```

# tmux (터미널 멀티플렉서)

세션을 유지해 SSH가 끊겨도 작업이 살아있다. 기본 prefix는 `⌃` + `b`.

```bash
tmux                    # 새 세션
tmux new -s work        # 이름 있는 세션
tmux ls                 # 세션 목록
tmux attach -t work     # 세션 재접속
```

- `prefix` `c` - 새 창(window)
- `prefix` `,` - 창 이름 변경
- `prefix` `n` / `p` - 다음 / 이전 창
- `prefix` `%` - 좌우 분할
- `prefix` `"` - 상하 분할
- `prefix` `방향키` - 분할 패널 이동
- `prefix` `d` - 세션 분리(detach, 백그라운드 유지)
- `prefix` `x` - 패널 닫기

# iTerm2

## 여러 터미널 (탭)

- `⌘` + `T` - 새 탭
- `⌘` + `←` / `→` - 이전 / 다음 탭
- `⌘` + `w` - 탭 닫기

## 한 탭 안에서 분할

- `⌘` + `D` - 세로 분할
- `⇧` + `⌘` + `D` - 가로 분할
- `⌘` + `]` / `[` - 다음 / 이전 패널
- `⌥` + `⌘` + `방향키` - 방향으로 패널 이동

## 기타

- `⌘` + `K` - 버퍼 비우기(화면 정리)
- `⌘` + `-` / `0` / `+` - 글꼴 축소 / 기본 / 확대
- `⌘` + `F` - 검색
- `⌥` + `클릭` - 커서를 클릭 위치로 이동

# macOS

- `⌃` + `⌘` + `Space` - 특수문자 / 이모지 입력
- `⌘` + `,` - 환경설정
- `⌘` + `Space` - Spotlight 검색
- `⌃` + `←` / `→` - 데스크톱(스페이스) 전환
- `⌘` + `⇧` + `4` - 영역 스크린샷
- `⌘` + `⇧` + `5` - 화면 녹화 / 캡처 옵션
- `⌘` + `⌥` + `Esc` - 강제 종료 메뉴
