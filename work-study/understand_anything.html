5개 AI 에이전트가 분업하여 분석

각 에이전트가 전문 영역을 담당하고, 분석 결과를 통합해 하나의 시각적 지식 그래프로 출력합니다.

핵심 기능

코드 파악 시간을 단축하는 3가지 기능

새 프로젝트에 합류했거나 복잡한 레거시(오래된 기존 코드)를 분석해야 할 때 가장 빛납니다.

🗺

인터랙티브 지식 그래프

전체 코드베이스를 노드(파일·함수)와 엣지(의존성·호출 관계)로 시각화합니다. 각 노드를 클릭하면 AI가 쉬운 말로 해당 코드의 역할을 요약해줍니다.

/understand
💬

자연어 코드 Q&A

코드에 대해 궁금한 것을 채팅하듯 물어볼 수 있습니다. "이 함수는 어디서 호출되나요?" "인증 로직은 어디 있나요?" 같은 질문에 답해줍니다.

/understand-chat
🔍

변경 영향도 미리보기

커밋(코드 저장) 전, 내 수정 사항이 다른 파일·함수에 어떤 영향을 미치는지 사전에 파악할 수 있어 예상치 못한 버그를 예방합니다.

/understand-diff
내부 구조

5개 AI 에이전트 상세

각 에이전트는 전문 역할을 분담하여 병렬로 실행됩니다. 분업을 통해 분석 속도와 정확도를 높입니다.

1

구조 에이전트

파일·폴더 계층 구조를 파악하고 모듈 경계를 식별합니다.

2

함수 에이전트

함수·클래스·메서드를 추출하고 시그니처(입출력)를 기록합니다.

3

의존성 에이전트

import·require 관계와 함수 호출 관계를 그래프로 매핑합니다.

4

요약 에이전트

각 노드(파일·함수)를 비개발자도 이해할 수 있는 쉬운 말로 설명합니다.

5

영향도 에이전트

코드 변경 시 파급 범위를 예측해 /understand-diff 출력을 생성합니다.

명령어 가이드

3가지 명령어로 모든 것 해결

Claude Code 터미널에서 슬래시(/) 명령어로 바로 실행합니다. 총 6가지 명령어를 제공합니다.

/understand

지식 그래프 분석 실행

현재 프로젝트 전체를 분석해 지식 그래프를 생성하고 .understand-anything/knowledge-graph.json에 저장합니다.

/understand-dashboard

인터랙티브 시각화 대시보드 열기

분석 결과를 브라우저에서 노드-엣지(연결선) 그래프로 시각화합니다. 노드를 클릭하면 AI가 해당 코드를 쉬운 말로 설명합니다.

/understand-chat <질문>

코드에 대해 자연어로 질문

코드베이스를 컨텍스트(배경 지식)로 삼아 자연어 질의응답을 제공합니다. 예: "결제 흐름은 어떻게 동작하나요?"

/understand-diff

변경 영향 범위 사전 파악

현재 스테이징(커밋 준비 중인) 변경 사항이 기존 코드에 미치는 영향을 분석합니다. 커밋 전에 실행해 예기치 않은 부수 효과(side effect)를 사전에 확인하세요.

/understand-explain <경로>

특정 파일·함수 심층 분석

파일 경로나 함수명을 지정하면 해당 코드를 집중적으로 분석해 역할·의존성·호출 관계를 설명합니다.

/understand-onboard

온보딩 가이드 자동 생성

새 팀원을 위한 프로젝트 온보딩(합류 안내) 문서를 자동으로 생성합니다. 핵심 모듈·아키텍처·시작 방법을 정리합니다.

설치 방법

명령어 한 줄로 설치

Claude Code가 설치된 환경이라면 플러그인 추가만으로 바로 사용할 수 있습니다.

# 1. Claude Code 플러그인 마켓플레이스에서 설치 (명령어 한 줄)
/plugin marketplace add Lum1104/Understand-Anything

# 2. 설치 확인
/plugin install understand-anything

# 3. 분석하고 싶은 프로젝트 폴더에서 실행
/understand

# 4. 시각화 대시보드 열기
/understand-dashboard

# 5. 코드에 대해 자연어로 질문하기
/understand-chat 결제 흐름은 어떻게 동작하나요?

# 6. 커밋 전 변경 영향도 확인
/understand-diff
활용 시나리오

이럴 때 특히 유용합니다

코드를 처음 보거나, 구조가 복잡한 프로젝트를 파악해야 할 때 시간을 크게 절약합니다.

🚀 새 프로젝트 온보딩

  • 팀에 합류해 낯선 코드베이스를 처음 파악할 때
  • 전체 구조를 빠르게 조감(큰 그림으로 파악)하고 싶을 때
  • "어디서부터 봐야 하지?" 막막할 때
  • 핵심 모듈과 진입점(entry point)을 빠르게 찾고 싶을 때

🏗 레거시 코드 분석

  • 몇 년 된 복잡한 기존 코드를 분석해야 할 때
  • 문서(주석)가 부족한 프로젝트를 이해해야 할 때
  • 특정 기능을 수정하기 전 영향 범위를 파악할 때
  • 팀원이 없고 코드만 남아있는 상황에서 구조를 파악할 때
기존 방법과 비교

Understand Anything vs 기존 방식

수작업으로 코드를 읽는 것 대비 어떤 점이 다른지 정리했습니다.

항목 기존 방식 (수작업) Understand Anything
전체 구조 파악 파일을 하나씩 열어 직접 읽기 ✓ 시각적 그래프로 즉시 파악
함수 역할 이해 코드를 직접 해석 ✓ 노드 클릭 → 쉬운 말로 AI 요약
의존성 파악 import 문을 추적하며 수동 매핑 ✓ 자동으로 그래프 생성
코드 Q&A 팀원에게 물어보거나 문서 검색 ✓ /understand-chat으로 즉시 답변
변경 영향 분석 머릿속으로 추정하거나 테스트로 확인 ✓ /understand-diff로 사전 파악
