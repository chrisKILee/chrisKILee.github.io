◆ Lightpanda Guide
성능 특징 설치 한계 활용 예
Headless Browser · 오픈소스 · AGPL-3.0

Chrome의 80%를 버렸다. 속도는 11배가 됐다.

Lightpanda는 AI 에이전트와 웹 자동화를 위해 처음부터 새로 만든 headless 브라우저입니다. 화면 렌더링 없이 JavaScript 실행과 DOM 조작만 남겨, Chrome 대비 극적으로 빠르고 가볍습니다. Playwright · Puppeteer와 그대로 연결됩니다.

📅 2026-03-24 · ⭐ 24,300 GitHub Stars · 🔧 Zig 언어로 작성

02 — Architecture

왜 이렇게 빠른가?

Chrome에서 자동화에 필요 없는 부분을 의도적으로 제거했기 때문입니다.

⚡
렌더링 엔진 제거
Blink(렌더링), CSS 엔진, GPU 컴포지팅, 폰트 렌더링 등 Chrome 복잡도의 80%를 차지하는 부분을 완전히 제거했습니다. 화면을 그릴 필요가 없으니 필요 없는 기능입니다.
🦎
Zig 언어로 네이티브 작성
Chrome(C++)과 달리 Zig로 처음부터 headless 목적으로만 설계했습니다. 메모리 관리를 수동으로 제어하여 GC(가비지 컬렉션) 오버헤드 없이 극도로 효율적입니다.
🔌
CDP 호환 — 기존 코드 그대로
17개 CDP(Chrome DevTools Protocol) 도메인을 구현했습니다. Puppeteer, Playwright, chromedp 코드에서 launch()를 connect()로만 바꾸면 즉시 연결됩니다.
🤖
V8 JavaScript 완전 지원
Chrome과 동일한 V8 엔진을 사용합니다. JavaScript가 필요한 현대 웹사이트(SPA, React, Vue 등)를 정상적으로 실행하고 DOM을 조작할 수 있습니다.
🐳
Docker 즉시 사용
공식 Docker 이미지를 제공합니다. 단 한 줄로 CDP 서버를 실행할 수 있습니다. amd64, arm64 모두 지원합니다.
🔓
100% 오픈소스 (AGPL-3.0)
완전한 오픈소스입니다. 소스코드를 직접 수정하거나 기여할 수 있습니다. GitHub 스타 24,300개 이상. 회사는 관리형 클라우드 서비스로 수익화합니다.
03 — Installation

설치 및 연동

3가지 방법으로 설치할 수 있습니다. 가장 빠른 방법은 Docker입니다.

01
Docker로 실행 (권장)
가장 빠르게 시작하는 방법입니다. CDP 서버가 9222 포트에서 시작됩니다.
bash
docker run -d --name lightpanda -p 9222:9222 lightpanda/browser:nightly
02
원라이너 설치 (Linux / macOS)
curl, jq, sha256sum이 필요합니다. 최신 nightly 빌드를 자동으로 설치합니다.
bash
curl -fsSL https://pkg.lightpanda.io/install.sh | bash
03
Puppeteer 연동
기존 코드에서 launch()를 connect()로만 바꾸면 됩니다. 다른 코드는 그대로입니다.
javascript
const puppeteer = require('puppeteer'); // 기존 Chrome 방식 (변경 전) // const browser = await puppeteer.launch(); // Lightpanda 방식 (변경 후) — connect()로만 바꾸면 끝 const browser = await puppeteer.connect({ browserWSEndpoint: 'ws://localhost:9222' }); const page = await browser.newPage(); await page.goto('https://example.com'); const title = await page.title(); console.log('페이지 제목:', title); await browser.close();
💡 Puppeteer는 안정적으로 호환됩니다. Playwright는 기본 기능은 작동하지만 일부 고급 기능은 아직 개발 중입니다.
04
텔레메트리(사용 통계 수집) 비활성화
기본값으로 익명 사용 통계를 수집합니다. 원하지 않으면 환경 변수로 끄세요.
bash
export LIGHTPANDA_DISABLE_TELEMETRY=true
플랫폼 지원 여부 비고
Linux x86_64 ✓ 지원 Nightly 빌드 제공
macOS Apple Silicon ✓ 지원 aarch64 바이너리 제공
macOS Intel (x86_64) △ 부분 Docker 또는 소스 빌드 필요
Windows ✕ 미지원 WSL2 내 Linux로 우회 가능
04 — Limitations

현재 한계와 주의사항

Beta 단계입니다. 프로덕션 도입 전에 아래 항목을 반드시 확인하세요.

⚠️ Beta 소프트웨어입니다. 간헐적 충돌 및 안정성 문제가 있을 수 있습니다. Google 검색 등 봇 탐지가 강한 사이트는 차단됩니다.
🚫
멀티탭 미지원
현재 CDP 연결 하나당 하나의 탭만 지원합니다. 여러 탭을 동시에 열어야 하는 작업은 불가합니다. 다중 인스턴스를 별도로 실행해야 합니다.
🤖
봇 탐지 우회 불가
Google, Cloudflare 봇 탐지 시스템에 차단됩니다. 브라우저 핑거프린팅 기반으로 Lightpanda를 감지합니다. 공격적 우회 기능이 없습니다.
📋
Web API 미구현 다수
수백 개의 Web API가 아직 구현되지 않았습니다. history.pushState(), 일부 location 객체 등이 불완전합니다. 복잡한 SPA에서 문제가 생길 수 있습니다.
🎨
CSS 레이아웃 정보 없음
CSS 렌더링 엔진이 없으므로 요소의 실제 화면 위치(getBoundingClientRect 등)를 알 수 없습니다. 스크린샷, 시각적 테스트에는 사용할 수 없습니다.
기능지원비고
JavaScript 실행 (V8) ✓ Chrome과 동일한 V8
DOM 조작 ✓ 네이티브 Zig 구현
Fetch / XHR 요청 ✓ 네트워크 인터셉션 포함
Cookie 관리 ✓ 설정·조회 모두 지원
Form 입력 처리 ✓
Playwright 연동 △ WIP 기본 작동, 고급 기능 불안정
멀티탭 ✕ 1 CDP = 1 탭
스크린샷 ✕ 렌더링 엔진 없음
Windows 네이티브 ✕ WSL2 우회 필요
05 — Use Cases

실전 활용 예시

AI 에이전트, 대규모 크롤링, 자동화 파이프라인에 적합합니다.

🤖
AI 에이전트 웹 탐색
LLM 기반 AI 에이전트가 웹사이트를 탐색할 때 사용합니다. 1,000개 요청을 병렬로 보내도 메모리가 감당됩니다. Chrome이었으면 서버가 OOM으로 죽었을 부하입니다.
📊
경쟁사 모니터링 자동화
매일 경쟁사의 가격 페이지, 랜딩 페이지를 스크래핑해 Slack으로 요약 보고. Lightpanda로 처리 시간을 10분의 1로 줄이고 서버 비용도 절감합니다.
🧠
LLM 훈련 데이터 수집
대규모 웹 크롤링으로 LLM 훈련용 데이터셋을 만들 때 사용합니다. JavaScript 렌더링이 필요한 현대 웹사이트의 텍스트를 정상적으로 추출합니다.
🧪
CI/CD 회귀 테스트
PR 머지 시 자동으로 웹사이트 핵심 동작을 테스트합니다. Chrome 대비 9배 빠르므로 CI 파이프라인 병목이 줄어듭니다. 스크린샷 비교는 불가능합니다.
💼
업무 자동화 봇
사내 시스템, 레거시 웹 앱의 반복 작업을 자동화합니다. 로그인 → 데이터 수집 → 보고서 생성 흐름에 적합합니다. 봇 탐지가 없는 내부 시스템에 이상적입니다.
📡
API 없는 사이트 데이터 추출
공개 API가 없는 사이트에서 JavaScript로 동적 렌더링되는 데이터를 추출합니다. 1,000개 제품 페이지 기준 Chrome 45~60초 → Lightpanda 4~5초.
💡
Lightpanda가 적합한 경우
JavaScript 실행이 필요한 현대 웹사이트 크롤링 · AI 에이전트 웹 탐색 · 대규모 병렬 자동화 · 봇 탐지 없는 내부 시스템 자동화

Chrome이 더 나은 경우
스크린샷 / 시각적 회귀 테스트 · Google 등 봇 탐지가 강한 사이트 · 멀티탭 동시 작업 · CSS 레이아웃 정보가 필요한 경우
