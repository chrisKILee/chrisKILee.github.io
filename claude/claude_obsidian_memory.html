💸 무료 설정 📝 마크다운 기반 🔌 2700+ 플러그인 🧠 컨텍스트 성능 향상
01 Obsidian

Obsidian이란 무엇인가?

Obsidian은 마크다운 파일(.md) 위에 얹는 무료 조직화 레이어입니다. 특정 폴더를 "Vault(보관함)"로 지정하면 그 안의 모든 파일을 연결하고 시각화할 수 있습니다.

🗂️
Vault (보관함)

어느 폴더든 Vault로 지정할 수 있습니다. 그 폴더 안의 모든 .md 파일이 하나의 지식 베이스가 됩니다. 새 폴더를 만들어도 되고, 기존 프로젝트 폴더를 그대로 사용해도 됩니다.

기본 개념
🔗
파일 링킹

[[파일명]] 문법으로 다른 .md 파일을 연결합니다. 연결된 파일들은 그래프 뷰에서 노드로 시각화됩니다. Claude Code가 이 링크 구조를 따라 관련 문서를 탐색할 수 있습니다.

핵심 기능
🧩
2700+ 플러그인

캘린더, 칸반 보드, 코드 실행, AI 연동 등 방대한 플러그인 생태계를 갖추고 있습니다. 커뮤니티 플러그인은 모두 무료로 설치할 수 있습니다.

확장성
02 가치

세 가지의 공생 관계

당신, Obsidian, Claude Code 세 가지가 서로를 강화하는 구조입니다. 각각이 없으면 생기는 한계를 나머지가 채워줍니다.

핵심 인사이트
Claude Code가 Obsidian 형식(.md + 링크)으로 문서를 작성하면, 나중에 Claude Code가 그 문서를 읽을 때 링크 구조를 따라 대용량 문서도 효율적으로 탐색할 수 있습니다. 블랙박스 효과를 제거합니다.
03 설치

설치 방법 (3단계)

설치 자체는 5분이면 완료됩니다.

사전 조건
Claude Code가 이미 설치되어 있어야 합니다. Obsidian은 무료이며 어떤 OS에서도 동작합니다.
1
Obsidian 다운로드
obsidian.md에 접속하여 Download 버튼을 클릭합니다. Windows, macOS, Linux 모두 지원합니다.
2
Vault 폴더 지정
설치 마법사를 실행하면 Vault로 사용할 폴더를 지정하라고 합니다. 어떤 폴더든 Vault가 될 수 있습니다 — 새 폴더를 만들거나 기존 프로젝트 폴더를 그대로 사용합니다.
3
Claude Code를 Vault 안에서 실행
Vault로 지정한 폴더 안에서 터미널을 열고 Claude Code를 실행합니다. 이것이 연동의 전부입니다.
bash 
cd ~/TheVault    # Vault로 지정한 폴더로 이동
claude           # Claude Code 실행 — 이제 Vault 안에서 작업
Claude Code 버전 정보(Opus/Max 등)와 함께 Vault 경로가 표시되면 성공입니다.
04 연동

Claude Code에게 Obsidian 규칙 따르도록 지시

Vault 안에서 Claude Code를 실행한 뒤, 자연어로 Obsidian 규칙을 따르도록 지시합니다.

핵심 프롬프트
Claude Code에게 이렇게 말합니다:
"이 Vault의 모든 .md 파일에 Obsidian 규칙을 적용해줘. 파일 링크는 [[파일명]] 형식을 사용하고, 태그는 #태그 형식으로 달아줘."
터미널 예시 
Claude Code v2.1.68
Opus 4.6 · Claude Max
~/TheVault

> 이 Vault의 모든 .md 파일에 Obsidian 링크 규칙을 따라줘.
  새 문서 만들 때 관련 문서는 [[파일명]]으로 연결해줘.
왜 이게 중요한가?
Claude Code가 [[링크]] 구조로 문서를 생성하면, 이후 세션에서 해당 링크를 따라 관련 문서를 효율적으로 찾아갑니다. 수백 개의 .md 파일이 있어도 관련 내용을 찾아내는 성능이 크게 향상됩니다.

06 베스트 프랙티스

최대 효과를 내는 방법

Claude Code + Obsidian Vault를 최대한 활용하는 두 가지 핵심 원칙입니다.

🧠
claude.md = 두뇌 속 두뇌

Vault 루트에 claude.md를 만들고, Claude Code가 이 Vault를 다루는 방법·규칙·컨텍스트를 여기에 모읍니다. Claude Code는 매 세션마다 이 파일을 읽어 Vault 전체의 "뇌"처럼 활용합니다.

핵심 설정
🔄
자기 업데이트 루프

새 .md 파일이 쌓일수록 Claude Code에게 claude.md 안의 컨벤션을 스스로 업데이트하도록 지시합니다. Vault가 성장할수록 Claude Code의 탐색 효율도 함께 올라갑니다.

자동화
프롬프트 예시 — 자기 업데이트
"Vault에 새 파일들이 추가됐어. claude.md에 있는 컨벤션이 여전히 유효한지 확인하고, 필요하면 업데이트해줘."
