AI Concepts AI 개념

  • Extended Context Window — 최대 200,000 토큰의 긴 문서를 한 번에 처리하는 능력
  • Adaptive Thinking — 문제 복잡도에 따라 사고 깊이를 자동 조절 (구 Extended Thinking)
  • In-Context Learning — 프롬프트 안에 예시를 넣어 즉시 학습시키는 방식
  • Constitutional AI — 규칙 집합을 기반으로 안전하게 응답을 생성하는 Anthropic 훈련 방법론
  • RLHF — 인간 피드백 강화학습. 사람의 선호를 반영해 모델을 개선
  • Hallucination — AI가 사실이 아닌 내용을 그럴듯하게 생성하는 현상
  • Tokenization — 텍스트를 AI가 처리 가능한 숫자 조각(토큰)으로 분할하는 과정
  • Temperature — 응답의 창의성·다양성을 조절하는 파라미터 (0 = 일정, 1 = 창의적)

Products 제품

  • Claude 3.7 Sonnet — 최신 플래그십 모델. 코딩·분석·200k 컨텍스트 지원
  • claude.ai — 웹/앱 기반 Claude 대화 인터페이스 (무료 + Pro 플랜)
  • Claude API — 개발자가 Claude 기능을 자체 앱에 통합할 수 있는 HTTP API
  • Claude Code — 터미널 기반 AI 코딩 에이전트 (이 사이트 제작 도구)
  • Claude for Enterprise — 기업용 보안·관리 기능 탑재 버전
  • Workspaces — API 사용량 및 팀 권한을 조직 단위로 관리하는 대시보드
  • Model Tiers — Haiku(빠름/저렴) → Sonnet(균형) → Opus(최고성능) 3단계
  • Prompt Library — Anthropic 공식 제공 검증된 프롬프트 모음

Core Features 핵심 기능

  • Tool Use (Function Calling) — Claude가 외부 함수·API를 직접 호출하는 기능
  • System Prompt — 대화 전체에 적용되는 역할·규칙을 설정하는 숨겨진 지시문
  • Artifacts — 코드·문서·SVG 등 결과물을 별도 창에 렌더링하는 기능
  • Vision — 이미지·PDF·차트를 분석하고 이해하는 멀티모달 기능
  • Streaming — 응답을 단어 단위로 실시간 전달하는 방식 (타이핑 효과)
  • Prompt Caching — 반복 사용되는 프롬프트를 캐싱해 비용·속도 최적화
  • Batch API — 대량 요청을 비동기로 처리해 50% 비용 절감
  • Citations — 문서 기반 답변 시 출처 구절을 자동 인용하는 기능

Agents & Automation 에이전트 & 자동화

  • MCP (Model Context Protocol) — AI 어시스턴트와 외부 도구를 연결하는 Anthropic 공개 표준
  • Computer Use — AI가 직접 마우스·키보드·화면을 조작하는 기능 (Vercept 인수 기술)
  • Multi-Agent — 여러 Claude 인스턴스가 역할을 나눠 협업하는 아키텍처
  • Subagent — 오케스트레이터가 위임한 단일 작업을 수행하는 하위 에이전트
  • Hooks — Claude Code에서 특정 이벤트(파일 저장 등) 발생 시 자동 실행되는 스크립트
  • Projects — claude.ai에서 문서·지시사항을 세션 간 유지하는 작업공간
  • Memory — 대화나 파일을 통해 Claude가 정보를 장기 기억하는 메커니즘

AI Concepts

8개 용어
🔤 AI 기초
Token (토큰)

Claude가 읽고 쓰는 텍스트의 최소 단위 — 영문 약 4글자(≈ 단어의 ¾) 1토큰에 해당.

API 사용 요금은 토큰 수로 청구됩니다. 한국어는 영문보다 토큰을 더 많이 사용합니다. 이미지·PDF 페이지도 토큰으로 환산되며, 요청당 최대 600개 이미지/PDF 페이지 제한이 있습니다.

💡 1M 컨텍스트 창 ≈ 약 750K 단어 분량
🪟 핵심 개념
Context Window (컨텍스트 창)

Claude의 작업 메모리 — 한 번에 읽고 기억할 수 있는 모든 텍스트의 최대 범위.

대화 이력, 시스템 프롬프트, 현재 입력, 출력 토큰이 모두 포함됩니다. 컨텍스트가 늘어날수록 정확도가 저하되는 "context rot" 현상이 발생할 수 있습니다.

모델컨텍스트 창
Opus 4.6 / Sonnet 4.61M 토큰
Haiku 4.5 / Sonnet 4.5200K 토큰
🎭 모델 선택
Model (모델)

대화 상대인 Claude의 특정 버전 — Haiku, Sonnet, Opus 3가지 등급으로 제공.

각 등급은 속도·비용·지능의 균형이 다릅니다. Haiku는 가장 빠르고 저렴하며, Opus는 가장 지능적입니다.

등급특징비용(입/출)
Haiku 4.5최고 속도$1 / $5 /MTok
Sonnet 4.6속도·지능 균형$3 / $15 /MTok
Opus 4.6최고 지능$5 / $25 /MTok
🤔 추론 기능
Extended Thinking (확장 사고)

Claude가 최종 답변 전 단계별 사고 과정을 거치는 심층 추론 기능.

응답에 thinking(내부 추론) 블록과 text(최종 답변) 블록이 함께 포함됩니다. Opus 4.6 / Sonnet 4.6에서는 Adaptive Thinking이 권장됩니다 (Claude가 복잡도에 따라 사고량을 자동 조절).

⚠️ Extended Thinking 활성화 시 temperature는 반드시 1로 설정
🌀 주의사항
Hallucination (환각)

Claude가 사실과 다른 정보를 자신 있게 말하는 현상.

지식 공백을 채우려 하거나 입력이 모호할 때 발생합니다. Claude는 모르는 질문에 추측 대신 거부하도록 훈련되어 있지만 완전하지는 않습니다. 중요한 팩트·링크는 반드시 별도 검증이 필요합니다.

⚠️ Sonnet 4.6 computer use 평가에서 환각된 링크 0개 생성 (이전 ⅓ 대비 개선)
💬 기본 개념
Prompt (프롬프트)

사용자가 Claude에게 전달하는 메시지 또는 지시문.

API에서는 messages 배열의 user 역할 메시지로 전달됩니다. Anthropic은 "brilliant but new employee"(똑똑하지만 신입 직원) 비유를 사용 — 원하는 출력 형식과 제약사항을 명확히 명시하는 것을 권장합니다.

💡 XML 태그로 구조화(<instructions>, <context>, <examples>) 시 품질 향상
⚙️ 개발자 도구
System Prompt (시스템 프롬프트)

개발자가 Claude의 역할·행동 방식·응답 톤을 사전에 설정하는 숨겨진 지시문.

API 요청의 system 파라미터로 전달됩니다. 모든 대화에 걸쳐 일관되게 적용됩니다.

⚠️ Claude.ai의 내부 시스템 프롬프트는 Claude API에는 적용되지 않음
🌡️ 파라미터
Temperature (온도)

Claude 응답의 창의성(무작위성)을 조절하는 다이얼 — 낮을수록 일관되고, 높을수록 다양함.

API 기본값은 1. 코드 생성·사실 기반 답변은 낮게, 창의적 글쓰기는 높게 설정합니다. Extended Thinking 활성화 시 반드시 1로 고정해야 합니다.

Products

8개 용어
🌐 웹 앱
Claude.ai

대부분의 사람들이 Claude와 대화하는 공식 웹사이트 및 앱.

무료·Pro·Max·Team·Enterprise 플랜을 제공합니다. Artifacts, Projects, Memory, Deep Research, Web Search, Style, Connectors(MCP) 등 모든 주요 기능을 포함합니다.

🖥️ 데스크톱 앱
Claude Desktop

MCP 연결과 로컬 도구 사용을 가능하게 하는 다운로드 앱.

내장 Node.js 환경으로 Python·바이너리 MCP 서버를 지원합니다. "Desktop Extensions Directory"에서 원클릭 MCP 서버 설치, macOS Keychain / Windows Credential Manager를 통한 보안 API 키 관리 기능을 제공합니다.

🤝 에이전트
Cowork

실제 파일과 앱에서 작업하는 Claude 데스크톱 에이전트.

목표를 제시하면 로컬 파일·폴더·애플리케이션에서 작업하여 완성된 결과물을 반환합니다. 비기술 지식 노동자를 대상으로 설계된 자율 실행 에이전트입니다. Claude Desktop 앱을 통해 Research Preview로 이용 가능합니다.

💡 Claude.ai(대화형) vs Cowork(자율 다단계 워크플로우)
⌨️ 개발자 도구
Claude Code

터미널에서 코드베이스를 읽고, 파일을 수정하고, 테스트하고, 커밋까지 수행하는 AI 코딩 에이전트.

터미널·IDE·데스크톱 앱·브라우저에서 사용 가능합니다. Skills, MCP, Subagents, Hooks, 스케줄 실행을 지원합니다. 비개발자도 자연어로 소프트웨어를 개발할 수 있게 합니다.

🌏 브라우저 확장
Claude in Chrome

현재 보고 있는 웹 페이지를 읽고 작업을 수행하는 Chrome 사이드패널 확장.

다중 탭 동시 관리, Slack·Gmail·Google Docs·GitHub 네이티브 탐색, 워크플로우 녹화 후 학습·반복 실행, 브라우저 콘솔 에러·네트워크 요청 읽기 기능을 포함합니다.

⚠️ 현재 Max 플랜 구독자 베타 제공
📊 Office 통합
Claude in Excel

스프레드시트 안에서 살아 숨쉬는 Claude — 수식·피벗·차트를 자연어로 조작.

워크북 질문 답변(셀 수준 인용), 수식 의존성 보존, 오류 탐지/수정, 피벗 테이블 편집, MCP 커넥터(S&P Global, LSEG, Bloomberg 등) 연동 기능을 제공합니다. Excel on the web, Windows(Microsoft 365), Mac(16.46+), iPad를 지원합니다.

📑 Office 통합
Claude in PowerPoint

프레젠테이션 제작을 돕는 PowerPoint 통합 에이전트.

기업 템플릿을 유지하며 슬라이드 생성, 자연어로 전체 덱 구조 생성, 편집 가능한 네이티브 차트·다이어그램 생성, 브랜드 가이드라인 유지 기능을 제공합니다.

⚠️ 세션 간 채팅 이력 미저장 — 매 사용 시 새 대화 시작
🏪 통합 허브
Claude Marketplace

외부 서비스와 Claude를 연결하는 커넥터(Connector)를 검색·설치하는 디렉토리.

MCP(Model Context Protocol) 기반의 서드파티 통합 카탈로그입니다. 데이터, 코드, 커뮤니케이션, 디자인, 금융, 생산성, 영업/마케팅 등 카테고리를 포함합니다. Claude.ai, Claude Code, Skills 제품군과 호환됩니다.

Core Features

8개 용어
📎 창작 도구
Artifact (아티팩트)

Claude가 사이드 패널에 생성하는 파일 또는 앱 — 문서, 코드, SVG, 위젯.

콘텐츠가 15줄 이상이고 대화 밖에서 재사용 가능할 때 자동 생성됩니다. 단일 페이지 HTML 웹사이트, SVG 이미지, 다이어그램, 인터랙티브 React 컴포넌트 등을 지원합니다.

💡 공유 시 사용량은 각 열람자의 구독 한도에서 차감됨
📁 조직화
Project (프로젝트)

관련 대화, 문서, 지식을 한 공간에 모아 관리하는 전용 작업 공간.

각 프로젝트는 200K 컨텍스트 창(약 500페이지 분량)을 보유합니다. 문서/코드/인사이트를 업로드해 Claude 응답을 기반화하고, 프로젝트별 커스텀 지시문을 설정할 수 있습니다. Pro/Team 플랜 이용 가능.

✅ 프로젝트 내 데이터는 동의 없이 모델 학습에 사용되지 않음
🧠 개인화
Memory (메모리)

대화 간 사용자 정보와 선호도를 기억하는 기능.

Claude.ai에서는 Profile Preferences(계정 전체 적용)로 구현됩니다. API에서는 Memory Tool(파일 디렉토리 기반 영구 저장소)을 통해 세션 간 지식을 축적합니다. 다른 AI 제공자의 메모리를 가져와 이전 가능합니다.

🔬 리서치
Deep Research (심층 연구)

Claude가 자율적으로 여러 검색을 순차적으로 수행해 인용 출처가 포함된 심층 리포트를 작성.

에이전트로서 다각도의 질문을 자동 탐색합니다. Gmail, Google Calendar, Google Docs 등 연결된 내부 소스와 웹 모두에서 리서치를 수행합니다.

⚠️ 유료 플랜(Pro, Max, Team, Enterprise)만 이용 가능
🔎 실시간 정보
Web Search (웹 검색)

Claude가 대화 중 실시간으로 인터넷을 검색하여 최신 정보를 반영하는 기능.

Deep Research 기능의 핵심 의존 도구입니다. 유료 플랜에서 활성화할 수 있으며, Deep Research를 사용하려면 반드시 활성화 상태여야 합니다.

✍️ 개인화
Style (스타일)

Claude가 사용자의 문체를 학습하고 흉내 내는 기능 — 응답 어조와 형식을 맞춤화.

세 가지 레이어: Profile Preferences(계정 전체 선호도), Project Instructions(프로젝트별 컨텍스트), Styles(concise·explanatory 등 응답 포맷 전환).

🎛️ 설정
User Preferences (사용자 선호도)

Claude가 응답 시 고려할 선호 어조·형식·전문 용어를 계정 수준에서 설정.

모든 대화에 걸쳐 적용되는 계정 전체 설정입니다. 특정 프로젝트에만 적용하려면 Project Instructions를 활용합니다.

🗜️ 컨텍스트 관리
Compaction (컴팩션)

컨텍스트 창 한도에 근접하면 대화를 자동 요약해 새 컨텍스트를 시작 — 무한 대화 가능.

API에서는 서버사이드 컴팩션(Opus 4.6, Sonnet 4.6 베타)으로 서버에서 자동 요약 처리합니다. Claude Code에서는 세션 내 컨텍스트가 임계치 도달 시 자동 실행됩니다.

💡 Claude Code: /compact 명령으로 수동 실행 가능

Agents & Automation

7개 용어
🔗 자동화
Connector (커넥터)

Claude와 외부 서비스(캘린더, Slack, Drive 등)를 연결하는 라이브 링크.

MCP 기반으로 동작합니다. 연결된 앱에서 데이터 읽기/생성/수정/삭제, 대시보드·작업 보드 표시, 사용자 대신 자동 작업 수행이 가능합니다. OAuth를 통한 사전 승인이 필요합니다(실제 비밀번호 공유 불필요).

🔌 표준 프로토콜
MCP
Model Context Protocol

모든 커넥터를 구동하는 오픈 표준 — AI와 외부 데이터 소스를 연결하는 범용 프로토콜.

AI 시스템과 데이터 소스를 연결하는 범용 표준입니다. MCP 서버(데이터 제공자)와 MCP 클라이언트(AI 앱)의 양방향 구조로 동작합니다. 기존 개별 통합을 단일 프로토콜로 대체해 Slack, GitHub, Google Drive, Asana 등을 연동합니다.

💡 Anthropic이 제안한 오픈 표준 — 다른 AI 시스템도 구현 가능
📖 확장 모듈
Skill (스킬)

Claude에게 특정 도구나 실천법을 가르치는 마크다운 파일.

지시문·스크립트·리소스가 포함된 폴더 형태의 확장 모듈입니다. Composable(여러 스킬 자동 조합), Portable(Claude.ai·Claude Code·API 전체에서 동일 포맷), Efficient(필요할 때만 컨텍스트에 로드) 특성을 가집니다.

💡 적용 범위: Enterprise > Personal (~/.claude/skills/) > Project (.claude/skills/)
⚡ 단축 명령
Slash Command (슬래시 커맨드)

스킬 + 커넥터 묶음으로 Claude에게 특정 AI 역할을 부여하는 /명령어 형태의 단축키.

빌트인 커맨드(/help, /compact)와 스킬 기반 커스텀 커맨드로 구분됩니다. 스킬의 name 필드가 슬래시 커맨드 이름이 됩니다.

⚠️ 같은 이름의 스킬과 커맨드가 충돌 시 스킬이 우선
⏰ 자동화
Scheduled Task (스케줄 작업)

Claude가 일정에 따라 자동으로 실행하는 반복 작업.

매일 아침 PR 리뷰, 야간 CI 실패 분석, 주간 의존성 감사, PR 머지 후 문서 동기화 등에 활용됩니다. Claude Code에서는 Anthropic 관리 인프라에서 실행되므로 컴퓨터가 꺼져 있어도 계속 실행됩니다.

📱 원격 제어
Dispatch (디스패치)

Claude 모바일 앱에서 Cowork를 원격으로 제어하는 기능.

모바일에서 작업을 위임하면 데스크톱 세션이 생성되어 실행됩니다. Cowork의 다단계 워크플로우를 외출 중에도 시작할 수 있습니다.

🖱️ 컴퓨터 제어
Computer Use (컴퓨터 사용)

화면을 보고, 커서를 움직이고, 버튼을 클릭하고, 텍스트를 입력하는 방식으로 Claude가 컴퓨터를 사람처럼 조작하는 기능.

반복 프로세스 자동화, 소프트웨어 빌드/테스트, 오픈엔드 리서치 등에 활용됩니다. 스크린샷·마우스 동작·키보드 입력·관련 파일은 모두 사용자 환경에 저장됩니다(Anthropic에 저장 불필요).
