에이전트
KAIROS — 항상 켜진 자율 에이전트Always-on Autonomous Agent
슬라이드 3 / 9

사용자가 명령을 내리지 않아도 Claude Code가 스스로 작동하는 상시 에이전트 시스템입니다. 기존의 "질문 → 응답" 방식이 아니라, Claude Code가 먼저 상황을 관찰하고 판단해서 자율적으로 행동합니다.

🔄 작동 사이클: Observe(관찰) → Decide(판단) → Log(기록) → Act(행동) 4단계를 반복합니다.
⏱ 15초 규칙: 15초를 넘는 블로킹 작업(긴 빌드, 테스트 등)은 자동으로 defer(연기) 처리합니다.
📤 SendUserFile: 작업 완료 시 파일을 직접 사용자에게 전송하는 액션이 가능합니다.
🔔 PushNotification: 장시간 작업 완료 시 사용자에게 푸시 알림을 보낼 수 있습니다.
👀 SubscribePR: PR 상태를 구독해 변경이 생기면 자동으로 반응하는 기능입니다.
Observe → Act SendUserFile PushNotification SubscribePR 15s defer

Dream System — 클로드가 꿈을 꿉니다Autonomous Memory Consolidation
슬라이드 4 / 9

Claude Code가 하루에 한 번 자동으로 기억을 정리·압축하는 시스템입니다. 사람이 수면 중에 기억을 재정리하는 것처럼, Claude도 일정 조건이 충족되면 스스로 메모리를 정돈합니다.

📋 발동 조건: 마지막 Dream 이후 24시간 경과 + 5세션 이상 + 잠금(lock) 획득 시 자동 실행됩니다.
🌀 Orient(방향 설정): 기억 정리의 목표와 방향을 결정하는 단계입니다.
📦 Gather(수집): 흩어진 기억·컨텍스트를 하나로 모읍니다.
🗜 Consolidate(통합): 중복·유사 내용을 합치고 핵심만 남깁니다.
✂️ Prune(가지치기): 낡거나 불필요한 기억을 삭제해 메모리를 최적화합니다.
24h + 5세션 Orient Gather Consolidate Prune

ULTRAPLAN — 30분 원격 딥 플래닝Cloud-based Deep Planning with Opus 4.6

복잡하고 대규모 작업이 들어오면, 로컬 터미널이 아닌 클라우드 서버에서 Opus 4.6이 최대 30분 동안 깊이 생각해서 실행 계획을 만들어 줍니다. 계획 결과는 브라우저에서 사용자가 승인하면 터미널로 TELEPORT되는 방식입니다.

☁️ Cloud CCR: Claude Code Remote — 클라우드 서버에서 별도로 실행되는 플래닝 인스턴스입니다.
🧠 Opus 4.6 사용: 가장 강력한 모델이 최대 30분간 깊이 생각합니다. 로컬에서 불가능한 긴 추론이 가능해집니다.
✅ 브라우저 승인 흐름: 완성된 플랜은 바로 실행되지 않고, 브라우저에서 사용자가 검토 후 승인해야 합니다.
🚀 TELEPORT: 승인 완료 시 계획이 터미널로 전송되어 즉시 실행 가능한 상태가 됩니다.

BUDDY — 터미널 안의 타마고치Companion Pet for Developers

🐱 Nebulynx: 코드에서 발견된 최고 희귀 동물 이름. Shiny Legendary 등급으로 확률 0.01%.
💬 말 걸기: Buddy에게 직접 말을 걸 수 있는 인터랙션이 구현되어 있습니다.

🐧 penguinModeOrgEnabled: 소스코드에서 발견된 실제 플래그 이름입니다. 조직 단위로 켜고 끄는 구조입니다.

📜 동물 이름 계보: Fennec(구 Fast Mode 전신) → Tengu(중간 버전) → Capybara(현재 v1) 순으로 코드명이 변천했습니다.

소스맵(.map) 파일 유출 경위How the Source Was Exposed
슬라이드 2 / 9

npm에 패키지를 배포할 때 .map(소스맵) 파일이 함께 포함된 것이 원인입니다. 소스맵 파일은 원래 개발자 디버깅용으로, 빌드된 JS 코드와 원본 TypeScript 소스를 1:1로 매핑합니다. npm 공개 배포 시 이 파일이 그대로 올라가면서 원본 TypeScript 소스코드 전체가 외부에 노출됐습니다.

📦 npm publish: 빌드 결과물에 .map 파일이 포함된 채로 패키지가 배포됐습니다.
🗺 .map 파일: 소스맵은 minified JS ↔ 원본 TS 코드의 매핑 정보를 담고 있어, 이를 통해 원본 소스 전체 복원이 가능합니다.
🔓 발견된 미공개 기능: KAIROS, DREAM, ULTRAPLAN, BUDDY, COORDINATOR, VOICE_MODE — 총 6가지 플래그가 소스에서 확인됐습니다.
