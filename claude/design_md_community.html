What is

DESIGN.md란?

Google Stitch가 도입한 포맷. 마크다운 파일 하나에 브랜드 색상, 타이포그래피, 간격, 컴포넌트 규칙을 담아 AI 에이전트에게 전달한다. 에이전트가 UI를 생성할 때마다 이 파일을 먼저 읽어 일관된 결과를 낸다.

1
프로젝트 루트에 파일 하나 추가
DESIGN.md 또는 SKILL.md 한 파일로 끝
2
AI 에이전트가 자동으로 읽음
Claude Code, Cursor, Gemini CLI 등 마크다운을 읽는 에이전트라면 모두 작동
3
일관된 UI 생성
스크린샷은 모호하지만 마크다운의 color: #635BFF는 모호하지 않다

Installation

CLI · MCP 연동 방법

1 designmd.ai — MCP 연동 (Claude Code)
claude mcp add -s user designmd \ -e DESIGNMD_API_KEY=dk_your-key \ -- npx designmd-mcp
API Key는 designmd.ai 회원가입 후 무료 발급. 다운로드·업로드 시 필요.
designmd.ai — CLI 명령어
# 설치 없이 바로 사용 npx designmd # 검색 designmd search "dark fintech" # 다운로드 designmd download shafius/neon-fintech # 업로드 designmd upload ./DESIGN.md \ --name "My Kit" --tags dark,saas
2 typeui.sh — CLI 연동
# 설치 불필요 (npx 직접 실행) npx typeui.sh generate # SKILL.md 생성 npx typeui.sh pull modern # 스킬 다운로드 npx typeui.sh list-skills # 목록 조회 npx typeui.sh update # 업데이트
에이전트별 파일이 자동 경로에 배치된다.

Decision Guide

어떤 상황에서 어떤 걸 쓸까?

🎨
"Stripe처럼 만들어줘" → getdesign.md
실제 브랜드의 CSS를 추출한 파일. Apple, Stripe, Vercel 등 66개 브랜드의 정확한 값(#635BFF, border-radius: 6px)을 그대로 AI에 전달한다. 스크린샷보다 훨씬 정확하다.
⚡
"깔끔하고 미니멀하게" → typeui.sh
특정 브랜드가 아닌 스타일로 고른다. Paper, Modern, Enterprise, Neumorphism, Fantasy 등 57개 스킬 중에서 원하는 분위기를 선택하고 CLI로 설치하면 끝.
🌐
"커뮤니티에서 찾아보고 싶어" → designmd.ai
100개+ DESIGN.md를 탐색·검색. MCP 서버를 연결하면 Claude Code나 Cursor에서 사이트를 떠나지 않고 바로 적용할 수 있다. 내가 만든 것도 업로드 가능.
셋 다 공통: 파일 하나 넣고 끝
# 프로젝트 루트에 파일 추가 cp downloaded-DESIGN.md ./DESIGN.md # Claude Code에게 지시 "DESIGN.md 스펙대로 랜딩 페이지 만들어줘" # → Claude가 파일을 읽고 일관된 UI 생성
Claude Code, Cursor, Codex, Gemini CLI 등 마크다운을 읽는 에이전트라면 어떤 것이든 작동한다. 무료로 시작할 수 있고, 설치 없이 npx 하나면 충분하다.
