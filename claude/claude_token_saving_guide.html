Claude는 메시지 수가 아니라 토큰(글자 단위)을 셉니다. 대화 방식에 따라 한도를 10배 빨리 소모할 수 있어요. 지금 바로 바꿀 수 있는 습관들입니다.

80~90%
Trick 1로 토큰 절감 가능
50,000+
30번째 메시지의 토큰 비용
150~200+
Pro 플랜 일일 가능 메시지 수

📌 원본 인포그래픽 (클릭하면 확대)

10가지 트릭 상세 설명

인포그래픽의 모든 팁을 한국어로 풀어서 정리했습니다.

1
✏️ Edit
프롬프트를 수정하세요, 추가 메시지를 보내지 마세요
Claude의 답변이 마음에 들지 않으면 원래 메시지의 수정 아이콘을 클릭해 프롬프트를 고치고 재생성하세요. 이전 대화가 히스토리에 쌓이지 않고 교체됩니다.

10번의 대화에서 이 습관 하나만으로 토큰 사용량을 80~90% 줄일 수 있어요.
프롬프트를 고쳐라. 대화를 쌓지 마라.
2
💬 Fresh Chat
15~20 메시지마다 새 대화를 시작하세요
아무도 얘기 안 하는 숨겨진 비용이 있어요. Claude는 매 턴마다 전체 대화 히스토리를 다시 읽습니다.

1번째 메시지 비용: ~200 토큰. 30번째 메시지 비용: 50,000+ 토큰.

요약을 요청해서 복사하고, 새 대화에 붙여넣으세요.
긴 대화는 비싼 대화입니다.
3
📦 Batching
여러 질문을 하나로 묶어서 보내세요
3개의 메시지를 따로 보내는 대신, 이렇게 묶으세요:
"이 글 요약하고, 핵심을 불릿으로 정리하고, 헤드라인도 제안해줘."

3번 대신 1번의 컨텍스트 로드. 그리고 Claude가 전체 그림을 보기 때문에 답변 품질도 더 좋아요.
질문 3개. 메시지 1개. 항상.
4
📁 Projects
반복 파일은 Projects에 업로드하세요
같은 PDF, 브리프, 가이드를 여러 대화에 업로드하고 있다면, Claude는 매번 그 토큰을 다시 소모합니다.

사이드바의 Projects에 파일을 올려두면 각 대화에서 재비용 없이 캐시됩니다. 긴 문서를 자주 다루는 분들께 큰 절약이에요.
한 번 업로드. 매번 돈 내지 마세요.
5
🧠 Memory
메모리 & 커스텀 지시사항을 설정하세요
컨텍스트 없이 시작하는 대화마다 자기 소개에 3~5개의 설정 메시지를 낭비합니다.

설정 → Memory & User Preferences에서 한 번만 저장하세요: 내 역할, 톤, 선호사항. Claude가 모든 대화에 자동으로 반영합니다.
한 번 설정하면, 영원히 작동합니다.
6
🔧 Toggle
안 쓰는 기능은 꺼두세요
웹 검색, 리서치 모드, 커넥터는 필요 없을 때도 모든 응답에 토큰을 추가합니다.

내 콘텐츠로만 작업하거나 글 쓸 때는 "Search and tools"를 꺼주세요. Extended Thinking(확장 사고)도 기본 OFF — 첫 시도가 부족할 때만 켜세요.
켜지 않은 기능은 꺼두세요.
7
⚡ Model Selection 최고 임팩트
간단한 작업에는 하루 종일 Haiku를 사용하세요
Haiku 4.5는 문법 검사, 빠른 답변, 브레인스토밍, 서식 지정, 번역을 Sonnet이나 Opus의 몇 분의 1 비용으로 처리합니다.

올바른 모델 선택은 단일 최고 임팩트 결정입니다. Haiku로 간단한 작업을 처리하면 실제로 필요한 큰 모델에 쓸 예산이 50~70% 확보됩니다.
초안엔 Haiku. 실전엔 Sonnet. 어려운 건 Opus.
8
⏰ Pacing
작업을 하루에 나눠서 진행하세요
Claude는 연속으로 재설정되는 롤링 5시간 윈도우로 운영됩니다. 오전 세션 하나에 한도를 다 써버리면 윈도우가 롤오버될 때까지 끝이에요.

한 번에 몰아치는 대신 하루 2~3 세션으로 나누면, Pro 플랜에서 45개 대신 150~200+ 메시지를 효과적으로 쓸 수 있어요.
스프린트하지 마세요. 페이스를 조절하세요.
