공식 미지원
설정 가이드
플랫폼별 설정 방법
설정은 공통적으로 ① 봇 생성 → ② 플러그인 설치 → ③ 토큰 설정 → ④ 재시작 → ⑤ 페어링 5단계
1
Telegram에서 봇 생성
Telegram에서 @BotFather를 검색해 대화 시작 → /newbot 전송 → 봇 이름과 사용자명 입력 → 발급된 토큰 복사
2
Claude Code에서 플러그인 설치
Claude Code 세션에서 아래 명령어 실행
/plugin install telegram@claude-plugins-official # 플러그인을 찾을 수 없다면 마켓플레이스 먼저 추가: /plugin marketplace add anthropics/claude-plugins-official /plugin install telegram@claude-plugins-official
3
봇 토큰 설정
복사한 토큰을 아래 명령어로 등록 (토큰은 ~/.claude/channels/telegram/.env에 저장됨)
/telegram:configure YOUR_BOT_TOKEN_HERE # 또는 환경변수로 설정: export TELEGRAM_BOT_TOKEN=YOUR_BOT_TOKEN_HERE
4
Channels 플래그로 Claude Code 재시작
터미널에서 Claude Code를 아래 명령어로 새로 시작
claude --channels plugin:telegram@claude-plugins-official # Telegram + Discord 동시 연결: claude --channels plugin:telegram@claude-plugins-official plugin:discord@claude-plugins-official
5
페어링 코드 입력
Telegram에서 등록한 봇에게 아무 메시지나 전송 → 봇이 페어링 코드로 답장 → Claude Code에서 확인
/telegram:access pair PAIRING_CODE # 허가된 사용자만 접근하도록 허용 목록 정책 설정: /telegram:access policy allowlist
1
Discord Developer Portal에서 봇 생성
discord.com/developers/applications 접속 → New Application 생성 → Bot 섹션 → 사용자명 설정 → Reset Token → 토큰 복사
2
Message Content Intent 활성화
Bot 설정 → Privileged Gateway Intents 섹션 → Message Content Intent 토글 ON → Save Changes
이 설정 없이는 봇이 메시지 내용을 읽지 못합니다. 반드시 활성화해야 합니다.
3
봇을 서버에 초대
OAuth2 → URL Generator → Scope: bot → 권한 선택 후 초대 URL로 서버에 추가
# 필요 권한 체크리스트: ✓ View Channels ✓ Send Messages ✓ Send Messages in Threads ✓ Read Message History ✓ Attach Files ✓ Add Reactions
4
플러그인 설치 및 토큰 설정
/plugin install discord@claude-plugins-official /discord:configure YOUR_BOT_TOKEN_HERE
5
재시작 및 페어링
claude --channels plugin:discord@claude-plugins-official # Discord에서 봇에게 DM 전송 → 페어링 코드 수신 → /discord:access pair PAIRING_CODE /discord:access policy allowlist
데모용 로컬 채널 외부 서비스 계정 없이 localhost에서 Channels 구조를 체험하는 테스트 모드입니다.
1
플러그인 설치
/plugin install fakechat@claude-plugins-official
2
Channels 플래그로 실행
claude --channels plugin:fakechat@claude-plugins-official
3
브라우저에서 테스트
브라우저에서 http://localhost:8787 접속 → 메시지 입력 → Claude Code 세션으로 전달 확인
보안
보안 모델
누구나 메시지를 보낼 수 있으면 위험합니다. Channels는 페어링 + 허용 목록 이중 구조로 보호합니다.
🔗

페어링 필수

봇이 페어링 코드를 발급하고, Claude Code에서 확인하는 2단계 인증. 한 번만 설정하면 이후 자동 인식.

📋

Sender Allowlist

/telegram:access policy allowlist로 허가된 ID만 메시지 수신. 설정 안 하면 누구나 Claude에게 명령 전송 가능해집니다.

🔑

토큰 로컬 저장

봇 토큰은 ~/.claude/channels/{플랫폼}/.env에 로컬 저장. 서버로 업로드되지 않습니다.

⚡

무인 실행 옵션

--dangerously-skip-permissions 플래그로 권한 확인 대화 없이 자동 실행. 신뢰된 환경에서만 사용 권장.

설정 우선 순위 페어링 코드 입력 후 반드시 /telegram:access policy allowlist 또는 /discord:access policy allowlist를 설정하세요. 그렇지 않으면 해당 봇을 아는 누구나 메시지를 보낼 수 있습니다.

Channels vs 유사 기능 비교
공식 문서 기준 — Channels가 다른 Claude 기능들과 어떻게 다른지
기능 무엇을 하는가 실행 위치 적합한 용도
🛰 Channels (이 문서) 외부 이벤트를 실행 중인 로컬 세션으로 push 로컬 터미널 채팅 브리지, 폰에서 원격 지시
Remote Control claude.ai/모바일에서 로컬 세션 직접 조작 로컬 터미널 진행 중인 세션을 다른 기기에서 조종
Claude Code on the web GitHub에서 클라우드 샌드박스에서 작업 실행 클라우드 (신선한 환경) 비동기 작업 위임
Claude in Slack @Claude 멘션으로 웹 세션 생성 클라우드 팀 채팅에서 작업 요청
Standard MCP Server Claude가 필요할 때 서버에 쿼리 로컬 또는 원격 온디맨드 읽기/쿼리
요금제별 사용 가능 여부
플랜기본값활성화 방법
Pro / Max (개인) 사용 가능 세션마다 --channels 플래그 추가
Team / Enterprise 비활성화됨 claude.ai 관리자 설정 → Claude Code → Channels → 활성화, 또는 managed settings에서 channelsEnabled: true
참고
Google Chat 연동 현황
공식 Channels 플러그인은 현재 미지원 (2026-03 기준)
Google Chat은 공식 Channels 플러그인 없음 현재 Anthropic이 제공하는 claude-plugins-official 저장소에는 Telegram·Discord·Fakechat 플러그인만 존재합니다. Google Chat 공식 플러그인은 아직 발표되지 않았습니다.
대안 — Telegram MCP Server 사용자 메시지에서 언급된 Telegram MCP Server는 Bun 기반의 커뮤니티 도구로, 텔레그램 봇을 Claude Code에 MCP로 연결합니다. 공식 Channels와 유사하지만 별도 프로젝트입니다. 봇 토큰만 있으면 비교적 빠르게 연결 가능합니다.
Google Chat 우회 방법 (비공식) Google Chat은 Incoming/Outgoing Webhook을 지원합니다. 중간에 Webhook 수신 서버를 두고 Claude Code를 폴링하거나, n8n·Make 같은 워크플로우 자동화 도구로 Google Chat → Telegram → Channels 브리지를 구성하는 방식이 사용됩니다. 단, 이는 공식 지원 방식이 아닙니다.
