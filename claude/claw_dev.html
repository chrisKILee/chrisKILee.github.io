Claw Dev
멀티 프로바이더 런처

Claude Code 소스맵 유출을 기반으로 만들어진 오픈소스 프로젝트. 로컬에 Anthropic 호환 프록시(중계 서버)를 띄워 Ollama 로컬 모델부터 OpenAI, Gemini까지 — 동일한 Claude Code 터미널 인터페이스로 9가지 AI 백엔드를 연결합니다.

9가지 프로바이더 지원 🏠 Ollama 로컬 모델 TypeScript 100% Node.js 22+
01 작동 원리

Anthropic 호환 프록시(중계 서버)로 번역

Claude Code 터미널 클라이언트는 원래 Anthropic API와만 통신합니다. Claw Dev는 중간에서 다른 모델의 API 포맷으로 번역해주는 프록시 서버를 로컬에 띄웁니다.

3가지 동작 모드로 운영됩니다:

Direct
Anthropic API에 직접 연결. 번역 레이어 없음. 가장 안정적입니다.
AWS Bedrock
AWS Bedrock을 통해 Claude 모델에 연결. 엔터프라이즈 환경에 적합합니다.
Proxy
Anthropic 스타일 프로토콜을 다른 프로바이더 API 포맷으로 번역하는 호환성 프록시 모드. Ollama, OpenAI, Gemini, Groq 등에서 사용합니다.
02 프로바이더

9가지 백엔드 지원

시작 시 번호로 프로바이더를 선택합니다. 클라우드 API 키가 있으면 클라우드로, 로컬 모델이 있으면 로컬로.

Ollama
로컬 실행 · 비용 0원 · 오프라인 가능
Anthropic
Claude 직접 연결 · 가장 안정적
OpenAI
GPT-5-Mini 등 · 클라우드

2.5-Flash(속도) / 2.5-Pro(추론)
Groq
초고속 추론 · 클라우드
OpenRouter
멀티 모델 게이트웨이
GitHub Copilot
Copilot Models API
z.ai
클라우드 대안
Amazon Bedrock
AWS 환경 · 엔터프라이즈
무료 옵션으로는 Ollama가 가장 안정적
클라우드 무료 티어는 자주 변동되지만, Ollama는 로컬에서 완전 무료로 안정적으로 동작합니다. README에서도 Ollama를 가장 안정적인 무료 옵션으로 권장하고 있습니다.
프로바이더 추천 모델 비용 특징
Anthropic claude-sonnet-4 유료 가장 안정적, 원본 Claude Code 경험
Gemini gemini-2.5-flash / 2.5-pro 유료 속도(Flash) vs 추론(Pro) 선택
OpenAI gpt-5-mini 유료 가성비 모델
Ollama qwen3 0원 완전 로컬 · 인터넷 불필요
03 Ollama 조합

API 비용 0원 — 로컬 코딩 에이전트

qwen3 같은 8B급(8억 개 파라미터) 모델을 로컬에 올리면 API 비용이 완전히 0원입니다. 세 줄로 시작할 수 있습니다.

bash 
ollama pull qwen3       # 로컬에 qwen3 모델 다운로드
npm run claw-dev        # Claw Dev 실행
→ 4. Ollama 선택        # 대화형 메뉴에서 Ollama 선택
💾
최소 사양
  • RAM 16GB — 시작 가능
  • RAM 32GB — 한결 쾌적
  • GPU 없어도 CPU만으로 동작함
  • GPU 있으면 체감 속도가 확 달라짐
HARDWARE
✅
장점
  • API 비용 완전 0원
  • 클라우드 의존 없음
  • 인터넷 없이도 동작
  • 데이터가 외부로 전송되지 않음
PROS
⚠️
한계
  • 8B 모델은 Claude보다 추론 능력이 낮음
  • GPU 없으면 응답이 느림
  • 복잡한 태스크는 클라우드 모델이 유리
CONS
04 설치

설치 및 실행

Node.js 22 이상이 필요합니다. TypeScript 100% 프로젝트입니다.

사전 조건
Node.js 22 이상, npm, 사용할 프로바이더의 API 키 또는 Ollama 설치
1
저장소 클론
GitHub에서 claw-dev 저장소를 클론합니다.
bash 
git clone https://github.com/Leonxlnx/claw-dev
cd claw-dev
2
의존성 설치 및 환경 설정
패키지를 설치하고 환경 변수 파일을 준비합니다.
bash 
npm install
cp .env.example .env
# .env 파일에 사용할 API 키 입력
3
실행 및 프로바이더 선택
실행하면 대화형 메뉴가 뜹니다. 번호로 프로바이더를 선택하고 커스텀 모델 ID도 지정할 수 있습니다.
bash 
npm start
# 또는
npm run claw-dev
