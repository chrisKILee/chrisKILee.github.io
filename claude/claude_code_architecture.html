03 확장 타입

5가지 Extension Types

Claude Code 워크플로우를 강화하는 5가지 확장 메커니즘입니다.

타입 활성화 시점 역할 예시
⚡ Skills 태스크 매칭 시 자동 특정 작업에 특화된 가이드·스크립트 제공 code-review, security-audit, deploy
🪝 Hooks 라이프사이클 이벤트 PreToolUse · PostToolUse · SessionStart 등 시점에 스크립트 실행 시크릿 감지, 린트 자동 실행, Slack 알림
🔌 MCP 항상 연결 유지 외부 도구·서비스와 실시간 연동 GitHub PRs, PostgreSQL, Playwright
🤖 Subagents 명시적 호출 시 복잡한 작업을 병렬로 분산 처리 테스트 작성 + 코드 리뷰 동시 진행
📦 Plugins 설치 시 일괄 적용 설정·스킬·훅을 묶어 배포 가능한 단위로 패키징 vercel-plugin, ccpp (Claude Code Power Pack)
04 Hook Events

라이프사이클 훅

Claude가 특정 행동을 취하는 시점에 자동으로 실행되는 셸 스크립트입니다.

🔴
PreToolUse

도구 실행 직전 호출. 위험한 명령을 차단하거나, 시크릿 노출을 감지하는 데 사용합니다.

Block before execution
🟡
PostToolUse

도구 실행 직후 호출. 파일 수정 후 자동 린트, 테스트 실행, 로그 기록 등에 활용합니다.

Auto lint after writes
🟢
SessionStart

세션 시작·재개 시 호출. 컨텍스트 주입, 초기화 스크립트, 환경 변수 로드 등에 사용합니다.

Load content on launch
💾
SessionStop

세션 종료 시 호출. 세션 요약 저장, 작업 상태 기록, 핸드오프 문서 자동 생성 등에 활용합니다.

Save session summaries
🔒
PreCommit

git commit 전 호출. API 키·비밀번호 등 시크릿이 코드에 포함됐는지 자동으로 탐지합니다.

Secret detection
🔔
Notification

작업 완료·오류 발생 시 호출. Slack 웹훅, 이메일, 데스크탑 알림 등으로 이벤트를 전달합니다.

Slack webhook alerts

settings.json 훅 설정 예시:

json — .claude/settings.json 
{
  "permissions": { "allow": [...], "deny": [...] },
  "hooks": {
    "PreToolUse": [{ "matcher": "Bash",
      "hooks": [{ "type": "command",
        "command": "sbock-safety.sh" }]}],
    "PostToolUse": [{ "matcher": "Write",
      "hooks": [{ "type": "command",
        "command": "npm run lint" }]}]
  },
  "env": {
    "MAX_THINKING_TOKENS": "10000",
    "CLAUDE_AUTOCOMPACT_PCT_OVERRIDE": "50"
  }
}
05 MCP 통합

인기 MCP 서버

MCP(Model Context Protocol)는 Claude가 외부 도구·데이터에 직접 접근할 수 있게 해주는 표준 프로토콜입니다. .mcp.json에 서버를 등록하면 Claude가 해당 도구를 자유롭게 사용할 수 있습니다.

MCP 서버기능주요 용도
GitHub PRs, Issues, Repos 조회·생성 PR 리뷰 자동화, 이슈 트래킹
JIRA / Linear 티켓 조회·업데이트 작업 스케줄링, 진척 추적
PostgreSQL DB 직접 쿼리 데이터 분석, 스키마 탐색
Playwright 브라우저 자동화 E2E 테스트, UI 스크래핑
Filesystem 파일 읽기·쓰기 (스코프 제한) 문서 자동 생성, 파일 관리
Slack 메시지 전송, 채널 조회 알림 발송, 팀 커뮤니케이션
json — .mcp.json 
{
  "mcpServers": {
    "github": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@anthropic/mcp-github"],
      "env": { "GITHUB_TOKEN": "${GITHUB_TOKEN}" }
    },
    "postgres": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@anthropic/mcp-postgres"],
      "env": { "DATABASE_URL": "${DATABASE_URL}" }
    }
  }
}
보안 주의
.mcp.json에 API 키를 직접 입력하지 말 것. 반드시 환경 변수(${GITHUB_TOKEN} 등)로 참조하고, .env 파일은 .gitignore에 추가하세요.
06 시작 가이드

Getting Started — 6단계

Claude Code 프로젝트 아키텍처를 처음 세팅하는 순서입니다.

1
Claude Code 설치
npm으로 전역 설치합니다.
bash 
npm i -g @anthropic-ai/claude-code
2
프로젝트 디렉토리로 이동 후 claude 실행
프로젝트 루트에서 claude 명령을 입력하면 자동으로 CLAUDE.md를 탐색합니다.
bash 
cd your_project && claude
3
CLAUDE.md 작성
기술 스택, 아키텍처, 컨벤션, 보안 규칙을 정의합니다. Claude가 매 세션마다 자동으로 이 파일을 읽습니다.
4
.claude/commands/ 에 슬래시 명령어 추가
자주 쓰는 작업 패턴을 /review, /deploy 같은 명령어로 정의합니다.
5
.mcp.json 에 MCP 서버 등록
GitHub, PostgreSQL, Playwright 등 필요한 외부 도구를 연결합니다. API 키는 반드시 환경 변수로 참조합니다.
6
skills/ 추가로 워크플로우 확장
프로젝트가 성장하면서 code-review, security-audit, deploy 등 스킬을 하나씩 추가해 자동화 범위를 넓힙니다.
07 Pro Tips

컨텍스트 관리 & 베스트 프랙티스

Claude Code를 효과적으로 사용하기 위한 핵심 팁입니다.

컨텍스트 사용률 가이드
0~60% — 정상 작업 / 60~70% — 사용량 모니터링 / 70~80% — /compact 실행 / 80%+ — /clear 필수
🔄
Start small, iterate fast 작은 단위로 시작해 빠르게 반복하세요. 한 번에 큰 작업보다 모듈화된 소작업이 더 좋은 결과를 냅니다.
📝
스킬 문서를 명확하게 SKILL.md의 설명이 구체적일수록 Claude가 정확하게 매칭·활용합니다.
🧩
모듈형 스킬 설계 복잡한 작업은 작은 스킬 단위로 쪼개세요. 재사용성과 유지보수성이 높아집니다.
🔐
시크릿은 환경 변수로 API 키·비밀번호를 코드나 설정 파일에 직접 넣지 마세요. 항상 환경 변수를 사용합니다.
🧹
컨텍스트 80%에서 /clear 컨텍스트가 오래될수록 응답 품질이 저하됩니다. /compact → /clear 패턴으로 관리하세요.
🤖
서브에이전트로 병렬 처리 독립적인 작업(테스트 작성 + 코드 리뷰)은 서브에이전트로 동시에 실행해 시간을 절약합니다.
