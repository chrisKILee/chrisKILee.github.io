02 — Architecture

Recurrent-Depth Transformer (RDT)

동일한 Transformer 블록을 T회 반복 실행. 파라미터를 늘리지 않고 추론 깊이를 확보합니다.

3단계 파이프라인

01
Prelude
입력을 고정 인코딩 e로 변환. 표준 Transformer 1회 통과.
02
Recurrent Block
동일 가중치의 블록을 T회 반복 실행. 매 반복마다 은닉 상태 h_t 정제. MoE가 각 반복마다 다른 전문가 활성화.
03
Coda
최종 은닉 상태를 디코딩해 출력 토큰 생성. 중간 추론 토큰 없음.

LTI 안정화 공식

math
h_{t+1} = A · h_t + B · e + Transformer(h_t, e) A : 스펙트럼 반경 < 1인 대각 행렬 → 발산 방지 (spectral_radius = 0.99) B : 학습 가능한 입력 주입 파라미터 e : Prelude의 고정 인코딩 h_t: t번째 반복의 은닉 상태
✦ 스펙트럼 반경 제약으로 반복이 깊어져도 은닉 상태가 폭발하지 않음. "과도한 생각" 방지.
03 — Core Technologies

핵심 기술 4가지

OpenMythos가 통합한 최신 아키텍처 기술들.

🔁
Recurrent-Depth Transformer
동일 가중치 블록을 T회 반복 실행. 770M 파라미터 RDT가 1.3B Dense Transformer와 동등 성능 달성 (Parcae/Prairie 2026 논문 기반).
🧩
Mixture of Experts (MoE)
DeepSeekMoE 방식 채택. 64개 라우팅 전문가 + 고정 공유 전문가. 각 반복마다 서로 다른 전문가 부분 집합이 활성화되어 계산적 다양성 확보.
💾
Multi-Latent Attention (MLA)
DeepSeek-V2 방식. K/V 텐서를 저차원 잠재 벡터로 압축. KV 캐시 10–20배 절감, 생성 처리량 5.76배 향상 (DeepSeek-V2 공식 수치).
⏱️
Adaptive Computation Time (ACT)
토큰별 학습 가능한 halting unit. 쉬운 토큰은 조기 종료, 어려운 토큰은 충분한 반복. 손실에 Ponder Cost를 추가해 과도한 계산 방지.
🔇
Latent Reasoning (내부 추론)
반복 루프 내에서 벡터 공간에만 계산. 중간 추론 토큰 미출력. Claude Extended Thinking의 외부 CoT와 달리 "생각한 후 말하는" 패러다임.
📐
Depth Extrapolation
훈련 시 N회로 학습해도 추론 시 N+k회 실행 가능. 모델 재훈련 없이 추론 깊이를 런타임에서 동적 조정. 문제 난도별 비용 최적화 가능.
04 — Comparison

기존 LLM과의 차별점

표준 Transformer 대비 RDT 방식의 장단점 비교.

비교 항목 Standard Transformer RDT (OpenMythos)
파라미터 효율 레이어마다 고유 가중치 가중치 공유 → 770M ≈ 1.3B Dense 1.7× 절감
추론 비용 구조 고정 (파라미터 수에 비례) 동적 (반복 수 조정 가능) → 쉬운 문제 절감
추론 토큰 CoT 방식: 토큰으로 출력 내부 벡터 공간에서만 계산 (외부 토큰 불필요)
깊이 확장 재훈련 필요 런타임에서 T값 조정 가능 (Depth Extrapolation)
Turing 완전성 이론적으로 아님 입력 의존적 깊이 → Turing 완전 (Universal Transformer 연구 기반)
KV 캐시 MHA 기본 (대용량) MLA: 10–20× 절감, 처리량 5.76× 증가
05 — Usage

설치 및 사용

pip 설치 후 MythosConfig로 아키텍처를 설정해 모델을 초기화합니다.

01
패키지 설치
pip으로 설치합니다.
bash
pip install open-mythos
02
모델 초기화
MythosConfig로 아키텍처를 설정하고 모델을 생성합니다.
python
from open_mythos import OpenMythos, MythosConfig config = MythosConfig( vocab_size=32000, dim=2048, seq_len=4096, attn_type="mla", # Multi-Latent Attention n_experts=64, # 라우팅 전문가 수 max_loop_iters=16, # 반복 깊이 (추론 시 동적 변경 가능) spectral_radius=0.99, # LTI 안정화 제약 ) model = OpenMythos(config)
03
텍스트 생성
generate()로 토큰을 생성합니다. 추론 시 max_loop_iters 값을 높여 더 깊은 추론을 시도할 수 있습니다.
python
tokens = model.generate( prompt_tokens=[1, 2, 3], max_new_tokens=100, temperature=0.8, top_k=50, )
04
분산 훈련 (선택)
FineWeb-Edu 데이터셋, bfloat16 정밀도, Muon+AdamW 옵티마이저 설정.
bash
torchrun --nproc_per_node=8 train.py \ --model_dim 2048 \ --max_loop_iters 16 \ --batch_size 32 \ --dataset FineWeb-Edu \ --dtype bfloat16

07 — Limitations

한계점 및 주의사항

OpenMythos를 사용하거나 참고할 때 반드시 인지해야 할 사항들.

🎲
가설적 구현
Anthropic은 Mythos 아키텍처를 공식 공개한 적 없음. OpenMythos는 공개 연구 기반 추측이므로 실제 Claude Mythos와 무관할 수 있음.
📍
위치 신호 부재
반복 루프 전체에서 위치 신호 없음. 조기 패턴 매칭과 후기 정제에 동일 가중치 사용 → 고도로 제한된 제약 조건.
📉
과반복 성능 저하
최적 깊이를 초과하면 은닉 상태가 해에서 벗어나 노이즈로 빠질 수 있음. ACT 메커니즘으로 완화 시도.
🔬
학술·실험 목적
프로덕션 사용 부적합. RDT 메커니즘 탐구를 위한 교육적 참조 구현으로 활용 권장. 소규모 실험에만 적합.
