02 개념

Harness가 하는 일

Claude Code의 실험적 Agent Teams 시스템을 활용해 복잡한 작업을 전문화된 에이전트 협업 팀으로 분해합니다.

Harness 실행 흐름: 프롬프트 → 도메인 분석 → 에이전트/스킬 파일 생성 → 팀 구동

03 아키텍처

6가지 팀 구성 패턴

Harness는 작업 성격에 따라 6가지 에이전트 팀 구조 중 최적을 선택합니다.

6가지 팀 아키텍처 패턴 — 실선: 데이터 흐름 / 점선: 선택적 흐름

⛓️ Pipeline 순차
에이전트가 일렬로 연결되어 이전 결과를 다음 에이전트가 이어받습니다.
→ 데이터 가공, 번역→검수→배포 등 의존 순서가 고정된 작업
🔀 Fan-out / Fan-in 병렬
독립적인 여러 작업을 병렬로 처리하고 결과를 하나로 합칩니다.
→ 다국어 번역, 멀티-소스 조사, 병렬 코드 분석
🎓 Expert Pool 선택
요청 내용에 따라 전문 에이전트를 선택적으로 호출합니다.
→ 도메인별 전문가 풀, 질의 라우팅
🔍 Producer-Reviewer 검토
생성 에이전트가 초안을 만들고, 검토 에이전트가 품질을 확인합니다.
→ 코드 생성+리뷰, 문서 작성+검수
🎛️ Supervisor 중앙집중
중앙 에이전트가 상황에 따라 동적으로 작업을 분배합니다.
→ 복잡한 프로젝트 관리, 동적 태스크 할당
🏛️ Hierarchical Delegation 위임
상위 에이전트가 하위 에이전트에게 하향식으로 위임합니다.
→ 대규모 프로젝트, 조직 계층 구조 모방
04 워크플로우

6단계 실행 흐름

/harness 또는 "build a harness for this project" 입력 시 아래 6단계가 자동으로 진행됩니다.

사전 요건
Claude Code 실험적 Agent Teams 기능 활성화가 필요합니다:
CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1
1
도메인 분석 (Domain Analysis)
프로젝트 구조, 기술 스택, 작업 패턴을 파악합니다. 어떤 전문성이 필요한지 식별합니다.
2
팀 아키텍처 설계 (Team Architecture Design)
Agent Teams vs Subagents 중 선택, 6가지 패턴 중 최적 구조를 결정합니다.
3
에이전트 정의 생성 (Agent Definition Generation)
각 전문 에이전트의 역할, 능력, 트리거 조건을 담은 파일을 .claude/agents/에 생성합니다.
4
스킬 생성 (Skill Generation)
에이전트가 사용할 스킬을 Progressive Disclosure 방식으로 .claude/skills/에 자동 작성합니다.
5
통합 & 오케스트레이션 (Integration & Orchestration)
에이전트 간 데이터 전달 방식, 에러 처리, 협업 프로토콜을 연결합니다.
6
검증 & 테스트 (Validation & Testing)
트리거 검증, 드라이런 테스트, Harness 유무 비교 테스트로 팀 품질을 확인합니다.
05 설치

설치 방법

두 가지 방법으로 설치할 수 있습니다.

🛒
Claude Code 마켓플레이스 (권장)

/plugin install harness@harness
자동 업데이트 지원
📁
직접 복사 (글로벌 스킬)

저장소를 clone한 뒤 스킬 파일을 글로벌 Claude 디렉토리에 복사합니다.

오프라인 환경용

Claude Code에서 /harness 또는 "build a harness for this project"라고 입력하면 자동으로 6단계 워크플로우가 시작됩니다.
06 실행 모드

Agent Teams vs Subagents

Harness는 작업 성격에 따라 두 가지 실행 방식을 선택합니다.

구분 Agent Teams (기본) Subagents
메커니즘 TeamCreate + SendMessage + TaskCreate Agent 도구 직접 호출
에이전트 수 2개 이상 협업 단독 or 비협업
에이전트 간 통신 ✓ 지원 미지원
적합한 작업 복잡한 협업 필요 태스크 독립적 일회성 태스크
요구 환경변수 CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 불필요
