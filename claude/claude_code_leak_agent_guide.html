01 배경

유출된 코드, 왜 중요한가요?

맛집 레시피가 공개된 것과 같습니다. Claude Code가 어떻게 동작하는지 설계도가 드러났고, 이걸 보면 "아, 이렇게 만드는 거구나"를 배울 수 있습니다.

이 가이드는 이런 분들을 위해 썼어요
코드를 처음 접하는 분 · ChatGPT나 Claude로 코딩을 해본 적은 있는 분 · "AI 에이전트"가 뭔지 감은 오는데 어떻게 만드는지 모르는 분

AI 에이전트(Agent)가 뭔가요?

일반 AI와 AI 에이전트의 가장 큰 차이는 "혼자 여러 단계를 실행할 수 있느냐"입니다.

일반 AI vs AI 에이전트
쉽게 말하면
AI 에이전트는 "심부름을 시킬 수 있는 AI"입니다. "이 폴더 안에 있는 엑셀 파일들 전부 분석해서 요약 보고서 만들어줘" 같은 걸 혼자 처리해요.
02 핵심 발견

유출 코드에서 발견된 핵심 아이디어 5가지

Claude Code의 설계 원리를 쉽게 이해할 수 있는 5개의 개념입니다. 각각 내 서비스에 어떻게 적용할 수 있는지도 함께 살펴봅니다.

🔧
도구 상자 (Tool System)

AI에게 쓸 수 있는 도구 목록을 주면, AI가 상황에 맞게 골라서 씁니다. 파일 읽기, 코드 실행, 검색 등을 도구로 정의합니다.

아이디어 01
🔄
자기가 알아서 반복 (Agentic Loop)

목표를 달성할 때까지 AI가 생각 → 도구 사용 → 결과 확인을 스스로 반복합니다. 개발자들이 "agentic loop"라고 부르는 핵심 패턴입니다.

아이디어 02
🧠
기억 노트 (Memory System)

대화가 끝나도 중요한 내용을 파일로 저장하고, 다음 대화 때 읽어서 기억합니다. 정해진 형식의 마크다운 파일로 구현됩니다.

🌙

03 상세 설명

각 아이디어 자세히 살펴보기

개념과 함께 "내 서비스에 어떻게 쓸 수 있는지"도 함께 설명합니다.

🔧
아이디어 01
도구 상자 (Tool System)

AI 혼자서는 파일을 열거나 프로그램을 실행할 수 없어요. 그래서 Claude Code는 AI에게 도구 상자(Tool Box)를 줬습니다. AI에게 "이런 일들은 할 수 있어" 하고 도구 목록을 주면, AI가 알아서 판단해서 씁니다.

Claude Code 도구 목록 
AI가 쓸 수 있는 도구들:
🔨 Bash      → 터미널 명령어 실행
📖 FileRead  → 파일 읽기
✏️ FileEdit  → 파일 수정
🔍 Grep      → 코드 검색
🤖 Agent     → 다른 AI 호출
내 서비스에 적용하면: 쇼핑몰 운영 AI라면 주문 조회 도구 · 재고 확인 도구 · 문자 발송 도구를 주면, AI가 알아서 판단해서 씁니다.
🔄
아이디어 02
자기가 알아서 반복 (Agentic Loop)

유출 코드에서 가장 중요한 부분입니다. 레고를 맞추는 것처럼 목표를 달성할 때까지 AI가 스스로 반복합니다.

실제 예시 
나: "이 폴더에 있는 모든 이미지 파일 이름을 날짜 순서로 정리해줘"

AI: (파일 목록 확인)
  → (날짜 확인)
  → (이름 변경)
  → (완료 확인)
  → "다 됐습니다!"
내 서비스에 적용하면: 목표를 주면 AI가 스스로 단계를 나눠서 처리합니다. 사람이 중간에 개입할 필요가 없어요.
🧠
아이디어 03
기억 노트 (Memory System)

Claude Code는 대화가 끝나도 중요한 내용을 파일로 저장하고, 다음 대화 때 그 파일을 읽어서 기억하는 척(?)합니다. 기억 파일에는 정해진 형식이 있어요.

폴더 구조 
내 컴퓨터/.claude/
└── memory/
    ├── MEMORY.md         ← 목차 (가장 먼저 읽는 파일)
    ├── 내_작업스타일.md
    ├── 프로젝트_맥락.md
    └── 자주_쓰는_설정.md
기억 파일 형식 
---
name: 기억 이름
description: 한 줄 설명
type: user (나에 대한 정보) 또는 project (프로젝트 정보)
---
실제 내용을 여기에 써요
내 서비스에 적용하면: 고객 상담 AI라면 "이 고객은 배송 문제로 3번 연락했음" 같은 걸 기억 파일에 저장하면, 다음에 AI가 먼저 알고 있는 척 대응할 수 있어요.
🌙
아이디어 04 · 미공개 기능
자는 동안도 일해요 (AutoDream & Kairos)

유출 코드에서 발견된 숨겨진 기능 2가지입니다.

AutoDream
Claude Code를 닫은 뒤에도 백그라운드에서 오늘 대화를 분석해서 중요한 내용을 자동으로 기억 파일에 정리해 둡니다. 마치 자는 동안 뇌가 기억을 정리하는 것처럼요.
Kairos (tengu_kairos)
사용자가 아무것도 안 해도 AI가 스스로 깨어나서 작업을 수행하는 데몬(Daemon, 백그라운드 프로그램)입니다. 아직 일반에게 공개되지 않은 기능이며, Anthropic이 준비 중인 것으로 보입니다.
내 서비스에 적용하면: 매일 밤 자동으로 "오늘 고객 문의 분석 → 패턴 파악 → 내일 FAQ 업데이트"를 혼자 하는 AI를 만들 수 있어요.
💰
아이디어 05 · 미공개 기능
AI가 알아서 결제 (x402)

제일 충격적인 발견입니다. 유출 코드에 x402라는 폴더가 있는데, AI 에이전트가 유료 서비스를 이용할 때 USDC(암호화폐)로 자동 결제하는 시스템입니다.

x402 결제 흐름 
AI 에이전트가 유료 데이터 API 요청
      ↓
서버: "이건 0.01달러짜리입니다"
      ↓
AI: (한도 내면) 자동으로 암호화폐 결제
      ↓
데이터 수신 → 작업 계속
의미: 미래에는 AI가 사람 개입 없이 유료 서비스를 사용하고 결제하는 게 가능해진다는 의미예요. 아직 일반에 공개되지 않은 기능입니다.
04 실습

바이브코딩으로 실제로 만들어보기

Claude나 ChatGPT에게 아래 프롬프트를 그대로 붙여넣으면 위 아이디어들을 구현할 수 있어요.

1
나만의 AI 비서 (기억 있는 버전)
대화가 끝나도 기억하는 AI 비서를 만듭니다. Memory System(아이디어 3)을 직접 구현해 볼 수 있어요.
Claude / ChatGPT에게 붙여넣기 
Python으로 간단한 AI 비서를 만들어줘.
조건:
1. 대화를 나눌 때마다 중요한 내용을 memory.md 파일에 저장해
2. 다음에 실행할 때 memory.md를 읽어서 이전 대화를 기억하는 것처럼 행동해
3. Anthropic API 사용해
4. 터미널에서 실행할 수 있게 해줘
2
파일 정리 AI 에이전트
폴더 경로를 알려주면 AI가 스스로 파일 분류부터 이동까지 처리합니다. Agentic Loop(아이디어 2)와 Tool System(아이디어 1)이 결합된 예시예요.
Claude / ChatGPT에게 붙여넣기 
Python으로 파일 정리 AI 에이전트를 만들어줘.
조건:
1. 사용자가 폴더 경로를 알려주면 그 안의 파일들을 분석해
2. AI가 스스로 파일 목록 확인 → 분류 → 폴더 이동을 순서대로 진행해
3. 각 단계에서 "지금 이걸 하려고 합니다, 괜찮을까요?" 하고 물어보게 해
4. Anthropic API 사용해
3
매일 자동 실행되는 AI
AutoDream(아이디어 4)처럼 매일 정해진 시간에 스스로 작업을 수행하는 AI를 만듭니다.
Claude / ChatGPT에게 붙여넣기 
Python으로 매일 오전 9시에 자동 실행되는 AI를 만들어줘.
조건:
1. 매일 아침 정해진 폴더의 새 파일들을 확인해
2. 새 파일이 있으면 내용을 요약해서 summary.md에 추가해
3. Mac에서 백그라운드로 실행되게 해줘
4. Anthropic API 사용해
05 꿀팁

바이브코딩할 때 꿀팁

처음 AI로 코딩을 시작할 때 알아두면 완성 확률이 크게 올라가는 4가지 팁입니다.

팁 01
기능을 하나씩 추가하세요
❌ 한 번에 다 만들어달라고 하기
✅ 가장 기본 버전 먼저 → 동작 확인 → 기능 추가
팁 02
에러가 나면 그대로 붙여넣기
에러 메시지를 그대로 복사해서 "이런 에러가 났어. 어떻게 고치면 돼? 전/후로 알려줘. 메서드 단위로 알려줘." 라고 물어보세요.
팁 03
"이해하기 쉽게 설명해줘"를 자주 쓰세요
코드가 왜 이렇게 생겼는지 모르겠으면 물어보세요. 이해해야 나중에 수정할 수 있어요.
팁 04
실제로 쓸 것만 만드세요
있으면 좋겠다 싶은 기능보다
지금 당장 불편한 것부터 해결하는 게 완성 확률이 높아요.
