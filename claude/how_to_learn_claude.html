How To Learn Claude

Claude를 제대로 활용하는 10가지 방법. Chat부터 Claude Code까지 — 당신에게 맞는 진입점을 찾아보세요.

출처: anthropic.com · chris-donnelly.co.uk
Overview
Claude 생태계 한눈에

Claude는 하나의 챗봇이 아닙니다. 10가지 접근 방식으로 어떤 업무든 처리할 수 있습니다.

💬 Chat 🤖
Claude.ai
WEB INTERFACE · 무료 플랜 시작

Claude를 만나는 가장 쉬운 방법. 브라우저에서 바로 대화하며 글쓰기, 분석, 리서치, 법률 검토, 전략 수립 등 어떤 주제든 다룰 수 있습니다.

  • 200K 컨텍스트 윈도우 (약 500페이지 분량)
  • Artifacts로 코드·문서를 실시간 미리보기
  • Projects · Skills 연동으로 지속적 컨텍스트
Best For
인터넷을 쓰는 모든 사람. 비개발자부터 전문직까지 — 진입장벽이 가장 낮습니다.
🧠 Reasoning 💡
Extended Thinking
DEEP REASONING · Pro 이상

Claude가 답변 전 단계별 내부 추론을 거치는 모드. 빠른 답변이 부족한 복잡한 문제에서 정확도가 크게 올라갑니다.

  • Thinking budget으로 추론 깊이 직접 제어
  • 수학·논리·과학 문제에서 정확도 대폭 향상
  • 내부 추론 과정(thinking block)이 사용자에게 투명하게 공개
Best For
창업자·애널리스트·재무 모델러 — 빠른 답보다 깊은 분석이 필요한 의사결정자.
🖥 Developer ⚙️
API
DEVELOPER ACCESS · 종량제

Claude를 직접 자신의 제품·서비스에 통합하는 공식 API. 자동화 파이프라인부터 AI 스타트업 인프라까지 제한 없이 활용할 수 있습니다.

  • Prompt caching으로 반복 호출 비용 절감
  • Context compaction으로 긴 대화 자동 관리
  • Skills 연동(/v1/skills), Effort controls 제공
Best For
AI 제품을 만드는 개발자·엔지니어링 팀. 내부 도구 자동화, SaaS 통합.
🔧 Build 🏗️
Artifacts
INTERACTIVE OUTPUTS · Free 포함

대화 옆 패널에서 코드·문서·인터랙티브 앱을 실시간으로 만들고 바로 사용할 수 있습니다. 코딩 없이도 프로토타입을 뚝딱 완성합니다.

  • 대시보드, 간트차트, 게임, 학습도구 즉시 생성
  • MCP로 Asana·Google Calendar·Slack 연동 가능
  • 세션 간 데이터 저장 (개인/공유 스토리지)
Best For
예산 계산기·트래커·플래너가 필요한 누구나. 비개발자 프로토타이퍼.
⚙️ Automation 🤝
Cowork
DESKTOP AGENT · Research Preview

로컬 파일을 직접 읽고 Excel·Word·PDF를 폴더에 생성하는 데스크탑 AI 코워커. 업로드 없이 복잡한 문서 작업을 자동화합니다.

  • 실제 파일 읽기·쓰기 (업로드 없이 바로 접근)
  • 복잡한 작업을 병렬 워크스트림으로 분해 실행
  • 반복 작업 자동화 스케줄링
Best For
매일 대량의 문서를 다루는 운영 매니저·임원 보좌 담당자. (Pro/Max/Team/Enterprise)
🌐 Browser 🔍
Claude in Chrome
BROWSER AGENT · 베타

Chrome 사이드패널에서 Claude가 웹페이지를 읽고, 클릭하고, 반복 작업을 대신 처리합니다. 수동으로 정보를 수집하는 시간을 없앱니다.

  • 탭 그룹 관리 및 멀티탭 동시 작업
  • 반복 워크플로우 녹화 후 자동 재실행
  • 로그인된 사이트 전체 접근 (Gmail, Notion, Slack 등)
Best For
웹에서 정보를 손으로 모으는 리서처·전략가. (Pro/Max/Team/Enterprise)
💻 Coding ⌨️
Claude Code
CLI · AGENTIC CODING

터미널과 IDE에서 전체 코드베이스를 이해하고 파일 편집·명령 실행·Git 작업을 자율로 수행하는 AI 코딩 도구입니다.

  • 멀티 에이전트 팀 구성으로 병렬 작업 처리
  • VS Code·JetBrains·Slack 통합 지원
  • 대규모 리팩토링·자동 PR 생성
Best For
품질을 포기하지 않고 더 빠르게 개발하고 싶은 개발자·기술 창업자.
🔌 Integrations 🔗
Connectors
MCP INTEGRATIONS · Team 이상

Slack, Google Drive, Notion 등 50개 이상의 외부 도구를 Claude에 연결합니다. 스크린샷 없이 실시간으로 데이터를 조회하고 액션을 실행합니다.

  • Jira·Asana·Linear·Confluence·Slack 등 지원
  • Zapier 통해 수천 개 앱 연결 가능
  • 원격 MCP 서버 기반으로 안전한 통합
Best For
여러 플랫폼에서 일하는 팀. 하나의 창구로 모든 것을 찾고 싶은 경우.
📋 Instructions 📦
Skills
REUSABLE PACKS · 2025.12 출시

재사용 가능한 지시·스크립트·리소스 묶음으로 Claude에게 특정 전문성을 부여합니다. 매번 설명하지 않아도 원하는 방식으로 작동합니다.

  • Composable — 여러 Skills 자동 조합
  • Portable — Claude.ai·Claude Code·API 전 플랫폼 호환
  • Excel 수식, PowerPoint, Word, PDF 폼 내장 Skills 제공
Best For
특정 보이스·규칙이 필요한 마케터·브랜드 매니저. 도메인 전문 워크플로우 팀.
📁 Context 💾
Projects
PERSISTENT WORKSPACE · Pro 이상

파일·지시사항·대화 이력을 저장해 Claude가 매 세션 이전 작업을 기억합니다. 같은 설명을 반복할 필요가 없어집니다.

  • 200K 컨텍스트에 코드베이스·스타일 가이드 업로드
  • 커스텀 지시사항으로 톤·관점 고정
  • Team 플랜: 대화 스냅샷 공유로 팀 협업 가능
Best For
반복 업무가 많은 콘텐츠 팀·법무·재무·고객 서비스 담당자.

Getting Started
어디서부터 시작해야 할까?

역할별 추천 진입점 — 당신에게 맞는 경로를 선택하세요.

Step 01 · 일반 사용자
💬
Claude.ai로 시작

가입 → Free 플랜 → 채팅 시작. 글쓰기·분석·번역·요약 어떤 것이든 먼저 물어보세요.

Step 02 · 직장인
📁
Projects 만들기

Pro 가입 → 새 Project 생성 → 사내 문서 업로드 → 커스텀 지시사항 설정. 반복 업무를 자동화하세요.

Step 03 · 개발자
💻
Claude Code 설치

npm install -g @anthropic-ai/claude-code 후 프로젝트 디렉토리에서 claude 실행.

Step 04 · 분석가
🧠
Extended Thinking 켜기

Pro/Max 플랜에서 채팅 좌측 메뉴 → Extended Thinking 활성화. 복잡한 모델 분석부터 적용해보세요.

Step 05 · 팀장
🔌
Connectors 연결

Team 플랜 → Settings → Integrations → Slack/Jira/Notion 연결. 팀 전체가 같은 컨텍스트로 작업하세요.

Step 06 · AI 빌더
⚙️
API 키 발급

console.anthropic.com → API Keys → 키 생성. Anthropic SDK 또는 Vercel AI Gateway로 제품을 만드세요.
