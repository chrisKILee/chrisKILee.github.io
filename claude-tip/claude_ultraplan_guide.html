계획은 브라우저에서,
실행은 터미널에서

/ultraplan은 Claude Code v2.1.91에서 공개된 클라우드 기반 계획 도구입니다. 터미널에서 명령을 내리면 Opus 4.6이 클라우드에서 구현 계획서를 작성하고, 사용자는 브라우저의 풍부한 UI에서 검토·수정한 뒤 원하는 환경에서 실행합니다.

📅 2026년 4월 11일 출시 ⚡ v2.1.91 이상 필요 🔬 Research Preview 👤 Pro / Max / Team / Enterprise
01 배경

터미널만으론 부족해진 이유

코드가 방대해지고 에이전트의 자율성이 높아지면서, 좁은 터미널 창만으로는 의도를 파악하기 어려워졌습니다. Ultraplan은 이 세 가지 문제를 해결합니다.

🔒
터미널 블로킹

기존 /plan은 계획 생성 동안 터미널이 점유되어 다른 작업이 불가능했습니다. Ultraplan은 계획을 클라우드로 위임해 터미널을 즉시 해방합니다.

blocking → async
📜
좁은 화면 가독성

긴 계획서를 터미널 스크롤로 파악하기 어렵고, 전체 구조를 한눈에 보기 힘듭니다. 브라우저 UI는 구조화된 목차·섹션 이동을 제공합니다.

terminal → browser
💬
섹션별 피드백 불가

터미널에서는 계획 전체에 대한 응답만 가능했습니다. Ultraplan 브라우저 뷰에서는 특정 구절을 선택해 인라인 댓글을 달고 반복 수정을 요청할 수 있습니다.

inline comments
02 사용 방법

3가지 실행 경로

Ultraplan을 시작하는 방법은 세 가지입니다. 확인 다이얼로그가 표시되고 클라우드 세션이 생성됩니다.

필수 요건
GitHub 저장소 연결이 필요합니다. 클라우드 세션은 실행 시점의 저장소 스냅샷을 사용합니다.
A
슬래시 명령어 직접 입력
터미널에서 /ultraplan 뒤에 작업 설명을 입력합니다. 확인 다이얼로그 후 클라우드 세션이 즉시 시작됩니다.
terminal 
/ultraplan migrate the auth service from sessions to JWTs
B
키워드 트리거
일반 프롬프트에 ultraplan 단어를 포함하면 자동 감지됩니다. 슬래시 없이도 동작합니다.
terminal 
ultraplan으로 결제 모듈 리팩토링 계획 잡아줘
C
로컬 /plan에서 전환
로컬 /plan 완료 후 승인 다이얼로그에서 "No, refine with Ultraplan on Claude Code on the web"을 선택합니다. 로컬 계획 초안이 컨텍스트로 클라우드 세션에 전달되며, 확인 다이얼로그가 생략됩니다.
03 워크플로우

투트랙 계획-실행 흐름

클라우드에서 계획하고, 웹 또는 로컬 중 실행 위치를 선택합니다. 터미널은 계획 생성 동안 다른 작업에 자유롭게 사용할 수 있습니다.

터미널 전송 시 선택지
계획서를 터미널로 보낼 때 세 가지 옵션이 제공됩니다: Implement here (현재 대화에 주입) · Start new session (새 세션으로 시작, claude --resume 명령 출력) · Cancel (파일로 저장, 경로 출력).
04 상태 표시

터미널에서 확인하는 클라우드 진행 상황

Ultraplan이 실행 중일 때 터미널 입력창에 실시간 상태가 표시됩니다. /tasks 명령으로 세션 링크 열기 또는 중단도 가능합니다.

◇ ultraplan
계획 작성 중 — Claude가 코드베이스를 분석하고 구현 계획 초안을 작성하고 있습니다. 이 동안 터미널은 다른 작업에 자유롭게 사용할 수 있습니다.
◇ ultraplan needs your input
명확화 질문 발생 — Claude가 계획 진행을 위해 추가 정보가 필요합니다. 브라우저 세션으로 이동해 질문에 답변해야 합니다.
◆ ultraplan ready
계획 완성 — 브라우저에서 검토 가능한 상태입니다. 세션 링크를 열어 계획서를 확인하고 인라인 댓글로 수정을 요청하세요.
05 브라우저 UI

계획서 검토 화면의 구성 요소

◆ ultraplan ready 상태에서 세션 링크를 열면 전용 검토 뷰가 표시됩니다.

💬
인라인 댓글 (Inline Comments)

계획서의 특정 구절을 드래그로 선택하고 댓글을 달면, Claude가 해당 부분만 수정해 업데이트된 초안을 제시합니다. 반복 횟수 제한이 없습니다.

iterative feedback
😊
이모지 반응 (Emoji Reactions)

텍스트를 작성하지 않고도 섹션에 이모지로 승인(👍) 또는 우려(⚠️) 반응을 표시할 수 있습니다. 빠른 검토에 적합합니다.

quick review
📑
개요 사이드바 (Outline Sidebar)

계획서 섹션이 좌측 사이드바에 목차로 표시됩니다. 클릭 한 번으로 원하는 섹션으로 이동할 수 있어 긴 계획서도 빠르게 탐색 가능합니다.

navigation

3가지 계획 변형 (A/B 테스트)

자동 배정
현재 변형을 직접 선택할 수 없으며, A/B 테스트로 자동 배정됩니다.

🗒 Simple Plan

간단한 작업용 기본 모드. 핵심 단계만 간결하게 정리합니다.

🖼 Visual Plan

다이어그램 포함, 협업 팀이 함께 검토하기에 적합합니다.

🔬 Deep Plan

다수 서브에이전트 활용, 위험 평가·아키텍처 검토 포함. 복잡한 작업에 적합합니다.

07 맥락

인지 흐름에 맞춘 UI 재설계

Ultraplan은 단순한 기능 추가가 아니라, 인간이 계획을 세우고 실행하는 방식에 맞춰 워크플로우 자체를 재설계한 시도입니다.

공식 정의 (Claude Code Docs)
"Ultraplan hands a planning task from your local CLI to a Claude Code on the web session running in plan mode. Claude drafts the plan in the cloud while you keep working in your terminal."
기존 방식

계획 → 터미널 점유 → 스크롤로 검토 → 전체 재질문 → 실행

Ultraplan 방식

명령 → 터미널 즉시 해방 → 브라우저에서 시각적 검토·섹션별 수정 → 웹 또는 로컬 선택 실행
