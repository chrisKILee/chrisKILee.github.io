🔥 Claude Code Tip

내 토큰은 어디에 쓰이고 있을까?
CodeBurn

Claude Code 세션 파일을 직접 읽어 토큰 사용량을 분석하는 터미널 대시보드. API 키 없이, 프록시 없이 동작한다.

📅 2026-04-16 🔗 github.com/AgentSeal/codeburn 📦 Node.js 20+ ⭐ 1.7k stars

왜 쓰는가

💡
토큰이 너무 많이 쓰인다 싶으면 — 무작정 절약법을 찾기 전에 먼저 어디에 얼마나 쓰이는지 파악하는 게 먼저다. 대화(63%), 코딩(16%), 탐색(15%), 디버깅(4%)처럼 활동 유형별로 비용이 쪼개져 나온다. 어디를 줄여야 할지 보인다.
API 키 불필요
0
디스크의 세션 파일(~/.claude/projects/)을 직접 읽는 방식. 외부 서버로 데이터를 전송하지 않는다.
지원 도구
4종
Claude Code, OpenAI Codex, Cursor, OpenCode. 복수 도구를 동시에 쓰는 경우 p 키로 전환.
분석 방식
결정론적
LLM 호출 없이 패턴 매칭으로 활동 유형을 분류. 빠르고 비용 없음.
구현 기술
Ink
터미널용 React인 Ink + TypeScript 100%로 만들어진 인터랙티브 TUI 앱.

설치 및 실행

전역 설치 (권장)
# Node.js 20 이상 필요
npm install -g codeburn

# 대시보드 실행
codeburn
설치 없이 바로 실행
# npx로 즉시 실행
npx codeburn

# 오늘만 보기
npx codeburn today

By Activity — 13가지 분류 상세

⚙️
분류 방식 — LLM 없이 결정론적 패턴 매칭으로 동작. 2단계 결정 트리를 거친다.
1단계: 어떤 도구(Tool)가 사용되었는가
2단계: 사용자 메시지에 어떤 키워드가 있는가
● Coding
도구 기반

Edit 또는 Write 도구가 사용된 턴. 실제 파일 수정이 발생한 코딩 작업. 메시지 키워드가 없으면 일반 Coding으로 분류.

Edit 도구 Write 도구
● Feature Dev
키워드 기반

Coding 분류 이후 2단계에서 기능 추가 키워드가 감지된 경우. 새 기능 구현, 컴포넌트 추가 등이 해당.

add create implement new build
● Debugging
키워드 기반

Coding/Exploration 분류 이후 오류 관련 키워드가 감지된 경우. 에러 수정, 버그 추적 등이 해당. 원샷 성공률도 함께 표시됨.

fix bug error crash 500 exception
● Refactoring
키워드 기반

코드 구조 개선 키워드가 감지된 경우. 기능 변경 없이 코드 품질을 높이는 작업.

refactor cleanup rename extract reorganize
● Exploration
도구 기반

Bash + 읽기 도구 사용, 또는 웹 검색/MCP 도구 사용, 또는 읽기 전용 턴. 코드베이스 탐색, 파일 조회, 외부 정보 수집 등.

Read 도구 Grep 도구 WebFetch WebSearch research analyze
● Delegation
도구 기반

Agent 도구가 실행된 턴. 서브에이전트를 스폰(spawn)하여 복잡한 작업을 위임한 경우. 원샷 성공률이 표시됨.

Agent 도구
● Conversation
기본값

도구 미사용 + 키워드 미매칭인 순수 텍스트 대화. 질문·답변·설명 요청 등이 모두 여기에 해당. 비율이 높다면 대화가 많다는 의미.

도구 없음 키워드 없음
● Brainstorming
키워드 기반

도구 미사용 턴에서 아이디어 탐색 키워드가 감지된 경우. 전략 논의, 설계 방향 탐색 등.

brainstorm idea strategy how should what if
● Planning
도구 기반

EnterPlanMode, TaskCreate 등 계획 도구가 사용된 턴. Claude Code의 Plan 모드나 Task 관리 작업이 해당.

EnterPlanMode TaskCreate TaskUpdate
● Testing
도구 기반

Bash만 사용한 턴에서 테스트 실행 키워드가 감지된 경우. 테스트 프레임워크를 CLI로 직접 실행하는 경우.

Bash 도구 pytest jest vitest test
● Build/Deploy
도구 기반

Bash만 사용한 턴에서 빌드·배포 키워드가 감지된 경우. npm 빌드, Docker, 서버 배포 등.

npm build docker deploy pm2
● Git Ops
도구 기반

Bash만 사용한 턴에서 Git 동기화 명령이 감지된 경우. push, pull, commit, merge 등 Git 협업 작업.

git push git pull git commit git merge
● General
기타

Skill 도구가 사용되었거나, 위 분류 중 어디에도 해당하지 않는 기타 턴.

Skill 도구 미분류 나머지

원샷 성공률 (One-Shot Rate)

🎯
원샷 성공률이란 — AI가 처음 시도에서 바로 작동 가능한 코드를 만들어낸 비율이다. Coding 90%라면 10번 중 9번은 수정 없이 통과했다는 의미.
측정 방식
Edit → Bash → Edit 패턴 감지. 수정 후 실행했는데 다시 수정이 필요했다면 원샷 실패로 카운트.
표시 대상
Coding, Debugging, Delegation, Refactoring 등 코드 수정이 포함된 활동에만 표시. Conversation에는 표시 안 됨(—).
활용법
원샷 성공률이 낮다면 프롬프트가 불명확하거나 컨텍스트가 부족한 것. 높으면 AI가 효과적으로 동작 중.

codeburn export --json
💱
환율 자동 갱신 — Frankfurter API(유럽중앙은행 데이터)를 사용해 162개 ISO 4217 통화를 지원. 24시간 캐싱. 가격 데이터는 LiteLLM DB에서 자동 가져옴.
