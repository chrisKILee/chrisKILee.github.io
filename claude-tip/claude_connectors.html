커넥터는 100개가 넘는다. 뭐부터 깔지 막막한 비전공자를 위해, 매일 쓰는 5개를 콕 집었다. 붙이는 순간 Claude가 내가 쓰는 앱들을 넘나들며 진짜 직원처럼 일한다.

🔌 외부 앱 연결 🗂️ Co-work 폴더 ✋ 항상 허용
01 개념

먼저, 커넥터가 뭐냐면

Claude에 외부 앱을 연결하는 '플러그'다. 채팅 모드가 아니라 코워크(Co-work) 모드에서 쓰며, 폴더를 정해주면 그 안에서 파일을 만들고 다룬다. 기술적으로는 MCP(Model Context Protocol)라는 개방형 표준 위에서 동작한다.

연결은 다 비슷하다
Customize → Connectors → 검색 → Connect. 매번 권한을 묻는 게 귀찮으면 '항상 허용'으로 두면 된다.
02 라인업

매일 쓰는 다섯 개

콘텐츠·영업·메일·데이터·만능 연결. 각자 자기 일에 맞는 걸 하나씩 얹으면 된다.

🎨
① Higgsfield
Claude 안에서 이미지·영상 만들기

Claude는 원래 그림을 못 그리는데, 이걸 붙이면 가능해진다. 시중 거의 모든 이미지 모델을 Claude 안에서 바로 쓴다. 제품 사진 한 장으로 설명용 인포그래픽을 만들고, 일관된 가상 인물로 UGC 광고 영상까지 찍어준다.

④ Supabase
데이터 저장 + 실시간 대시보드

매일 아침 유튜브 지표를 자동으로 긁어와 저장하면, 조회수·좋아요가 실시간으로 갱신되는 대시보드를 Claude 안에서 본다. 표에 항목을 추가하면 DB에도 바로 반영되는 양방향 앱이 된다. 아이디어 쌓는 '제2의 뇌'로도 쓴다.

데이터 · 대시보드
🔗
⑤ Zapier
커넥터가 없는 앱까지 연결

원하는 앱이 목록에 없을 때 쓰는 만능 키. Zapier MCP에 연결하면 9,000개가 넘는 앱에 접근한다. 전용 커넥터가 없는 Skool·Beehiiv 같은 것도 이걸로 다룬다. MCP 서버를 직접 만드는 건 개발자용이라, 비개발자는 이게 훨씬 편하다.

어떤 일에 어떤 커넥터?

자기 일에 맞춰 고르면 된다. 콘텐츠면 Higgsfield, 영업이면 Clay·Zapier, 데이터면 Supabase, 그리고 누구에게나 Gmail.

04 연결

붙이는 법은 다 똑같다

어떤 커넥터든 흐름은 동일하다. 처음 한 번만 익히면 나머지는 검색어만 바꾸면 된다.

1
Customize → Connectors 열기
Claude 설정에서 커넥터 화면으로 들어간다. 채팅이 아니라 코워크(Co-work) 모드에서 동작한다는 점을 기억한다.
2
검색 → Connect
붙일 커넥터 이름을 검색해 Connect를 누르고, 해당 서비스 계정으로 로그인·인증한다.
flow 
Customize → Connectors → "Gmail" 검색 → Connect → 로그인
3
'항상 허용'으로 두기 (선택)
작업할 때마다 권한을 묻는 게 번거로우면 '항상 허용'으로 설정한다. 단, 민감한 데이터에 접근하는 커넥터는 허용 범위를 한 번 더 확인한다.
4
작업 폴더 지정
코워크 모드에서 폴더를 정해주면, Claude가 그 안에서 파일을 만들고 다룬다.
