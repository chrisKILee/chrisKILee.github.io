01 기능 개요

claude-code-action이란?

Anthropic 공식 GitHub Action. PR과 이슈 워크플로우에 Claude를 직접 통합하여 AI 기반 코드 작업을 자동화합니다.

🔍
PR 코드 리뷰

PR 변경사항을 분석하고 보안 이슈, 성능 개선, 코드 품질에 대한 피드백을 자동으로 댓글로 남깁니다.

pull_request
🐛
이슈 대응 & 코드 구현

이슈에 할당되면 자동으로 버그를 수정하거나 기능을 구현하고, 진행 상황을 체크박스로 업데이트합니다.

issues
💬
대화형 어시스턴트

PR 댓글에서 @claude 멘션하면 아키텍처 질문, 리팩토링 제안 등 자유롭게 대화합니다.

issue_comment

02 기본 설정

Workflow YAML 작성법

가장 빠른 방법은 Claude Code CLI에서 /install-github-app을 실행하는 것입니다. 수동 설정은 아래를 참고하세요.

yaml — .github/workflows/claude.yml 
name: Claude Assistant
on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]
  issues:
    types: [opened, assigned]
  pull_request:
    types: [opened, synchronize]

jobs:
  claude:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          # claude_args: "--model claude-sonnet-4-6 --max-turns 10"

주요 파라미터

파라미터설명예시
anthropic_api_keyAnthropic API 키 (API Key 방식)${{ secrets.ANTHROPIC_API_KEY }}
prompt자동화 모드용 지시사항"Review for security issues"
trigger_phrase커스텀 트리거 문구 (기본값: @claude)"@review"
claude_argsClaude CLI 인자 전달--model --max-turns --allowedTools
assignee_trigger이슈 할당 트리거 계정명"claude"
03 OAuth 방식 (Max 구독)

API Key 없이 Max 구독으로 사용하기

Claude Pro/Max 구독자는 OAuth 토큰을 발급해 API Key 대신 사용할 수 있습니다. GitHub Actions에서도 동일하게 적용됩니다.

⚠️ 구독 필수
OAuth 방식은 Claude Pro ($20/월), Max ($100~200/월), Team, Enterprise 구독자만 사용 가능합니다. 구독 없이는 사용할 수 없습니다.
1
OAuth 토큰 발급
Claude Code CLI에서 아래 명령어를 실행합니다. 브라우저 인증 후 1년 유효한 토큰이 발급됩니다.
bash 
claude setup-token
2
GitHub Secret 등록
발급된 토큰을 GitHub 저장소 Settings → Secrets → Actions에 CLAUDE_CODE_OAUTH_TOKEN으로 등록합니다.
3
Workflow 수정
anthropic_api_key 대신 환경변수로 OAuth 토큰을 주입합니다.
yaml 
      - uses: anthropics/claude-code-action@v1
        env:
          CLAUDE_CODE_OAUTH_TOKEN: ${{ secrets.CLAUDE_CODE_OAUTH_TOKEN }}
        with:
          # anthropic_api_key는 설정하지 않음

인증 우선순위 (높은 순)

Claude Code는 아래 순서로 인증 방식을 확인합니다. ANTHROPIC_API_KEY가 설정되어 있으면 OAuth보다 먼저 적용되어 API 과금이 발생합니다.

1
Cloud Provider (Bedrock / Vertex / Foundry)

2
ANTHROPIC_AUTH_TOKEN (Bearer)
고급
3
ANTHROPIC_API_KEY
⚠️ API 과금 발생
4
apiKeyHelper 스크립트
커스텀
5
CLAUDE_CODE_OAUTH_TOKEN
구독 사용량 내
6
Subscription OAuth (기본값)
구독 사용량 내
⚠️ 주의: Max 구독자도 API Key 설정 시 별도 과금
Max 구독을 보유하더라도 workflow에 ANTHROPIC_API_KEY가 설정되어 있으면 구독이 아닌 API 토큰 기반으로 청구됩니다. OAuth 방식 사용 시 API Key는 반드시 제거하거나 빈 값으로 두어야 합니다.
04 요금 구조

API Key vs Max 구독 — 어떤 게 더 저렴할까?

API Key는 사용량 기반 과금, Max 구독은 정액제. 팀 규모와 사용 빈도에 따라 최적 방식이 다릅니다.

항목API Key 방식Max 구독 (OAuth)
청구 대상Console 워크스페이스개인 Claude 계정
기본 비용$0 (선불 없음)$100~200/월
과금 방식입출력 토큰 기반구독 사용량 내 포함
구독 필요불필요필수 (Pro/Max/Team)
유효 기간무제한 (키 삭제 전)OAuth 토큰 1년
초과 사용계속 과금됨사용량 제한 (Max는 Pro의 5배)
사용량 확인/cost 명령/stats 명령

✅ 핵심 결론
OAuth(Max) 방식은 Claude Max 구독 사용량 안에서 처리됩니다. 별도 API 과금이 없습니다. 단, ANTHROPIC_API_KEY가 환경변수에 함께 설정되어 있으면 우선순위에 의해 API 과금이 발생하므로, OAuth 전용으로 쓸 때는 API Key를 제거해야 합니다.
