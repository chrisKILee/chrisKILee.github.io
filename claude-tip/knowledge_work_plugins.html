01 개요

knowledge-work-plugins이란?

Claude를 특정 직무·팀·회사에 맞춰 전문화하는 오픈소스 플러그인 모음입니다. 일회성 프롬프트 작성이 아니라, 직무 전문 지식과 워크플로우를 영구적으로 인코딩합니다.

MCP(Model Context Protocol)란?
Claude와 외부 도구 간의 표준화된 연결 프로토콜입니다. 플러그인의 .mcp.json에 도구 URL을 설정하면 Claude가 해당 도구에 직접 접근합니다.
02 직무 플러그인

04 사용 방법

단계별 설치 & 사용 가이드

Claude.ai(Cowork) 또는 Claude Code(CLI) 두 가지 방법으로 사용할 수 있습니다.

사전 요건
Claude 구독(Claude.ai Pro/Team/Enterprise 또는 Claude API)이 필요합니다. 플러그인 자체는 무료(Apache 2.0)이나 Claude 사용 비용은 발생합니다.

방법 A — Claude.ai (Cowork) 브라우저 사용

1
플러그인 마켓플레이스 접속
claude.com/plugins에 접속하거나 Claude.ai 좌측 사이드바에서 Plugins 탭을 클릭합니다.
2
원하는 직무 플러그인 설치
"Sales", "Finance" 등 직무명으로 검색 후 Install을 클릭합니다. Anthropic 공식 플러그인은 배지가 표시됩니다.
3
도구 연동 (선택사항)
플러그인 설정에서 Slack, HubSpot 등 연동할 도구의 OAuth 인증을 완료합니다. 도구 없이도 기본 기능은 사용 가능합니다.
4
슬래시 명령어로 실행
채팅창에 /sales:call-summary 등 슬래시 명령어를 입력합니다. Skills는 관련 업무 맥락에서 자동으로 활성화됩니다.

방법 B — Claude Code (CLI) 개발자 사용

bash 
# 1. 마켓플레이스에 저장소 추가
claude plugin marketplace add anthropics/knowledge-work-plugins

# 2. 원하는 플러그인 설치
claude plugin install sales@knowledge-work-plugins
claude plugin install finance@knowledge-work-plugins
claude plugin install data@knowledge-work-plugins

# 3. 설치된 플러그인 확인
claude plugin list

# 4. 슬래시 명령어 사용 (Claude Code 내에서)
# /sales:call-summary
# /finance:journal-entry ap-accrual 2026-05
# /data:analyze "monthly revenue by product"
05 활용 예시

직무별 실전 시나리오

각 플러그인이 실제 업무에서 어떻게 사용되는지 구체적인 시나리오로 설명합니다.

💼 Sales — 영업팀 HubSpot · Fireflies
시나리오 1 · 콜 후 CRM 자동 업데이트

/sales:call-summary 명령 후 Fireflies 통화 기록을 붙여넣으면, Claude가 액션 아이템·담당자·팔로업 이메일을 자동으로 추출하고 HubSpot 연동 시 거래 단계를 자동 업데이트합니다.

시나리오 2 · 파이프라인 주간 검토

HubSpot 파이프라인 데이터를 가져와 오래된 거래·마감일 초과·단일 연락처 거래에 위험 플래그를 표시하고 이번 주 실행 계획을 자동 생성합니다.

⚖️ Legal — 법무팀 내부 playbook 기반
시나리오 · 계약서 빠른 검토

/legal:review-contract로 계약서를 업로드하면, 회사 playbook의 기준(배상 한도 12개월, 면책 쌍방 여부 등)과 대조하여 조항별로 Green/Yellow/Red 위험도를 표시하고 수정 초안을 제안합니다.

시나리오 · NDA 자동 분류

/legal:triage-nda로 NDA를 분석해 "표준 승인 가능 / 검토 필요 / 에스컬레이션"으로 분류합니다. 반복 작업을 줄여 법무팀이 고위험 계약에 집중할 수 있게 합니다.

💰 Finance — 재무팀 Snowflake · BigQuery
시나리오 · 월말 마감 자동화

/finance:journal-entry ap-accrual 2026-05로 AP 미지급액 분개를 생성하고, /finance:reconciliation cash 2026-05로 은행 조정을 수행합니다. /finance:income-statement monthly 2026-05로 P&L과 분산 분석을 자동 생성합니다.

📊 Data — 데이터팀 Databricks · Hex
시나리오 · 자연어 → 대시보드

"최근 12개월 제품 라인별 월간 매출 트렌드 보여줘"라고 입력하면 Claude가 SQL을 작성해 Snowflake를 직접 쿼리하고, Chart.js 기반의 인터랙티브 HTML 대시보드를 생성합니다. 별도 BI 도구 없이 이해관계자와 공유 가능합니다.

🔍 Enterprise Search — 전사 검색 Slack · Notion · Gmail
시나리오 · 의사결정 추적

"API 재설계 관련 결정 사항이 뭐였지?"라고 물으면, Slack 채널·Gmail·Notion 문서·Linear 이슈를 동시에 검색하여 "3월 화요일 팀 회의에서 REST 방식으로 결정, Sarah가 설계서 이메일 전송"처럼 출처가 포함된 통합 답변을 제공합니다.

06 커스터마이징

회사에 맞게 조정하기

플러그인은 마크다운과 JSON만으로 구성되어 개발자가 아니어도 수정할 수 있습니다. GitHub에서 fork한 후 회사 특화 정보를 채우면 됩니다.

sales/ ├── .claude-plugin/ │ └── plugin.json # 플러그인 메타 (이름, 버전, 설명) ├── .mcp.json # 외부 도구 URL 연결 (HubSpot, Slack 등) ├── commands/ │ ├── call-summary.md # /sales:call-summary 슬래시 명령 정의 │ └── pipeline-review.md ├── skills/ │ ├── account-research.md # 자동 실행 Skills 정의 │ ├── call-prep.md │ └── draft-outreach.md └── settings.local.json # 조직 특화 설정 (담당자명, 제품, 경쟁사)

Legal playbook.md — 계약 기준 정의

markdown 
## Limitation of Liability
- 표준: 12개월 수수료 상한 (상호적)
- 허용 범위: 6~24개월
- 에스컬레이션: 무제한 조항

## Indemnification
- 표준: 상호 면책
- 허용: 제3자 클레임 한정
- 에스컬레이션: 일방적 의무

## 준거법
- 표준: 대한민국 법률
- 허용: 싱가포르, 영국
- 에스컬레이션: 미국 특정 주
커스터마이징 3단계 원칙
1. GitHub에서 anthropics/knowledge-work-plugins를 fork합니다.
2. settings.local.json과 skills/*.md에 회사 프로세스를 반영합니다.
3. 실제 케이스로 테스트 후 팀 전체에 공유합니다. 비개발자도 마크다운 편집만으로 가능합니다.
