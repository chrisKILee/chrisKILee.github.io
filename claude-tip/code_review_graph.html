01 토큰 문제

왜 토큰 낭비가 생기나?

AI 코딩 도구는 기본적으로 전체 코드베이스를 읽으려 합니다. code-review-graph는 변경 영향 범위(Blast Radius)만 잘라내 컨텍스트를 최소화합니다.

02 작동 원리

어떻게 동작하나?

코드 변경 시 Tree-sitter가 AST를 파싱하고, 그래프 DB가 의존 관계를 추적해 실제 영향받는 파일만 Claude Code에 전달합니다.

🌳
Tree-sitter AST 파싱

함수·클래스·의존성을 구문 트리로 분석합니다. 언어별 타입 매핑으로 노드를 식별하고 매개변수·반환 타입·기본 클래스를 추출합니다. 문법 버전 간 호환성이 쿼리 방식보다 견고합니다.

PARSER
💾
SQLite 그래프 저장

분석 결과를 .code-review-graph/ 디렉토리의 SQLite DB에 저장합니다. NetworkX 대비 더 빠른 BFS로 영향 범위를 추적하며 파일 해시로 중복 처리를 방지합니다.

STORAGE
🔄
증분 업데이트

파일 저장 시 git diff로 변경 파일만 재분석합니다. 전체 재파싱 없이 2,900개 파일 프로젝트에서 2초 이내에 그래프를 최신 상태로 유지합니다.

INCREMENTAL
03 핵심 기능

Recall 100%

04 설치 & 설정

Claude Code에 연결하기

Python 3.10+ 환경에서 pip 설치 후 3단계로 Claude Code에 연결할 수 있습니다. Claude Code, Cursor, Windsurf 등 주요 AI 도구를 자동 감지합니다.

사전 요구사항
Python 3.10~3.13, git이 설치된 환경에서 진행합니다. Windows 사용자는 WSL 환경을 권장합니다.
1
pip 설치
PyPI에서 code-review-graph를 설치합니다. 벡터 임베딩·커뮤니티 감지 등 추가 기능이 필요하면 [all] 옵션을 사용합니다.
bash 
pip install code-review-graph

# 모든 기능 포함 설치 (임베딩, 커뮤니티 감지 등)
pip install code-review-graph[all]
2
자동 구성 (MCP 서버 등록)
install 명령이 Claude Code를 자동 감지하고 MCP 서버를 등록합니다. --dry-run으로 변경 내용을 미리 확인할 수 있습니다.
bash 
code-review-graph install

# 변경 내용 미리 확인
code-review-graph install --dry-run
3
그래프 빌드
저장소 루트에서 실행합니다. 전체 코드베이스를 지식 그래프로 파싱해 .code-review-graph/에 SQLite DB를 생성합니다.
bash 
code-review-graph build
4
Claude Code에서 사용
빌드가 완료되면 Claude Code에서 MCP 슬래시 커맨드로 바로 사용할 수 있습니다. 코드 변경 시 자동 업데이트를 원하면 watch 명령을 활성화합니다.
bash 
# 파일 저장 시 자동 업데이트 활성화
code-review-graph watch

# 수동 업데이트
code-review-graph update
Claude Code 슬래시 커맨드
/code-review-graph:review-changes — 최근 변경사항 리뷰 (Blast Radius 포함)

/code-review-graph:architecture-map — 아키텍처 맵 생성
05 성능 수치

측정된 토큰 절감 효과

6개 실제 오픈소스 저장소를 대상으로 측정한 공식 벤치마크입니다. 저장소 구조에 따라 4.9x~27.3x 범위로 변동합니다.

지표 기존 방식 그래프 방식 절감율
평균 토큰 (6개 저장소) 전체 코드베이스 영향 파일만 평균 8.2x
Next.js (27,732 파일) 27,732 파일 컨텍스트 ~15개 파일 최대 49x
리뷰 품질 점수 7.2 / 10 8.8 / 10 +22%
Recall (영향 파일 누락) — 100% 누락 없음
F1 Score — 0.54 보수적 추정
증분 업데이트 속도 전체 재파싱 < 2초 (2,900 파일) 대폭 향상
F1 Score 0.54에 대해
Recall 100%이지만 Precision은 낮습니다. 영향받지 않는 파일도 일부 포함됩니다(보수적 추정). 토큰 절감보다 리뷰 완전성을 우선하는 설계 철학입니다.

07 주의사항

알려진 제한사항

v2.3.2 기준 71개의 미해결 이슈가 있습니다. 활발히 개발 중인 프로젝트이니 아래 사항을 사전에 확인하세요.

Windows 호환성 문제
Windows stdio MCP에서 get_minimal_context_tool / detect_changes_tool의 git subprocess가 hang되는 문제가 있습니다. WSL 환경 사용을 권장합니다.
동적 호출 미지원
리플렉션·동적 디스패치·AOP/Proxy 패턴은 호출 추적에서 분석되지 않습니다. 정적 분석 도구임을 감안해 사용하세요.
MCP 프로세스 누적 (Claude Code)
Claude Code 서브에이전트 사용 시 MCP serve 프로세스가 고아 프로세스로 누적될 수 있습니다. 장시간 사용 후 프로세스를 확인하세요.
권장 사용 패턴
.code-review-graphignore로 생성된 코드·의존성 폴더를 제외하면 성능이 향상됩니다. 정기적으로 code-review-graph update를 실행해 그래프를 최신 상태로 유지하세요.
