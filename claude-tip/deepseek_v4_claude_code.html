DeepSeek V4 × Claude Code

환경변수 몇 줄로 Anthropic 구독 없이 1M 토큰 컨텍스트와 최상위권 코딩 성능을. Base URL 교체만으로 Claude Code 워크플로우 그대로 유지.

DeepSeek V4 Pro · MoE 1.6T/49B · 프로모션 75% 할인 ~2026.05.31
한 줄 결론

코딩 성능은 DeepSeek V4 Pro, 신뢰도·보안은 Claude.

비민감 코딩 작업 + 비용 절감이 목적이면 V4 Pro. 기업 코드·기밀 데이터가 포함되면 Claude가 정답.

연결 방법 — 3단계 설정

💡
원리: Claude Code는 ANTHROPIC_BASE_URL 환경변수를 읽어 API 요청 대상을 결정합니다. DeepSeek가 Anthropic 호환 엔드포인트(https://api.deepseek.com/anthropic)를 제공하므로, 구독 없이도 Claude Code를 그대로 사용할 수 있습니다.
1

DeepSeek API Key 발급

platform.deepseek.com에서 계정 생성 → API Keys 메뉴 → 새 키 생성 → 크레딧 충전 (신규 $5 무료 크레딧 제공).

⚠️
API Key는 발급 즉시 복사해두세요. 페이지를 벗어나면 다시 볼 수 없습니다.
2

기존 Anthropic 인증 해제

기존 Claude 구독 세션을 먼저 로그아웃합니다. 환경변수와 충돌할 수 있습니다.

claude logout
3

환경변수 설정 (.zshrc / .bashrc)

아래 블록을 복사해 쉘 설정 파일에 추가하고 source ~/.zshrc로 적용하세요.

# DeepSeek V4 × Claude Code 연결 설정 unset ANTHROPIC_API_KEY D_M='deepseek-v4-pro' export \ ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic \ ANTHROPIC_AUTH_TOKEN="your-deepseek-api-key" \ ANTHROPIC_MODEL="$D_M" \ ANTHROPIC_DEFAULT_OPUS_MODEL="$D_M" \ ANTHROPIC_DEFAULT_SONNET_MODEL="$D_M" \ CLAUDE_CODE_SUBAGENT_MODEL="$D_M" \ ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-v4-flash \ CLAUDE_CODE_EFFORT_LEVEL=high \ CLAUDE_CODE_MAX_OUTPUT_TOKENS=100000

설정 후 새 터미널에서 claude를 실행하면 DeepSeek V4 Pro로 동작합니다.

환경변수 설명

변수명설명예시값
ANTHROPIC_BASE_URL API 요청 대상 주소. Anthropic 대신 DeepSeek 엔드포인트로 교체. https://api.deepseek.com/anthropic
ANTHROPIC_AUTH_TOKEN 인증 토큰. ANTHROPIC_API_KEY 대신 사용 (Key 이름 충돌 방지). sk-xxxxxxxxxx
ANTHROPIC_MODEL 기본 모델 슬롯. 대부분의 주 작업에 사용. deepseek-v4-pro
ANTHROPIC_DEFAULT_OPUS_MODEL Opus 슬롯 대체 모델. Claude Code가 "최고 성능" 요청 시 사용. deepseek-v4-pro
ANTHROPIC_DEFAULT_SONNET_MODEL Sonnet 슬롯 대체 모델. 주 작업 처리. deepseek-v4-pro
ANTHROPIC_DEFAULT_HAIKU_MODEL Haiku 슬롯 대체 모델. 빠른 소작업에 사용. deepseek-v4-flash
CLAUDE_CODE_SUBAGENT_MODEL 서브에이전트(병렬 작업)에 사용할 모델. Flash 권장 (안정성). deepseek-v4-flash
CLAUDE_CODE_EFFORT_LEVEL 추론 노력 수준. max는 초기 불안정 → high 권장. high
CLAUDE_CODE_MAX_OUTPUT_TOKENS 최대 출력 토큰 수. V4 Pro는 최대 384K 지원. 100000

보안 고려사항

🚨
중요: DeepSeek는 모든 입력 데이터를 중국 서버에 저장합니다. 중국 사이버보안법에 따라 정부가 데이터 접근을 요청할 수 있습니다. 회사 기밀 코드, 고객 정보, API 키는 절대 입력하지 마세요.

⚠️ DeepSeek 사용 시 주의

  • 모든 프롬프트 데이터 중국 서버 저장
  • iOS 앱에서 비암호화 전송 확인됨 (CLI API는 HTTPS)
  • 이탈리아 개인정보보호 당국이 차단 조치
  • 미국 정부·군 기관 사용 금지
  • 회사 코드, 고객 PII, 내부 시스템 정보 입력 금지

✓ 안전한 사용 범위

  • 공개 오픈소스 코드 분석
  • 개인 프로젝트 (민감 정보 없는 것)
  • 알고리즘 공부·코딩 연습
  • 공개된 기술 문서 정리
  • 비민감 데이터 파이프라인 개발

알려진 문제 및 주의사항

🐛
다중 턴 대화 오류: V4 Pro가 thinking 모드를 자동 활성화하면 다음 요청에 reasoning_content 필드가 필요합니다. liteLLM 기반 래퍼에서 버그 보고됨. Claude Code 직접 사용 시에는 대부분 자동 처리됩니다.
📝
모델명 변경 예정: 레거시 별칭 deepseek-chat, deepseek-reasoner는 2026년 7월 24일 지원 종료됩니다. 신규 사용 시 deepseek-v4-pro, deepseek-v4-flash를 사용하세요.
⚡
초기 서버 불안정: 2026년 5월 현재 V4 Pro는 출시 초기로 레이트 제한·타임아웃이 빈발합니다. 안정성이 중요한 작업에는 V4-Flash 우선 사용을 권장합니다. 화웨이 Ascend 950PR 슈퍼노드 배포 후 개선 예정.
