Claude Code Artifacts

세션이 만든 결과물을 라이브 인터랙티브 웹 페이지로 발행하고, 조직 내부 비공개 링크로 공유한다. 세션이 계속 일하면 페이지는 그 자리에서 새로고침된다.

플랜 · Team / Enterprise (beta) 난이도 · 입문 업데이트 · 2026.06.19 출처 · claude.com/blog

Artifacts란

Artifacts는 Claude Code 세션의 작업 결과를 단일 자체 포함(self-contained) HTML 페이지로 변환하여, 조직 내부의 비공개 URL에서 공유할 수 있게 하는 기능입니다. 터미널 텍스트로는 전달하기 어려운, 시각적·상호작용적 결과물에 적합합니다.

TL;DR

① 세션 중 "이걸 artifact로 만들어줘" 요청 → ② Claude가 HTML/MD를 작성하고 발행 권한을 물음 → ③ Yes 하면 비공개 URL 발행 + 브라우저 자동 오픈 → ④ Share로 조직 동료에게 공유 → ⑤ 세션이 작업을 이어가면 같은 URL의 페이지가 실시간으로 갱신됩니다.

  • 세션의 전체 컨텍스트(코드베이스·커넥터·대화 내역)를 활용해 페이지를 구성
  • 기본은 작성자 본인만 조회 가능 — 공유 전까지 비공개
  • 공유는 조직 경계 안에서만 — 외부 공개 옵션 없음
  • 뷰어는 조회 전용 — 수정은 작성자(세션)만 가능

실시간 갱신 원리

세션이 artifact 파일을 편집하고 같은 URL에 재발행하면, 열려 있는 페이지가 그 자리에서 즉시 새로고침됩니다. 장시간 실행되는 작업에도 단일 링크만 공유하면 되고, 동료는 항상 최신 버전을 봅니다. 각 발행은 새로운 버전이 되며, 페이지 헤더의 Share 컨트롤에서 어떤 버전을 보여줄지 선택할 수 있습니다.

Tip · 버전 공유 "Always share latest version" 토글을 켜면 항상 최신 버전이 자동 공유됩니다. 특정 버전만 고정해 공유하는 것도 가능합니다.

활용 유형

공식 문서가 제시하는 대표 패턴입니다. 각 카드의 한 줄 프롬프트로 바로 요청할 수 있습니다.

🔍

PR 워크스루

diff를 인라인 주석과 함께 렌더링하고, 심각도별로 색상 구분. "Make an artifact that walks through this PR…"

🎛️

인터랙티브 대시보드

슬라이더·토글로 값을 실시간 조정. 이징 커브·duration을 움직이며 애니메이션을 라이브로 확인.

✅

진행 상황 체크리스트

마이그레이션 계획을 체크리스트로. 작업이 끝나면 항목이 자동 체크되고, 건너뛴 항목엔 메모.

🗂️

트리아주 보드

오픈 이슈를 드래그 카드로. Now / Next / Later / Cut 컬럼을 오가며 상태 관리.

📊

장애·배포 분석

지난주 배포 실패를 서비스별 대시보드로. 조사하는 동안 데이터가 계속 갱신.

🧩

옵션 비교

설정 패널의 4가지 레이아웃을 밀도·그룹핑을 달리해 그리드로. 각 옵션 아래 한 줄 트레이드오프.

활용 가능한 데이터 소스 소스 코드·import 그래프, 연결된 모니터링/인프라 도구(MCP), 컴포넌트 라이브러리·디자인 시스템, Terraform 정의, 병합된 PR·Git 히스토리 등 — 추가 인프라 설정 없이 세션이 접근한 컨텍스트를 그대로 활용합니다.

생성하기

결과가 페이지에 적합하면 Claude가 자동으로 발행을 제안하기도 하고, 직접 명시적으로 요청할 수도 있습니다.

1

Claude가 파일을 작성한다

프로젝트에 .html 또는 .md 파일을 만듭니다.

2

발행 권한을 묻는다

Claude wants to publish "Deploy failures by service" (deploy-failures.html) to a private page on claude.ai — Yes를 선택하면 발행됩니다. (기존 artifact 재발행 시엔 다시 묻지 않음)

3

URL 출력 + 브라우저 자동 오픈

발행되면 비공개 URL이 터미널에 인쇄되고 브라우저가 열립니다. 자동 오픈을 끄려면 CLAUDE_CODE_ARTIFACT_AUTO_OPEN=0.

단축키 터미널에서 Ctrl] 을 누르면 가장 최근 artifact를 다시 엽니다.

기술 제약

Artifact 페이지는 보안을 위해 강한 샌드박스(CSP) 안에서 렌더링됩니다. 설계 시 아래 제약을 고려해야 합니다.

제약의미
외부 요청 차단다른 호스트의 스크립트·스타일·폰트·이미지·fetch/XHR/WebSocket 불가 → 모두 인라인 또는 data URI
백엔드 없음폼 입력 저장, 뷰어 인증, 조회 시점 API 호출 불가
단일 페이지상대 링크 미작동 → 섹션 이동은 페이지 내 앵커 사용
파일 형식.html / .htm / .md (Markdown은 styled HTML로 렌더)
렌더링 크기최대 16 MiB (대형 임베디드 이미지가 주원인)

토큰 비용 절감

스타일링된 페이지는 일반 터미널 텍스트보다 출력 토큰을 더 많이 씁니다(인라인 CSS·JS, 특히 이미지). Artifact 생성은 일반 응답과 동일하게 출력 토큰을 소모하므로, 다음을 권장합니다.

  • 래스터 이미지 대신 SVG·HTML/CSS로 다이어그램을 그린다
  • 필요 없는 상호작용은 제거한다
  • 대규모 데이터셋은 전체 인라인 대신 요약한다

비활성화

개인 세션에서 artifact 발행을 끄는 세 가지 방법입니다.

방법설정
Settings 파일"disableArtifact": true
환경 변수CLAUDE_CODE_DISABLE_ARTIFACT=1
Permission 규칙permissions.deny에 Artifact 추가

용어 사전

Artifact 아티팩트
세션 결과를 담은 단일 자체 포함 HTML/MD 페이지. 조직 내부 비공개 URL로 공유된다.
버전 version
매 발행마다 생성되는 스냅샷. Share 컨트롤에서 뷰어에게 보여줄 버전을 고를 수 있다.
샌드박스 sandbox
외부 네트워크·백엔드를 차단하는 격리 실행 환경. 오리진은 *.claudeusercontent.com.
Surface 표면
artifact를 발행할 수 있는 실행 환경. CLI·Desktop은 지원, Agent SDK·GitHub Action 등은 기본 비활성.
