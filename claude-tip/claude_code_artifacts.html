터미널 안에 머물던 결과물을,
링크 하나로 팀과 함께

Artifacts는 Claude Code 세션이 한 일을 라이브 인터랙티브 웹 페이지로 발행하고 조직 내부 비공개 URL로 공유합니다. 세션이 계속 일하면 같은 주소의 페이지가 그 자리에서 갱신됩니다.

터미널 워크플로우 공식 문서
01 · Why

바뀐 건 기능이 아니라, 줄어든 설명

Claude Code는 까만 터미널 창 안에서 일합니다. 그 창을 띄운 사람만 과정을 볼 수 있었죠. Artifacts는 그 결과를 모두가 보는 살아있는 문서로 꺼내옵니다.

Before — 터미널 안

일을 시킨 사람만 본다

  • 과정이 한 사람의 터미널 안에서만 벌어짐
  • AI가 한 일을 사람이 따로 정리·캡처해 공유
  • 회의에서 "에이전트가 뭘 찾았는지" 말로 풀어야 함
  • 일은 끝났는데 전달에 또 시간이 듦
After — 라이브 페이지

팀이 같은 화면을 같이 본다

  • 세션 결과가 비공개 URL 페이지로 발행됨
  • 세션이 더 일하면 같은 URL이 자동 갱신
  • 링크 받은 동료는 항상 최신 버전을 봄
  • 상태 공유에 쓰던 시간을 만드는 데 씀
02 · How — 터미널에서 실제로

만들고 · 발행하고 · 공유하기

전용 슬래시 커맨드는 없습니다. 평소처럼 자연어로 "이걸 artifact로 만들어줘"라고 말하면 됩니다. Claude가 HTML/MD 파일을 쓰고, 발행 권한을 물은 뒤, 비공개 URL을 터미널에 출력합니다.

claude code — 생성 
# ① 자연어로 요청한다 (슬래시 커맨드 아님)
> Make an artifact that walks through this PR
  with the diff annotated inline.

# ② Claude가 파일을 쓰고 발행 권한을 묻는다
Claude wants to publish "PR walkthrough" (pr-walkthrough.html)
to a private page on claude.ai
  ❯ Yes
    No

# ③ 발행되면 비공개 URL이 출력되고 브라우저가 열린다
✓ Published → https://claude.ai/code/artifact/5fbea6f3-…
  Opening in browser…
Tip · 단축키 / 자동 오픈 터미널에서 Ctrl ] 를 누르면 가장 최근 artifact를 다시 엽니다. 브라우저 자동 오픈을 끄려면 CLAUDE_CODE_ARTIFACT_AUTO_OPEN=0.
claude code — 갱신 
# 같은 세션: 수정 요청 → 같은 URL에 재발행 (다시 묻지 않음)
> Add a per-region breakdown below the summary chart and republish.
✓ Republished → https://claude.ai/code/artifact/5fbea6f3-… (v2)

# 다른 세션: URL을 직접 지정해 갱신할 수도 있다
> Update https://claude.ai/code/artifact/5fbea6f3-…
  with today's numbers.

공유는 브라우저에서

발행된 페이지를 브라우저에서 열고, 페이지 헤더의 Share 컨트롤로 범위를 정합니다.

1

페이지 헤더의 Share 클릭

발행 직후 자동으로 열린 브라우저 탭, 또는 claude.ai/code/artifacts 갤러리에서 연다.

2

오디언스 선택 — "Everyone at [Org]" 또는 특정 인원

조직 전체 또는 지정한 동료에게만 보이도록 설정.

3

버전 옵션 — "Always share latest version" 토글 / "Sharing version" 선택

항상 최신을 보여줄지, 특정 버전을 고정해 공유할지 고른다.

4

"Copy link"으로 링크 복사 → 팀에 전달

뷰어는 같은 조직 구성원으로 claude.ai에 로그인되어 있어야 열람 가능.

주의 · 인증 방식 API 키·게이트웨이 토큰·클라우드 자격증명으로 인증한 세션에서는 발행할 수 없습니다. /login 으로 claude.ai 계정에 로그인되어 있어야 합니다.
03 · Patterns

한 줄 프롬프트로 바로 만드는 것들

공식 문서가 제시한 대표 패턴입니다. 아래 문장을 그대로 붙여 넣으면 됩니다.

🔍 PR 워크스루

diff를 여백 주석과 함께 렌더링, 심각도별 색상 구분.

Make an artifact that walks through this PR. Render the diff with margin annotations and color-code findings by severity.

📊 라이브 대시보드

조사하는 동안 계속 갱신되는 장애·배포 분석.

Build a dashboard artifact of last week's deploy failures by service and keep it updated as you investigate.

✅ 진행 체크리스트

작업이 끝나면 항목이 자동 체크, 건너뛴 건 메모.

Turn this migration plan into a checklist artifact. Check items off as you complete them and add a note for anything you skip.

🎛️ 인터랙티브 튜닝

슬라이더로 값을 바꾸며 애니메이션을 라이브 확인.

Build an artifact with sliders for the easing curve, duration, and delay. Show the animation live as I move them.

🧩 옵션 비교

4가지 레이아웃을 그리드로, 각 옵션 아래 트레이드오프.

Make an artifact with four distinctly different layouts for the settings panel, as a grid with a one-line tradeoff under each.

🛡️ 인시던트 페이지

타임라인·의심 커밋·에러 급증을 포스트모템으로.

Turn this incident into an artifact — timeline, suspect commits, and the error spike.
활용 데이터 소스 소스 코드·import 그래프, 연결된 모니터링/인프라 도구(MCP), 컴포넌트 라이브러리, 병합된 PR·Git 히스토리 등 — 추가 인프라 설정 없이 세션이 접근한 컨텍스트를 그대로 끌어다 씁니다.

05 · Sandbox

페이지 설계 시 제약

artifact는 강한 CSP 샌드박스 안에서 렌더링됩니다. 외부 요청·백엔드가 없으므로 모든 것을 인라인으로 담아야 합니다.

제약의미
외부 요청 차단다른 호스트의 스크립트·스타일·폰트·이미지·fetch/XHR/WebSocket 불가 → 모두 인라인 또는 data URI
백엔드 없음폼 입력 저장, 뷰어 인증, 조회 시점 API 호출 불가 (정적 페이지)
단일 페이지상대 링크 미작동 → 섹션 이동은 페이지 내 앵커 사용
파일 형식.html / .htm / .md (Markdown은 styled HTML로 렌더)
렌더링 크기최대 16 MiB (대형 임베디드 이미지가 주원인 → SVG·요약 권장)
06 · Governance

조직 정책 · 비활성화

공유는 조직 경계에서 멈춥니다. 외부 공개 옵션은 없고, 관리자가 접근·보관을 통제합니다.

항목내용
공유 범위조직 내부 한정 — 같은 조직 인증 회원만 조회, 외부 공개 불가
관리자 활성/비활성claude.ai admin → Settings → Claude Code → Capabilities → Artifacts 토글 (Enterprise는 Roles로 역할별 제어)
네트워크뷰어는 *.claudeusercontent.com 접근 필요 — 아웃바운드 제한 시 화이트리스트
감사 로그발행·공유·삭제가 claude_artifact_* 이벤트로 기록
보존 정책Admin → Data & privacy controls에서 비공개/공유별로 설정
Compliance APIEnterprise는 artifact 목록·버전 조회·삭제 API 제공
