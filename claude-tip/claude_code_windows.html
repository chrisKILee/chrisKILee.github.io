Claude Tip · 비개발자 가이드

Windows에서
Claude Code 시작하기

개발 지식 없이도 OK. Windows 11 환경에서 Claude Code를 설치하고 첫 대화를 시작하는 방법을 단계별로 안내합니다.

난이도 · 입문 읽기 · 15분 업데이트 · 2026.04.26 OS · Windows 11

개요

Claude Code는 Anthropic이 만든 AI 코딩 어시스턴트로, 터미널(명령창)에서 대화하듯 사용하는 도구입니다. 코드 작성은 물론 문서 정리, 파일 분석 등 다양한 업무에 활용할 수 있습니다.

Windows에서 Claude Code를 사용하는 방법은 크게 두 가지입니다. 이 가이드를 끝까지 읽으면 다음을 할 수 있습니다.

  • 내 상황에 맞는 설치 방법을 선택한다
  • PowerShell 또는 WSL에 Claude Code를 설치한다
  • Claude 계정으로 로그인하고 첫 대화를 시작한다
  • 기본적인 오류 상황에 대처한다

두 가지 방법 비교

설치 방법에 따라 사용 경험이 다릅니다. 비개발자라면 PowerShell 방식을 먼저 시도하는 것을 권장합니다.

▲ FIG.1 · PowerShell vs WSL 방식 한눈 비교 (클릭하면 크게 보기)
⊞ PowerShell 방식 권장
  • 설치가 가장 간단
  • 별도 도구 설치 불필요
  • Windows 폴더 바로 접근
  • 터미널 렌더링 일부 제한
  • Linux 전용 도구 사용 불가
🐧 WSL 방식
  • Linux 환경 완전 지원
  • 개발 도구 호환성 높음
  • 터미널 렌더링 안정적
  • 설치 과정이 더 복잡
  • 재부팅 필요, 20~30분 소요
선택 기준 평소 Windows에서만 작업하고 코딩 경험이 없다면 → PowerShell 방식
Linux 도구나 개발 환경이 필요하다면 → WSL 방식

⊞ PowerShell 방식 — Claude Code 설치

Windows 11에 기본 내장된 PowerShell을 이용해 Claude Code를 설치합니다. 별도 도구 없이 명령어 한 줄로 완료됩니다.

PowerShell 관리자 권한으로 열기

1

시작 메뉴에서 PowerShell 검색

Windows 키를 누르고 PowerShell 을 검색합니다.

2

관리자 권한으로 실행

검색 결과에서 Windows PowerShell 우클릭 → 관리자 권한으로 실행을 선택합니다.

▲ FIG.2 · PowerShell에서 Claude Code 설치 및 첫 실행 화면 예시 (클릭하면 크게 보기)

Claude Code 설치 명령어

아래 명령어를 PowerShell에 그대로 붙여넣고 Enter를 누르세요.

PowerShell (관리자)
PS C:\> irm https://claude.ai/install.ps1 | iex
명령어 설명 irm은 인터넷에서 설치 스크립트를 가져오고, iex는 그것을 실행하는 명령입니다. Node.js 없이도 설치됩니다.
실행 정책 오류 시 "이 시스템에서 스크립트를 실행할 수 없습니다" 오류가 나오면 아래를 먼저 실행하세요.
PowerShell (관리자)
PS C:\> Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

첫 실행 및 로그인

설치가 완료되면 아래 명령어로 Claude Code를 시작합니다.

PowerShell
PS C:\> claude
? How would you like to authenticate?
❯ Login with Claude.ai (claude.ai/code)
1

인증 방법 선택

Login with Claude.ai를 선택하면 브라우저가 열립니다.

2

브라우저에서 로그인

claude.ai 계정으로 로그인 후 "Allow" 버튼을 클릭합니다.

3

터미널로 돌아오기

로그인 성공 시 터미널에 Welcome to Claude Code! 메시지가 나타납니다.

첫 대화 로그인 후 안녕, 간단하게 자기소개 해줘 를 입력해보세요. Claude가 응답하면 정상적으로 설치된 것입니다.

🐧 WSL 방식

WSL(Windows Subsystem for Linux)은 Windows 안에서 Linux 환경을 실행하는 기능입니다. 가상머신보다 가볍고, 파일 공유도 편리합니다.

▲ FIG.3 · WSL2 구조 — Windows 안에서 Linux 환경이 실행됨 (클릭하면 크게 보기)

WSL 설치하기

PowerShell을 관리자 권한으로 열고 아래 명령어를 실행합니다.

PowerShell (관리자)
PS C:\> wsl --install
WSL을 설치하는 중...
Ubuntu를 설치하는 중...
설치가 완료되었습니다. 재부팅 후 계속하세요.
1

명령어 실행

wsl --install 을 실행하면 WSL2와 Ubuntu가 자동으로 설치됩니다.

2

재부팅

설치 완료 후 반드시 PC를 재시작해야 합니다.

3

Ubuntu 초기 설정

재부팅 후 Ubuntu가 자동으로 열립니다. 사용자 이름과 비밀번호를 설정하세요. (이 비밀번호는 Linux 전용이며, Windows 비밀번호와 별개입니다.)

▲ FIG.4 · Ubuntu 초기 설정 — 사용자 이름과 비밀번호 설정 (클릭하면 크게 보기)
비밀번호 입력 시 주의 Linux 터미널에서는 비밀번호를 입력해도 화면에 아무것도 표시되지 않습니다. 정상이니 당황하지 말고 입력 후 Enter를 누르세요.

Claude Code 설치 (WSL)

Ubuntu 터미널에서 아래 명령어를 순서대로 실행합니다.

Ubuntu (WSL)
# 1. Claude Code 설치 (네이티브 인스톨러)
$ curl -fsSL https://claude.ai/install.sh | bash

# 또는 npm을 통한 설치 (Node.js 18+ 필요)
# sudo apt update && sudo apt install -y nodejs npm
# npm install -g @anthropic-ai/claude-code
설치 방법 선택 네이티브 인스톨러(curl 방식)가 더 간단합니다. Node.js 설치 없이 바로 사용 가능합니다.

첫 실행 (WSL)

Ubuntu (WSL)
$ claude
? How would you like to authenticate?
❯ Login with Claude.ai (claude.ai/code)

Opening browser for authentication...
✓ Logged in as chris@example.com
Welcome to Claude Code!
Windows 파일 접근 WSL에서 Windows의 C 드라이브는 /mnt/c/ 경로로 접근합니다.
예: cd /mnt/c/Users/내이름/Documents

문제 해결

실행 정책 오류 이 시스템에서 스크립트를 실행할 수 없습니다
PowerShell 관리자 권한으로 Set-ExecutionPolicy RemoteSigned -Scope CurrentUser 실행 후 재시도
WSL 가상화 오류 Please enable the Virtual Machine Platform Windows feature
Windows 기능에서 가상 머신 플랫폼을 켜고 재부팅. 또는 wsl --set-default-version 2 실행
claude: command not found
설치 후 터미널을 완전히 닫고 다시 열거나, source ~/.bashrc (WSL) 실행
로그인 브라우저가 열리지 않음
기본 브라우저 설정 확인. WSL의 경우 claude auth login 명령 후 출력되는 URL을 직접 브라우저에 붙여넣기
계정 권한 오류 Subscription required
Claude Pro / Max / Teams 플랜 또는 API 크레딧이 필요합니다. claude.ai에서 플랜 확인
