빠른 시작 — 환경변수 하나로 끝

Claude Code v2.1.89부터 CLAUDE_CODE_NO_FLICKER=1 환경변수를 설정하면 새 alt-screen(대체 화면 버퍼) 렌더러가 활성화됩니다. Week 14(2026년 3월 30일~4월 3일) 업데이트에 포함된 Research Preview 기능입니다.

1

현재 세션에서만 켜보기

아래 명령을 실행하면 이번 실행에서만 적용됩니다.

terminal 
CLAUDE_CODE_NO_FLICKER=1 claude
2

영구 적용 — 쉘 프로필에 추가

터미널을 새로 열 때마다 자동으로 활성화됩니다.

~/.zshrc 또는 ~/.bashrc 
export CLAUDE_CODE_NO_FLICKER=1
적용 
source ~/.zshrc

작동 원리 — alt-screen이란?

새 렌더러의 핵심은 alternate screen buffer(대체 화면 버퍼)입니다. vim, htop, less 같은 전통적인 터미널 도구들이 오래전부터 사용해온 방식을 Claude Code가 채택한 것입니다.

alt-screen은 터미널에서 독립된 화면 버퍼를 사용하는 방식입니다. 활성화 시 기존 터미널 내용을 보존한 채 별도 공간에서 전체 화면을 렌더링하고, 종료하면 원래 화면으로 복원됩니다. ANSI 이스케이프 시퀀스 ESC[?1049h로 진입하고, ESC[?1049l로 복귀합니다.

키보드 & 마우스 내비게이션

새 렌더러를 활성화하면 다양한 네비게이션 단축키를 사용할 수 있습니다. Ctrl+o를 누르면 전사(Transcript) 모드로 진입해 대화 전체를 탐색할 수 있습니다.

단축키 동작 모드
PgUp / PgDn 반 페이지 위/아래로 스크롤 기본
Ctrl+Home 대화 맨 위로 이동 기본
Ctrl+End 최신 메시지로 이동 (자동 팔로우 재활성화) 기본
마우스 휠 몇 줄씩 스크롤 기본
Ctrl+o 전사 모드 진입 / 초점 뷰 순환 전사
/ 대화 내 검색 시작 전사
n / N 다음/이전 검색 결과로 이동 전사
[ 전체 대화를 터미널 스크롤백에 기록 전사
v 대화를 임시 파일로 저장 후 $EDITOR에서 열기 전사
Esc / q 프롬프트로 돌아가기 전사
💡

마우스 휠 스크롤 속도는 CLAUDE_CODE_SCROLL_SPEED=3 환경변수로 조정할 수 있습니다 (범위: 1~20, 기본값: 1). 값 3이 vim과 유사한 속도입니다.

⚖️

비교 & 트레이드오프

새 렌더러는 장점만 있는 것은 아닙니다. alt-screen 방식의 특성상 일부 터미널 기능이 달라집니다.

기존 방식
✗ 스크롤 시 화면 깜빡임 발생
✗ 스트리밍 중 입력창 위치 이동
✗ 대화 길이에 비례해 메모리 증가
✓ 터미널 기본 Cmd+F 검색 사용 가능
✓ 터미널 네이티브 텍스트 선택 가능
✓ 자동 스크롤백 접근
새 방식 (NO_FLICKER)
✓ 깜빡임 없음
✓ 입력창 화면 하단 고정
✓ 메모리 사용량 일정 유지
△ Cmd+F 불가 → Ctrl+o 후 / 로 대체
△ 네이티브 선택 불가 → DISABLE_MOUSE=1 옵션
△ 스크롤백은 [ 키로 수동 내보내기

tmux 사용자라면 set -g mouse on을 ~/.tmux.conf에 추가하면 마우스 휠 스크롤이 정상 동작합니다. 단, iTerm2의 tmux integration mode(tmux -CC)에서는 호환되지 않습니다.

기능기존NO_FLICKER대응 방법
Cmd+F 검색 가능 불가 Ctrl+o → /
터미널 텍스트 선택 가능 제한 CLAUDE_CODE_DISABLE_MOUSE=1
스크롤백 접근 자동 수동 전사 모드에서 [
메모리 효율 선형 증가 일정 자동 개선
깜빡임 심각 제거 자동 개선

롤백 & 추가 옵션

환경변수를 해제하면 언제든지 이전 렌더러로 되돌아갈 수 있습니다. 마우스 캡처는 유지하면서 클릭만 비활성화하는 옵션도 있습니다.

1

롤백 — 환경변수 해제

현재 세션 비활성화 
unset CLAUDE_CODE_NO_FLICKER
claude
2

마우스 캡처 비활성화 (alt-screen은 유지)

터미널 네이티브 텍스트 선택이 필요한 경우 마우스 캡처만 끌 수 있습니다.

terminal 
# 마우스 캡처 완전 비활성화
CLAUDE_CODE_NO_FLICKER=1 CLAUDE_CODE_DISABLE_MOUSE=1 claude

# 클릭만 비활성화 (휠 스크롤은 유지)
CLAUDE_CODE_NO_FLICKER=1 CLAUDE_CODE_DISABLE_MOUSE_CLICKS=1 claude
3

스크롤 속도 조정

~/.zshrc 
export CLAUDE_CODE_NO_FLICKER=1
export CLAUDE_CODE_SCROLL_SPEED=3  # 1~20, 기본값 1

권장 설정 (시작점): CLAUDE_CODE_NO_FLICKER=1과 CLAUDE_CODE_SCROLL_SPEED=3을 함께 설정하면 vim과 유사한 스크롤 속도로 쾌적하게 사용할 수 있습니다. 불편하면 언제든지 unset으로 되돌리면 됩니다.

⚠️

iTerm2의 tmux integration mode(tmux -CC)에서는 새 렌더러가 작동하지 않습니다. 일반 tmux 세션에서는 문제없이 동작합니다. Kitty, WezTerm, Ghostty, iTerm2(일반 모드)가 가장 잘 지원됩니다.
