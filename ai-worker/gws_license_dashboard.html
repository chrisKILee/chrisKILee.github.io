흩어진 구글 시트 관리에서 벗어나, 라이선스 현황·인사발령 반영·월별 정산까지 하나의 화면에서 실시간으로 확인하고 관리할 수 있습니다.

왜 만들었나요?

이런 불편함이 있었습니다

기존에는 구글 시트로 수작업 관리하다 보니 여러 문제가 반복되었습니다.

📋

수작업 시트 관리

인사발령이 발생할 때마다 담당자가 직접 구글 시트를 열어 라이선스를 수정해야 했습니다.

⚠️

휴먼 에러 발생

수기 입력 과정에서 라이선스 중복 할당, 미반영 건이 발생해 월말 정산 시 불일치가 생겼습니다.

🔍

현황 파악의 어려움

계열사별 사용 현황, 미사용 라이선스 수를 즉시 확인할 방법이 없어 매번 시트를 열어야 했습니다.

📊

월말 정산 부담

일할 계산이 필요한 신규 라이선스를 수작업으로 계산하고 계열사별로 나눠 보고하는 데 많은 시간이 들었습니다.

주요 기능

5가지 전용 관리 화면

대시보드부터 정산 추출까지, 라이선스 관리에 필요한 모든 기능을 갖추고 있습니다.

📊

운영 대시보드

총 라이선스·사용 중·미사용 수를 한눈에 파악하고, 계열사별 현황과 최근 동기화 이력을 즉시 확인할 수 있습니다.

실시간 현황 계열사 현황 동기화 이력
📋

라이선스 목록

회사별·월별로 라이선스 현황을 필터링하고, 계열사가 지정되지 않은 라이선스를 별도로 확인해 누락 없이 관리할 수 있습니다.

회사별 필터 월별 조회 수정 기능
⚙️

자동 처리 현황

매주 목요일 밤 인사발령 시트에서 자동으로 가져온 등록·삭제 데이터를 처리한 내역과 과거 처리 이력을 확인합니다.

주간 자동화 처리 결과 확인 이력 관리
🔍

이력 조회

삭제된 계정을 포함한 전체 라이선스 변경 이력을 이메일 검색으로 조회할 수 있어, 과거 할당 내역도 언제든 확인 가능합니다.

삭제 이력 포함 이메일 검색 전체 변경 이력
💰

정산 관리

월별·계열사별 라이선스 수량과 일할 계산 내역을 확인하고, 계열사별 정산 내역서를 엑셀로 추출할 수 있습니다.

일할 계산 엑셀 추출 계열사별 정산

1

인사발령 확인

신규 입사·퇴사 정보가 인사발령 시트에 등록됩니다.

2

자동 처리 (목요일)

매주 목요일 밤 10시, 지난 1주일치 발령 내역을 자동으로 라이선스에 반영합니다.

3

담당자 검토

처리 현황 화면에서 결과를 확인하고, 필요시 수기 보정이나 비고 처리를 합니다.

4

이력 조회

이메일로 검색해 특정 계정의 라이선스 변경 이력을 언제든 확인합니다.

5

월말 정산 추출

정산 관리 화면에서 계열사별 내역을 엑셀로 추출해 보고에 활용합니다.

주요 화면

이미지를 클릭하면 크게 볼 수 있습니다.

1. 운영 대시보드 — 전체 라이선스 현황 및 계열사별 요약
2. 라이선스 목록 — 회사별·월별 라이선스 현황 조회
3. 자동 처리 현황 — 인사발령 기반 주간 자동 처리 이력
4. 이력 조회 — 삭제 이력 포함 전체 변경 내역 검색
5. 정산 관리 — 월별 계열사별 정산 및 엑셀 추출
6. 대시보드 초기 구성 — 동기화 진행 이력 뷰
