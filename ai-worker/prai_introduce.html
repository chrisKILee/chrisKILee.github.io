PRAI

운영서버 에러, AI가 알아서 고칩니다!

Production Runtime AI — 프로덕션 에러 자동 수정 파이프라인

PRAI는 프로덕션 환경에서 발생한 런타임 에러를 감지하고, AI가 자동으로 코드를 분석·수정한 뒤,5관점 리뷰를 거쳐 Pull Request를 생성하는 end-to-end 자동화 파이프라인입니다. 개발자는 Slack 알림이나 대시보드에서 "Fix" 버튼만 누르면 됩니다.

어떤 문제를 해결하는가

Before PRAI
  • • 프로덕션 에러 발견까지 수 시간 소요
  • • 에러 로그 → 원인 분석 → 수정 → PR의 반복 작업
  • • 급한 핫픽스에서 리뷰 없이 배포하는 위험
  • • 동일 에러에 여러 개발자가 중복 대응
After PRAI
  • • 에러 발생 즉시 Slack + 대시보드 알림
  • • AI가 에러 분석 → 수정 → 리뷰 → PR 자동 생성
  • • 5관점 AI 리뷰로 코드 품질 보장
  • • 중복 요청 자동 감지 및 방지

5관점 AI 리뷰

Claude가 수정한 코드를 5개의 독립적인 서브에이전트가 병렬로 리뷰합니다. CRITICAL/HIGH 이슈 발견 시 자동으로 재수정합니다.

CorrectnessClaude
수정이 원래 에러를 해결하는지, 새로운 버그를 만들지 않는지 검증
  • 에러 원인 정확히 수정됐는가
  • 엣지 케이스 처리
  • 타입 안전성
SecurityClaude
보안 취약점 (OWASP Top 10) 도입 여부 검사
  • Injection 취약점
  • 인증/인가 우회
  • 민감 데이터 노출
ArchitectureClaude
프로젝트 구조와 컨벤션을 준수하는지 검토
  • 기존 패턴 준수
  • 책임 분리
  • 의존성 방향
PerformanceClaude
성능 저하 가능성 검사
  • 불필요한 연산
  • 메모리 누수
  • N+1 쿼리
CodexOpenAI Codex
독립적인 AI 관점에서 코드 품질 교차 검증
  • Claude와 다른 관점
  • 패턴 안티패턴
  • 코드 품질

자동 재수정 (Auto Re-fix)

리뷰에서 CRITICAL 또는 HIGH 심각도 이슈가 발견되면, Claude가 자동으로 해당 이슈를 수정하고 다시 리뷰를 실행합니다. 최종 verdict가 PASS 또는 FIXED일 때만 PR이 생성됩니다.

대시보드

에러 현황, 수정 결과, 실행 이력을 한 곳에서 모니터링합니다.

Overview
에러 통계, 타임라인 차트, 상태 분포
Errors
에러 목록, 상태 필터, Fix/Ignore 액션
Error Detail
에러 상세, Fix 결과, Review 카드, 메타데이터
Runs
파이프라인 실행 이력, 소요 시간, 결과 상태

Slack 연동

에러 발생 시 Slack 채널에 자동 알림이 전송됩니다. Slack에서 직접 "Fix" 버튼을 눌러 수정 파이프라인을 실행할 수 있으며, 결과도 Slack으로 전달됩니다.

6

7

에러 상세 결과 표시

Fix/Review/Metadata 카드

8

실행 이력 페이지

success/analysis_only/failed 필터
