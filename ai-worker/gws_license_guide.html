GWS 라이선스 관리,
시스템으로 자동화

수십 개 계열사의 구글 워크스페이스 라이선스를 스프레드시트 수작업에서 벗어나, 자동 배치 수집·관리자 승인·월말 정산까지 하나의 시스템으로 처리합니다.

5개 전용 관리 화면
주1회 자동 인사발령 배치
실시간 라이선스 현황 조회
1-Click 계열사별 정산 엑셀
Problem & Solution

왜 이 시스템이 필요했나요?

세아그룹 계열사 수십 개의 GWS 라이선스를 관리자가 매주 구글 시트를 직접 열어 수동으로 처리하고 있었습니다.

😓

수작업 시트 관리

인사발령마다 구글 시트를 수동 확인 → 라이선스 직접 기입 → 실수 발생 시 추적 불가

⏰

월말 정산 부담

계열사별 사용 라이선스를 월마다 수동 집계, 일할 계산을 엑셀 수식으로 직접 처리

🔍

이력 추적 불가

누가 언제 라이선스를 할당·회수했는지 기록이 없어 문제 발생 시 원인 파악 어려움

⚡

해결: 자동 배치 수집

매주 목요일 22시, 인사발령 시트를 자동으로 읽어 DB에 적재 — 관리자는 확인·승인만

📊

해결: 자동 정산 계산

일할 계산 포함 월별 정산이 자동으로 집계, 버튼 하나로 계열사별 엑셀 다운로드

📋

해결: 전체 이력 관리

할당·회수·수정·마이그레이션 모든 변경 이력을 DB에 기록, 이메일로 검색 가능

How It Works

어떻게 자동화하나요?

인사발령 구글 시트 하나에서 시작합니다. 시스템이 이를 읽어 할당·회수를 처리하고, 이력을 남기며, 정산까지 계산합니다.

User Guide

화면별 사용 가이드

5개 전용 화면의 역할과 사용 방법을 단계별로 설명합니다. 1~3번은 구현 완료, 4~5번은 개발 중입니다.

1

운영 대시보드 ✓ 구현 완료

접속 시 가장 먼저 보이는 화면. 전체 라이선스 현황을 한눈에 파악합니다.

  • 총 라이선스 수 / 사용 중 / 미사용(대기) 라이선스 수를 KPI 카드로 표시
  • 계열사별 라이선스 현황을 테이블로 즉시 확인
  • 최근 동기화(배치) 실행 이력 및 처리 결과 확인 가능
2

라이선스 목록 ✓ 구현 완료

전체 라이선스를 조건별로 필터링하여 상세 내역을 확인하고, 비고를 수정할 수 있습니다.

  • 키워드(이름/이메일), 상태(사용/대기/폐기), 계열사 기준으로 검색
  • 라이선스 등급(STD / PLUS) 확인
  • 비고 항목을 인라인으로 수정 저장
  • 계열사가 없는 라이선스 별도 확인 가능 (누락 관리)
3

배치 처리 현황 ⋯ 개발 중

구글 시트에서 수집된 인사발령 건을 확인하고, 검토 후 라이선스에 반영(Apply)하는 화면. 자동화의 핵심입니다.

  • 시트 불러오기: 구글 시트 ID 입력 → 인사발령 데이터 자동 읽기 → 대기열 적재
  • 목록 확인: 등록(ADD) / 삭제(REMOVE) 구분, 처리 상태(대기/완료/에러) 확인
  • 일괄 반영: 체크박스로 선택 후 Apply 버튼 → 라이선스 할당·회수 자동 처리
  • 에러 재처리: 라이선스 부족 등 에러 건에 번호 직접 지정하여 재처리
4

이력 조회 ⋯ 개발 중

삭제된 데이터까지 포함하여 모든 라이선스 변경 내역을 이메일 키워드로 검색합니다.

  • 이메일 주소 입력 → 해당 계정의 전체 이력(할당/회수/수정/마이그레이션) 조회
  • "이 사람 라이선스 언제 회수됐어요?" 즉시 확인 가능
5

정산 관리 ⋯ 개발 중

월말 정산 업무를 위한 화면. 연월 선택 시 계열사별 라이선스 사용 금액을 자동 계산합니다.

  • 정산 공식: 합계 = 현재 사용 중 + 당월 종료 + 당월 시작
  • 당월 시작된 라이선스는 일할 계산 자동 적용 (사용 일수만큼만 정산)
  • 계열사별 정산 내역서를 엑셀로 다운로드
