🤔 왜 만들었나요?
MSP 운영보고서는 SLA 기반 정기 문서입니다. 인프라가 안정적으로 운영되고 있는지 고객사에 보고하는 핵심 업무인데, 지금까지는 전부 수작업이었습니다.

❌ 기존 방식의 문제

  • 📅 분기 1회 보고서 작성에 1~2주 수작업 투입
  • ✋ GCP 비용·리소스 데이터를 손으로 직접 취합
  • ⚠️ 수작업 과정에서 데이터 누락·오기입 위험 상존
  • 📉 리소스 부족으로 월간 보고서 제공 불가
  • 📋 단순 현황 나열 위주로 인사이트 부족

✅ NaviOps의 해결

  • ⚡ GCP API에서 데이터를 자동 수집·구조화
  • 🤖 AI가 비용 변동 원인과 이상 징후 분석
  • 📄 One-Click으로 전문 PDF 보고서 자동 생성
  • 📆 분기 → 월간 보고서로 발행 주기 단축
  • 💡 비용 최적화 가이드까지 자동 제공
⚙️ 주요 기능
버튼 하나로 GCP 데이터 수집부터 PDF 보고서 생성까지 자동으로 처리합니다.
📄

One-Click PDF 생성

클릭 한 번으로 GCP 비용 및 사용량 데이터를 기반으로 한 전문적인 PDF 보고서 출력. 수동 작업 없이 완성된 문서를 즉시 확보.

🤖

AI 기반 인사이트 추출

단순 수치 나열이 아닌, AI가 비용 변동 원인과 리소스 이상 징후를 분석하여 요약 보고서 자동 작성. 전문 엔지니어 수준의 분석 제공.

📊

통합 관리 어드민

고객사 정보, 담당자, 계약 현황을 한눈에 관리하는 대시보드 환경. 운영 현황을 실시간으로 파악 가능.

💰

비용 최적화 가이드

GCP Recommender API 연동으로 보안·비용·성능·안정성에 대한 자동화된 추천 권장사항 제공. AI가 절감 포인트를 직접 제시.

🔔

이상 탐지 알림

GCP Monitoring의 Incident 데이터를 활용하여 서비스 이상 징후를 자동 감지하고 보고서에 반영.

🏢

고객사 대시보드 (Phase 2)

고객사가 직접 로그인하여 인가된 권한 범위 내에서 보고서와 운영 현황을 실시간으로 확인. 2026년 7월 SaaS 오픈 예정.

🛠️ 기술 구성
GCP 네이티브 API와 AI 엔진을 연동하여 데이터 수집부터 문서 생성까지 자동화했습니다.

AI 분석 엔진

수집된 비용·성능 지표를 분석하여 이상 징후 요약 및 조치 권고안 자동 생성

🔧 기술적 난제 해결 사례

  • Recommender API 와일드카드 미지원 우회: GCP 문서에는 locations/- 와일드카드를 지원한다고 명시되어 있으나, 실제 호출 시 HTTP 400 오류 발생. → Cloud Compute API로 실제 zone 목록을 먼저 조회한 뒤, zone/region/global 타입별로 분류하여 개별 호출하는 방식으로 해결.
