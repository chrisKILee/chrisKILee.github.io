기존 방식과 무엇이 달라졌나요?

GWS 관리자 로그는 방대합니다. AI 도입 전후를 비교해보세요.

기존 방식
  • 담당자가 수백~수천 건의 로그를 항목별로 직접 확인
  • 도메인 6개 기준 월 1회 작업에 약 36시간 소요
  • 판단 기준이 담당자 역량에 의존, 일관성 유지 어려움
  • 증빙 자료 취합과 관리가 개별적으로 이루어져 추적 불편
  • 감사 대응 보고서 작성도 별도로 수작업 진행
AI 자동화 후
  • CSV 파일 업로드 한 번으로 AI가 전체 로그를 자동 분석
  • 도메인 6개 기준 약 3시간으로 단축 (92% 절감)
  • Gemini AI 기반 일관된 판단 기준 적용, DB에 누적
  • 소명 첨부 → 검토 → 승인/반려 워크플로우 내장
  • 소명 완료 시 통합 보고서 자동 생성, PDF 출력 지원

주요 기능

5가지 핵심 기능으로 GWS 보안 모니터링 전 과정을 다룹니다.

📥

로그 자동 분석

CSV 형식의 GWS 관리자 로그를 업로드하면 Gemini AI가 각 항목을 자동으로 분석하여 위험도(상·중·하)와 분석 내용을 즉시 제공합니다.

🔍

분석 보고서 검증

AI 분석 결과를 관리자가 직접 검토하고 검증 상태를 업데이트합니다. 필터링 기능으로 검증 대기·완료·소명 필요 항목을 빠르게 분류할 수 있습니다.

📎

소명 자료 관리

GWS 관리자가 의심 행위에 대한 증빙 문서와 이미지를 직접 첨부하고 소명을 완료합니다. 진행률 표시로 미완료 항목을 한눈에 파악할 수 있습니다.

✅

승인·반려 워크플로우

소명 완료 항목에 대해 담당자가 승인 또는 반려 처리합니다. 반려된 항목은 재증빙이 필요하며, 승인된 항목은 별도 증빙이 요구되지 않습니다.

📄

통합 보고서 출력

모든 소명이 완료되면 통합 보고서 기능이 활성화됩니다. 분석 현황 요약, 상세 소명 내역을 포함한 PDF 보고서를 즉시 출력할 수 있습니다.

🏢

계열사별 모니터링

로그인 시 VNTG, SeAH 등 모니터링 대상 계열사를 선택합니다. 계열사별로 분리된 환경에서 독립적으로 로그 분석과 소명 관리가 이루어집니다.

어떻게 사용하나요?

로그 업로드부터 최종 보고서 출력까지, 4단계로 완료됩니다.

1

로그인 후 계열사 선택

대시보드에 로그인하면 모니터링할 계열사를 선택하는 화면이 나타납니다. 담당 계열사를 선택하여 해당 데이터 공간으로 진입합니다.

2

신규 로그 업로드 → AI 자동 분석

메인 페이지에서 '신규 로그 업로드' 버튼을 눌러 이달의 GWS 관리자 로그 CSV 파일을 올립니다. 업로드가 완료되면 AI가 즉시 분석을 시작하며, 완료 후 위험도가 '상'인 항목은 관리자 확인 요청 알림이 표시됩니다.

3

분석 보고서 검증 및 소명 요청

상세 분석 보고서 탭에서 AI 분석 결과를 검토합니다. 필터로 '검증 대기' 항목만 골라 확인하고, 소명이 필요한 항목을 GWS 관리자에게 요청합니다. GWS 관리자는 소명 자료 탭에서 증빙 문서를 첨부하여 소명을 완료합니다.

4

최종 승인 → 통합 보고서 출력

모든 소명 항목의 승인·반려 처리가 완료되면 통합 보고서 버튼이 활성화됩니다. 메인 현황 요약, 상세 분석 및 소명 내역을 포함한 보고서를 PDF로 저장하거나 인쇄할 수 있습니다.
