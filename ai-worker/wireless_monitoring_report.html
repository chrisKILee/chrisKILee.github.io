1. 프로그램 개요

무선 장비 모니터링 및 운영보고서는 사내 무선 네트워크 장비(AP, 스위치, 라우터 등)의 상태와 성능 데이터를 자동으로 수집·분석하여 운영 보고서를 생성하는 AI 기반 자동화 프로그램입니다.

기존에는 담당자가 개별 장비에 접속해 수기로 현황을 확인하고 보고서를 작성해야 했습니다. 이 프로그램은 데이터 수집 → 분석 → 보고서 생성 → 배포의 전 과정을 자동화하여 담당자의 업무 부담을 줄이고, 더 빠르고 정확한 네트워크 현황 파악을 가능하게 합니다.

핵심 가치: 사람이 직접 확인해야 했던 수십~수백 대의 무선 장비 상태를 자동으로 집계하여, 매일 아침 출근 전에 이미 보고서가 준비되어 있습니다. 이상 징후 발생 시 즉시 알림을 받아 빠른 조치가 가능합니다.

대상 사용자: 네트워크 운영 담당자, 현장 관리자, IT 인프라 팀, 경영진 보고 담당자 등 무선 네트워크 현황을 주기적으로 파악해야 하는 모든 분

2. 주요 기능 소개
장비 상태 실시간 조회

AP, 스위치, 라우터 등 모든 무선 네트워크 장비의 온라인/오프라인 상태를 실시간으로 모니터링합니다. 장비가 응답하지 않으면 즉시 감지합니다.

운영 보고서 자동 생성

일간·주간 단위로 장비 현황, 접속자 통계, 성능 지표 등을 자동 집계하여 시각화된 HTML 보고서를 생성합니다. 별도 작업 없이 보고서가 자동으로 완성됩니다.

접속자 수 모니터링

각 AP에 현재 연결된 클라이언트(사용자 기기) 수를 실시간으로 추적합니다. 시간대별·요일별 접속 패턴을 분석하여 피크 시간대를 파악할 수 있습니다.

성능 지표 수집 (CPU/메모리)

장비의 CPU 사용률과 메모리 사용률을 주기적으로 수집합니다. 특정 장비의 부하가 높아질 경우 사전에 감지하여 장애를 예방할 수 있습니다.

이상 감지 및 알림

장비 다운, 성능 임계치 초과 등 이상 상황 발생 시 담당자에게 자동으로 알림을 발송합니다. 빠른 장애 대응으로 서비스 중단 시간을 최소화합니다.

AI 인사이트 자동 분석

수집된 데이터를 AI가 분석하여 주요 트렌드, 이상 패턴, 개선 권고사항을 자동으로 도출합니다. 전문 지식 없이도 핵심 시사점을 쉽게 파악할 수 있습니다.

3. 사용 방법 (Step by Step)
1
보고서 페이지 접속

담당자로부터 받은 보고서 URL 링크를 클릭하거나, 이메일/메신저로 전달된 링크를 열어줍니다. 별도의 설치나 로그인 없이 웹 브라우저에서 바로 확인할 수 있습니다.

크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 최신 웹 브라우저 모두에서 정상 동작합니다. 모바일에서도 확인 가능합니다.

2
지역(사이트) 선택

보고서 상단의 지역 선택 드롭다운에서 확인하고 싶은 사이트(지역)를 선택합니다. "전체 지역"을 선택하면 모든 사이트의 통합 현황을 볼 수 있습니다.

지역을 변경하면 통계 카드, 차트, 장비 목록이 선택된 지역에 맞게 자동으로 갱신됩니다. 잠시 기다려 주세요.

3
요약 통계 카드 확인

상단의 통계 카드에서 총 AP 수, 최대 접속자, 평균 접속자, 평균 CPU/메모리 사용률 등 핵심 지표를 한눈에 확인합니다. 이상 수치가 있을 경우 배경색이 달라질 수 있습니다.

4
차트로 추이 분석

시간대별/요일별 접속자 수, CPU 사용률, 메모리 사용률 차트를 통해 네트워크 사용 패턴을 파악합니다. 특정 시간대에 급격한 변화가 있으면 원인을 확인해 보세요.

5
AI 인사이트 검토

AI가 자동 분석한 주요 인사이트를 확인합니다. 특이 패턴, 주의가 필요한 장비, 개선 권고사항 등이 번호 순서대로 중요도에 따라 정리되어 있습니다.

AI 인사이트는 데이터 기반의 자동 분석 결과입니다. 현장 상황과 종합하여 판단하시고, 의심스러운 항목은 담당 엔지니어에게 확인을 요청하세요.

6
장비 상세 현황 테이블 확인

하단의 AP 장비 상세 현황 테이블에서 개별 장비의 접속자 수, CPU, 메모리 수치(최대/현재/평균)를 확인합니다. "표 복사" 버튼을 이용하면 엑셀에 붙여넣기 할 수 있습니다.

4. 보고서 항목 설명

보고서에 포함되는 항목

접속자 수 (Clients)
각 AP에 현재 무선으로 연결된 기기(스마트폰, 노트북, 태블릿 등)의 수입니다. 최대값은 지난 30일 중 가장 많이 접속했던 순간, 현재값은 보고서 생성 시점, 평균값은 30일간 평균 접속자 수를 나타냅니다.
CPU 사용률 (%)
장비 내부의 프로세서(CPU)가 얼마나 바쁘게 일하고 있는지를 나타냅니다. 일반적으로 30% 이하가 정상이며, 80% 이상이 지속되면 장비 성능이 저하되거나 접속 장애가 발생할 수 있습니다.
정상: ~30% 주의: 30~70% 위험: 70%+
메모리 사용률 (%)
장비의 임시 저장 공간(메모리)을 얼마나 사용하고 있는지를 나타냅니다. 50% 이하가 안정적이며, 90% 이상이 지속되면 장비 재시작이 필요할 수 있습니다.
안정: ~50% 주의: 50~80% 위험: 80%+
지역 (Region / Site)
장비가 위치한 사업장 또는 지역 구분입니다. 여러 사이트를 관리하는 경우 지역별로 필터링하여 해당 사이트의 현황만 따로 확인할 수 있습니다.
AP 장비명 (Hostname)

5. 자주 묻는 질문 (FAQ)
Q 보고서는 언제 자동으로 업데이트되나요?
보고서는 설정에 따라 매일 새벽 또는 지정된 시간에 자동으로 생성되어 배포됩니다. 일반적으로 업무 시작 전인 오전 7~8시에 전날 데이터를 포함한 보고서가 준비됩니다. 정확한 업데이트 주기는 담당 엔지니어에게 문의하세요.
Q 특정 장비가 "오프라인"으로 표시됩니다. 어떻게 해야 하나요?
장비가 오프라인으로 표시되면 즉시 현장 확인이 필요합니다.

확인 절차:
1. 해당 장비의 전원이 켜져 있는지 확인
2. 케이블(PoE 스위치 연결선) 상태 확인
3. 인근 다른 장비도 오프라인인지 확인 (스위치 이슈 가능성)
4. 위 확인 후에도 해결되지 않으면 IT 담당자에게 즉시 연락
Q 데이터는 얼마나 오래된 것을 보여주나요?
기본 설정은 최근 30일간의 데이터를 기준으로 최대값·평균값을 계산합니다. "현재값"은 보고서가 생성된 시점의 실시간 데이터입니다. 더 긴 기간의 이력 데이터가 필요한 경우 별도 데이터 조회 기능을 통해 확인할 수 있습니다.
Q 보고서를 엑셀로 저장할 수 있나요?
장비 상세 현황 테이블 우측 상단의 "표 복사" 버튼을 클릭하면 테이블 데이터가 클립보드에 복사됩니다. 엑셀을 열고 붙여넣기(Ctrl+V)하면 데이터가 표 형태로 입력됩니다. 전체 페이지를 PDF로 저장하려면 브라우저의 인쇄 기능(Ctrl+P)을 이용하세요.
Q CPU나 메모리 수치가 높게 나오는 장비는 즉시 교체해야 하나요?
반드시 그렇지는 않습니다. 순간적인 피크는 일시적인 트래픽 증가로 인한 것일 수 있습니다. 하지만 평균값이 지속적으로 높다면 조치가 필요합니다.

단계별 조치 방법:
1. 장비 재시작으로 임시 해소 가능 여부 확인
2. 해당 AP의 접속자가 너무 많다면 인근 AP로 트래픽 분산 설정
3. 하드웨어 노후화가 원인이라면 장비 교체 검토
4. 정확한 진단은 IT 담당자에게 문의
Q 모니터링 대상 장비를 추가하거나 변경할 수 있나요?
네, 가능합니다. 신규 장비 추가, 기존 장비 제거, 지역 구분 변경 등은 IT 담당 엔지니어에게 요청하면 됩니다. 장비 정보 업데이트 후 다음 보고서 생성 주기부터 반영됩니다.
Q 보고서를 받지 못했거나 링크가 열리지 않습니다.
다음 사항을 순서대로 확인해 주세요:
1. 사내 네트워크(VPN 포함)에 연결되어 있는지 확인
2. 브라우저 캐시 삭제 후 재시도 (Ctrl+Shift+Delete)
3. 다른 브라우저로 시도
4. 위 방법으로도 해결되지 않으면 IT 담당자에게 문의하여 보고서 URL 재확인 또는 재발송 요청

추가 문의 및 지원

기술적 문의
장비 이상, 데이터 오류, 시스템 장애 등 기술적인 문제는 IT 인프라/네트워크 담당 엔지니어에게 문의하세요. 장비명, 지역, 발생 시간 등 구체적인 정보를 함께 제공해 주시면 빠른 대응이 가능합니다.
보고서 설정 변경 요청
모니터링 대상 장비 추가/제거, 보고서 발송 주기 변경, 알림 수신자 변경 등의 설정 변경은 시스템 관리자에게 요청하세요. 변경사항은 일반적으로 1~2 영업일 이내에 처리됩니다.
데이터 해석 및 개선 제안
보고서 데이터를 어떻게 해석해야 할지 모르겠거나, 추가로 확인하고 싶은 지표가 있다면 IT 팀과 상의해 주세요. AI 인사이트에서 제시된 개선 권고사항은 전문가와 함께 검토 후 적용하는 것을 권장합니다.
