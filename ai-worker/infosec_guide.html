🔐 주요 기능 소개

🖧
NAC

네트워크 접근 제어 보고서

전체 노드 현황·PC 정책·운영체제를 금월/전월 비교 표와 가로형 바차트로 확인합니다.

  • 전체 노드 구분별 현황 (PC·서버·VOIP 등)
  • PC별 정책 현황 (금전월 비교)
  • OS 요약 (Win11 / Win10 EOS / 식별불가)
📂
DLP

데이터 유출 방지 보고서

9개 탭 구조의 월별 DLP 운영보고서를 확인하고 PDF로 다운로드합니다.

  • 요약·정책현황·매체제어·파일첨부·출력
  • SW차단·웹차단·이슈사이트·라이선스
  • PDF 다운로드 (전체 템플릿 포함)
📧
APT

악성메일 모의훈련 보고서

훈련 결과를 기간·회사·팀 단위로 조회하며 막대그래프·도넛 차트로 시각화합니다.

  • 미열람·메일열람·링크클릭·스팸신고 통계
  • 스팸신고: 피싱/스팸 스택 막대 구분
  • 엑셀 다운로드 (비밀번호 보호)

라이선스 구매 수량 관리

회사별 DLP 라이선스 구매 수량을 등록·수정합니다. 변경 이력(이전값·변경값)이 자동 저장됩니다.

항목 설명
회사별 구매 수량 최신 수량을 회사명별로 조회
수량 변경 변경 전·후 수량이 이력 테이블에 자동 기록
엑셀 업로드 라이선스 현황·퇴사자 현황 일괄 업로드 가능
ℹ️ 라이선스 현황은 DLP 운영보고서 > 라이선스현황 탭에 연동되어 표시됩니다.

📋 이용 방법

1

Google 계정으로 로그인

vntgcorp.com 또는 seah.co.kr 도메인 Google 계정으로 접속합니다. 미등록 계정은 자동으로 가입 화면으로 이동합니다.

2

회사 및 기간 선택

상단 메뉴에서 인가된 회사와 조회 기간(YYYYMM)을 선택합니다. 기본값은 가장 최근 기간입니다.

3

보고서 메뉴 선택

NAC 운영보고서 / DLP 운영보고서 / 악성메일 모의훈련 중 원하는 항목을 선택합니다.

4

탭별 데이터 확인 및 다운로드

각 탭을 클릭해 항목별 통계·차트를 확인합니다. DLP는 PDF, APT는 엑셀(비밀번호 보호) 다운로드를 지원합니다.

ℹ️ 로그인 후 "권한 인가가 진행중입니다" 메시지가 표시되면 브이엔티지 플랫폼정보보호팀으로 문의해 주세요.

🔑 권한 안내

ADMIN

모든 페이지 읽기·쓰기. 보고서 Publish, 사용자 관리 포함.

EDITOR

정보보호 담당자. Admin과 동일한 권한으로 보고서 작성·Publish 가능.

REVIEWER

입력·저장 UI는 보이나 실제 저장 불가. 경영진 데모 확인용.

VIEWER

인가된 회사의 Published 보고서만 열람 가능. (Read-only)
