02 How It Works

3단계로 끝나는 사용법

복잡한 설정 없이 파일 하나 추가로 완성된다.

핵심 원리
DESIGN.md는 AI 에이전트가 참조할 수 있는 구조화된 컨텍스트다. 색상·폰트·UI 패턴을 텍스트로 명시하면 에이전트가 코드 생성 시 자동으로 반영한다.
1
원하는 브랜드의 DESIGN.md 선택
getdesign.md에서 70개 브랜드 중 원하는 디자인 스타일을 찾는다. 카테고리 필터나 검색으로 탐색 가능.
url 
https://getdesign.md/vercel   # Vercel 스타일
https://getdesign.md/stripe   # Stripe 스타일
https://getdesign.md/airbnb   # Airbnb 스타일
2
프로젝트 루트에 DESIGN.md 추가
다운로드한 파일을 프로젝트 루트 디렉토리에 배치. AI 에이전트가 자동으로 파일을 컨텍스트로 인식한다.
bash 
my-project/
├── DESIGN.md        ← 여기 추가
├── src/
└── package.json
3
AI 에이전트에 지시 → 브랜드 스타일 UI 자동 생성
에이전트가 DESIGN.md의 색상·폰트·UI 패턴을 참조하여 해당 브랜드 미학과 일치하는 UI를 자동 생성한다. 반복 재구성 없이 일관성 유지.
prompt 
DESIGN.md를 참고해서 대시보드 UI를 만들어줘.
→ AI가 Vercel 스타일의 흑백 정밀 UI를 자동 생성

06 Paradigm

디자인 핸드오프의 패러다임 전환

AI 에이전트 시대에 디자인 시스템 전달 방식이 바뀐다.

구 패러다임
디자이너 → Figma 파일 작성 → 개발자에게 공유 → 코딩 에이전트 호출 → UI 구현 (불일치 발생)
→
신 패러다임
getdesign.md 선택 → DESIGN.md 프로젝트 추가 → AI 에이전트 직접 호출 → 브랜드 일치 UI 자동 생성
🧠
LLM 네이티브 포맷

마크다운은 LLM이 가장 잘 이해하는 포맷. 이미지 기반 Figma보다 토큰 효율적으로 디자인 스펙을 전달한다.

Token Efficient
🔄
재현 가능한 디자인 일관성

매 세션마다 수동으로 디자인 스펙을 설명할 필요 없음. DESIGN.md 하나로 일관된 브랜드 UI가 반복 생성된다.

Reproducible
