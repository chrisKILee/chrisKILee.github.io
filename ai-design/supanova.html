Supanova Design Skill
AI 냄새 없는 디자인

바이브코딩으로 만든 서비스, 다들 비슷하게 생긴 거 아시죠? Supanova는 AI가 뻔하게 만드는 디자인 패턴을 원천 차단하고, 프리미엄 규칙을 강제합니다. 특히 한국어 서비스를 만드는 분들께 유용합니다.

금지 패턴 자동 차단 Pretendard 기본 적용 한국어 줄바꿈 최적화 Claude Code 스킬
01 문제

AI가 만든 디자인, 왜 다 똑같을까?

AI에게 랜딩 페이지를 만들어달라고 하면 거의 예외 없이 같은 패턴이 나옵니다. AI가 학습 데이터에서 가장 자주 본 조합을 반복하기 때문입니다.

이게 바로 "AI 냄새"입니다

보라색 그라데이션 + Inter 폰트 + 가운데 정렬 + 이모지 아이콘. 실제로 만들어보면 열에 아홉은 이 패턴입니다. Supanova는 이 기본값 자체를 처음부터 막아버립니다.

🔵
보라·파랑 AI 그라데이션

AI가 기본으로 선택하는 색상 조합. #6366f1 → #ec4899 같은 인디고-핑크 그라데이션이 대표적입니다.

AI가 가장 자주 쓰는 폰트 두 가지. 무난하지만, 그래서 AI 티가 납니다.

타이포그래피

SVG 아이콘 대신 이모지로 아이콘을 처리하는 패턴. 빠르지만 일관성이 없고 플랫폼마다 다르게 보입니다.

아이콘
02 금지 항목

Supanova가 막는 것들

단순히 "쓰지 마세요" 수준이 아닙니다. AI에게 해당 패턴을 사용하지 못하도록 명시적으로 금지 규칙을 주입합니다.

항목 AI 기본값 (금지) Supanova 대체 이유
본문 폰트 Inter, Noto Sans KR Pretendard Pretendard는 한국어+라틴 혼용에 최적화된 프리미엄 폰트
강조 색상 보라·파랑 그라데이션 단색 강조 (브랜드컬러) 그라데이션 남용은 AI 특유의 "SaaS 클리셰" 느낌을 만듦
아이콘 이모지 아이콘 SVG 아이콘 라이브러리 이모지는 OS마다 다르게 보이고 크기 조절이 안 됨
텍스트 정렬 전체 center 정렬 left 정렬 기본 긴 텍스트의 center 정렬은 가독성을 크게 해침
제목 폰트 강조 background-clip: text 그라데이션 1~3 단어에만 단색 강조 제목 전체 그라데이션은 AI 티의 가장 큰 원인 중 하나
이것만 막아도 체감이 완전히 다릅니다
위 5가지는 AI가 반복적으로 선택하는 "기본 패키지"입니다. 이것만 차단해도 결과물이 눈에 띄게 달라집니다.
03 한국어 최적화

한국어 서비스에 특히 유용한 이유

AI가 한국어 서비스를 만들 때 자주 놓치는 두 가지가 있습니다. Supanova는 이걸 기본값으로 강제합니다.

폰트
Pretendard 기본 적용
한국어+영문 혼용 텍스트에서 가장 자연스럽게 보이는 폰트입니다. AI가 기본으로 선택하는 Noto Sans KR보다 자간·굵기 밸런스가 훨씬 뛰어나 프리미엄 느낌이 납니다.
css 
font-family: 'Pretendard', -apple-system,
  BlinkMacSystemFont, sans-serif;
줄바꿈
word-break: keep-all 자동 적용
한국어는 기본 설정에서 단어 중간에 줄바꿈이 발생해 어색하게 보입니다. keep-all을 적용하면 단어 단위로 줄이 바뀌어 자연스러운 가독성이 확보됩니다.
css 
word-break: keep-all; /* 한국어 단어 보호 */
overflow-wrap: break-word;
번역투 없는 자연스러운 한국어
Supanova는 폰트·CSS 설정 외에도 AI가 생성하는 텍스트 자체를 자연스러운 한국어로 출력하도록 프롬프트를 구성합니다. "활용하다", "제공하다" 같은 번역투 표현이 줄어듭니다.
04 시작하기

Claude Code에 적용하는 방법

GitHub에서 스킬 파일을 받아 Claude Code 설정에 추가하면 됩니다.

사전 조건
Claude Code가 설치되어 있어야 합니다. Claude Code는 Anthropic이 만든 터미널 기반 AI 코딩 도구입니다.
1
GitHub에서 스킬 파일 받기
아래 저장소에서 Supanova Design Skill 파일을 다운로드합니다.
bash 
git clone https://github.com/uxjoseph/supanova-design-skill
2
Claude Code 스킬 디렉토리에 추가
다운로드한 파일을 Claude Code의 스킬 경로에 복사합니다. 경로는 설정에 따라 다를 수 있습니다.
bash 
cp supanova-design-skill/* ~/.claude/skills/
3
페이지 생성 시 스킬 호출
Claude Code에서 UI 생성을 요청할 때 Supanova 스킬을 함께 사용합니다. 스킬이 금지 패턴을 자동으로 차단하고 프리미엄 규칙을 적용합니다.
4
자세한 사용법은 영상 참고
아래 YouTube 영상에서 실제 사용 흐름을 확인할 수 있습니다.
