AI가 만든 티 나는 밋밋한 디자인 대신, 프로페셔널한 프론트엔드를 뽑아주는 4개 스킬 조합.

New Tool Vibe Coding Open Source github.com/Leonxlnx/taste-skill

왜 필요한가?

AI 코딩 도구의 프론트엔드 결과물이 갖는 공통적인 문제

📐
천편일률 레이아웃
어느 AI가 만들어도 비슷한 그리드 구조. 개성이 없다.
🎨
무난한 색상
파란색 버튼, 회색 카드. 2020년 부트스트랩 템플릿 수준.
💤
애니메이션 없음
호버 효과도 없는 정적인 UI. 생동감이 없다.
🔲
대충 처리된 여백
요소 간 간격이 들쭉날쭉. 리듬감이 없다.

frontend-design 스킬이 이 문제를 풀어왔는데, Taste Skill은 접근이 좀 달라요. 4개의 스킬을 조합해서, 단계별로 다른 문제를 해결합니다.

4개의 스킬 구성

각 스킬은 독립적이며, 필요한 것만 골라 쓸 수 있습니다

01
taste-skill
메인 디자인
처음부터 잘 만드는 법을 가르치는 스킬. 레이아웃, 타이포그래피, 색상, 여백, 모션. AI가 프론트엔드 코드를 쓸 때 "이건 이렇게 해야 좋아 보인다"는 기준을 심어줍니다.
DESIGN_VARIANCE MOTION_INTENSITY VISUAL_DENSITY
02
redesign-skill
업그레이드
이미 만든 게 있는데 디자인이 별로일 때. 처음부터 다시 만드는 게 아니라, 지금 있는 걸 감사(audit)하고 가장 큰 문제부터 고치는 방식. "전부 갈아엎어"가 아니라 "이것만 고치면 확 달라진다"를 찾아줍니다.
03
soft-skill
프리미엄
프리미엄 폰트, 넉넉한 여백, 깊이감 있는 카드 디자인, 스프링 기반 부드러운 애니메이션, 플로팅 네비게이션. AI의 천편일률적인 기본값을 전부 금지시키고 "비싸 보이는 느낌"을 공짜로 넣어줍니다.
04
output-skill
행동 교정
AI가 코드를 쓰다가 // 나머지는 여기에 구현 으로 플레이스홀더만 남기고 넘어가거나, 반만 쓰고 끝내는 걸 방지합니다. 아무리 디자인 스킬이 좋아도 코드가 절반이면 소용없으니까.

taste-skill 세팅 다이얼

세 가지 숫자(1~10)를 바꾸면 같은 프로젝트도 완전히 다른 느낌이 나옵니다

Design_Variance
1–10

8–10 비대칭, 넓은 여백, 아주 모던한 느낌.
Motion_Intensity
1–10

4–7 페이드인, 스무스 스크롤링.
8–10 마그네틱 효과, 스프링 물리, 스크롤 트리거 애니메이션.

사용 방법

SKILL.md 파일을 프로젝트에 복사하고, AI한테 읽으라고 하면 끝

1
GitHub에서 다운로드
taste-skill 레포에서 필요한 SKILL.md 파일을 내려받습니다.
2
프로젝트에 복사
Claude Code는 .claude/skills/ 폴더에 넣으면 자동 발동. Cursor는 SKILL.md로 참조.
3
AI에게 읽으라고 지시
스킬 파일을 인식시키면 이후 UI 생성 시 자동으로 적용됩니다.
# Claude Code — 자동 발동 .claude/skills/ ├── taste-skill.md ├── soft-skill.md └── output-skill.md # 새 프로젝트 추천 조합 taste-skill # 메인 디자인 기준 soft-skill # 프리미엄 레이어 output-skill # 게으름 방지 # 기존 프로젝트 개선 redesign-skill # 감사 + 핵심 수정 output-skill # 코드 완성 보장

frontend-design vs Taste Skill

두 가지를 함께 쓰는 것도 가능합니다

항목 frontend-design Taste Skill
출처 Anthropic 빌트인 스킬 커뮤니티 오픈소스
설치 ✓ 별도 설치 불필요 GitHub에서 다운로드 필요
구성 단일 스킬 4개 스킬 조합
디자인 조절 고정된 기준 ✓ 다이얼 3개로 세밀 조정
"비싸 보이게" ✗ 없음 ✓ soft-skill 전담
코드 완성 강제 ✗ 없음 ✓ output-skill 전담
기존 프로젝트 개선 ✗ 없음 ✓ redesign-skill 전담
함께 사용 가능 — frontend-design이 기본 품질, Taste Skill이 프리미엄 레이어
스킬을 잘 조합하는 시대

바이브코딩으로 만든 결과물에서 "AI가 만든 티"를 빼는 게 점점 쉬워지고 있어요. 프롬프트를 잘 쓰는 시대에서, 스킬을 잘 조합하는 시대로 넘어가고 있습니다.

SKILL.md 파일 하나가 디자인 감각을 대신해주는 시대. 이게 바이브코더에게 가장 좋은 소식이에요.
