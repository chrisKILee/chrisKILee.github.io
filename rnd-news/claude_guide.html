02 도구별 상세

8가지 도구, 각각 이렇게 다르다

챗봇 이상으로 Claude를 활용하려면 각 도구의 용도를 명확히 알아야 한다.

핵심 메시지
대부분의 사람은 Chat만 쓴다. 하지만 진짜 생산성은 나머지 7개에서 나온다.
1
💬 Chat

대부분의 사람이 시작하고 끝나는 곳. 질문하고 답을 받는 기본 대화 인터페이스.

Try "이 이메일을 직접적이지만 무례하지 않게 다시 써줘"
Tip Extended Thinking + Search 먼저 켜자. 클릭 두 번, 효과는 크다.
실수 매번 새 채팅에 내 소개를 붙여넣는 것. Projects를 써라.
2
🤝 Cowork

실제 파일(업로드 아닌 로컬 파일)에서 직접 작동하는 AI 동료. 파일을 직접 처리하고 이름까지 바꾼다.

Try "이 파일들을 종류별로 정리하고 이름을 명확하게 바꿔줘"
Tip 폴더 지시사항을 설정하면 매번 설명 안 해도 된다.
실수 파일을 하나씩 넘기는 것. 폴더 전체를 가리켜라.
3
📁 Projects

프롬프트, 파일, 컨텍스트를 한 곳에 저장. Claude가 프로젝트 안의 모든 것을 기억한다.

Try "Content" 프로젝트를 만들고 브랜드 보이스 문서와 스타일 가이드를 넣어라.
Tip 맞춤 지시사항 추가하면 첫 메시지부터 내 목소리로 쓴다.
실수 같은 내용으로 매번 새 채팅을 시작하는 것.
4
🎨 Artifacts

인터랙티브 앱, 대시보드, 도구를 채팅 안에서 바로 빌드. 다운로드도 된다.

Try "오전 9시~오후 6시 타임슬롯이 있는 주간 플래너 만들어줘"
Tip 원하는 모습이 될 때까지 계속 수정을 요청해라.
실수 코드만 만들 수 있다고 생각하는 것. 계산기, 플래너, 트래커 다 된다.
5
📊 Excel

스프레드시트 안에서 직접 작동. 데이터를 읽고, 수식을 작성하고, 차트를 만든다.

Try "이 지저분한 데이터 정리하고 피벗 요약본 만들어줘"
Tip Excel AND PowerPoint 모두 지원. 데이터 분석 후 덱까지 만들 수 있다.
실수 데이터를 채팅에 복붙하는 것. Excel 애드인을 써라. Claude가 직접 읽는다.
6
🔗 Connectors

Gmail, Drive, Slack, Notion, Figma 등 50개 이상의 도구를 Claude에 연결.

Try "지난주 Q3 관련 이메일을 전부 찾아서 요약해줘"
Tip 연결은 커넥터당 30초면 된다. 그냥 권한 허용하면 끝.
실수 도구를 연결 안 하는 것. 실제 데이터가 있어야 Claude가 10배 강해진다.
7
🧩 Plugins

세일즈, 마케팅, 법무, 재무 등 특정 역할에 맞게 미리 제작된 에이전트 팩.

Try Marketing 플러그인 설치 후 'marketing draft post' 입력.
Tip 직접 커스텀 플러그인을 만들거나 다른 사람 것을 설치할 수 있다.
실수 플러그인이 이미 있는데 일반 프롬프트로 처리하는 것.
8
⚡ Skills

Claude에게 전문 지식을 부여하는 재사용 가능한 태스크 템플릿. 저장된 워크플로우의 끝판왕.

Try 내 형식과 톤에 맞는 "회의 메모" 스킬을 만들어라.
Tip Cowork, Excel, Projects 전체에서 쓸 수 있다. 한번 만들면 어디서든.
실수 매번 같은 지시사항을 입력하는 것. 최고의 프롬프트를 스킬로 만들어라.
03 한눈에 비교

어떤 상황에 어떤 도구?

상황별로 가장 적합한 Claude 도구를 빠르게 찾을 수 있다.

도구 핵심 용도 입력 출력 적합한 상황
💬 Chat 대화형 Q&A 텍스트 텍스트 일상 질문, 글쓰기
🤝 Cowork 로컬 파일 처리 로컬 폴더 파일 변경 파일 정리, 배치 처리
📁 Projects 컨텍스트 저장 문서+지시 지속 기억 반복 작업, 장기 프로젝트
🎨 Artifacts 인터랙티브 빌드 요구사항 앱/도구 도구 제작, 프로토타입
📊 Excel 스프레드시트 Excel/PPT 수식+차트 데이터 분석, 보고서
🔗 Connectors 외부 도구 연결 실시간 데이터 분석+요약 업무 자동화, 검색
🧩 Plugins 역할별 에이전트 명령 전문 결과물 마케팅, 법무, 재무
⚡ Skills 재사용 템플릿 스킬 호출 표준화 출력 반복 워크플로우 자동화
활용 수준별 추천 시작점
초보자: Chat → Projects 순서로 익혀라.
중급자: Artifacts + Connectors로 생산성을 크게 높여라.
고급자: Skills를 만들어 전체 워크플로우를 표준화하라.
