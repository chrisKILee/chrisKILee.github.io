Core Concept

스킬의 두 가지 철학

Skills 2.0은 스킬을 목적에 따라 두 유형으로 명확히 구분합니다. 어떤 스킬을 만들지 먼저 결정하세요.

⚡ Capability Uplift Skill

능력 확장형 스킬
Claude가 아직 못 하는 것을 가르친다

Claude 모델이 기본적으로 수행하지 못하거나 일관되게 못하는 작업을 보완합니다. 외부 API 연동, 특수 포맷 출력, 브라우저 자동화 등이 대표적입니다.

대표 예시

🕸️ Firecrawl 웹 스크래핑 📄 PDF 파일 생성 🌐 Playwright E2E 테스트 🔌 외부 API 연동 🗃️ DB 직접 쿼리

⚠️ 모델이 발전하면 기능이 기본 내장될 수 있습니다. "은퇴 날짜"를 고려하세요.

🏢 Encoded Preference Skill

우리 팀 방식 인코딩형 스킬
방법은 알지만, 우리 규칙대로

Claude는 이미 해당 작업을 할 수 있습니다. 이 스킬은 "우리 팀의 특정 방식"을 인코딩합니다. 사내 규정, 코딩 컨벤션, 보고서 양식 등이 대표적입니다.

대표 예시

📋 NDA 검토 체크리스트 📊 주간 보고 작성 🔍 코드 리뷰 절차 📝 장애 보고서 양식 🚀 배포 승인 프로세스

✅ 모델이 발전해도 사라지지 않습니다. 팀의 규칙과 문화를 담기 때문에 장기적으로 복리(compound) 효과를 냅니다.

💡
어떤 스킬을 먼저 만들어야 할까?
팀 내 반복되는 프로세스(코드 리뷰 방식, 커밋 메시지 규칙, 배포 절차)를 Encoded Preference 스킬로 먼저 만드세요. 이는 모델 버전에 관계없이 지속적으로 가치를 냅니다. 외부 도구 연동이 필요한 경우에만 Capability Uplift 스킬을 고려하세요.
Skill Creator 2.0

스킬이 스스로 테스트하고 개선한다

코드 없이 스킬의 품질을 측정·비교·개선할 수 있는 완전히 새로운 워크플로우입니다.

1
Evals 작성 — 기대 결과를 테스트로 정의
스킬이 어떤 입력에 어떤 결과를 내야 하는지 테스트 케이스를 작성합니다. 코드가 아닌 자연어와 예시 파일로 정의합니다. 예: "PR diff를 주면 핵심 변경사항 3줄 요약을 반환해야 한다."
2
벤치마크 실행 — 통과율·시간·토큰 자동 측정
벤치마크 모드를 실행하면 eval 통과율, 소요 시간, 토큰 사용량을 자동으로 추적합니다. 로컬 저장, 대시보드 통합, CI/CD 파이프라인 연동이 가능합니다.
3
A/B 비교 — 블라인드 테스트로 개선 효과 검증
비교 에이전트가 "어느 버전인지 모르는 상태"에서 두 버전의 출력을 판단합니다. 스킬 개선 전후 또는 스킬 적용 여부를 객관적으로 비교할 수 있습니다.
4
트리거 튜닝 — Description 자동 최적화
스킬 개수가 많아질수록 description의 정밀도가 핵심입니다. Skill Creator가 현재 description을 샘플 프롬프트와 비교해 "너무 광범위" 또는 "너무 좁음"을 분석하고 수정안을 제안합니다.
5
병렬 에이전트 실행 — 독립 컨텍스트로 빠른 평가
여러 eval을 순차 실행하면 느리고 컨텍스트가 누적됩니다. 병렬 에이전트는 각각 독립 환경·깨끗한 컨텍스트로 실행되어 정확하고 빠른 평가가 가능합니다.
Technical Reference

새로운 프론트매터 필드 완전 정리

SKILL.md 상단 YAML 프론트매터에 추가된 필드들입니다. 기존 name·description·allowed-tools 외에 아래가 추가되었습니다.

필드 타입 설명 기본값
context NEW fork로 설정 시 독립된 서브에이전트 컨텍스트에서 스킬 실행. 메인 대화에 영향 없음 inline
agent NEW context: fork일 때 사용할 에이전트 타입 지정. Explore, Plan, 커스텀 에이전트 이름 가능 general-purpose
hooks NEW 스킬 전용 라이프사이클 훅 정의. PreToolUse, PostToolUse 등 스킬 범위에서만 적용 없음
argument-hint NEW 자동완성 시 표시되는 인수 힌트. 예: [issue-number] 또는 [filename] [format] 없음
user-invocable UPDATED false로 설정 시 / 메뉴에서 숨김. Claude만 자동으로 호출. 배경 지식형 스킬에 사용 true
model NEW 이 스킬이 실행될 때 사용할 모델 지정. 스킬별로 다른 모델 사용 가능 현재 세션 모델

새 문자열 치환 변수

$ARGUMENTS[N] / $N
인수를 위치(0부터 시작)로 접근합니다. $0은 첫 번째, $1은 두 번째 인수.
NEW
${CLAUDE_SKILL_DIR}
스킬 디렉토리의 절대 경로. 번들된 스크립트를 현재 작업 디렉토리 관계없이 참조할 수 있습니다.
NEW
${CLAUDE_SESSION_ID}
현재 세션 ID. 로깅, 세션별 파일 생성, 출력 추적에 활용합니다.
NEW
Code Examples

Skills 2.0 실전 예시

① 동적 컨텍스트 주입 — PR 자동 요약

스킬 실행 전 !`셸 명령` 문법으로 실시간 데이터를 주입합니다.

YAML + Markdown ~/.claude/skills/pr-summary/SKILL.md 
---
name: pr-summary
description: 현재 PR의 변경사항을 한국어로 요약합니다
context: fork          # 서브에이전트에서 실행
agent: Explore      # 읽기 전용 에이전트 사용
allowed-tools: Bash(gh *)
---

## PR 컨텍스트 (자동 주입)
- PR 변경사항: !`gh pr diff`
- PR 댓글: !`gh pr view --comments`
- 변경 파일 목록: !`gh pr diff --name-only`

## 작업
위 PR을 한국어로 요약해주세요:
1. 핵심 변경사항 (3줄 이내)
2. 영향을 받는 모듈
3. 리뷰어가 주의할 점

② 위치 인수 활용 — 컴포넌트 마이그레이션

YAML + Markdown ~/.claude/skills/migrate/SKILL.md 
---
name: migrate
description: 컴포넌트를 한 프레임워크에서 다른 프레임워크로 마이그레이션
argument-hint: [component] [from] [to]   # 자동완성 힌트
---

$0 컴포넌트를 $1에서 $2로 마이그레이션합니다.
기존 동작과 테스트를 모두 유지하세요.

# 사용: /migrate SearchBar React Vue
# $0=SearchBar, $1=React, $2=Vue

Migration Guide

기존 스킬을 2.0으로 업그레이드하려면

항목 Skills 1.0 (기존) Skills 2.0 (신규) 조치
파일 위치 .claude/commands/deploy.md .claude/skills/deploy/SKILL.md 기존 파일은 그대로 작동. 신규는 skills 권장
인수 처리 $ARGUMENTS (전체) $ARGUMENTS[N] / $N (위치 접근) 기존 $ARGUMENTS 그대로 사용 가능
실행 방식 항상 메인 컨텍스트에서 실행 context: fork로 독립 실행 가능 기본값은 1.0과 동일. 필요 시 fork 추가
지원 파일 단일 파일 디렉토리 + 보조 파일 큰 스킬은 파일 분리 권장
테스트 수동 확인 Evals + 벤치마크 Skill Creator에서 eval 작성 시작
✅
기존 스킬은 수정 없이 그대로 동작합니다
Skills 2.0은 하위 호환성을 완전히 유지합니다. 기존 .claude/commands/ 파일도 계속 작동하며, 점진적으로 마이그레이션할 수 있습니다. 급히 전환할 필요가 없습니다.

우리 팀에서 바로 쓸 수 있는 아이디어

Encoded Preference 스킬 유형으로 만들 수 있는 사내 활용 예시입니다.

🚀
배포 전 체크리스트 자동화
disable-model-invocation: true 설정으로 /deploy 시에만 실행. 테스트 실행 → 빌드 → 배포 → 검증 순서를 팀 방식대로 인코딩.
📋
사내 코드 리뷰 가이드라인
PR 리뷰 시 자동 활성화. 팀 컨벤션, 보안 체크포인트, 성능 기준을 context: fork + Explore 에이전트로 독립 실행.
🛡️
보안 취약점 스캔 스킬
동적 컨텍스트 주입으로 변경된 파일 목록을 자동 주입 후 OWASP 기준으로 분석. 별도 보안팀 리뷰 없이 1차 스크리닝 자동화.
📝
장애 보고서 자동 작성
사내 장애 보고서 포맷 인코딩. /incident-report [이슈번호]로 Jira 티켓 정보를 자동 주입해 초안 생성.
📊
주간 업무 요약 리포트
Git log, Jira 이슈, PR 목록을 동적으로 수집해 팀장 보고용 주간 리포트 초안 자동 생성.
🔧
온보딩 지식베이스 스킬
user-invocable: false로 Claude만 자동 호출. 신규 입사자가 코드를 질문할 때 사내 구조와 컨벤션 자동 참조.
