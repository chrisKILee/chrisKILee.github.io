Go 네이티브 컴파일러

Microsoft가 TypeScript 코드베이스 전체를 Go로 포팅한 7.0 Beta를 공개했습니다. 기존 TypeScript 6.0 대비 최대 10배 빠른 컴파일 속도와 50% 메모리 절감을 제공합니다. Project Corsa(코드명)는 JavaScript 기반 컴파일러 10년 역사의 전환점입니다.

핵심 변경사항

Lead Story

10년 만의 대전환 — TypeScript 컴파일러를 Go로 완전 재작성

Microsoft는 TypeScript 컴파일러(파서, 타입 체커, 이미터)를 Go 언어로 완전히 포팅했습니다. 코드명 Project Corsa로 진행된 이 작업은 기존 TypeScript/JavaScript 의미론(semantics)과 타입 체크 동작을 최대한 보존하면서 네이티브 바이너리로 동작하도록 설계되었습니다.

Go의 고루틴(goroutine)을 활용해 파싱, 타입 체킹, emit을 병렬로 처리할 수 있게 되었으며, 이는 JavaScript 런타임이 구조적으로 제공하기 어려운 수준의 병렬화입니다. 성능 향상의 약 50%는 네이티브 코드 속도, 나머지 50%는 병렬화에서 비롯됩니다.

Microsoft TypeScript Team · 2026-04-21 · 공식 발표

Breaking Changes

ES5 타겟 제거, CommonJS 기본값 변경 등 주요 호환성 변경

target: es5, CommonJS 모듈, AMD/UMD/SystemJS 등 레거시 옵션이 제거됩니다. strict가 기본 true로 바뀌며, module의 기본값도 esnext로 전환됩니다.

호환성 주의 · 마이그레이션 필요

Limitation

안정적 Programmatic API 부재 — 린터·포매터·IDE 확장 미지원

기존 Strada API 기반 도구(ESLint, Prettier 등)가 TS 7.0에서 작동하지 않습니다. 새 Corsa API는 TypeScript 7.1 이후 안정화 예정입니다.
