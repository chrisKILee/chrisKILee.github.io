Kubernetes Manifest Manager와
Argo CD API의 연관성 연구

본 연구는 수백 개의 Kubernetes Manifest(YAML)를 수동으로 관리하는 복잡성을 해결하기 위해 'Manifest Manager'라는 추상화 계층을 도입하고, 이를 Argo CD API와 연동하여 자동화된 배포 파이프라인(GitOps)을 구축하는 전략을 분석합니다.

Problem

YAML 파일의 파편화, 버전 관리의 어려움, 수동 `kubectl apply`로 인한 휴먼 에러 발생.

Solution

중앙화된 Manifest Manager 시스템 구축 및 Argo CD를 배포 엔진(Execution Engine)으로 활용.

Key Enabler

Argo CD API: 외부 시스템이 배포 상태를 제어하고 모니터링할 수 있는 프로그래밍 인터페이스 제공.

통합 아키텍처 및 데이터 흐름

결론: Manifest Manager의 미래

Kubernetes Manifest Manager는 단순히 YAML 파일을 저장하는 도구가 아닙니다. 이는 조직의 인프라 정책을 코드로 정의하고(Policy as Code), Argo CD API를 통해 이를 강제하고 실행하는 지능형 제어 센터입니다.

Argo CD API와의 긴밀한 통합은 개발자에게는 복잡한 Kubernetes 내부를 숨기고(Abstraction), 운영팀에게는 투명한 제어권과 가시성을 제공합니다.
