# Prompt Generator SPA PRD

## 1. 목적

이미지 생성 프롬프트를 매번 새로 작성하지 않고, 사용자가 상황별 템플릿과 변수를 선택/입력하면 완성된 프롬프트를 자동 조합해주는 SPA를 만든다.

핵심 목표:
- 가족사진 꾸미기, 수채화 포스터, 키링, 분신/애교, 여행 포스터, 3x3 박스 꼬맹이 등 반복 사용 프롬프트를 구조화한다.
- 템플릿마다 다른 입력값을 UI로 쉽게 받는다.
- 분위기, 스타일, 보존 규칙, 네거티브 프롬프트를 선택형 블록으로 조합한다.
- 특히 사진 위 손글씨/낙서/메시지 배치 프롬프트를 정교하게 만들 수 있게 한다.
- 최종 프롬프트를 버튼 한 번으로 clipboard에 복사한다.

## 2. 사용자

주 사용자:
- 이미지 생성 도구에 넣을 프롬프트를 자주 만드는 개인 사용자
- 가족사진, 인물사진, 여행사진, 제품/굿즈 이미지를 여러 스타일로 변환하고 싶은 사용자
- 한글 문구가 포함된 이미지 편집 요청을 자주 만드는 사용자

사용자 특성:
- 전문 프롬프트 엔지니어가 아니어도 된다.
- 매번 긴 프롬프트를 처음부터 쓰고 싶지 않다.
- 비슷한 요청을 사진/문구/분위기만 바꿔 반복한다.
- 한글이 깨지거나 얼굴 위에 글씨가 올라가는 문제를 줄이고 싶다.

## 3. 문제 정의

현재 문제:
- 프롬프트가 길고 복잡해서 재사용이 어렵다.
- 템플릿마다 바꿔야 하는 단어와 문장이 섞여 있다.
- 한글 텍스트 생성, 얼굴 보존, 장식 배치 같은 중요 규칙을 매번 빼먹기 쉽다.
- 가족사진 손글씨 꾸미기처럼 배치가 중요한 작업은 문구 위치, 얼굴 보호, 검은 여백 제거 조건을 명확히 넣어야 한다.
- 완성 프롬프트를 복사하기 위해 수동 편집이 많다.

해결 방향:
- 프롬프트를 `템플릿 + 변수 + 선택 블록 + 네거티브 블록`으로 분리한다.
- 사용자 입력 UI를 통해 변수만 채우게 한다.
- 자주 쓰는 분위기와 배치 규칙을 프리셋으로 제공한다.
- 최종 출력 프롬프트는 항상 복사 가능한 텍스트로 제공한다.

## 5. 핵심 사용자 시나리오

### 시나리오 A: 가족사진 위 손글씨 꾸미기

1. 사용자가 `사진 손글씨 꾸미기` 템플릿을 선택한다.
2. 사진 유형을 `가족 해변사진`으로 선택한다.
3. 이벤트를 `세부여행`으로 입력한다.
4. 분위기를 `따뜻한 가족 여행 기록`으로 선택한다.
5. 문구 목록에 아래 문구를 입력한다.
   - 세부여행중...
   - 행복한 우리가족 쭌쭌이네 ♡
   - 서로 사랑하자
   - 든든한 아빠
6. 배치 규칙에서 아래 옵션을 켠다.
   - 실제 사진 영역만 크롭
   - 얼굴 위 장식 금지
   - 화살표는 얼굴 통과 금지
   - 메시지는 사진 안 빈 배경 공간에 배치
7. 최종 프롬프트를 확인한다.
8. `복사` 버튼을 눌러 clipboard에 저장한다.

### 시나리오 B: 수채화 포스터

1. `수채화 editorial poster` 템플릿을 선택한다.
2. 장면 분위기를 `조용한 바다`로 선택한다.
3. 배경 디테일에 `바다, 난간, 식물`을 입력한다.
4. 문구를 `그냥 이렇게, 너답게.`로 입력한다.
5. 한글 정확도 우선 모드를 켠다.
6. 최종 프롬프트에는 `텍스트는 생성하지 않고 빈 여백을 남긴다` 블록이 추가된다.
7. 복사한다.

### 시나리오 C: 키링

1. `키링 product mockup` 템플릿을 선택한다.
2. 스트랩 문구를 `SEOJUN`으로 입력한다.
3. 스트랩 색상을 `charcoal`로 선택한다.
4. 옷 단서를 `gray sweatshirt`로 입력한다.
5. `텍스트 정확도 강하게` 옵션을 켠다.
6. 최종 프롬프트를 복사한다.

## 6. 템플릿 목록

### A. 사진 손글씨 꾸미기

목적:
- 원본 사진을 유지한 채 흰색 손글씨 메시지, 하트, 별, 화살표, 점선 장식을 추가하는 프롬프트 생성

핵심 입력:
- 사진 유형
- 이벤트/상황
- 문구 리스트
- 장식 스타일
- 배치 안전 규칙
- 한글 텍스트 처리 방식

중요 옵션:
- 실제 사진 영역만 사용
- 검은 여백 제거
- 얼굴/머리/손 위 장식 금지
- 화살표는 얼굴 통과 금지
- 메시지는 사진과 가까운 빈 공간에 배치

### B. 수채화 editorial poster

목적:
- 인물 사진을 감성 수채화 포스터 스타일로 변환하는 프롬프트 생성

핵심 입력:
- 장면 분위기
- 배경 디테일
- 문구
- 서명
- 비율
- 텍스트 후처리 여부

### C. 키링 product mockup

목적:
- 인물 사진 기반 SD/chibi 키링 제품사진 프롬프트 생성

핵심 입력:
- 스트랩 텍스트
- 스트랩 색상
- 옷 단서
- 배경
- 장난감 표현 강도

### D. 분신/애교 사용법

목적:
- 같은 인물이 여러 미니 버전으로 등장하는 카드형 프롬프트 생성

핵심 입력:
- 제목
- 테마
- 미니 인물 수
- 액션 목록
- 캡션 목록

### E. 여행 poster collage

목적:
- 도시/국가 기반 editorial travel poster 프롬프트 생성

핵심 입력:
- 국가
- 도시
- 헤드라인
- 서브텍스트
- 여행자 스타일

### F. 3x3 cardboard box toddler

목적:
- 실제 인물을 tiny toddler 버전으로 바꿔 3x3 박스칸에 배치하는 프롬프트 생성

핵심 입력:
- 그리드 테마
- 벽 메모
- 상호작용
- 조명/톤

### G. 3D 미니어처 카드뉴스

목적:
- 주제를 표현한 감성 3D 미니어처 인스타 카드뉴스 프롬프트 생성 (파스텔톤, 손글씨 메모)

핵심 입력:
- 주제
- 메인 문구 / 부제 문구
- 손글씨 메모 목록
- 비율(기본 4:5)

### H. 트래블로그 타이포 포스터

목적:
- 거대 도시명 타이포그래피 위를 미니 chibi(인물 정체성 보존)가 여행하는 premium travel-log 포스터 프롬프트 생성
- E(여행 poster collage)와 구분: 콜라주가 아니라 typography photo-mask + chibi 탐험 구도

핵심 입력:
- 도시(대형 타이포) / 국가 / 여행 날짜
- 랜드마크 목록(타이포 안 콜라주)
- 미니 캐릭터 수 / 비율

## 7. 분위기 프리셋

모든 템플릿에서 공통으로 선택 가능한 분위기:

- 따뜻한 가족 기록
- 한국 인스타 감성
- 조용한 감정 포스터
- 밝고 귀여운 생일파티
- 여행 스냅 감성
- 프리미엄 제품사진
- 포근한 브라운톤
- 미니멀하고 깨끗한 편집
- 영화적인 따뜻한 조명
- 장난스럽고 사랑스러운 톤

각 분위기는 프롬프트 블록으로 변환된다.

예:

```text
따뜻한 가족 기록:
cozy, warm, lovely, intimate family memory, natural photo decoration, soft white handwritten doodles, emotional but not excessive.
```

## 8. 사진 위 기록/낙서 기능 요구사항

이 기능은 제품의 핵심 차별점이다.

### 8.1 문구 관리

사용자는 여러 문구를 추가할 수 있어야 한다.

각 문구 항목 필드:
- 문구 내용
- 문구 역할
  - 제목
  - 가족 전체 문구
  - 인물 라벨
  - 감정 메모
  - 음식/사물 설명
- 추천 위치
  - 상단 하늘
  - 좌측 여백
  - 우측 여백
  - 하단 모래/테이블
  - 인물 주변 빈 공간
- 화살표 필요 여부
- 장식 강도
  - 없음
  - 약함
  - 보통

### 8.2 배치 안전 옵션

필수 체크박스:
- 얼굴 위 글씨 금지
- 머리 위 점선 금지
- 눈/입 위 장식 금지
- 손 위 장식 금지
- 화살표 얼굴 통과 금지
- 검은 여백에 문구 배치 금지
- 실제 사진 영역만 사용
- 배경 빈 공간 위주 배치

### 8.3 사진 유형별 배치 추천

해변사진:
- 하늘, 바다, 모래에 문구 배치
- 얼굴 주변 장식 최소화
- 수평선 근처는 과도한 글씨 피하기

생일파티 사진:
- 벽, 소파, 테이블 빈 공간 활용
- 케이크와 음식은 가리지 않기
- 주인공 근처에 왕관/하트만 작게 배치

카페/실내 사진:
- 벽, 창문, 테이블 여백 활용
- 얼굴 주변보다 상단/좌우 여백 활용

단독 인물사진:
- 인물 주변 배경 여백에 짧은 감성 문구
- 얼굴 위 장식 금지
- 과한 말풍선 금지

## 10. 성공 기준

정량 기준:
- 사용자가 1분 안에 가족사진 손글씨 프롬프트를 만들 수 있다.
- 최종 프롬프트 복사까지 클릭 5회 이내로 가능하다.
- 템플릿별 필수 변수 누락 시 UI에서 바로 표시한다.

정성 기준:
- 사용자가 어떤 단어를 바꿔야 하는지 헷갈리지 않는다.
- 얼굴 보존/한글 깨짐/장식 배치 문제를 예방하는 규칙이 자연스럽게 포함된다.
- 완성 프롬프트가 바로 이미지 생성 도구에 붙여넣기 가능한 수준이다.

## 11. 비기능 요구사항

- SPA는 로컬 파일 또는 정적 호스팅에서 동작 가능해야 한다.
- 서버 없이 동작하는 것을 우선한다.
- 사용자 입력값은 기본적으로 브라우저 localStorage에 저장한다.
- 외부 API 키가 없어도 프롬프트 생성은 가능해야 한다.
- 템플릿 데이터는 코드와 분리된 JSON/TS 객체로 관리한다.

## 12. 권장 기술 방향

1차 구현 추천:
- React + Vite + TypeScript
- Tailwind CSS
- shadcn/ui 또는 자체 컴포넌트
- Zustand 또는 React state
- localStorage persistence

대안:
- SvelteKit static SPA
- Vue 3 + Vite
- 순수 HTML/CSS/JS 단일 파일

추천은 React + Vite + TypeScript다. 템플릿/폼/프리뷰 구조가 명확하고, 이후 컴포넌트 확장이 쉽다.
