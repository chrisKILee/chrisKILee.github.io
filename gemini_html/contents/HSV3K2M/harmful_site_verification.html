왜 만들었나요?

기존 수동 분석 방식의 한계에서 출발했습니다

기존 방식

관리자가 직접 하나씩 확인

  • 매월 전 계열사 접속 로그를 수동 분석 (0.5~1일 소요)
  • 담당자마다 판단 기준이 달라 일관성 부족
  • 계열사별로 각각 관리해 동일 URL 중복·상이 분석 발생
  • 대량 로그에서 위험 사이트를 놓칠 위험
  • 감사·증적 자료 준비 별도 필요
유해사이트 검증 시스템

AI가 자동으로 분류·판정

  • 로그 업로드만 하면 AI가 URL별 유해 여부 자동 판정
  • 전 계열사 데이터를 한 곳에서 중앙 집중 관리
  • 허용/차단 기준이 DB에 누적되어 일관성 유지
  • 대량 로그에서도 핵심 위험 사이트만 필터링
  • 분석 이력이 자동 저장되어 감사 자료로 즉시 활용

주요 기능

세 가지 핵심 기능으로 URL 분석부터 대시보드까지 한 번에

🔍

URL 분석

업로드된 접속 로그의 각 URL(호스트)을 Gemini AI가 하나씩 분석합니다. 분석 진행률을 실시간으로 확인할 수 있으며, 중간에 중단해도 재시작 시 남은 항목부터 이어서 분석합니다.

  • 계열사명 · 카테고리 · 호스트 기반 분석
  • 10초 이하 단순 접속 · 광고 노이즈 자동 제거
  • 허용 사이트 목록에 이미 등록된 URL은 건너뜀
  • 분석 중단 후 재시작 시 이어서 진행
🏷️

유해사이트 분류

AI 분석 결과를 바탕으로 사이트를 자동 분류합니다. 비업무 사이트로 판정된 항목은 분류 내역 파일에 저장되며, 관리자가 최종 허용/차단 여부를 결정할 수 있습니다.

  • 업무/비업무 여부 AI 자동 판정 + 사유 기입
  • 계열사 · 카테고리 · 비업무여부 · 차단여부 필터
  • 동일 사이트 중복 없이 한 번만 등록
  • 관리자 수동 변경 시 허용 사이트 자동 업데이트
📊

결과 대시보드

분석된 데이터를 한눈에 볼 수 있는 대시보드를 제공합니다. 카테고리별 비업무 접속 현황과 계열사별 Top 5 사이트를 시각화하여 보안 현황을 즉시 파악할 수 있습니다.

  • 카테고리별 비업무 접속 횟수 현황
  • 계열사별 비업무 사이트 접속 현황 Top 5
  • 기간 · 카테고리 필터 조건 적용 가능
  • 허용/차단 사이트 중앙 집중 관리

사용 방법

0
연간 최초 1회

연도별 폴더 구조 초기 설정

매년 1월 1일, 사이드 메뉴에 해당 연도 폴더를 생성합니다. 그 아래 원본 파일 폴더와 비업무사이트 폴더를 만들어 두면 이후 모든 분석 결과가 자동으로 분류됩니다.

1
매월

원본 로그 파일 업로드

유해사이트 차단 솔루션에서 추출한 접속 로그 엑셀 파일을 업로드합니다. 파일은 자동으로 YY.MM.DD_vX 형식으로 버전 관리됩니다.

  • 이미 허용 사이트로 등록된 URL은 자동 제외
  • 계열사·카테고리·호스트 중 하나라도 비어 있으면 제외
  • 접속 시간 10초 이하 (광고·노이즈) 자동 제거
  • 예외 카테고리로 관리 중인 항목 자동 제외
2
자동

AI 비업무 사이트 분석

업로드된 로그의 URL을 Gemini AI가 하나씩 분석합니다. 화면에서 분석 진행률을 확인할 수 있으며, 필요 시 분석을 중단했다가 나중에 이어서 진행할 수 있습니다.

  • AI가 판단한 카테고리, 사이트 정보, 비업무 여부 자동 기입
  • 분석률 실시간 확인 가능
  • 중단 후 재시작 시 남은 항목부터 이어서 분석
3
검토

비업무 사이트 분류 내역 검토

AI 분석이 완료되면 비업무사이트 폴더에 분류 내역 파일이 생성됩니다. 계열사 · 카테고리 · 비업무여부 · 차단여부로 필터링하며 결과를 검토합니다.

  • 업무 사이트로 재판정 시 → 허용 사이트 관리 파일 자동 업데이트
  • 차단 항목 체크 시 → 차단 사이트 관리 파일 자동 업데이트
  • 동일 사이트는 한 번만 등록 (중복 방지)
  • 내보내기로 엑셀 추출 가능
4
모니터링

대시보드에서 현황 확인

대시보드에서 전 계열사 비업무 접속 현황을 한눈에 확인합니다. 기간과 카테고리 필터를 활용해 원하는 구간의 데이터를 빠르게 조회할 수 있습니다.

  • 카테고리별 비업무 접속 횟수 차트
  • 계열사별 비업무 사이트 접속 현황 Top 5
  • 기간 · 카테고리 필터 적용
