01. 기본 구조와 개념

AI 아키텍처를 이해하는 첫 단추는 데이터의 계층 구조를 파악하는 것입니다. 각 요소는 서로 유기적으로 연결되어 있습니다.

T

토큰 (Token)

AI 모델이 텍스트를 연산하기 위해 쪼개는 최소 의미 단위입니다. 한 글자일 수도 있고, 단어의 일부일 수도 있습니다.

C

청크 (Chunk)

토큰들을 검색 효율에 맞게 묶은 지식 덩어리입니다. 검색의 품질을 결정하는 가장 중요한 변수입니다.

V

벡터 DB (Vector DB)

청크를 숫자 배열로 변환하여 저장하는 창고입니다. 키워드가 아닌 '의미'를 좌표로 찾아냅니다.

포함 관계 이해하기

전체 문서는 여러 개의 청크로 나뉘고, 하나의 청크는 수백 개의 토큰을 포함하며, 각 토큰은 다시 수치화되어 벡터가 됩니다.

문서 ➔ 청크 ➔ 토큰 ➔ 벡터

03. 기술 심화: 데이터의 실체

토큰이 분절되는 실제 메커니즘과 벡터 DB에 저장되는 숫자 배열의 실체를 직접 확인합니다.

A 실시간 토크나이저 시뮬레이터

04. 템플릿(Template) 설계의 중요성

검색된 청크를 사용자에게 그대로 보여주지 않습니다. 템플릿은 AI에게 역할을 부여하고 결과 형식을 고정하는 도구입니다.

SYSTEM PROMPT TEMPLATE

당신은 사내 지식 검색 전문가입니다.
다음에 주어지는 [지식 청크]만을 바탕으로 답변하세요.

[지식 청크]: {context}
[직원 질문]: {query}

답변 규칙:
1. 답변은 반드시 JSON 형식으로 제공할 것.
2. 근거가 부족하면 "정보 없음"을 리턴할 것.
