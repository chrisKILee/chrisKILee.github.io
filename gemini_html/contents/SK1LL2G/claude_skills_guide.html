Commit-Push
/commit-push
PR 없이 커밋 + 푸시만 수행합니다. commitlog.md 기반 커밋 규칙 적용 — 타입: 요약 (50자 이내, 쌍따옴표 금지), 변경사항은 불릿 포인트. diff보다 실제 작업 내용 기준으로 작성.
Git PR 없음
▼ ▾ 팁 보기

타입: 요약 (50자 이내) - 변경사항 1 - 변경사항 2
타입 종류
  • fix: 버그 수정
  • feat: 새로운 기능
  • refactor: 코드 리팩토링
  • docs: 문서 수정
  • style: 코드 스타일 변경
  • test: 테스트 관련
  • chore: 기타 작업

프로젝트 초기화 SDD
▼ ▾ 팁 보기
12문항 인터뷰 순서
  • 프로젝트 이름
  • 핵심 Pain Point
  • 주요 사용자 (타겟)
  • 핵심 기능 3~5가지
  • 기능 우선순위 P0/P1/P2
  • MVP 범위
  • 외부 API / 연동 서비스
  • 예상 동시 접속자 / 데이터 규모
  • 보안 요구사항
  • 레퍼런스 서비스
  • 개발 기간 목표
  • 팀 구성 / 협업 방식
생성 파일
CLAUDE.md (프로젝트 헌법) .claude/docs/PRD.md (왜 만드는가) .claude/docs/TRD.md (어떻게 만드는가) .claude/docs/ADR.md (왜 이 기술인가) .claude/docs/SPEC.md (무엇을 만드는가) .claude/docs/IMPLEMENTATION_PLAN.md tmux-dev.sh (선택)

Program-Guide
/program-guide
Confluence/Google Docs 링크를 받아 비개발자용 프로그램 소개 가이드 HTML을 생성합니다. 문서 분석 → 콘텐츠 성격 분류(대시보드/자동화/협업/분석) → 패턴 선택 → HTML 생성 → site.json 자동 등록.
문서 생성 HTML
▼ ▾ 팁 보기
7가지 인터뷰 질문
  • 프로그램 이름
  • 문서 링크 (Confluence / Google Docs)
  • 한 줄 소개
  • 주요 사용자
  • 핵심 기능 3가지
  • 스크린샷 파일 경로
  • 첨부 파일 (PDF, 양식 등)
디자인 패턴 자동 선택
  • 패턴 A: 포탈/대시보드형 (네이비 계열)
  • 패턴 B: 자동화/AI 도구형 (다크 + 인디고)
  • 패턴 C: 협업/지식 플랫폼형 (밝은 톤)
  • 패턴 D: 자유형
출력 경로
contents/{7자리ID}/{파일명}.html site.json → 30BD927 (🤖 AI-Worker) 자동 등록
개발자 용어(API, DB, 쿼리 등)는 비개발자 언어로 자동 변환

Tmux
/tmux on | off | status
개발 tmux 세션을 켜거나 끕니다. on 시 backend·frontend·test·terminal 4개 창 자동 구성. tmux-dev.sh 있으면 해당 스크립트 사용, 없으면 기본 레이아웃으로 즉시 생성.
개발 환경 tmux
▼ ▾ 팁 보기
명령어
/tmux on → 세션 시작 /tmux off → 세션 종료 /tmux status → 현재 상태 확인
창 구성 (on 실행 시)
  • [1] backend — 상단: 서버 / 하단: DB
  • [2] frontend — React 개발 서버
  • [3] test — 좌: BE 테스트 / 우: FE 테스트
  • [4] terminal — 일반 터미널
tmux-dev.sh 없으면 기본 레이아웃으로 자동 생성 후 실행 · 접속: tmux attach -t [세션명]

Dirtree
/dirtree [경로] [깊이]
프로젝트 디렉토리 구조를 tree 형태로 시각화합니다. 깊이·시작 경로·--all 옵션 지정 가능. node_modules, .git, .claude 등 노이즈 디렉토리는 자동 제외.
파일 탐색 개발 환경
▼ ▾ 팁 보기
명령어
/dirtree → 현재 디렉토리, 깊이 3 /dirtree 4 → 깊이 4로 탐색 /dirtree backend → backend 디렉토리 탐색 /dirtree backend 4 → 경로 + 깊이 조합 /dirtree --all → 숨김 도구 디렉토리(.claude 등) 포함
자동 제외 목록
  • 항상 제외: node_modules, dist, build, .git, __pycache__, .venv, .next
  • 기본 제외: .claude, .cursor, .gemini, .vscode (--all 시 포함)
tree 명령이 없으면 find + awk 로 자동 대체 · 출력 후 주요 구조 한국어 요약 제공

ValidateData
/validatedata YYYYMM
NAC 보고서 데이터 정합성 검증. 전체 계열사의 4개 섹션(S1 전체노드·S2 정책현황·S3 OS요약·S4 운영체제별) PC 카운트 일치 여부를 검증. DB 쿼리 → cron worker 전송 → 마크다운 표로 PASS/FAIL 출력.
데이터 검증 NAC
▼ ▾ 팁 보기
사용법
/validatedata 202602 → 2026년 2월 검증 (전월 자동 계산)
4개 섹션 정합성 기준
  • S1 전체노드 PC — 기준값 (nl_genidev=20 전체 COUNT)
  • S2 PC별 정책현황 — S1과 동일해야 함
  • S3 PC별 OS 요약 — Win7/Win8/Mac 제외 → S1보다 작을 수 있음
  • S4 운영체제별 PC — S1과 동일해야 함
판정 기준
✅ PASS: S1 = S2 = S4 (S3는 참고) ❌ FAIL: 하나라도 다르면 FAIL
결과는 계열사별 마크다운 표로 출력 · gcloud cron worker 경유 실행

커스텀 스킬 참조표
명령어 설명 사용 시점
/sdd-init SDD 프로젝트 초기화 (인터뷰 → 문서 → tmux) 새 프로젝트 시작 시
/prd PRD(제품 요구사항 문서) 생성 왜 만드는가 정의 시 · sdd-init 내 자동 호출
/trd TRD(기술 요구사항 문서) 생성 어떻게 만드는가 정의 시 · sdd-init 내 자동 호출
/adr ADR(아키텍처 결정 기록) 생성 기술 선택 이유 기록 시 · sdd-init 내 자동 호출
/impl-plan 구현 계획(Phase별 Task) 생성 + 컨펌 대기 개발 시작 전 · sdd-init 내 자동 호출
/commit-push 커밋→푸시 (PR 없이) master 직접 푸시 또는 PR 불필요 시
/jira-ticket [URL] Jira 티켓 기반 버그 수정 또는 기능 구현 Jira 티켓으로 작업 시작 시
/dogfood 웹앱 QA 탐색 테스트 배포 전 QA, 버그 헌팅
/program-guide 프로그램 소개 가이드 HTML 비개발자용 문서 생성 시
/table2md [N] 표 → Confluence MD 변환 대화의 표를 Confluence에 붙여넣기 전
/tmux on|off|status 개발 tmux 세션 토글 개발 환경 시작/종료 시
/dirtree [경로] [깊이] 디렉토리 구조 tree 시각화 프로젝트 구조 파악이 필요할 때
/validatedata YYYYMM NAC 데이터 정합성 검증 NAC 보고서 월별 검증 시
/add-skill-to-doc 새 커스텀 스킬을 가이드 HTML에 자동 추가 새 스킬 설치 후 문서 업데이트 시
/ai-worker-mail AI-WORKER 활동 홍보 이메일 초안 작성 팀 AI 활용 성과 공유 이메일 작성 시
/prod-db-access itinfosec 운영 DB 접근 및 마이그레이션 실행 운영 DB 조회 또는 일회성 마이그레이션 시
/itinfosec-get-meta "검색어" DLP 메타 테이블 조회 (프로그램↔프로세스, 사이트↔URL) DLP 매핑 확인 시
/itinfo-meta-program-mapping "proc" "prog" 프로세스명 ↔ 프로그램명 매핑 추가/수정 소프트웨어 매핑 등록 시
/itinfo-meta-web-mapping "url" "site" URL ↔ 사이트명 매핑 추가/수정 웹사이트 매핑 등록 시
/page-index-add AI Tech Feed에 새 아이템 추가 블로그 피드 항목 추가 시
/page-index-remove AI Tech Feed에서 아이템 영구 삭제 블로그 피드 항목 삭제 시
/add-new-page gemini_html 사이트에 새 HTML 페이지 추가 새 페이지 등록 시
/sheet-diff 구글 스프레드시트 두 시트 라인 단위 비교 시트 변경사항 비교 시
/weekly Confluence 주간 보고 bullet 정리 및 이전 주 비교 주간 보고 작성 시
/ai-worker-mail-v2 AI-WORKER 홍보 메일 초안 v2 (레이아웃·관점 랜덤 조합) 팀 AI 활용 성과 공유 이메일 작성 시
