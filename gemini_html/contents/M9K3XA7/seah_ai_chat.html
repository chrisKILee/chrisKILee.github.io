왜 만들었나요?

반복되는 불편함을 없애고, 직원 스스로 안전하게 업무할 수 있도록

Before — 기존의 어려움
  • 😓 정보보호 규정이 궁금해도 담당자에게 직접 문의해야 했습니다
  • 🔄 담당자는 동일한 질문을 반복 응대하며 시간을 낭비했습니다
  • 📁 방대한 규정 문서를 직접 찾아보기가 쉽지 않았습니다
  • 📧 의심 메일을 받아도 피싱 여부를 빠르게 확인할 수단이 없었습니다
  • ⏰ 업무 시간 중에만 담당자에게 문의가 가능했습니다
After — 이제는 이렇게
  • 💬 궁금한 규정을 AI에게 바로 물어보고 즉시 답변을 받습니다
  • 🤖 80% 이상의 반복 문의를 AI가 자동으로 처리합니다
  • 🔎 세아 규정과 KISA 가이드라인을 출처와 함께 안내받습니다
  • 🛡️ 의심 메일을 우클릭하면 30초 안에 위험도를 확인합니다
  • 🌙 Chrome 사이드바에서 24시간 언제든 사용할 수 있습니다

사용 방법

설치 후 바로 시작하세요 — 복잡한 설정이 필요 없습니다

📋 규정 Q&A 사용법

1

익스텐션 아이콘 클릭

Chrome 도구 모음에서 세아 AI Chat 아이콘을 클릭합니다. 오른쪽에 사이드바가 열립니다.

2

Google 계정으로 로그인

회사 이메일(vntgcorp.com 또는 seah.co.kr)로 로그인합니다. 한 번만 하면 8시간 유지됩니다.

3

궁금한 점 입력

입력창에 정보보호 관련 질문을 자유롭게 입력합니다. "비밀번호는 몇 자 이상이어야 하나요?"처럼 쉽게 물어보세요.

4

AI 답변 확인

세아 규정과 KISA 가이드라인에 근거한 답변이 섹션별로 표시됩니다. 출처를 색상 배지로 한눈에 확인하세요.

🔴 악성메일 분석 사용법

1

Gmail에서 의심 메일 열기

Chrome 브라우저에서 Gmail을 열고 분석하고 싶은 이메일을 클릭합니다.

2

메일 본문에서 우클릭

이메일 본문 위에서 마우스 오른쪽 버튼을 클릭합니다. 메뉴에서 "AI 악성메일 분석"을 선택합니다.

3

분석 진행

AI가 자동으로 링크 안전성, 첨부파일 위험도, 발신 도메인을 종합 점검합니다. 약 30초 소요됩니다.

4

위험도 결과 확인

사이드바에 위험 수준과 세부 분석 결과가 표시됩니다. 위험 또는 주의 판정 시 해당 항목을 확인하세요.

🚨
Critical — 위험
악성 URL 또는 악성 파일이 실제로 탐지된 경우. 즉시 열지 마세요.

설치 안내

3단계로 간편하게 설치합니다 — IT 전문 지식이 필요 없습니다

1

정보보호 포털에서 다운로드

정보보호 포털 내 AI Chat 소개 페이지에서 "Chrome에 추가" 버튼을 클릭하여 설치 파일(ZIP)을 다운로드합니다.

2

설치 스크립트 실행

다운로드한 ZIP 파일을 압축 해제합니다. 폴더 안에 있는 설치.bat 파일을 실행합니다. 화면 안내에 따라 진행하세요.

3

Google 계정으로 로그인

Chrome 도구 모음에 세아 AI Chat 아이콘이 나타납니다. 아이콘을 클릭하고 회사 Gmail 계정으로 로그인하면 바로 사용 가능합니다.

설치 관련 문의 — 설치 중 문제가 발생하면 정보보호팀에 문의하거나 정보보호 AI Chat으로 "설치 방법 안내" 를 입력해 보세요.
