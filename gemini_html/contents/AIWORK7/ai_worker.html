AI Worker
업무 자동화 플랫폼

PPT·PDF·이미지를 업로드하면 AI가 자동으로 발표 스크립트, 면접 질문, 엑셀 데이터를 생성합니다. TDD + AI 페어 프로그래밍 방법론으로 1인 개발된 실무 자동화 플랫폼입니다.

주요 기능

📊

발표 스크립트 생성기

PPT·PDF를 업로드하면 슬라이드별 발표 스크립트를 자동으로 생성합니다.

  • 3단계 AI 파이프라인 (병렬 분석 → 순차 생성 → 전체 후처리)
  • LibreOffice PDF 변환 + Gemini Vision 분석
  • 매직바이트 이중 검증 (스푸핑 방지)
  • 지수 백오프 재시도 (API 장애 대응)
  • 처리 상태 실시간 표시
🖼️

표·차트 이미지 분석기

복잡한 표·차트 이미지를 자연어 텍스트 설명으로 변환합니다.

  • 지원 형식: JPEG, PNG, WebP (최대 10MB)
  • 간략/상세 모드 선택, 한국어/영어 출력
  • 이미지 유형 분류 + 주요 인사이트 3가지
  • 일회성 분석 (히스토리 저장 없음)
📋

이미지 → 엑셀 변환기

영수증·명함 이미지를 구조화된 엑셀 파일로 자동 변환합니다.

  • 최대 20장 다중 업로드 지원
  • AI 데이터 추출 (날짜·금액·상호명·연락처)
  • exceljs 기반 엑셀 파일 생성 및 다운로드
  • 처리 진행률 실시간 추적
  • 히스토리 저장·조회
🎯

JD 기반 면접 질문 생성기

채용 공고(JD)와 이력서를 입력하면 맞춤형 면접 질문 세트를 생성합니다.

  • 직무 유형 6종 (개발/디자인/기획/마케팅/영업/일반)
  • AI 출력: 5개 질문 × (역량명 + 내용 + 평가의도 + 기준)
  • 이력서 첨부 시 개인화 질문 생성
  • 엑셀 다운로드 지원
  • 히스토리 저장·조회

실행 방법

🐳 Docker (권장)

# 환경변수 설정
cp apps/api-server/.env.example \
   apps/api-server/.env
# .env 파일 편집 후:

# 전체 실행
docker-compose up --build

# 백그라운드 실행
docker-compose up -d --build

💻 로컬 개발

# 의존성 설치
pnpm install

# DB 마이그레이션
cd apps/api-server
npx prisma migrate dev

# 전체 개발 서버 실행
pnpm dev

# 개별 실행
pnpm -F @ai-worker/api-server dev     # :3002
pnpm -F @ai-worker/user-client dev   # :5175

🔑 필수 환경변수

DATABASE_URL         # PostgreSQL
GEMINI_API_KEY       # Google Gemini
GOOGLE_CLIENT_ID     # OAuth 클라이언트
GOOGLE_CLIENT_SECRET # OAuth 시크릿
GOOGLE_CALLBACK_URL  # 콜백 URL
JWT_SECRET           # JWT 서명키
CORS_ORIGIN          # 허용 프론트엔드 URL
PORT                 # API 포트 (기본: 3002)

🧪 테스트

# 전체 테스트
pnpm test

# 백엔드 커버리지
pnpm -F @ai-worker/api-server
  test:cov
