버그 메커니즘

왜 세션을 이어가면 토큰이 터지나

두 개의 독립적인 버그가 각각 다른 방식으로 캐시를 파괴합니다.

🐛
버그 #1 — db8() 필터
Claude Code는 세션 저장 시 Anthropic 내부 사용자가 아니면 attachment 타입 메시지를 전부 삭제합니다. 이 과정에서 deferred_tools_delta와 mcp_instructions_delta도 함께 사라집니다.
이 두 기록은 "모델에게 이미 안내한 도구 목록"이에요. 세션 재개 시 기록이 없으니 매번 전체 도구를 처음부터 다시 안내 → 메시지 배열 구조 변경 → 캐시 브레이크포인트 어긋남 → 전체 대화 캐시 무효화.
⚙️
버그 #2 — 커스텀 Bun 포크
~/.local/share/claude/에 설치되는 독립 실행 바이너리가 커스텀 Bun 포크를 씁니다. 이 포크는 API 요청마다 cch=00000 값을 덮어씁니다.
대화 내용에 이 문자열이 우연히 포함되면 캐시가 깨집니다. npm/Node.js로 실행하면 이 문제가 없다고 합니다. 독립 실행 바이너리 고유의 문제예요.
패치 상세

두 줄로 26% → 99%

deferred_tools_delta와 mcp_instructions_delta를 삭제 대상에서 제외하는 게 전부입니다.

db8() 함수 패치 — 변경 diff JavaScript (난독화 해제 표현)
// db8() 내부 — attachment 타입 필터링 로직 // 원본: 모든 attachment 타입 삭제 - const FILTERED_TYPES = ['attachment'] // 패치: deferred_tools_delta, mcp_instructions_delta는 유지 + const FILTERED_TYPES = ['attachment'] + const KEEP_SUBTYPES = ['deferred_tools_delta', 'mcp_instructions_delta'] + // → 이 두 서브타입은 삭제 대상에서 제외
ℹ
왜 이 두 타입이 중요한가
deferred_tools_delta는 "모델에게 이미 전달한 도구 목록" 기록입니다. 이 기록이 세션 파일에 살아있어야 재개 시 "이미 안내했다"고 인식해서 도구를 다시 전송하지 않습니다. 재전송이 없으면 메시지 배열 구조가 유지되고, 캐시 브레이크포인트가 어긋나지 않습니다.
⚠
함수명 난독화 주의 — db8은 실제 소스의 난독화된 이름입니다. 패치는 패턴 매칭으로 적용되며, 버전이 바뀌면 함수명이 달라져 패치가 실패할 수 있습니다. v2.1.81에서만 검증됐습니다.
설치 가이드

기존 설치와 완전히 분리해서 적용

기존 Claude Code를 건드리지 않고 별도 npm 버전에 패치를 적용합니다. claude-patched 래퍼로 분리 실행합니다.

1
GitHub 저장소 클론
패치 스크립트와 설치 안내가 포함돼 있습니다.
git clone https://github.com/Rangizingo/cc-cache-fix cd cc-cache-fix
2
npm 버전 별도 설치
독립 실행 바이너리(Bun 포크)가 아닌 npm/Node.js 버전을 사용합니다. 버그 #2도 함께 우회됩니다.
npm install -g @anthropic-ai/claude-code
3
패치 적용
저장소의 패치 스크립트를 실행하면 db8 함수에서 두 서브타입을 제외시킵니다.
node apply-patch.js # 저장소 내 스크립트
✓
래퍼 스크립트로 실행
claude 대신 claude-patched로 실행하면 기존 설치와 완전히 분리됩니다. Anthropic이 공식 수정을 배포하면 패치 폴더를 삭제하고 원래대로 사용하면 됩니다.
claude-patched # 패치 적용 버전 claude # 기존 설치 — 영향 없음
