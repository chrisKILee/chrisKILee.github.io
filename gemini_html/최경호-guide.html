문제 정의 · 배경

기존의 어려움

조직장이 면담 내용을 수기로 작성하고 이력 관리가 어려웠습니다. 전사 현황 파악은 개별 취합 메일을 발송한 후 수일이 소요되었으며, 액션아이템도 매번 수동으로 확인해야 했습니다. 범용 SaaS로는 계열사별 독립 평가 프로세스를 커버하기 어려운 구조적 한계도 있었습니다.

AI로 해결한 방식

면담 생성 시 AI가 R&R과 이전 미팅 내용을 분석하여 아젠다를 자동 추천합니다. 면담 녹음이 끝나면 Whisper STT → GPT-4o 화자분리 → 요약 → Action Item 추출이 자동으로 처리됩니다. 관리자 대시보드에서 전사 현황을 실시간으로 조회할 수 있습니다.

주요 기능

AI 아젠다 자동 추천

팀원의 R&R과 이전 미팅 요약을 GPT-4o가 분석하여 면담 질문 3~5개를 자동으로 추천합니다.

STT + 화자 분리

면담 녹음 파일을 Whisper로 텍스트 변환하고 GPT-4o로 리더/팀원 발언을 자동으로 구분합니다.

AI 전체 요약 + Action Item

면담 전체 내용을 요약하고 다음 미팅까지 완료할 액션아이템을 GPT-4o가 자동 추출합니다.

리더십 평가 자동화

면담 내용 기반으로 leader_hints와 leadership_score를 GPT-4o가 병렬로 자동 생성합니다.

관리자/리더 대시보드

전사 1on1 실시율, R&R 등록 현황, 부서별 면담 주기 상태를 실시간으로 조회합니다.

TMS 인사정보 연동

그룹 인사평가 시스템 TMS와 직접 연동하여 조직도·임직원 마스터 데이터를 자동으로 동기화합니다.
