⚡ 주요 기능

🤖 AI 아젠다 추천

팀원 R&R + 이전 만티 요약 기반으로 GPT-4o가 코칭 질문 3~5개 자동 생성

🎙️ 녹음 자동 분석

Whisper STT 음성 인식 → 화자 분리 → 구간전체 요약 → Action Item 자동 추출

📋 액션 아이템 이월

미완료 액션 아이템을 다음 면담 시작 시 100% 자동 이월 — 후속 관리 누락 없음

📊 리더 대시보드

팀원별 면담 현황런R&R 진행률 한눈에 파악. 상태(연체예정정상) 자동 판별

🏢 관리자 대시보드

전사 1on1 실시율부서별 현황 실시간 조회. 기존 수일 소요 → 즉시 확인

🔗 TMS 연동

VNTG 인사평가 시스템(TMS) 인터페이스 연동 — 마스터 데이터 이중관리 차단

🧠 AI 활용 방식 · 기술 스택

AI 파이프라인 흐름

🎙️ GCS 오디오 업로드
→ 🔤 Whisper STT (25MB 초과 시 ffmpeg로 10분 단위 분할)
→ 👥 GPT-4o 화자 분리 (LEADER / MEMBER 라벨링)
→ 📝 구간 요약 (타임라인 구간별 GPT-4o 요약)
→ 📋 전체 요약 + Action Item 추출
→ 🏆 leader_hints + 리더십 점수 생성
→ ✅ COMPLETED (PostgreSQL 저장)
