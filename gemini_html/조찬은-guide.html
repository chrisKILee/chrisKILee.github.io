😣 문제 정의 · 배경

❗ 기존의 어려움

  • 🔴 24시간 공장 가동 중 MES DB 데드락(ORA-00060) 발생 시 Level-2까지 연쇄 장애
  • 🔴 작업지시 불가 → 생산 중단으로 직결되는 심각한 조업 리스크
  • 🔴 사전 감지 시스템 부재 — 장애 발생 후에야 인지, 반복 장애 구조적 한계
  • 🔴 데드락 전조 패턴이 불규칙하여 규칙 기반 탐지도 한계

✨ AI로 해결한 방식

  • 🤖 Isolation Forest(비지도 학습)로 정상 패턴 대비 이상 징후 자동 탐지
  • 🧠 Gemini AI + RAG로 탐지 결과 기반 원인 분석 + 한국어 대응 가이드 자동 생성
  • 📊 위험 등급 4단계(CRITICAL/WARNING/INFO/NORMAL) 시각화 대시보드
  • 📬 위험 감지 즉시 이메일 자동 알림 — 전문 DBA 없이도 선제 대응 가능

⚡ 주요 기능

🔍 5개 지표 자동 수집

Oracle DB V$ 뷰에서 차단 세션, 트랜잭션 락, 교차 대기 등 데드락 전조 지표를 주기적으로 자동 수집

🤖 AI 이상 탐지

Isolation Forest 비지도 학습으로 정상 패턴 학습 후 이상 징후 자동 탐지 — 위험 점수 0~100 산출

🧠 Gemini AI 대응 가이드

탐지 결과를 Gemini API에 전달 — Oracle DBA 전문가 수준의 한국어 원인 분석 및 조치 가이드 자동 생성

📊 실시간 대시보드

React + Recharts 기반 웹 UI — 위험도 차트, 메트릭 분포, AI 분석 결과를 한 화면에서 실시간 확인

📬 이메일 자동 알림

위험 등급 4단계

🔴 CRITICAL (80점+) 즉시 조치 🟡 WARNING (60~79) 주의 모니터링 🔵 INFO (30~59) 참고 🟢 NORMAL (0~29) 정상

🧠 AI 활용 방식 · 기술 스택

🤖 AI 이상 탐지 — Isolation Forest

  • 🔹 비지도 학습 — 레이블 없이 정상 패턴 자동 학습
  • 🔹 오염률(contamination) 10% 기본 설정 — 이상치 민감도 조정 가능
  • 🔹 100개 트리(n_estimators) — 안정적 탐지 성능
  • 🔹 모델 `.pkl` 저장 — 주기적 재학습 지원

🧠 AI 원인 분석 — Gemini API + RAG

  • 🔹 Oracle DBA 전문가 역할 프롬프트 설계
  • 🔹 5개 메트릭 + 위험 점수 + 등급을 컨텍스트로 주입(RAG)
  • 🔹 한국어 마크다운 형식으로 분석 및 조치 가이드 생성
  • 🔹 정상 상태에는 간결한 상태 안내만 제공

기술 스택

Python scikit-learn Isolation Forest Google Gemini API Node.js/Express React + Recharts Oracle DB (oracledb) Ubuntu + Nginx + PM2
