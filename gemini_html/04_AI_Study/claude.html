Official Docs Introduction

Claude Code란 무엇인가?

Claude Code는 터미널 내에서 직접 실행되는 Anthropic의 차세대 코딩 에이전트입니다. 단순히 코드를 제안하는 것을 넘어, **도구 사용(Tool Use)**을 통해 코드를 수정하고, 테스트를 실행하며, 복잡한 소프트웨어 엔지니어링 작업을 자율적으로 완료합니다.

기존 AI 보조 도구와의 차이점

⚡

에이전트적 특성

IDE의 단순 확장이 아닌, 독립적인 프로세스로서 파일 시스템과 터미널을 직접 제어합니다.

🧠

심층적 맥락 이해

전체 코드베이스를 인덱싱하고 구조를 파악하여 파일 간의 복잡한 의존성을 이해합니다.

주요 역량 (Capabilities)

  • ✓ [Write] 파일 생성 및 코드 편집
  • ✓ [Read] 코드베이스 탐색 및 심층 분석
  • ✓ [Execute] 터미널 명령어 및 테스트 실행
  • ✓ [Analyze] Git 히스토리 분석 및 리뷰
  • ✓ [Search] 구글 검색 및 라이브러리 문서 조회
01. Getting Started

환경 구성 및 설치

Claude Code는 엔지니어링 워크플로우에 최적화된 CLI 도구입니다. 아래의 절차에 따라 설치를 진행하세요.

1. 시스템 요구사항

  • • Node.js v18.0.0+
  • • npm or yarn
  • • macOS, Linux, WSL2
  • • 유효한 API 크레딧

2. 설치 명령어

npm install -g @anthropic-ai/claude-code

성공 시 'claude' 명령어를 전역에서 사용할 수 있습니다.

3. 인증 (Auth)

claude auth login

브라우저를 통해 Anthropic 계정에 로그인합니다.

고급 설정 (Advanced Config)

환경 변수를 통해 Claude Code의 행동을 제어할 수 있습니다.

CLAUDE_CODE_THEME

인터페이스 테마 설정 (light, dark, auto)

HTTP_PROXY / HTTPS_PROXY

기업 내 방화벽 환경에서 프록시 서버 설정

02. Core Technology

에이전트 작동 루프

Claude Code는 문제를 해결하기 위해 지속적인 **사고-행동-관찰** 사이클을 수행합니다.

1

Think (사고)

사용자의 요청을 분석하고 문제 해결을 위한 단계별 계획을 수립합니다. (Chain of Thought)

2

Act (행동)

Bash 명령어 실행, 파일 편집, 웹 검색 등 구체적인 도구를 사용하여 작업을 수행합니다.

3

Observe (관찰)

도구 실행의 결과를 확인하고, 계획대로 진행되었는지 평가하여 다음 단계를 결정합니다.

"에이전트 루프는 최종 목표가 달성되거나 사용자의 개입이 필요할 때까지 반복됩니다."

04. Extensions

Model Context Protocol

Claude Code는 MCP를 통해 외부 데이터 소스 및 도구와 유기적으로 연결됩니다.

MCP의 역할

LLM이 자체적으로 수행할 수 없는 작업들(예: 데이터베이스 직접 쿼리, Slack 메시지 전송, 원격 서버 상태 확인 등)을 MCP 서버를 통해 수행할 수 있게 해주는 가교 역할을 합니다.

사용 가능한 서버 예시:
  • • GitHub, Slack, Linear
  • • Postgres, MySQL, Redis
  • • Google Drive, Notion

서버 추가 명령어

터미널에서 직접 MCP 서버를 명시하여 실행할 수 있습니다.

claude --mcp-server "npx @modelcontextprotocol/server-github"
"GitHub 서버를 연결하면 Claude가 저장소의 이슈를 읽고 답변할 수 있게 됩니다."
05. Security Policy

보안 및 프라이버시 가이드라인

엔터프라이즈 환경에서의 안전한 사용을 위한 기술적 보안 아키텍처입니다.

🛡️ Human-in-the-loop

Claude Code는 모든 명령어를 실행하기 전 사용자에게 가독성 있는 설명을 제공하고 명시적인 승인을 요청합니다. 특히 파일 삭제(`rm`), 네트워크 요청(`curl`), 패키지 설치(`npm install`) 등 위험도가 높은 작업은 별도의 경고창이 표시됩니다.

📁 데이터 격리 및 수집

사용자의 소스 코드는 Anthropic의 모델 학습에 사용되지 않습니다. 모든 연산은 로컬 터미널에서 제어되며, 모델로 전송되는 데이터는 대화 맥락 유지와 도구 호출 결과로 제한됩니다.

주의 사항 (Critical Warnings)

  • • API Key나 비밀번호가 포함된 파일을 Claude가 읽지 않도록 `.gitignore`에 추가하는 것이 권장됩니다.
  • • 에이전트가 실행하는 자동화 스크립트가 로컬 환경을 손상시키지 않도록 실행 전 코드를 검토하십시오.
