규격 참조 및 SDD 개발 전략

단순 코딩이 아닌 '설계'를 시키세요

GitHub Spec Kit이나 회사 내부 규격(Convention)이 있다면, 이를 Cursor가 강제로 따르게 만들 수 있습니다.
설계 문서(SDD) 없이 코딩을 시키면 나중에 스파게티 코드가 됩니다.

1 규격 강제화 (.cursorrules)

GitHub Spec Kit 등의 표준을 텍스트 파일로 저장하고, .cursorrules에서 이를 참조하게 합니다.

# .cursorrules 파일 내용
@context: ./docs/SPEC_KIT.md
@context: ./docs/SDD.md
"모든 코드는 SPEC_KIT.md의 규칙을 준수해야 한다.
구현 전 SDD.md의 설계를 먼저 확인하라."

2 SDD 기반 개발 흐름

  1. Step 1. SDD 작성 요청: "이 기능을 위한 SDD(설계문서)를 먼저 작성해줘. GitHub Spec Kit 포맷을 따라."
  2. Step 2. 설계 리뷰: 생성된 SDD.md를 읽고 수정합니다. (DB 스키마, API 명세 등)
  3. Step 3. 구현 명령: "이제 @SDD.md대로 코드를 구현해."
이 순서대로 하면 에러가 80% 줄어듭니다.

API Key 연결 (GUI 설정)

내 Gemini/Claude 키 사용하기

Cursor Pro 구독 없이, 개인 API Key를 연결하려면 터미널이 아니라 설정 화면에서 해야 합니다.

  1. 우측 상단 톱니바퀴 ⚙️ 클릭
  2. Models 탭 선택
  3. API Key 입력 (OpenAI / Anthropic / Google)
  4. 목록에 없는 모델은 Add model로 추가
    (예: gemini-1.5-pro, claude-3-opus)
// Cursor Settings > Models
Verified
claude-3.5-sonnet gemini-1.5-pro
4

Google 공식 Gemini CLI

공식 도구의 장점

Google이 직접 만든 도구입니다. 복잡한 API 키 설정 없이 Google 로그인만 하면 Gemini 3 Flash / 2.5 Pro 모델을 무료 티어로 바로 쓸 수 있습니다.

설치 방법

$ npm install -g @google/gemini-cli

$ gemini

# 실행 후 브라우저 로그인 진행

주요 활용법

gemini "안녕, 서울 날씨 어때?"
# 파이프라인 (파일 읽기)
cat file.py | gemini "코드 리뷰해줘"

범용 AI CLI (llm, fabric)

왜 또 다른 CLI가 필요한가요?

Google CLI는 Gemini만 쓸 수 있습니다. 하지만 'llm' 도구는 GPT-4o, Claude 3.5, Local LLM을 모두 연결해서 마음대로 골라 쓸 수 있는 "만능 맥가이버 칼"입니다.

🛠️ 'llm' 설치 및 플러그인 (by Simon Willison)

# 1. 기본 도구 설치 (Python pip 필요)
pip install llm
# 2. 모델 플러그인 설치 (Claude, Gemini 등)
llm install llm-claude-3
llm install llm-gemini
# 3. API 키 설정 (한 번만 하면 됨)
llm keys set claude

🔥 실전 파이프라인 명령어 (복붙용)

A. 모델 골라 쓰기 (-m)
llm -m claude-3-opus "이 이론 반박해봐"
B. 파일 요약 (파이프라인)
cat log.txt | llm "에러 원인 3줄 요약"
