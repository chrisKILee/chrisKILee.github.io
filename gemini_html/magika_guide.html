01 개요

왜 Magika가 필요한가?

기존 파일 감지 방식은 수작업 규칙(매직 바이트)에 의존해 텍스트·코드 파일 구분에 취약했습니다. Magika는 딥러닝으로 이 문제를 해결합니다.

🔍
파일 내용 기반 분석

이름이나 확장자가 아닌 파일 바이트 내용을 직접 읽어 판별합니다. "귀여운사진.jpg"로 위장한 악성 파일도 잡아냅니다.

content-based
⚡
밀리초 단위 추론

모델 로드 후 파일당 약 5ms. 파일 크기와 무관하게 앞·중간·끝 1,536바이트만 분석하기 때문입니다.

~5ms / file
🌐
Google 실전 투입

Gmail·Google Drive·Safe Browsing에서 주당 수천억 개 파일을 처리하는 데 이미 사용 중입니다.

production-grade
보안 활용 포인트
바이러스나 악성코드는 종종 확장자를 .jpg, .pdf 등으로 위장합니다. Magika는 확장자 대신 파일 내부를 분석하므로 이런 위장 공격을 탐지할 수 있어 보안 스캐너 라우팅(어떤 스캐너로 보낼지 결정)에 특히 유용합니다.

03 작동 원리

AI가 파일을 어떻게 읽는가

파일 전체를 다 읽지 않습니다. 앞·중간·끝 각 512바이트씩 총 1,536바이트만 추출해서 딥러닝 모델에 넣습니다. 파일 크기에 상관없이 처리 시간이 일정한 이유입니다.

Magika 추론 파이프라인 — 파일 크기와 무관하게 고정된 1,536바이트만 분석

구성 요소내용
입력앞 512B + 중간 512B + 끝 512B = 총 1,536바이트. 짧은 파일은 바이트값 256으로 패딩
임베딩Dense Embedding Layer → 128차원 벡터로 변환
특징 추출Dense Layer (256차원, GELU 활성화) × 2 + Global Max Pooling
정규화Layer Normalization + Dropout 10% + Spatial Dropout 10%
학습 프레임워크Keras (학습) → ONNX Runtime (추론)
모델 크기약 1MB (GPU 불필요, CPU만으로 추론 가능)
학습 데이터약 1억 개 파일 (GitHub + VirusTotal)
04 활용 사례

Google이 이미 쓰고 있는 방식

"Magika는 주당 수천억 개의 파일을 처리하면서 Google 사용자 안전을 돕는 데 사용됩니다." — Google OSS Blog (2024-02-16)

📧
Gmail — 첨부파일 스캐너 라우팅
업로드된 첨부파일이 어떤 종류인지 판별 후, 알맞은 보안·콘텐츠 정책 스캐너로 자동 분류합니다. 특수 악성 문서 스캐너 연결 파일이 11% 증가했습니다.
💾
Google Drive — 업로드 파일 분류
드라이브에 올라오는 파일의 타입을 판별하고 적절한 보안 검사 파이프라인으로 연결합니다. 미분류 파일 비율이 3%로 감소했습니다.
🛡️
Safe Browsing — 악성 파일 사전 탐지
브라우저 다운로드 파일을 사전 분류해 악성코드 스캐너 효율을 높입니다. 기존 대비 정확도가 50% 향상됐습니다.
🔬
VirusTotal — 악성코드 분석 전처리
Code Insight(생성 AI 기반 악성코드 분석 기능)의 입력 전처리 필터로 사용됩니다. 파일 타입에 따라 적합한 분석 모델을 선택합니다.
05 사용 방법

설치 및 기본 사용법

Python, CLI, JavaScript 등 다양한 환경을 지원합니다. pip 설치 후 바로 사용 가능합니다.

1
설치
pip 또는 원하는 패키지 매니저로 설치합니다.
bash 
# Python (pip)
pip install magika

# CLI 전용 설치 (pipx 권장)
pipx install magika

# macOS / Linux (Homebrew)
brew install magika

# Node.js / JavaScript
npm install magika
2
Python API 기본 사용
bytes, 파일 경로, 파일 스트림 세 가지 방식으로 분석할 수 있습니다.
python 
from magika import Magika

m = Magika()

# 방법 1: 바이트 직접 전달
res = m.identify_bytes(b'function log(msg) {console.log(msg);}')
print(res.output.label)       # javascript
print(res.output.mime_type)   # application/javascript
print(res.score)              # 0.99 (신뢰도 점수, 0.0 ~ 1.0)

# 방법 2: 파일 경로로 분석
res = m.identify_path('./document.pdf')
print(res.output.label)       # pdf
print(res.output.description) # PDF document

# 방법 3: 파일 스트림으로 분석
with open('./archive.zip', 'rb') as f:
    res = m.identify_stream(f)
    print(res.output.label)   # zip
3
CLI 사용
터미널에서 바로 파일 타입을 확인할 수 있습니다.
bash 
# 단일 파일 확인
magika ./suspicious_file.exe

# 디렉토리 내 모든 파일 재귀 스캔
magika -r ./target_dir/

# JSON 형식으로 출력 (신뢰도 포함)
magika ./file.py --json

# MIME 타입만 출력
magika ./file.py --mime-type

# 표준 입력(stdin)으로 전달
cat file.ini | magika -
4
신뢰도 모드 선택 (PredictionMode)
용도에 따라 신뢰도 기준을 조정할 수 있습니다.
python 
from magika import Magika, PredictionMode

# high-confidence: 확신이 높을 때만 구체적 타입 반환 (보안 용도 권장)
m = Magika(prediction_mode=PredictionMode.HIGH_CONFIDENCE)

# medium-confidence: 기본값 — 균형 잡힌 정확도
m = Magika(prediction_mode=PredictionMode.MEDIUM_CONFIDENCE)

# best-guess: 항상 가장 가능성 높은 타입 반환 (파일 정리 용도에 적합)
m = Magika(prediction_mode=PredictionMode.BEST_GUESS)
활용 아이디어
PredictionMode.BEST_GUESS + 재귀 스캔으로 폴더 내 파일을 자동 분류하는 "파일 정리 도우미"를 만들 수 있습니다. 확장자가 틀렸거나 없는 파일도 올바른 타입으로 분류·이동할 수 있습니다.

07 주의사항

알려진 한계

공식 논문(arXiv:2409.13768) 및 GitHub에서 명시한 제한 사항입니다.

커버리지
216개 타입만 지원. 새 파일 타입을 추가하려면 모델 재학습이 필요합니다.
폴리글랏
여러 포맷에 동시에 유효한 파일(예: ZIP 겸 JAR)을 완벽히 구분하기 어렵습니다.
적대적 공격
파일 내용에 소량의 조작을 가하면 잘못된 타입으로 오인될 수 있습니다. 모든 AI 모델의 공통 한계입니다.
초기화 오버헤드
첫 파일 처리 시 모델 로드에 <100ms 소요됩니다. 단일 파일 CLI 사용 시 체감될 수 있습니다.
샘플링 방식
앞·중간·끝 1,536바이트만 분석하므로, 핵심 시그니처가 파일 중간부에만 있는 포맷에서 불리할 수 있습니다.
보안 사용 시 주의
Magika는 파일 타입 분류를 돕는 도구이며, 단독으로 완전한 악성코드 탐지 솔루션이 되지는 않습니다. 실제 보안 파이프라인에서는 Magika로 타입을 분류한 뒤, 해당 타입에 특화된 안티바이러스/샌드박스 분석기와 함께 사용하는 것을 권장합니다.
