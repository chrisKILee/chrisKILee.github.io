배경

왜 DESIGN.md / SKILL.md가 필요한가?

코딩 에이전트는 기능은 만들어도 디자인 감각이 없어 "슬롭(slop)" 같은 평범한 UI를 생성합니다. 텍스트 파일 하나로 AI의 UI 판단 기준을 교체할 수 있습니다.

😑

슬롭(Slop) 문제

AI가 만드는 기본 UI — 파란 헤더, 흰 배경, Bootstrap 느낌. 기능은 되지만 인상이 남지 않는 디자인.

📄

DESIGN.md 개념

프로젝트 루트에 넣는 텍스트 파일. 색상, 폰트, 여백, 컴포넌트 패턴을 명시해 AI가 일관된 디자인을 유지하도록 가이드.

🔧

SKILL.md 개념

Claude Code 등 AI 에이전트에 주입하는 역할 지시 파일. "항상 Pretendard 폰트 사용", "보라→핑크 그라디언트 금지" 같은 규칙을 강제.

🚀

효과

파일 하나 추가로 AI 출력 퀄리티가 "기능 동작" 수준에서 "디자이너가 만든 것 같은" 수준으로 올라갑니다.

Taste-Skill
⭐ 5.5k

AI가 만드는 평범한 UI를 막아주는 디자인 감각 주입 스킬의 원조. 3가지 설정값으로 출력 스타일을 미세 조정할 수 있는 것이 특징입니다. 총 7종 스킬을 제공합니다.

✓ AI 디자인 감각 주입 스킬의 원조 (⭐ 5.5k)
✓ DESIGN_VARIANCE·MOTION_INTENSITY·VISUAL_DENSITY 3가지 설정값으로 미세 조정
✓ 다양한 스타일 변형 스킬 7종 포함
포함 스킬
taste redesign soft output minimalist brutalist +1

MOTION_INTENSITY 모션 강도 (0~1)

Taste-Skill (Leonxlnx)
Adaptive Config Template
3가지 설정 변수(다양성·모션·밀도)로 AI 출력 스타일을 미세 조정. 안티-슬롭 규칙과 함께 디자인 감각을 주입.
# DESIGN.md — Taste Adaptive Design

## Config Knobs
DESIGN_VARIANCE:   0.7  # 0=safe/consistent  1=bold/experimental
MOTION_INTENSITY:  0.5  # 0=no motion        1=rich animations
VISUAL_DENSITY:    0.6  # 0=spacious         1=information-dense

## Color Philosophy
base:       #0A0A0F    /* near black */
primary:    #7C3AED    /* deep violet */
highlight:  #FF4D6D    /* hot coral */
glass:      rgba(255,255,255,0.04)
glow:       rgba(124,58,237,0.15)

## Typography
heading: Clash Display 700 or Inter 800
body:    Inter 400, 16px, 1.75 line-height
mono:    Fira Code 400

## Motion (scales with MOTION_INTENSITY)
base-transition: 200ms cubic-bezier(0.4, 0, 0.2, 1)
hover-lift:      translateY(-4px)
reveal:          opacity 0→1, translateY 20px→0, 400ms
stagger-delay:   80ms per item

## Visual Density (scales with VISUAL_DENSITY)
low:   section-padding 120px,  card-padding 48px
mid:   section-padding 80px,   card-padding 32px
high:  section-padding 48px,   card-padding 20px

## Anti-Slop Rules
✗ No flat Bootstrap blue (#007bff)
✗ No plain white card backgrounds
✗ No default box-shadows — use glow/border instead
✓ Always: micro-interactions on every clickable element
✓ Always: gradient or texture on hero section
✓ Always: at least one "wow" element per screen
