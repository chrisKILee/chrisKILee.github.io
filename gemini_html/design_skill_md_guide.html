배경

왜 DESIGN.md / SKILL.md가 필요한가?

코딩 에이전트는 기능은 만들어도 디자인 감각이 없어 "슬롭(slop)" 같은 평범한 UI를 생성합니다. 텍스트 파일 하나로 AI의 UI 판단 기준을 교체할 수 있습니다.

😑

슬롭(Slop) 문제

AI가 만드는 기본 UI — 파란 헤더, 흰 배경, Bootstrap 느낌. 기능은 되지만 인상이 남지 않는 디자인.

📄

DESIGN.md 개념

프로젝트 루트에 넣는 텍스트 파일. 색상, 폰트, 여백, 컴포넌트 패턴을 명시해 AI가 일관된 디자인을 유지하도록 가이드.

🔧

SKILL.md 개념

Claude Code 등 AI 에이전트에 주입하는 역할 지시 파일. "항상 Pretendard 폰트 사용", "보라→핑크 그라디언트 금지" 같은 규칙을 강제.

🚀

효과

파일 하나 추가로 AI 출력 퀄리티가 "기능 동작" 수준에서 "디자이너가 만든 것 같은" 수준으로 올라갑니다.

4가지 핵심 DESIGN.md · SKILL.md 팩

각 팩은 목적과 철학이 다릅니다. 프로젝트 성격에 맞게 선택하거나 조합해서 사용하세요.

Taste-Skill
⭐ 5.5k

AI가 만드는 평범한 UI를 막아주는 디자인 감각 주입 스킬의 원조. 3가지 설정값으로 출력 스타일을 미세 조정할 수 있는 것이 특징입니다. 총 7종 스킬을 제공합니다.

✓ AI 디자인 감각 주입 스킬의 원조 (⭐ 5.5k)
✓ DESIGN_VARIANCE·MOTION_INTENSITY·VISUAL_DENSITY 3가지 설정값으로 미세 조정
✓ 다양한 스타일 변형 스킬 7종 포함
포함 스킬
taste redesign soft output minimalist brutalist +1
3가지 설정 변수
DESIGN_VARIANCE 디자인 다양성 (0~1)
MOTION_INTENSITY 모션 강도 (0~1)
VISUAL_DENSITY 정보 밀도 (0~1)
github.com/Leonxlnx/taste-skill 설정값 3종

Supanova-Design-Skill

✓ taste-skill을 한국 랜딩페이지 용으로 완전 재구성
✓ Pretendard 폰트 · 한국어 CTA 패턴 기본 내장
✓ React 의존성 없음 — 단일 HTML 파일로 바로 출력
✓ SKILL.md 복사 후 참조 지시만 하면 즉시 적용
한국어 특화 포인트
Pretendard 폰트 · 모바일 퍼스트 · 한국형 CTA ("지금 시작하기", "무료 체험") 패턴 내장. 별도 설정 없이 한국어 랜딩페이지에 최적화.
