Claude Code MCP 가이드

Model Context Protocol

AI와 도구를 잇는 공통 언어

MCP는 AI 모델이 외부 도구 및 데이터 소스에 연결될 수 있도록 하는 오픈 소스 표준입니다. Claude Code는 MCP 서버를 통해 사용자의 데이터베이스, 이슈 트래커, API에 직접 접근하여 복잡한 작업을 대신 수행합니다.

🛠️

자동 기능 구현

JIRA 이슈를 읽고 코드를 수정한 뒤 GitHub에 직접 PR을 생성할 수 있습니다.

🔍

실시간 모니터링

Sentry나 Statsig를 확인하여 배포된 기능의 오류와 사용량을 분석합니다.

💾

데이터베이스 쿼리

PostgreSQL 등의 DB에서 특정 데이터를 조회하여 통계를 내거나 분석합니다.

🎨

디자인 및 협업

Slack에 공유된 Figma 디자인을 기반으로 이메일 템플릿 코드를 업데이트합니다.

📧

워크플로우 자동화

피드백이 필요한 사용자 10명을 선정하여 Gmail 초안을 자동으로 작성합니다.

➕

무한한 확장

공식 서버 외에도 GitHub의 수많은 커뮤니티 서버를 사용하거나 직접 만들 수 있습니다.

1 전송 방식 (Transport)

HTTP (추천)

Remote

클라우드 기반 서비스 연결에 가장 적합한 표준 방식입니다. 원격 서버와 안전하게 통신합니다.

SSE (중단 예정)

Event

Server-Sent Events 방식입니다. 가능하면 HTTP 서버를 사용하세요.

Stdio (로컬 프로세스)

Local

로컬 머신에서 프로세스로 실행되는 서버입니다. 시스템 자원에 직접 접근이 필요할 때 사용합니다.

2 설정 범위 (Scope)

Local Scope (개인/프로젝트)

현재 프로젝트에서 나만 사용하는 비공개 설정입니다.

~/.claude.json

Project Scope (팀 공유)

Git 저장소에 포함되어 팀원 전체가 공유하는 설정입니다.

your-project/.mcp.json

User Scope (전역)

내 컴퓨터의 모든 프로젝트에서 공통으로 적용됩니다.

~/.claude.json

관리 및 보안 최적화

더 효율적이고 안전하게 MCP를 운영하는 방법입니다.

⚡

지능형 도구 검색 (Tool Search)

서버가 많아지면 모든 도구 정의를 로드하는 데 많은 토큰이 소모됩니다. Claude Code는 도구 정의가 컨텍스트의 10%를 초과할 경우 자동으로 'Tool Search' 모드로 전환됩니다. 필요한 도구만 동적으로 찾아 로드하여 비용을 아낍니다.

Tip: 수동 조절

ENABLE_TOOL_SEARCH=auto:5 claude
🛡️

엔터프라이즈 관리 정책

  • •

    managed-mcp.json: 사용자가 수정할 수 없는 고정된 서버 세트를 배포합니다.

  • •

    Allowlist/Denylist: 특정 이름, 명령어, URL 패턴별로 서버 접근을 제어합니다.

  • •

    OAuth 2.0: 보안이 필요한 원격 서버에 안전한 대화형 로그인을 지원합니다.
