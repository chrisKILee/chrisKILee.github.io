Etymology

두 단어의 의미

Souche
수슈 · 프랑스어
포도나무 뿌리줄기 · 대목(臺木)
땅에 심겨 Terroir와 연결되는 뿌리 구조체. 접붙임의 기반이 되는 부분. 눈에 보이지 않지만, 이것이 없으면 아무것도 자랄 수 없다.

→ 기존 솔루션을 분석하고, Terroir 위에서 개발할 수 있는 기반을 만드는 일. 보이지 않지만 모든 것의 출발점.
Cépage
세파주 · 프랑스어
포도나무 품종
카베르네 소비뇽, 메를로, 샤르도네처럼 — 각자의 특성과 정체성을 가진 품종. 같은 Terroir 위에서 자라지만, 저마다 다른 맛과 개성을 낸다.

→ Terroir 플랫폼 위에서 각자의 역할을 가진 애플리케이션들. VNTG ERP가 그 첫 번째 품종.
Naming Story

왜 CEPAGE인가

층위 와인 생태계 우리 프로젝트
TERROIR 땅의 고유한 특성 · 기후 · 미네랄 차세대 개발 플랫폼 Terroir — VNTG R&D실이 구축한 새 아키텍처
SOUCHE 뿌리줄기 · 땅 속 연결 구조체 분석 · 기반 구축 — 기존 솔루션을 분석하고, Terroir 위에서 개발 가능한 표준과 기반을 구축하는 보이지 않는 작업
CÉPAGE ★ 포도나무 품종
카베르네 소비뇽, 메를로처럼		 Terroir 위에서 자라는 애플리케이션들 — 각자의 역할과 정체성을 가진 채, 같은 플랫폼 위에서 공존하는 시스템들
VINTAGE 그해의 최고 산출물 미래의 목표 — CEPAGE가 완성된 이후의 이야기

프로젝트명을 CÉPAGE로 정한 이유 — 우리의 목표는 뿌리를 내리는 것(SOUCHE) 자체가 아니라, Terroir 위에서 제대로 된 품종들이 자라는 것(CÉPAGE)이기 때문이다.

Mission

우리의 미션

"Terroir 위에 첫 번째 품종을 접붙인다."
기존 솔루션을 분석하고, 개발 기반을 구축하고,
VNTG ERP로 그 가능성을 증명한다.

① Analyse — 땅을 읽다
기존 솔루션 분석 Terroir 관점에서 해부
기존 솔루션들을 Terroir 아키텍처 관점에서 분석하여 구조를 이해하고, 무엇이 기반이 되어야 하는지 정의한다.
  • 솔루션별 도메인 · 데이터 구조 분석
  • Terroir 아키텍처 적합성 평가
  • 표준화 대상 및 공통 요소 도출
② Foundation — 뿌리를 내리다
개발 기반 구축 다음 프로젝트를 위한 토대
새로운 프로젝트가 Terroir 위에서 시작될 수 있도록 — 데이터 표준, 개발 표준, 공통 모듈을 구축한다.
  • 데이터 표준화 · 카탈로그화
    LLM/Rule-based 메타데이터 자동 추출 · 엔티티 릴레이션십 구축 · 데이터 리니지 추적
  • 시스템 간 시맨틱 통합
    데이터 연계율 고도화 · 시스템 간 공통 언어 정의
  • 솔루션 개발 표준화 · 가이드라인
  • 공통 모듈 개발
③ Proof of Value — 열매를 맺다
VNTG ERP 구현 실제 운영으로 가능성 증명
VNTG ERP를 Terroir 위에 실제로 운영 가능한 형태로 구현하여, CÉPAGE 방식이 작동한다는 것을 증명한다.
  • Terroir 기반 ERP 컨버전 · 개발
  • 실운영 검증 및 피드백
  • 이후 신규 프로젝트의 레퍼런스
