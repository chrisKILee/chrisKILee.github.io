02 — Features

해커 툴킷 내장

실제 침투 테스터(펜테스터)가 사용하는 도구들을 기본 탑재합니다.

🌐
Full HTTP Proxy
모든 HTTP 요청·응답을 가로채고 조작합니다. 헤더 변조, 파라미터 변경, 토큰 탈취 등 실제 중간자 공격(MITM) 시뮬레이션이 가능합니다.
🖥️
브라우저 자동화
멀티 탭 브라우저를 자동으로 제어합니다. XSS, CSRF, 인증 플로우 등 브라우저 환경에서만 재현 가능한 취약점을 테스트합니다.
💻
터미널 환경
에이전트가 직접 인터랙티브 쉘을 실행하여 명령어를 수행합니다. 로컬 코드베이스를 실제로 실행해 동적 취약점을 탐지합니다.
🐍
Python 런타임
커스텀 익스플로잇 코드를 즉석에서 작성하고 실행합니다. PoC(개념 증명) 스크립트를 자동 생성하여 취약점이 실제로 작동함을 검증합니다.
🔭
OSINT 정찰
자동화된 오픈소스 인텔리전스(OSINT) 수집으로 공격 표면을 매핑합니다. 숨겨진 엔드포인트, 외부 서비스 연동, 노출된 자격증명을 탐색합니다.
📖
코드 정적·동적 분석
소스 코드 수준의 정적 분석(코드 리뷰)과 런타임 동적 분석을 결합합니다. 화이트박스·블랙박스·그레이박스 방식 모두 지원합니다.
✦ 정적 분석 도구와의 차이점 — Semgrep, Snyk, Bandit 같은 정적 분석 도구는 코드 패턴만 보고 "취약할 수 있다"고 경고합니다. Strix는 실제로 공격을 시도해 "실제로 뚫린다"는 것을 PoC로 증명해야만 취약점으로 보고합니다. 오탐(False Positive)이 없는 것이 핵심 차별점입니다.
03 — Vulnerability Coverage

탐지 가능한 취약점

OWASP Top 10을 포함한 광범위한 취약점 카테고리를 실제 PoC로 검증합니다.

카테고리 취약점 유형 예시 OWASP
접근 제어 IDOR, 권한 상승, 인증 우회 다른 사용자 데이터 접근, 관리자 기능 무단 사용 A01
인젝션 공격 SQL, NoSQL, 명령어 인젝션 DB 데이터 탈취, 서버 명령어 실행 A03
서버 사이드 SSRF, XXE, 역직렬화 취약점 내부 서비스 접근, 외부 요청 위조 A10
클라이언트 사이드 XSS, 프로토타입 오염, DOM 취약점 쿠키 탈취, 악성 스크립트 삽입 A03
비즈니스 로직 레이스 컨디션, 워크플로우 조작 중복 결제, 쿠폰 무한 사용 A04
인증 문제 JWT 취약점, 세션 관리 오류 토큰 위조, 세션 하이재킹 A07
인프라 미설정 노출된 서비스, 잘못된 권한 설정 공개 S3 버킷, 디버그 엔드포인트 노출 A05
⚠️ 윤리적 사용 원칙 — Strix는 자신이 소유하거나 명시적 허가를 받은 시스템에만 사용해야 합니다. 무단으로 타인의 시스템에 사용하는 것은 불법입니다. 사용자가 법적·윤리적 책임을 집니다.
04 — Installation & Usage

설치 및 사용법

Docker가 실행 중이어야 합니다. LLM API 키 1개만 있으면 시작할 수 있습니다.

01
Strix 설치
curl 한 줄로 설치됩니다. Docker가 실행 중이어야 합니다.
bash
curl -sSL https://strix.ai/install | bash
02
LLM 프로바이더 설정
OpenAI, Anthropic, Google 등 지원 LLM 중 하나의 API 키를 환경 변수로 설정합니다.
bash
# OpenAI 사용 시 export STRIX_LLM="openai/gpt-5.4" export LLM_API_KEY="sk-..." # Anthropic 사용 시 export STRIX_LLM="anthropic/claude-sonnet-4-6" export LLM_API_KEY="sk-ant-..." # 설정은 ~/.strix/cli-config.json에 자동 저장됩니다
✦ OSINT 검색 기능을 사용하려면 PERPLEXITY_API_KEY도 추가로 설정하세요.
03
보안 스캔 실행
로컬 코드베이스, GitHub 저장소, 배포된 웹앱 URL 등 다양한 타깃을 지원합니다.
bash
# 로컬 코드베이스 스캔 (화이트박스) strix --target ./app-directory # 특정 디렉토리 + 상세 스캔 모드 strix --target ./app-directory --scan-mode standard
bash
# GitHub 저장소 보안 리뷰 strix --target https://github.com/org/repo # 비공개 저장소 (SSH 인증 필요) strix --target git@github.com:org/private-repo.git
bash
# 배포된 웹앱 블랙박스 테스트 strix --target https://your-app.com # 인증이 필요한 앱 (그레이박스) strix --target https://your-app.com \ --instruction "user:pass 계정으로 인증 후 테스트"
bash
# 멀티 타깃 동시 테스트 strix -t https://github.com/org/app -t https://your-app.com # 특정 취약점에 집중 strix --target api.your-app.com \ --instruction "IDOR와 비즈니스 로직 취약점에 집중하여 테스트" # 범위 제한 파일 사용 strix --target api.your-app.com --instruction-file ./scope.md # 헤드리스 모드 (서버/자동화 환경) strix -n --target https://your-app.com
04
결과 확인
스캔 결과는 strix_runs/<run-name>/ 디렉토리에 저장됩니다. PoC 코드, 재현 단계, 수정 권고가 포함됩니다.
✦ 헤드리스 모드(-n)에서 취약점이 발견되면 비정상 종료 코드(non-zero exit code)로 종료되어 CI/CD 파이프라인을 자동으로 차단합니다.
05 — CI/CD Integration

GitHub Actions 통합

PR마다 자동 보안 스캔을 실행하여 취약한 코드가 프로덕션에 배포되기 전에 차단합니다.

yaml · .github/workflows/strix.yml
name: strix-penetration-test on: pull_request: # PR 생성/업데이트 시 자동 실행 jobs: security-scan: runs-on: ubuntu-latest steps: - uses: actions/checkout@v6 with: fetch-depth: 0 # 전체 히스토리 필요 (diff 스코프용) - name: Install Strix run: curl -sSL https://strix.ai/install | bash - name: Run Strix Security Scan env: STRIX_LLM: ${{ secrets.STRIX_LLM }} # 예: openai/gpt-5.4 LLM_API_KEY: ${{ secrets.LLM_API_KEY }} # LLM API 키 run: | strix -n -t ./ --scan-mode quick # -n: 헤드리스 모드, --scan-mode quick: PR 변경 파일만 스캔 # 취약점 발견 시 비정상 종료 → PR 머지 자동 차단
✦ PR 스코프 자동 적용 — CI 환경에서 --scan-mode quick 실행 시, Strix가 자동으로 변경된 파일만 스캔합니다. diff 스코프를 명시하려면 --scope-mode diff --diff-base origin/main을 추가하세요.

스캔 모드 비교

스캔 모드범위추론 노력권장 사용처
quick 변경 파일만 (PR diff) medium CI/CD PR 검사
standard 전체 코드베이스 high 일반 보안 감사
deep 전체 + 외부 의존성 high 정기 침투 테스트

07 — Cloud Platform

app.strix.ai 클라우드

CLI 오픈소스 버전에 더해 클라우드 플랫폼에서 추가 기능을 제공합니다.

🔧
원클릭 자동 수정
발견된 취약점을 AI가 자동으로 수정한 코드를 PR(풀 리퀘스트) 형태로 즉시 제출합니다. 개발자는 PR만 리뷰하고 머지하면 됩니다.
📡
지속적 모니터링
코드, 클라우드 인프라, 외부 서비스를 24/7 지속 모니터링합니다. 새로운 취약점 패턴이 발견되면 자동으로 재스캔을 트리거합니다.
🔗
외부 서비스 연동
GitHub, Slack, Jira, Linear와 연동하여 취약점 발견 즉시 팀에 알림을 보내고 이슈를 자동으로 생성합니다.
🧠
지속적 학습
과거 발견 취약점과 수정 이력을 학습하여 반복 취약점 패턴을 조기에 탐지합니다. 프로젝트별 맞춤 보안 프로파일을 구축합니다.

08 — Use Cases

주요 활용 시나리오

개발 팀, 보안 팀, 버그 바운티 연구자 모두에게 유용합니다.

🛡️
애플리케이션 보안 테스트
프로덕션 배포 전 코드베이스 전체를 스캔하여 치명적 취약점을 사전에 발견합니다. 기존 수동 침투 테스트 대비 시간과 비용을 절감합니다.
⚡
신속 침투 테스트
수주 걸리던 수동 침투 테스트를 몇 시간 내로 완료합니다. 규정 준수(Compliance) 보고서를 자동 생성하여 감사 대응도 지원합니다.
🏆
버그 바운티 자동화
버그 바운티 프로그램에서 PoC 생성 및 보고서 작성을 자동화합니다. 취약점 발견부터 리포트까지 전 과정을 지원합니다.
🔄
CI/CD 보안 게이트
모든 PR에 자동 보안 스캔을 추가하여 취약한 코드가 메인 브랜치에 머지되기 전에 차단합니다. DevSecOps 파이프라인 구현의 핵심 도구입니다.
