필수 슬래시 명령어 (ykdojo #1 · Ado #4, #16, #17)

명령어 설명 사용 시점 티어

!명령어 셸 명령 즉시 실행, 결과를 컨텍스트에 주입 !git status, !npm test, !docker ps 필수

Git Worktrees 병렬 브랜치 작업

여러 브랜치에서 동시 작업. 브랜치 전환 없이 병렬 개발 가능.

git worktree add \ ../myapp-feature-auth \ feature/auth # 탭 1: myapp-feature-auth (신기능) # 탭 2: myapp-hotfix (긴급 버그수정) # 탭 3: myapp (메인 브랜치)
ykdojo #33

승인된 명령어 보안 감사 (cc-safe)

자동 승인된 명령어 중 위험한 것을 감지합니다. 한 사용자는 rm -rf ~/를 승인해 홈 디렉토리를 삭제한 사례가 있습니다.

npm install -g cc-safe npx cc-safe ~/projects # 감지 대상: sudo, rm -rf, chmod 777, # curl | sh, git push --force, npm publish
⚠️ 월 1회 실행 권장 — 특히 --dangerously-skip-permissions 모드 사용자
ykdojo #4

자동 커밋 & Draft PR 생성

# 자동 커밋 메시지 생성 "변경 사항 분석 후 적절한 커밋 메시지로 커밋해줘" # Draft PR 자동 생성 "현재 브랜치로 draft PR 만들어줘. 제목은 변경 내용 요약, 본문은 주요 변경사항 리스트로."
ykdojo #26

gh pr checkout 123 → 변경 사항 요약 → 보안/성능 이슈 분석 → 테스트 커버리지 평가 → 개선 제안 & 자동 수정

고급 기능 — MCP, Hooks, Agents, Plugins

CLAUDE.md vs Skills vs Slash Commands vs Plugins (ykdojo #25)

기능 로딩 시점 주요 사용자 토큰 효율 사용 사례
CLAUDE.md 모든 대화 시작 시 개발자 낮음 (항상) 프로젝트 설명, 코딩 스타일, 금지 사항
Skills 필요 시 자동 Claude 높음 (필요 시) 번역, 크롤링, 특정 작업 자동화
Slash Commands 수동 호출 시 개발자 높음 (호출 시) 반복 작업 (커밋, PR 생성, 핸드오프)
Plugins 설치 시 개발자 — 여러 기능을 하나로 묶어 배포

MCP: 외부 세계와의 연결 (Ado #22-25)

# Playwright MCP (브라우저 자동화) claude mcp add -s user playwright \ npx @playwright/mcp@latest # Supabase MCP (DB 직접 쿼리) claude mcp add -s user supabase \ npx @supabase/mcp@latest # Firecrawl MCP (웹 크롤링) claude mcp add -s user firecrawl \ npx @firecrawl/mcp@latest
⚠️ ykdojo 성능 최적화 권장 MCP 10개 미만, 활성 도구 80개 미만 유지

Hooks: AI에 가드레일 강제 (Ado #26)

Hook실행 시점활용
PreToolUse도구 실행 전위험 명령어 차단
PostToolUse도구 실행 후로그 기록
PermissionRequest권한 요청 시자동 승인/거부
SubagentStart서브에이전트 시작모니터링
💡 Ado의 조언 "Hooks는 AI에게 절대적인 규칙을 강제합니다. 확률적으로 실수할 수 있는 AI에게 가드레일을 제공합니다."
