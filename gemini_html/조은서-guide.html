문제 정의 · 배경

기존의 어려움

이메일로 견적 요청 접수 → 엑셀로 견적서 수작업 작성 → 업체별 개별 연락으로 단가 확인 → PDF 변환 → 이메일 첨부 발송. 오류·누락 빈번, 월 약 3시간 소요.

시스템으로 해결한 방식

Google Apps Script 웹 앱으로 전 과정 자동화. 고객이 직접 제품 조회·선택 → 견적서 자동 생성 + PDF + 이메일 초안 + 이력 기록. 월 30분으로 단축.

주요 기능

역할 기반 접근

고객사·공급업체·관리자 3가지 역할로 분리된 전용 UI. 이메일+비밀번호 로그인.

통합 제품 카탈로그

4개 공급업체 스프레드시트에서 단가·재고를 실시간 통합 조회. 브랜드별 필터링.

견적서 자동 생성

제품 선택 → VNTG 로고·서식 포함 Google Sheets 견적서 자동 생성. PDF 변환까지 원클릭.

이메일 자동 초안

PDF 첨부 이메일 초안을 자동 생성. 최종 발송 전 내용 확인 후 전송 가능.

Drive 자동 정리

견적서·PDF를 업체명/날짜별 폴더에 자동 분류·저장. 수동 파일 관리 불필요.

견적 이력 관리

모든 견적 요청이 로그 스프레드시트에 자동 기록. 수정 견적 번호 체계(날짜-순번-수정).

단가·재고 셀프 관리

공급업체 담당자가 직접 본인 품목 단가·재고 수정. 관리자 중개 불필요.

갱신도래 관리

소프트웨어 라이선스 갱신 예정 항목을 고객사별로 별도 조회. 만료일 자동 파싱.

업체 담당자 등록

신규 공급업체 담당자 등록 요청 기능. 요청 시 관리자에게 이메일 자동 알림.
