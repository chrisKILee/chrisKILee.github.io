⚡ 주요 기능

🔐 3-역할 로그인

고객사·공급업체·관리자가 하나의 URL로 접근, 역할별 전용 화면으로 자동 분기

📦 제품 통합 조회

4개 공급업체 스프레드시트에서 제품·단가·재고를 실시간 통합하여 목록 제공

📝 견적서 자동 생성

견적 요청 시 Google Sheets 견적서 자동 생성, 로고 삽입, Drive 저장까지 자동화

📧 이메일 자동 발송

고객사 + VNTG 관리자에게 견적서 링크 Gmail 자동 발송, 수정 견적도 지원

🔄 단가·재고 직접 관리

공급업체 담당자가 자사 제품 단가·재고를 직접 갱신, 다음 조회 시 즉시 반영

📋 견적 이력 조회

고객사별 전체 견적 요청 이력 확인, 수정 견적 요청(계층 번호 체계)까지 지원
