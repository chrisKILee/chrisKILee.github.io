프론트엔드 하드 룰 — Design Hard Rules

OpenAI 권장 · 반드시 지켜야 할 10가지 규칙
01 단일 구성 DO 뷰포트당 하나의 일관된 구성만 사용. 여러 레이아웃을 한 화면에 섞으면 시선이 분산됩니다.
02 브랜드 정체성 전면 배치 DO 강한 브랜드·제품 아이덴티티를 페이지 첫 화면에 배치. 사용자가 "어디 사이트인지" 즉시 알아야 합니다.
03 표현력 있는 폰트 Don't Inter 기본값 Inter, Roboto 같은 기본값을 피하고 개성 있는 폰트를 사용. 기본 폰트는 모델이 훈련 데이터의 고빈도 패턴으로 후퇴하는 신호입니다.
04 동적 배경 DO 그라디언트, 이미지, 패턴 등 동적 배경 적극 활용. 흰 배경은 에너지가 없습니다.
05 풀블리드 히어로 DO 랜딩페이지에서 히어로 섹션은 화면 가득 채우는 풀블리드(full-bleed) 방식 사용. 인셋 프레임 금지.
06 오버레이·플로팅 요소 최소화 Don't 히어로 위 오버레이와 플로팅 요소를 최소화. UI 클러터(어수선함)를 만들어 브랜드 이미지를 해칩니다.
07 카드는 인터랙티브 컨테이너에만 Don't 남발 카드(Card)는 클릭·드래그 등 인터랙션이 있는 컨테이너 목적에만 사용. 정보 나열에 카드를 남발하면 시각적으로 무거워집니다.
08 섹션은 단 하나의 목적만 DO 각 섹션은 한 가지 메시지만 전달. 기능 소개 + 가격 + 후기를 한 섹션에 넣으면 모두 희석됩니다.
09 실제 맥락 이미지 DO 아이콘·일러스트보다 실제 제품·사용 맥락을 보여주는 사진. 사람들은 추상이 아닌 실제를 신뢰합니다.
10 의도적 모션 최소 2~3개 DO 핵심 애니메이션 2~3개를 의도적으로 설계. Framer Motion 권장. 노이즈 생성 목적의 무분별한 애니메이션 금지.

랜딩 페이지 권장 순서 — Content Structure

01
히어로 섹션
브랜드 아이덴티티 + 핵심 약속. 풀블리드, 헤드라인 최대 2~3줄.
02
보조 이미지
제품 또는 사용 맥락을 시각적으로 강화하는 이미지.
03
제품 상세
기능 설명. 각 섹션은 단 하나의 목적.
04
소셜 프루프
후기, 고객사 로고, 수치로 신뢰 구축.
05
최종 CTA
전환 버튼. 가장 강한 메시지로 마무리.

Claude Code 활용법 — 실전 프롬프트 가이드

1단계 — 디자인 시스템 토큰 먼저 정의하기

모델에게 먼저 색상·폰트·간격 시스템을 선언하면, 이후 모든 컴포넌트에서 일관성이 유지됩니다. "만들어줘"보다 "이 토큰 안에서 만들어줘"가 훨씬 좋은 결과를 냅니다.

디자인 토큰 선언 예시
# Claude Code 프롬프트 다음 디자인 시스템 토큰으로 랜딩 페이지를 만들어줘: 색상: - background: #09090B (다크 배경) - surface: #18181B (카드 배경) - accent: #6366F1 (인디고 강조) - text: #F4F4F5 (본문) - muted: #71717A (보조 텍스트) 폰트: - display: 'Outfit', sans-serif (Inter 쓰지 마) - body: 16px, line-height 1.7 규칙: - 히어로는 풀블리드로 - 카드는 인터랙티브 요소에만 - 각 섹션은 단 하나의 목적

2단계 — 비주얼 레퍼런스 첨부하기

스크린샷이나 무드보드를 프롬프트에 첨부하면 모델이 시각적으로 검증할 수 있습니다. GPT-5.4의 이미지 이해 능력을 최대한 활용하는 방법입니다.

"비주얼 레퍼런스 없이 '세련되게 만들어줘'라고 하면 모델은 가장 흔한 패턴으로 돌아간다. 무드보드 하나가 수백 단어의 설명을 대체한다."
Claude Code + 이미지 첨부 방법
# 터미널에서 이미지 파일 첨부 claude "이 스크린샷과 비슷한 느낌으로 히어로 섹션을 만들어줘. 단, 색상은 우리 브랜드 색(#6366F1)으로 바꾸고 폰트는 Outfit으로 교체해줘" \ --attach reference.png

3단계 — Frontend Skill 활용 (Codex CLI 방식 응용)

OpenAI는 Codex CLI용 "frontend-skill"을 제공합니다. Claude Code에서는 유사하게 CLAUDE.md에 디자인 규칙을 한 번 선언해두면, 이후 모든 프론트엔드 작업에서 자동으로 적용됩니다.

CLAUDE.md에 추가할 프론트엔드 규칙
## 프론트엔드 디자인 규칙 (GPT-5.4 Hard Rules 기반) HTML/CSS 작업 시 반드시 준수: - 뷰포트당 하나의 구성만 사용 - Inter, Roboto 기본 폰트 금지 → Outfit, Plus Jakarta Sans 등 사용 - 히어로 섹션은 풀블리드(full-bleed) - 카드는 클릭 가능한 컨테이너에만 사용 - 각 섹션은 단 하나의 목적 - 애니메이션 최소 2~3개 의도적으로 추가 - 배경은 단순 흰색 금지 (그라디언트 또는 패턴 활용) 랜딩페이지 섹션 순서: 1. 히어로 (브랜드 + 핵심 약속) 2. 보조 이미지 3. 제품 상세 4. 소셜 프루프 5. 최종 CTA

4단계 — 모션 추가하기

모션은 "있으면 좋은 것"이 아니라 계층 구조를 강화하는 설계 요소입니다. GPT-5.4는 Framer Motion을 권장합니다. Claude Code에서는 CSS 애니메이션으로도 충분히 구현 가능합니다.

Claude Code 모션 프롬프트
# 히어로 진입 애니메이션 히어로 섹션에 입장 시퀀스 애니메이션 추가해줘: - 제목이 아래에서 위로 fade-in (0.6s) - 부제목은 0.2s 딜레이 - CTA 버튼은 0.4s 딜레이 - 모두 cubic-bezier(0.16, 1, 0.3, 1) 이징 # 스크롤 연동 효과 스크롤에 따라 히어로 배경이 parallax로 움직이게 해줘 (배경 이동 속도는 스크롤의 0.5배) # 호버 효과 카드에 호버 시 translateY(-4px) + shadow 강화 전환 속도: 0.2s ease
