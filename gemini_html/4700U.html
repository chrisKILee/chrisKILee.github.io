BIOS 설정 및 TDP 튜닝

4700U의 기본 TDP는 보통 15W로 제한되어 있어 제 성능을 다 내지 못합니다. BIOS 상의 설정이 제한적이라면, 윈도우 상에서 Universal x86 Tuning Utility (UXTU)를 사용하는 것이 가장 안전하고 효과적입니다.

주의: TDP를 높이면 발열이 급격히 증가합니다. 아래 '서멀/쿨링' 탭의 작업을 먼저 수행하는 것을 강력히 권장합니다.

소프트웨어 튜닝 (추천)

  1. UXTU (Universal x86 Tuning Utility) 다운로드 및 설치.
  2. 'Custom' 프리셋 선택.
  3. APU TDP L1 (Slow): 지속적인 부하 시 전력 제한. 쿨링이 좋다면 25W~28W 추천.
  4. APU TDP L2 (Fast): 단시간 부스트 전력. 30W~35W 추천.
  5. 'Auto Apply' 체크하여 부팅 시 적용.

BIOS 접근 및 VRAM 설정

  • 부팅 시 DEL 또는 ESC 연타.
  • VRAM 할당: Chipset > North Bridge > GFX Configuration > UMA Frame Buffer Size.
    • 8GB 램 사용자: 1GB 또는 2GB 설정 (시스템 메모리 부족 방지)
    • 16GB 이상 사용자: 3GB 또는 4GB 권장 (게임 성능 안정화)

서멀 구리스 및 쿨링 최적화

중국산 미니 PC의 가장 큰 약점은 조립 마감입니다. 공장 출고 서멀 구리스는 품질이 낮고 도포가 엉망인 경우가 많습니다. 재도포만으로도 5°C~10°C의 온도 하락 효과를 볼 수 있습니다.

1. 준비물

정밀 십자 드라이버, 알코올 솜, 고성능 서멀 (추천: Honeywell PTM7950 또는 Arctic MX-4/6)

2. 히트싱크 분해

쿨링팬 커넥터를 조심스럽게 분리한 후, CPU 주변의 고정 나사 3~4개를 대각선 순서로 조금씩 풉니다.

3. 기존 서멀 제거

굳어있는 회색 공장 서멀을 알코올 솜으로 깨끗이 닦아냅니다. 코어(반짝이는 직사각형) 주변으로 흐르지 않게 주의하세요.

4. 재도포 (PTM7950 추천)

노트북/미니PC 같은 '베어 다이(Bare Die)'에는 펌프아웃 현상이 적은 Honeywell PTM7950 패드가 최고의 성능을 냅니다. 코어 크기에 맞춰 자르고 붙이세요.
