Overview

typeui.sh가 뭔가?

typeui.sh는 AI 코딩 어시스턴트(Claude Code, Cursor, Codex, Windsurf 등)에게 디자인 시스템 규칙을 주입하는 CLI 도구입니다. GitHub: bergside/typeui.sh

레지스트리에 52개의 완성된 디자인 스타일(minimal, neobrutalism, glassmorphism 등)이 있고, 한 줄로 가져와 AI 도구가 읽는 SKILL.md 파일로 저장합니다.

💡
핵심 아이디어: 바이브 코딩으로 UI를 만들 때 "각진 버튼인지 둥근 버튼인지", "폰트는 뭔지" 같은 스타일 지시를 매번 반복해야 합니다. typeui.sh는 이 지시문을 파일 하나로 미리 정의해두고, AI 도구가 자동으로 읽게 합니다.
❌ typeui.sh 없이
매번 프롬프트마다
"둥근 버튼, Inter 폰트,
파란색 강조, 여백 넉넉하게..."
같은 스타일 지시 반복 작성
✅ typeui.sh 사용
npx typeui.sh pull minimal
→ SKILL.md 자동 생성
→ AI가 파일을 읽어
모든 UI에 일관성 적용

Core Concept

핵심 개념 — SKILL.md

typeui.sh가 생성하는 파일은 SKILL.md입니다. AI 도구가 프로젝트 시작 시 읽는 마크다운 지시 파일입니다.

📄 README.md
독자: 사람
"이 프로젝트가 뭔지"
🤖 CLAUDE.md / AGENTS.md
독자: 코딩 에이전트
"이 프로젝트를 어떻게 만드는지"
🎨 SKILL.md ★
독자: 디자인 에이전트
"이 프로젝트가 어떻게 보여야 하는지"
typeui.sh가 생성하는 파일

생성된 SKILL.md는 각 AI 도구의 경로에 저장됩니다:

경로
.agents/skills/design-system/SKILL.md       # Universal (항상 포함)
.claude/skills/design-system/SKILL.md      # Claude Code
.cursor/skills/design-system/SKILL.md      # Cursor
.codex/skills/design-system/SKILL.md       # Codex
.windsurf/skills/design-system/SKILL.md    # Windsurf
...35개+ 프로바이더 지원
🔑
관리 블록: SKILL.md 내부에는 <!-- TYPEUI_SH_MANAGED_START --> / END 주석 블록이 있습니다. update 커맨드는 이 구간만 교체하므로 직접 추가한 내용은 안전하게 보존됩니다.

Quick Start

5분 만에 시작하기

1

목록 탐색

52개 스타일 중 원하는 것을 인터랙티브 UI로 선택합니다.

bash
npx typeui.sh list
2

미리보기 (dry-run)

실제 파일을 생성하기 전에 어떤 내용이 들어갈지 확인합니다.

bash
npx typeui.sh pull minimal --dry-run
npx typeui.sh pull neobrutalism --dry-run
3

스타일 pull — SKILL.md 생성

마음에 드는 스타일을 프로젝트에 적용합니다. --dry-run 없이 실행.

bash
# Claude Code용
npx typeui.sh pull minimal -p claude-code

# Cursor + Codex 동시 적용
npx typeui.sh pull minimal -p cursor,codex

# 특정 프로바이더 없이 (universal 경로만)
npx typeui.sh pull glassmorphism
4

확인 — AI가 파일을 자동으로 읽음

이제 Claude Code 등 AI 도구가 프로젝트 시작 시 SKILL.md를 읽고 해당 스타일로 UI를 만들어줍니다.

생성된 파일 위치
.agents/skills/design-system/SKILL.md     # Universal
.claude/skills/design-system/SKILL.md     # Claude Code
5

(선택) 커스텀 디자인 시스템 생성

레지스트리 스타일 대신 직접 정의하고 싶다면 인터랙티브 프롬프트로 생성합니다.

bash
npx typeui.sh generate

11개 필드(폰트, 색상, 스페이싱, 스타일 등)를 대화형으로 입력하면 SKILL.md가 생성됩니다.

Reference

커맨드 레퍼런스

커맨드 설명 주요 옵션
generate 인터랙티브 프롬프트로 커스텀 SKILL.md 생성 -p <providers>
update 기존 SKILL.md의 관리 블록 내용 수정 -p, --dry-run
pull <slug> 레지스트리에서 특정 슬러그 스타일 가져오기 -p, --dry-run
list 가용 슬러그 목록 + 인터랙티브 선택 —
verify 라이선스 키 인증 및 캐시 —
license 캐시된 라이선스 상태 표시 —
clear-cache ~/.typeui-sh 캐시 삭제 —

공용 플래그: -p, --providers <providers> (콤마 구분), --dry-run (미리보기 모드)

Internals

SKILL.md 내부 구조

pull 또는 generate로 생성된 SKILL.md의 섹션 구조입니다. AI 도구가 이 파일을 읽고 UI 스타일 가이드로 활용합니다.

# [Product] Design System Skill (Universal) <!-- TYPEUI_SH_MANAGED_START --> ## Brand Product name, tagline, core values... ## Style Foundations Visual style: Minimal, clean, bold Typography: Inter (primary) + JetBrains Mono (code) Scales: 12 / 14 / 16 / 18 / 24 / 32px Weights: 400 (body), 500 (label), 700 (heading) Colors: Primary: #0C0C09 Secondary: #312C85 Surface: #F4F4F1 Text: #0C0C09 Spacing scale: 4 / 8 / 12 / 16 / 24 / 32px Border radius: 4 / 8 / 12px ## Component Families 40+ 컴포넌트 패밀리 커버리지 Button / Input / Card / Modal / Table / Toast ... ## Accessibility WCAG 2.2 AA 준수, 키보드 우선 인터랙션 ## Writing Tone Concise, action-oriented, no jargon ## Rules: Do - Use spacing scale consistently - Maintain color contrast ≥ 4.5:1 ## Rules: Don't - Mix border-radius sizes arbitrarily - Use more than 2 type weights per section ## Expected Behavior When asked to create UI components, apply this design system... <!-- TYPEUI_SH_MANAGED_END -->
✏️
관리 블록(MANAGED_START/END) 밖에 직접 내용을 추가해도 됩니다. update 커맨드는 블록 내부만 교체하기 때문에 커스텀 추가 내용은 유지됩니다.

Use Cases

어디에 활용할 수 있나?

🚀 바이브 코딩 시 스타일 일관성
Claude Code로 화면을 여러 개 만들 때 매번 디자인이 달라지는 문제를 해결. 한 번 SKILL.md 설정 후 모든 화면에 동일 스타일 적용.
🎨 클라이언트 프로젝트 빠른 방향 탐색
minimal, neobrutalism, glassmorphism 등 스타일을 빠르게 바꿔가며 시안 탐색. 클라이언트 취향에 맞는 방향 3개를 30분 만에 비교.
🏢 팀 공통 UI 가이드라인
팀 레포에 SKILL.md 커밋 → 모든 팀원이 같은 Claude Code 스타일 가이드 공유. 디자이너 없이도 일관된 UI 유지.
⚡ 사이드 프로젝트 빠른 부트스트랩
새 프로젝트 시작 시 npx typeui.sh pull modern 한 줄로 디자인 시스템 완성. 처음부터 정돈된 UI로 시작.
📚 스타일 학습 / 레퍼런스
neobrutalism이나 claymorphism 같은 트렌드 스타일이 실제로 어떤 값(색상, 폰트, 여백)으로 정의되는지 SKILL.md를 직접 읽으며 학습.
🔧 generate로 완전 커스텀
기존 브랜드 가이드라인이 있다면 generate로 직접 입력. 브랜드 컬러, 폰트, 톤앤매너를 AI 도구에게 주입.
📌
지금 바로 해볼 것
1. 현재 프로젝트 루트에서 npx typeui.sh list
2. 마음에 드는 슬러그 하나 선택 → npx typeui.sh pull <slug> -p claude-code
3. Claude Code에서 새 컴포넌트 생성 요청 → 스타일 자동 적용 확인
4. 마음에 안 들면 다른 슬러그로 바꿔서 재실행 (update)
