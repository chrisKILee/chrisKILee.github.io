1. 개발 환경 (Development)

CS 환경에서 Modern Web(React)으로의 혁신적 전환

개발자가 생산성 높게 코드를 작성하고, 컴포넌트를 재사용하며, AI 도구(Cursor/Copilot)를 활용하여 빠르고 일관된 개발을 할 수 있는 통합 환경입니다. 기존 TFS의 소스 잠금(Lock) 방식에서 벗어나 Nx Monorepo 기반의 Git Branch 전략을 통해 협업 효율을 극대화합니다.

React 18 Next.js 14 TypeScript TailwindCSS Zustand

컴포넌트 라이브러리 Storybook 기반 재사용 가능한 UI 컴포넌트 (@vntg/ui-kit)

2. 배포 환경 (Deployment)

수동 파일 전송을 제거한 GitOps 완전 자동화

개발 코드를 자동으로 빌드, 테스트, 배포하여 서버에 안전하게 올리고 동작시키는 환경입니다. 기존 SIS 프레임워크의 'HTTP 파일 전송 툴' 수동 배포와 달리, ArgoCD 기반의 GitOps 파이프라인으로 배포 시간을 90% 단축하고 인적 오류를 제거합니다.
📦 핵심 기술 스택 (Tech Stack)
🔄 CI/CD 파이프라인
GitHub Actions ArgoCD (GitOps) Helm Charts
🐳 컨테이너 (Container)
Docker Harbor Registry Multi-stage Build
🔒 보안 (Security)
Trivy (Scan) SonarQube Jest/Playwright
✨ 주요 기능 (Key Features)
자동 빌드 Git Push 시 자동으로 Docker 이미지 빌드 및 레지스트리 등록
자동 테스트 단위/통합/E2E 테스트 자동 실행 (Nx Affected Test)
보안 스캔 Trivy를 통한 컨테이너 취약점 자동 탐지 및 차단
GitOps 배포 ArgoCD가 Git 상태와 K8s 상태를 자동으로 동기화
무중단 배포 Rolling Update 또는 Blue-Green 배포 전략 지원
자동 롤백 배포 실패 시 이전 안정 버전으로 즉시 복구
☁️

3. 인프라 환경 (Infrastructure)

Windows/Oracle 중심에서 K8s/Cloud로 무한 확장

애플리케이션이 IDC와 Cloud(GCP)에서 안정적으로 실행되고, 트래픽에 따라 자동 확장되며, 장애 시 자동 복구되는 환경입니다. Windows Server/IIS 중심의 고정된 인프라에서 벗어나, Kubernetes 기반의 유연한 컨테이너 오케스트레이션 환경을 구축합니다.
📦 핵심 기술 스택 (Tech Stack)
☁️ 플랫폼 (Platform)
GCP (Cloud) GKE (Kubernetes) On-Premise K8s Cloud Run
⚡ IaC & 네트워크
Terraform Istio (Service Mesh) Cloud Armor
💾 데이터 & 이벤트
PostgreSQL Apache Kafka Redis Cluster
✨ 주요 기능 (Key Features)
오토 스케일링 (Auto Scaling) 트래픽에 따라 Pod/Node 자동 확장
자동 복구 (Self Healing) 장애 발생 시 Pod 자동 재시작 및 복구
하이브리드 클라우드 보안이 중요한 데이터는 IDC, 확장이 필요한 서비스는 GCP 배치
서비스 메시 (Service Mesh) 마이크로서비스 간 안전한 통신 및 트래픽 제어 (Istio)
이벤트 구동 아키텍처 Kafka를 활용한 비동기 메시징 및 결합도 감소
비용 최적화 Spot Instance 활용 및 리소스 최적화로 비용 절감
📊

4. 운영 환경 (Operations)

단순 로그 확인에서 데이터 기반 선제적 장애 대응으로

서비스의 실시간 상태를 모니터링하고, 장애를 사전에 감지하며, 신속하게 대응할 수 있는 환경입니다. 기존의 단순 파일 로그 확인 방식에서 벗어나, LGT(Loki, Grafana, Tempo) 스택 기반의 완전한 통합 관제(Observability)를 제공합니다.
📦 핵심 기술 스택 (Tech Stack)
📈 LGT 스택 (관제)
Loki (Logs) Grafana (Dashboard) Tempo (Traces) Mimir (Metrics) Prometheus
🚨 알림 & 분석
AlertManager Slack Integration DORA Metrics
✨ 주요 기능 (Key Features)
실시간 대시보드 모든 서비스의 CPU, 메모리, 트래픽 상태 한눈에 확인
자동 알림 임계치 초과 시 Slack/Email 즉시 알림 (AlertManager)
분산 추적 마이크로서비스 간 요청 경로(Trace) 완전 추적 (Tempo)
통합 로그 분석 여러 Pod의 로그를 중앙에서 검색 및 분석 (Loki)
장애 원인 분석 에러 발생 시점의 스택 트레이스 및 연관 로그 자동 수집
DORA Metrics 배포 빈도, 변경 실패율 등 개발 생산성 지표 시각화
🎯

5. IDP (내부 개발자 플랫폼)

Helper Class를 넘어선 통합 개발자 셀프서비스 포털

개발자가 필요한 모든 것을 한 곳에서 셀프서비스로 이용할 수 있는 통합 플랫폼입니다. 문서, 도구, 배포 환경, 템플릿, 모니터링 대시보드까지 Golden Path를 제공하여 개발자 온보딩 시간을 80% 단축하고 인지 부하를 최소화합니다.
📦 핵심 기술 스택 (Tech Stack)
🎭 포털 (Portal)
Backstage Software Catalog TechDocs
🚀 셀프서비스 (Self-Service)
Scaffolder @vntg/create-app Sandbox Env Cost Dashboard
📦 공통 자산 (Assets)
@vntg/ui-kit @vntg/auth Open Metadata
✨ 주요 기능 (Key Features)
원클릭 프로젝트 생성 템플릿(Scaffolder)으로 5분 내 표준 아키텍처 프로젝트 생성
통합 검색 모든 문서, 서비스, API, 라이브러리를 한 곳에서 검색
Golden Path 검증된 모범 사례를 따르는 표준 경로 가이드 제공
셀프서비스 인프라 운영팀 승인 대기 없이 Dev/Sandbox 환경 즉시 생성
소프트웨어 카탈로그 마이크로서비스의 소유자, API 문서, 의존성 관계 시각화
Tech Radar 조직 내 권장 기술, 보류 기술, 금지 기술 현황 공유

🎁 핵심 기대 효과 (Key Benefits)
⚡
생산성 향상 (Productivity)
AI 코딩 도구, 재사용 컴포넌트(@vntg/ui-kit), 자동화된 파이프라인으로 기능 개발부터 배포까지의 리드 타임을 대폭 단축합니다.
🛡️
안정성 확보 (Stability)
Kubernetes의 자동 복구, 무중단 배포, 실시간 모니터링으로 시스템 가용성 99.9% 이상을 목표로 합니다.
🎓
빠른 온보딩 (Onboarding)
IDP의 Golden Path와 통합 문서화로 신규 개발자가 첫날부터 생산적인 업무를 수행할 수 있도록 지원합니다.
💰
비용 효율 (Cost Efficiency)
클라우드 오토스케일링과 Spot Instance 활용, 오픈소스 기반 스택으로 인프라 및 운영 비용을 효율적으로 관리합니다.
🔓
탈 벤더 종속 (No Lock-in)
특정 솔루션(OutSystems/Oracle)에 갇히지 않는 개방형 오픈소스 기술 스택으로 기술 주권과 유연성을 확보합니다.
👥
협업 강화 (Collaboration)
Nx Monorepo를 통해 30개 팀이 코드를 공유하고, 일관된 컨벤션과 프로세스로 협업하는 문화를 조성합니다.
