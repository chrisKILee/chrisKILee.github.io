## 1. 프로젝트 목표

AI-WORKER Project는 **전 직원이 AI에 대한 친밀성을 갖고, 자기 업무의 효율성을 위해 AI를 자신 있게 활용할 수 있는 수준**을 목표로 한다.

| 목표 레벨 | 명칭 | 설명 |
|-----------|------|------|
| **LEVEL 3** | Workflow Integrator / 업무 자동화 사용자 | 기존의 수작업 프로세스(예: 주간 보고 데이터 자동 취합, 티켓 자동 분류/요약 등)를 API·자동화 도구와 연결하여 **사람의 개입 없이 자동으로 처리되도록 구현**할 수 있어야 한다 |
| **LEVEL 4** | Solution Builder / 솔루션 제작자 | 단순한 업무 자동화를 넘어, **독립적인 기능을 수행하는 AI 기반 프로토타입/솔루션**(예: 사내 기술지원 챗봇 PoC 개발, 데이터 자동 분석 대시보드 구축 등)을 직접 기획하고 구현할 수 있어야 한다 |

> 💡 과제의 평가 레벨이 개인의 역량 레벨과 동일하지 않습니다.

## 5. AI API 사용 정책

> 📌 **적용 범위**: 개발 프로젝트 제외 — **개인 프로젝트 및 Study 전용**. 상용 프로덕트는 Vertex AI 등 별도 검토를 권장합니다.

### 발급 및 운영 흐름

```
이동열 매니저에게 요청
    → Gemini AI Studio 프로젝트 지정 후 신청
    → 개인별 API Key 발급 (추적·모니터링 목적)
    → 사용량 모니터링
```

### 운영 원칙

- **개인별 API Key 발급**: 추적·모니터링 목적으로 반드시 개인 Key를 사용합니다.
- **한도 및 알림 설정**: 각 API Key별 사용 한도(limit) 및 알림 설정. 한도 초과 시 인프라 담당자에게 알림.
- **사용량 현저히 감소 시**: 사용자에게 확인 후 미사용 확인되면 Key Expire 처리.
- **상용 프로덕트**: 개인 Gemini API가 아닌 Vertex AI 등 별도 솔루션 검토를 권장합니다.

### AI API 비용 안내

- **Gemini AI Studio API**: 소규모 학습·실험 목적에 적합. 개인별 Key로 부서별 사용량을 추적합니다.
- **경영진 비유**: AI API 비용은 **'업무용 복합기 토너 소모품'**과 같습니다. 공용 복합기를 관리하듯 개인 Key로 추적하되 비용은 팀·부서 단위로 투명하게 관리합니다.
- **MILO 활용**: 사내 AI 시스템 MILO를 통해 승인된 API 자원을 활용할 수 있습니다. MILO 채널을 통한 AI 활용은 별도 API Key 없이 가능하며, 보안 정책이 자동 적용됩니다.

## 6. Cloud Run 지원 정책

> 📌 **적용 범위**: 개발 프로젝트 제외 — **개인 프로젝트 중 부서장 승인이 있는 경우** (팀장, 센터장/실장)
> 💰 **비용 귀속**: 발생 비용은 해당 부서에 귀속됩니다.

### 인스턴스 생성 흐름

```
떼루아 준비 완료 → 떼루아 통해 생성
                            ↓
떼루아 준비 전 → 인프라팀 이동열 매니저에게 요청
                            ↓
                    인스턴스 생성 → 사용 현황 모니터링 → 미사용 감지 시 담당자 확인 후 삭제
```

> 📝 **Action Item**: 요청 템플릿 정리 필요

### 6-1. 운영의 주체

- **운영의 주체는 승인 부서**입니다.
- **미사용 서비스 종료**: 불필요한 비용 발생을 방지하기 위해, 사용하지 않는 서비스는 해당 부서에서 직접 종료 요청을 합니다.
- **부서 내 기술 이전 필수**: 운영자 퇴사나 조직 변경 시에도 서비스가 단절되지 않도록, 운영 지식은 반드시 부서 내에 공유·이전되어야 합니다.

## 7. LLM 데이터 사용 정책

### 7-1. 허용 기준

| 항목 | 내용 |
|------|------|
| **사용 가능 계정** | Enterprise 계정 필수 |
| **필수 설정** | opt-out 설정, 공유 금지 설정 |
| **Claude co-work** | ❌ 사용 불가 |

### 7-2. Gemini 개인정보보호 정책 유의사항

- **Gemini for Google Workspace**: 관리자 설정에서 **데이터 학습 opt-out 필수**. 기본값으로 사용자 입력 데이터가 Google 모델 개선에 활용될 수 있음. 반드시 관리 콘솔에서 비활성화 확인 후 사용.
- **Gemini API (AI Studio) Enterprise**: Data Protection Amendment(DPA) 적용 계정에서는 사용자 데이터가 학습에 사용되지 않음. API Key 발급 전 Enterprise 계정 여부 반드시 확인.
- **MILO 채널 활용 권장**: 사내 AI 시스템 MILO를 통한 AI 활용은 사내 보안 정책이 자동 적용되어, 별도 opt-out 설정 없이 안전하게 사용 가능합니다.

### 7-3. 입력 금지 데이터

| 분류 | 예시 |
|------|------|
| **개인정보 (PII)** | 이름, 연락처, 주민번호 등 (마스킹 없이 전송 금지) |
| **소스코드** | 내부 프로덕트 코드 |
| **계약서** | 파트너·고객 계약 문서 |
| **고객 정보** | CRM 데이터, 거래 이력 등 |
| **내부 전략** | 사업 계획, 로드맵 등 |

> ⚠️ **결정 필요**: 입력 금지 데이터의 범위를 조직 내 명확히 확정해야 합니다.

### 7-4. 절대 금지 행위

- 🚫 개인정보(PII)를 **마스킹 없이** 외부 AI API에 전송
- 🚫 API 키를 **코드 저장소(GitHub 등)에 커밋**
- 🚫 승인되지 않은 AI 서비스에 **법인카드 결제**
- 🚫 **기밀 데이터**를 클라우드 AI 모델에 입력
