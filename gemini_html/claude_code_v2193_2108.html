캐시 및 사용량 버그 심층 분석
왜 캐시 버그가 중요한가?
프롬프트 캐시(Prompt Caching)는 동일한 컨텍스트(대화 히스토리, 시스템 프롬프트)를 반복 요청할 때 캐시된 토큰은 입력 비용의 10%만 과금합니다. 긴 세션일수록 효과가 크며, 캐시 TTL(유효 시간)이 짧으면 매 요청마다 전체 비용을 내야 합니다. 캐시 버그가 있으면 사용자가 체감하는 비용이 예상보다 10배 가까이 늘어날 수 있습니다.

프롬프트 캐시 TTL 비교

* 5분 TTL 버그 상태에서는 캐시가 자주 만료되어 토큰 비용이 최대 10배 증가할 수 있음

v2.1.108
구독자 DISABLE_TELEMETRY 시 캐시 TTL 폴백 버그
증상: 구독(claude.ai) 플랜 사용자가 DISABLE_TELEMETRY=1을 설정하면 프롬프트 캐시 TTL이 1시간이 아닌 5분으로 폴백되었습니다. 구독 플랜에서는 텔레메트리 설정과 무관하게 1시간 TTL이 적용되어야 합니다.

영향: 텔레메트리를 비활성화한 프라이버시 지향 사용자들이 불필요하게 높은 토큰 비용을 지불하거나, 캐시 효율이 크게 저하되었습니다.

수정: 텔레메트리 설정과 캐시 TTL 결정 로직을 분리. 구독 플랜은 항상 1시간 TTL 적용.

v2.1.108
ENABLE_PROMPT_CACHING_1H — 1시간 캐시 TTL 신규 지원
배경: 기존 프롬프트 캐시의 기본 TTL은 5분이었습니다. API 사용자는 매 요청 후 5분이 지나면 동일 컨텍스트라도 전체 토큰 비용을 다시 지불해야 했습니다.

신기능: ENABLE_PROMPT_CACHING_1H=1 환경변수로 1시간 TTL을 활성화할 수 있습니다. 긴 세션, 반복 작업, 동일 코드베이스 탐색 등에서 비용 절감 효과가 큽니다.

지원 플랫폼: API key, Bedrock, Vertex, Foundry (claude.ai 구독 사용자는 이미 기본 적용).

수정: 도구 캐시 항목의 생명주기(lifecycle) 관리 로직 수정.

v2.1.101
--resume 후 세션 컨텍스트 손실 (대형 세션)
증상: 대형 세션(컨텍스트가 많은 대화)에서 --resume으로 재개 시 이전 컨텍스트 일부가 소실되었습니다. 이전 대화 내용을 참조하지 못하거나 엉뚱한 응답이 나타났습니다.

원인: 지연된 도구 입력 스키마(deferred tool schema)가 세션 직렬화/역직렬화 과정에서 누락되어 캐시 미스가 발생하거나 컨텍스트가 잘렸습니다.

수정: 세션 재개 시 지연된 도구 스키마 포함 여부 검증 로직 추가.
🔴 높음 — 작업 연속성 직접 영향
v2.1.98
429 재시도 지수 백오프 개선
배경: API 429(Too Many Requests) 오류 발생 시 재시도 대기 시간이 13초로 고정되어 있어 서버 부하나 플랜 제한 해제를 기다리는 데 비효율적이었습니다.

개선: 지수 백오프(exponential backoff) 최솟값을 적용하여 초기 재시도를 빠르게, 반복 실패 시 점진적으로 대기 시간을 늘립니다.

효과: 일시적인 레이트 제한 해소 시 더 빠른 재시도, 지속적인 제한 상황에서는 서버 부하 최소화.
🟢 낮음 — 성능 개선, 기능 정상 작동
v2.1.97
MCP HTTP/SSE 재연결 메모리 누수 (~50MB/hr)
증상: MCP를 HTTP/SSE 방식으로 연결한 환경에서 재연결(reconnect) 발생 시마다 약 50MB 규모의 메모리가 해제되지 않았습니다. 24시간 운용 시 약 1.2GB 누수.

원인: SSE 재연결 시 이전 연결의 이벤트 리스너와 버퍼가 GC(가비지 컬렉션)에 의해 회수되지 않는 참조 순환 문제.

수정: 재연결 시 이전 연결 객체 명시적 해제 및 이벤트 리스너 제거.
🔴 높음 — 장기 실행 환경(서버, CI) 필수 수정
v2.1.94
비스트리밍 fallback 시 토큰 사용량 추적 누락
증상: 스트리밍 오류로 비스트리밍 방식으로 fallback되어 응답을 받으면 해당 요청의 토큰 사용량이 /cost 명령에 집계되지 않았습니다.

영향: 실제 사용량보다 적게 표시된 /cost 결과. 비용 추적 목적으로 사용 시 잘못된 수치 제공.

수정: 비스트리밍 응답 경로에서도 토큰 카운트를 사용량 추적기에 기록하도록 수정.
