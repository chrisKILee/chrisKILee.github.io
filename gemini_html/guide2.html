토큰(Token)과 청크(Chunk)의 비밀

AI가 읽는 최소 단위인 토큰이 모여서 청크라는 지식 덩어리가 됩니다. 이들이 어떻게 숫자 배열로 변하고 템플릿에 담기는지 확인해보세요.

1 개념 정리: 포함 관계 이해하기

● 토큰 (Token)

AI 모델이 한 번에 처리하는 가장 작은 단위입니다. 한글은 보통 한 글자나 형태소 단위로 쪼개집니다. 모델은 "최대 몇 토큰까지 읽을 수 있다"는 한계를 가집니다.

● 청크 (Chunk)

여러 개의 토큰을 의미 있는 덩어리로 묶은 것입니다. 벡터 DB에 저장되는 실제 단위이며, 검색의 대상이 됩니다. 바구니(청크) 안에 사과(토큰)들이 담겨 있는 꼴입니다.

CHUNK (바구니)
안 녕 하 세 요 AI 가 읽 는 말

청크는 여러 개의 토큰을 포함하는 컨테이너입니다.

2 토큰-청크 생성 시뮬레이터

텍스트를 입력하면 AI 모델이 이를 어떻게 토큰화하고, 설정된 토큰 한도에 맞춰 어떻게 청크로 나누는지 실시간으로 보여줍니다.

AI 모델의 데이터 처리 결과

3 벡터 DB 저장 및 검색 아키텍처

생성된 청크는 AI 모델을 거쳐 숫자 배열(Vector)로 변환됩니다. 사용자가 질문을 던지면, 질문 또한 숫자로 변해 가장 유사한 숫자 배열을 가진 청크를 찾아옵니다.

Input Chunk

"연차 규정은 입사 1년 후..."

➔
AI Embedding Model
➔
STORED AS NUMERIC ARRAY
[0.1223, -0.4552, 0.8812, 0.3114, -0.1029, 0.5521, 0.9928, -0.2210, 0.0034, 0.7712, ...]

포인트: 벡터 DB는 텍스트를 저장하는 것이 아니라, 텍스트의 '의미적 좌표'인 숫자들의 모음을 저장합니다. 따라서 "휴가"라고 물어도 "연차"에 대한 정보를 찾을 수 있는 것입니다.

4 템플릿(Template)의 마법

검색된 청크들을 그대로 보여주는 것이 아니라, 템플릿이라는 양식에 넣어 AI가 질문자의 의도에 맞게 정해진 포맷으로 재가공하게 만듭니다.

Prompt Template Config

당신은 사내 가이드 봇입니다.

[사용자 질문]: {User_Query}
