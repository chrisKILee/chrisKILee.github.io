테루아 플랫폼 전체 네이밍 체계

테루아(Terroir) 플랫폼은 와인 제조 공정 용어를 기술 변환 맥락에 대응시킨 일관된 네이밍 체계를 가집니다. 모든 프로젝트명이 프랑스어 또는 와인 용어에서 파생됩니다.

테루아(Terroir)는 프랑스어로 "포도밭의 토양, 지역적 환경, 고유한 생태계"를 뜻합니다. 기술 인프라 플랫폼이 서비스들이 자라는 토대 — 환경 그 자체임을 은유합니다. 이 철학 아래 각 하위 모듈과 전환 트랙도 와인 용어로 통일되어 있습니다.

전환 트랙 3종

Nouvelle Cuvée
신규 프로젝트 — "새로운 혼합물". 기존 시스템 없이 처음부터 시작하는 신규 서비스 개발 트랙.
Vinification
완전 재구축 — "발효". 레거시를 완전히 해체하고 새로운 형태로 재구성하는 트랙. 완료 후 레거시 retire.
Élevage
시맨틱 강화 — "숙성". 레거시를 유지하면서 시맨틱 레이어를 덧씌워 가치를 강화. Vinification의 선행 단계.

와인 프로세스 용어 — 전환 단계 메타포

용어 와인 의미 기술 대응

Harvest포도 수확SPEC 전환 — 레거시 기능 명세화

02

가르드(Garde) — 어원과 의미

Garde는 프랑스어로 "보호, 경비, 감시; 보호하는 집단"을 뜻합니다. 통합관제모니터링이 수행하는 역할과 의미가 정확히 일치합니다.

어원
프랑스어 Garde
고대 프랑크어 wardā(감시하다)에서 유래. 영어 "Guard"의 어원이 된 단어. 와인 용어로는 garde-robe(지하 저장고 관리자), en garde(경계 준비)로도 쓰입니다.
의미
감시 · 보호 · 경비
단순한 "감시(Watch)"가 아닌 능동적 보호와 대응을 내포합니다. "En Garde(경계 상태, 언제든 대응 준비 완료)"는 상시 대기 관제 시스템의 개념과 자연스럽게 연결됩니다.

"테루아가 심은 대지를, 가르드가 지킨다."

플랫폼 네이밍 슬로건 제안

플랫폼(테루아)이 서비스가 자라는 토대(기반)라면, 가르드는 그 기반을 상시 감시하고 보호하는 경비대입니다. 기능 설명을 별도로 하지 않아도 이름만으로 역할이 전달되는 구조입니다.

관련 기술 레퍼런스에서의 Guard 계열 명칭

IT 보안·인프라 업계에서 Guard 계열 명칭은 이미 친숙한 개념입니다. 맥락적 친숙함(Contextual Familiarity)을 확보합니다.

테루아와의 브랜드 일관성

두 이름 모두 프랑스어에서 파생되어 동일한 언어적 뿌리를 공유합니다. 이는 플랫폼 브랜드 아이덴티티 측면에서 결정적인 장점입니다.

역할 플랫폼 전체 (기반) Ops 레이어 통합관제 ✓ 계층 관계 명확

플랫폼 전체 네이밍 체계 내 위치

TERROIR 플랫폼 네이밍 체계
│
├── 전환 트랙 (서비스 현대화 경로)
│   ├── Nouvelle Cuvée  ← 신규 프로젝트
│   ├── Vinification    ← 완전 재구축
│   └── Élevage         ← 시맨틱 강화·숙성
│
├── 프로세스 단계 (와인 제조 메타포)
│   ├── Crush     ← 레거시 역추출
│   ├── Harvest   ← SPEC 전환
│   ├── Ferment   ← 신규 개발
│   └── Bottle    ← 전환 완료
│
└── 플랫폼 레이어 모듈
    ├── Dev     ← SDD / AI 코드
    ├── Deploy  ← CI/CD / GitOps
    ├── Infra   ← K8s / 하이브리드
    ├── OPS → GARDE  ← 통합관제모니터링  ★ NEW
    └── IDP     ← Backstage 개발자 포털
체계 적합성 평가
가르드는 기존 네이밍 체계의 언어적 일관성(프랑스어)을 유지하면서, Ops 레이어의 역할을 직관적으로 표현합니다. 체계 내 공백을 자연스럽게 채웁니다.

확장성 — 가르드 파생 명칭

Garde는 프랑스어 조합어로 확장하기 용이합니다. 향후 기능·모듈 확장 시 일관된 네이밍 파생이 가능합니다.

Avant-Garde — 차세대 선행 관제 기능. 전위적 확장 모듈.

Avant-Garde(아방가르드)는 "전위, 선구자"를 뜻하는 복합어로, 가르드의 상위 확장 모듈명으로도 활용 가능합니다. "선행 관제" 또는 "예측적 모니터링" 기능에 자연스럽게 연결됩니다.
