01 변화

무엇이 달라졌나

기존 v2는 "문제를 가리키는" 도구였습니다. v3.0은 "방향을 보여주는" 도구로 확장됐습니다.

v2 · 기존
피드백 도구
화면 요소를 클릭해서 "이거 고쳐"라고 가리키는 방식.

클래스명, CSS 셀렉터, 위치를 캡처해서 Claude Code나 Cursor가 바로 알아듣는 마크다운을 생성합니다.
v3.0 · 신규
기획 + 피드백 도구
레이아웃 모드 추가로 "이렇게 만들어"가 가능해졌습니다.

에이전트에게 전달되는 건 글 문단이 아니라 좌표와 치수입니다.
02 기능

레이아웃 모드 3가지

L 키를 누르면 모드가 전환됩니다. 세 가지 작업이 가능합니다.

📐
와이어프레이밍

"Wireframe New Page"를 켜면 현재 페이지가 페이드아웃됩니다. 불투명도 슬라이더로 기존 화면을 참고하면서 새 레이아웃을 스케치합니다.

상단 용도 필드에 "가격표와 후기가 포함된 랜딩 페이지" 같은 컨텍스트를 함께 전달합니다.

Wireframe New Page
↕️
섹션 재배치

페이지의 모든 섹션이 드래그 가능해집니다. 마우스를 올리면 CSS 셀렉터 라벨과 함께 아웃라인이 표시되고, 끌어서 순서를 바꿉니다.

예: "후기 섹션을 가격표 위로 올려줘"를 말 대신 행동으로.

kind: rearrange
🧩
컴포넌트 배치

5개 카테고리(Layout, Content, Controls, Elements, Blocks)에 65개 이상의 컴포넌트 타입이 있습니다. 골라서 끌어다 놓고 크기를 조절합니다.

배치마다 컴포넌트 타입, 픽셀 치수, 위치가 기록됩니다.

kind: placement
상태 유지
와이어프레임 상태와 재배치 상태는 따로 저장됩니다. 모드를 왔다 갔다 해도 작업이 날아가지 않습니다.
03 컴포넌트

65+ 컴포넌트 타입

5개 카테고리로 분류된 컴포넌트 팔레트에서 선택해 배치합니다.

카테고리 용도 예시
Layout 페이지 구조 잡기 Section, Container, Grid, Sidebar, Header, Footer
Content 텍스트·미디어 영역 Heading, Paragraph, Image, Video, Card, List
Controls 인터랙션 요소 Button, Input, Select, Checkbox, Toggle, Form
Elements 보조 UI 요소 Badge, Icon, Divider, Tooltip, Tag, Avatar
Blocks 복합 섹션 블록 Hero, Pricing Table, Testimonials, CTA, FAQ
04 기술

Annotation Format Schema 1.1

어노테이션에 kind 필드가 추가됐습니다. 에이전트가 뭘 해야 하는지 구조화된 데이터로 바로 파악합니다.

feedback

기존 피드백 모드. 화면 요소를 클릭해서 CSS 셀렉터·위치를 캡처한 마크다운을 생성합니다.

placement

컴포넌트 배치 모드. 타입, 픽셀 치수, 위치 좌표가 구조화된 데이터로 기록됩니다.

rearrange

섹션 재배치 모드. 드래그한 섹션의 셀렉터와 새 순서 정보가 에이전트에게 전달됩니다.

어노테이션 데이터 예시 (placement 타입)

json 
{
  "kind": "placement",
  "component": {
    "type": "Pricing Table",
    "category": "Blocks"
  },
  "position": { "x": 120, "y": 480 },
  "dimensions": { "width": 860, "height": 320 },
  "context": "가격표와 후기가 포함된 랜딩 페이지"
}
MCP 서버 연동
MCP 서버가 돌고 있으면 레이아웃 변경이 실시간으로 에이전트에게 전달됩니다. Claude Code나 Cursor 어느 에이전트든 동일하게 작동합니다.
