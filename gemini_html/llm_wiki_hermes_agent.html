01 — 개념 이해

LLM Wiki란 무엇인가?

Andrej Karpathy(전 Tesla AI 디렉터, OpenAI 공동창업자)가 2025년 발표한 지식 관리 패러다임. 기존 RAG(Retrieval-Augmented Generation)의 복잡성을 버리고, AI가 직접 마크다운 위키를 컴파일하고 유지하는 방식입니다.

💡

핵심 아이디어: "검색(Retrieval)"이 아닌 "컴파일(Compilation)"로 전환. AI가 원본 소스를 읽고, 개념·엔티티를 추출하고, 교차 참조된 위키 문서를 자동 생성합니다. 50번째 소스는 첫 번째 소스보다 극적으로 더 유용해집니다.

📚 LLM Wiki (Obsidian + Claude Code)
강점
  • 목적 있는 지식 큐레이션
  • 구조화된 위키 + 그래프 탐색
  • 교차 참조 자동 생성
  • 30+ 소스 → 94% 페이지 연결
한계
  • 노트북 앞에 앉아야만 사용 가능
  • 자동화 없음 (수동 /ingest 필요)
  • 세션 간 학습 없음
🤖 Hermes Agent (NousResearch)
강점
  • 24/7 항시 가동
  • 자동 스킬 생성 + 자기 개선
  • 크로스 세션 메모리 축적
  • 텔레그램/디스코드/슬랙 멀티 접근
한계
  • 지식을 구조적으로 큐레이션하는 구조 없음
  • 위키/지식 그래프 없음
  • 초기 온보딩 난이도 있음
✅

연동의 핵심: LLM Wiki = 도서관 (지식이 구조적으로 쌓이는 곳) / Hermes Agent = 사서 + 비서 (도서관을 활용하며, 스스로 학습하고, 어디서든 접근 가능)

06 — 사용법

단계별 구축 가이드

LLM Wiki × Hermes Agent 통합 세컨드 브레인을 처음부터 구축하는 순서입니다.

  • 1

    필수 도구 설치

    Obsidian, Claude Code, Hermes Agent, Graphify, Python 3.11+, Node.js 18+ 설치.

  • 2

    Obsidian 볼트 세팅 (LLM Wiki 기본)

    raw/, wiki/, output/, templates/, .claude/commands/ 디렉토리 구조 생성. CLAUDE.md에 인제스트 규칙 정의.

  • 3

    Hermes Agent 설치 및 초기 설정

    curl 설치 스크립트 실행 → hermes setup 으로 모델 프로바이더(OpenRouter 추천) + 텔레그램 설정.

  • 4

    Hermes ↔ Obsidian 볼트 연결 (핵심)

    ~/.hermes/config.yaml에 MCP Filesystem 서버 설정으로 볼트 파일 직접 접근 허용. 볼트 루트에 .hermes.md 프로젝트 컨텍스트 생성.

  • 5

    Hermes 커스텀 스킬 생성

    wiki-query (위키 검색 답변), wiki-ingest (자동 인제스트), wiki-lint (정합성 점검), wiki-collect (URL 자동 수집) 스킬 4종 생성.

  • 6

    크론 자동화 설정

    매일 밤 11시 자동 인제스트 + 매주 일요일 wiki-lint + 매주 월요일 주간 요약 → 텔레그램 알림.

  • 7

    Graphify 연동 + 텔레그램 게이트웨이 실행

    graphify wiki/로 지식 그래프 생성. hermes gateway로 텔레그램 봇 상시 실행.

bash Hermes 설치 + 초기화 
# 1. Hermes Agent 설치 (Linux/macOS/WSL2)
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

# 2. 초기 설정 (wizard 자동 실행)
hermes setup

# 3. 동작 확인
hermes
> 안녕, 잘 작동하나?

# 4. 텔레그램 게이트웨이 실행
hermes gateway setup   # BotFather 토큰 입력
hermes gateway         # 백그라운드: nohup hermes gateway &

  default: "anthropic/claude-sonnet-4"
  provider: "openrouter"

07 — Hermes 커스텀 스킬

LLM Wiki 운영을 위한 스킬 4종

자연어로 Hermes에게 요청하면 스킬을 자동 생성합니다. ~/.hermes/skills/ 에 마크다운으로 저장됩니다.

🔍

wiki-query

위키에서 질문에 답변. wiki/index.md → 관련 문서 탐색 → graph.json 참조 → 출처 명시 답변. 트리거: "위키에서 찾아줘"

📥

wiki-ingest

raw/의 미처리 파일 자동 정제. 개념/엔티티 추출 → wiki/ 업데이트 → index.md·log.md 갱신 → raw 파일 status: processed

🔧

wiki-lint

위키 정합성 자동 점검. 깨진 링크 수정 → index.md 누락 추가 → 스키마 위반 수정 → graphify 자동 업데이트

🌐

wiki-collect

URL 자동 수집 (Hermes 전용). 웹 내용 추출 → 마크다운 변환 → raw/inbox/ 저장 → "인제스트할까?" 확인. 텔레그램에서도 작동

08 — 자동화 루프

크론 기반 완전 자동화

Hermes의 내장 크론 스케줄러로 위키 유지보수 전 과정을 자동화합니다.

매일 밤 11시 — 자동 인제스트

raw/inbox 스캔 → 미처리 파일 발견 → wiki-ingest 실행 → wiki 업데이트 → graphify --update → 텔레그램 알림

매주 일요일 10시 — 정합성 점검

wiki-lint 실행 → 깨진 링크/스키마 위반 자동 수정 → graphify 업데이트 → 텔레그램 요약 보고

매주 월요일 8시 — 주간 요약

지난 주 wiki 추가/업데이트 문서 목록 → 새로 형성된 연결관계 요약 → 텔레그램 보고

수시 — 이동 중 텔레그램 수집

URL 전송 → wiki-collect 자동 실행 → raw/inbox 저장 → "인제스트할까?" 확인 → wiki-ingest 실행

09 — 역할 분담

Claude Code vs Hermes Agent — 언제 무엇을?

작업 우선 사용 이유
인제스트 (간단한 아티클) Hermes 언제든 가능, 자동화, 이동 중 텔레그램으로
인제스트 (복잡한 논문·대량) Claude Code 토큰 효율 + 정밀도, 터미널에서
쿼리 (빠른 질문) Hermes 모바일 접근, 24/7 가능
쿼리 (깊은 교차 분석) Claude Code 컨텍스트 윈도우 최대 활용
위키 구조 변경 Claude Code CLAUDE.md 규칙과 밀접
정기 유지보수 (lint) Hermes 크론 자동화, 무인 실행
아웃풋 생성 (PPT·보고서) Claude Code 큰 산출물, output/ 생성

10 — 트러블슈팅

자주 발생하는 문제와 해결법

🚫

볼트 파일 못 읽는 경우

config.yaml 경로를 ~/ 대신 절대 경로(/home/사용자/)로 수정. Hermes 재시작 후 > /reload-mcp 실행.

🔄

스킬이 작동 안 하는 경우

> /skills 로 스킬 목록 확인. > /reload-skills 로 재로딩. 스킬 파일이 ~/.hermes/skills/ 에 있는지 확인.

📊

graphify 실행 안 되는 경우

hermes > terminal "which graphify" 로 설치 확인. 없으면 > terminal "pip install graphify-ai"

📋

CLAUDE.md vs .hermes.md 충돌

충돌 없음. Claude Code는 CLAUDE.md, Hermes는 .hermes.md를 읽습니다 (.hermes.md가 우선순위 높음).

11 — 고급 활용

확장 가능성

🔬

RL 트레이닝 데이터 수집: Hermes에는 Atropos RL 환경이 내장되어, 위키 인제스트/쿼리 작업의 trajectory를 수집해서 커스텀 모델 파인튜닝에 활용 가능합니다. 장기적으로는 자신만의 개인화 모델을 만들 수 있습니다.

👥

팀 확장 (PLUR 플러그인): 여러 사람이 각자 Hermes를 운용하면서 공유 위키를 쓸 경우, PLUR 플러그인으로 에이전트 간 지식 공유가 가능합니다. 팀 세컨드 브레인으로 확장됩니다.

🧠

외부 메모리 프로바이더 연동: 기본 MEMORY.md(2,200자 제한)가 부족하면 hermes plugins에서 Hindsight, Mem0, Holographic 등 외부 메모리 프로바이더를 연결해 무제한 장기 기억을 구현할 수 있습니다.
