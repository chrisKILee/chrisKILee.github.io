Step 1

Figma → Next.js 자동 변환용
프롬프트 설계

Figma 노드를 Next.js App Router 기반의 재사용 가능한 React 컴포넌트로 변환하는 프롬프트 구조입니다.

필수 변환 규칙
  • React Functional Component 사용
  • TypeScript 기반
  • TailwindCSS className 사용 (inline style 금지)
  • Auto Layout → flex 변환
  • 절대 위치 최소화
  • 반응형 기본 포함 (sm, md, lg)
예시 프롬프트
Convert the selected Figma nodes into:
- Next.js App Router compatible React components
- TypeScript
- TailwindCSS only (no inline styles)
- Extract reusable components
- Use semantic HTML
- Responsive layout included (sm, md, lg)
출력 구조 예시
/app
  /components
    Hero.tsx
    Card.tsx
    Button.tsx
  /page.tsx
Step 2

Antigravity MCP 설정 예시

Claude Code에서 Figma MCP 서버를 연결하는 단계별 설정 가이드입니다.

설정 단계
1

Figma Personal Access Token 발급

Figma Settings → Security → Personal Access Tokens → Generate Token

2

File Key 확인

Figma 파일 URL에서 파일 키를 추출합니다.

https://www.figma.com/file/ABC123XYZ/MyDesign
                              ↑ 이 부분이 File Key
3

MCP 설정 JSON

~/.claude/claude_desktop_config.json 또는 프로젝트 MCP 설정에 추가합니다.

{
  "mcpServers": {
    "figma": {
      "command": "npx",
      "args": ["-y", "figma-mcp-server"],
      "env": {
        "FIGMA_ACCESS_TOKEN": "YOUR_TOKEN",
        "FIGMA_FILE_KEY": "YOUR_FILE_KEY"
      }
    }
  }
}
4

연결 테스트

Claude Code에서 아래 명령으로 연결을 확인합니다.

List frames in the current Figma file.
Show me the node tree.
⚠️ 자주 발생하는 오류
  • 401 Unauthorized → Personal Access Token이 잘못됐거나 만료됨
  • File not found → File Key가 틀렸거나 파일 접근 권한 없음
  • Empty response → 해당 파일에 대한 뷰어 권한 부족
