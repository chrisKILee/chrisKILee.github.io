02 — What's New

주요 신기능

Opus 4.6 대비 새롭게 추가·변경된 핵심 기능입니다.

🚀
xhigh 노력 수준
기존 low / medium / high에 xhigh가 추가되었습니다. 복잡한 코딩·에이전틱 작업에서 품질을 최우선으로 할 때 사용합니다.
🖼️
고해상도 비전 (3.75MP)
이미지 해상도가 1,568px → 2,576px으로 향상(3.3배). 픽셀 1:1 좌표 매핑으로 화학 구조, 기술 다이어그램, 스크린샷 분석 정밀도가 크게 개선됩니다.
💡
Adaptive Thinking
Extended thinking의 수동 budget 설정이 제거되고, 모델이 문제 복잡도에 따라 생각 깊이를 자동 조절하는 Adaptive 방식으로 전환됩니다.
🗂️
Task Budgets (베타)
에이전틱 루프 전체에 소프트 토큰 예산을 설정할 수 있습니다. 모델이 예산을 인지해 작업 범위를 자율 조정합니다. (최소 20k 토큰, 베타 헤더 필요)
🧠
새 토크나이저
성능 향상을 위한 신형 토크나이저가 도입됩니다. 단, 동일 텍스트 기준 토큰 사용량이 최대 35% 증가할 수 있어 마이그레이션 시 비용 테스트가 필요합니다.
1M
1M 토큰 컨텍스트
Opus 4의 200k에서 1M 토큰으로 대폭 확장. 추가 요금 없이 표준 가격에 제공됩니다. 멀티-세션 파일시스템 기반 메모리 능력도 향상됩니다.
03 — Migration

Breaking Changes

Opus 4 / Opus 4.6에서 마이그레이션 시 반드시 확인해야 할 변경사항입니다.

⚠️ 아래 파라미터를 그대로 유지하면 400 에러가 발생합니다. 마이그레이션 전 코드 점검이 필수입니다.
변경 항목이전 (Opus 4 / 4.6)Opus 4.7
temperature temperature: 0.7 완전 제거 — 설정 시 400 에러
top_p / top_k top_p: 0.9 완전 제거 — 설정 시 400 에러
Extended thinking budget budget_tokens: 10000 Adaptive으로 대체 — 수동 budget 제거
토큰 사용량 기존 토크나이저 최대 35% 증가 — 비용 재산정 필요
04 — API Usage

API 사용법

Anthropic SDK 기준 호출 예시입니다. (출처: 공식 docs.anthropic.com)

기본 호출

python
import anthropic client = anthropic.Anthropic() response = client.messages.create( model="claude-opus-4-7", max_tokens=128000, messages=[{"role": "user", "content": "복잡한 코드 리팩토링 작업"}] ) print(response.content)

xhigh + Adaptive Thinking

python
response = client.messages.create( model="claude-opus-4-7", max_tokens=128000, thinking={"type": "adaptive"}, output_config={"effort": "xhigh"}, # 신규: xhigh messages=[{"role": "user", "content": "어려운 알고리즘 문제"}] )

Task Budget (베타)

python
response = client.beta.messages.create( model="claude-opus-4-7", max_tokens=128000, output_config={ "effort": "high", "task_budget": {"type": "tokens", "total": 128000}, }, messages=[{"role": "user", "content": "코드베이스 전체 리뷰 및 리팩토링 계획"}], betas=["task-budgets-2026-03-13"], )

07 — Use Cases

활용 사례

Opus 4.7이 특히 강점을 발휘하는 작업 유형입니다. (출처: Anthropic 공식 발표)

💻
복잡한 소프트웨어 엔지니어링
긴밀한 감독 없이 장시간 코딩 작업 위임 가능. SWE-bench Pro 64.3%로 복잡한 실제 코드베이스 리팩토링에 최적화됩니다.
🤖
에이전틱 워크플로우
멀티턴·멀티일 프로젝트 관리, 자기 검증 후 결과 보고. Task Budgets로 예산 내 자율 작업 범위 조정이 가능합니다.
📊
고해상도 차트·이미지 분석
3.75MP 이미지 지원으로 화학 구조, 기술 다이어그램, 스크린샷을 픽셀 1:1 정확도로 이해합니다. CharXiv +13% 향상.
📄
문서 전문 처리
.docx 리드라인, .pptx 편집, 슬라이드 레이아웃 자동 검증. 1M 컨텍스트로 대용량 문서 전체를 한 번에 처리합니다.
🧬
과학·기술 추론
GPQA Diamond 94.2%로 박사급 과학 문제 해결 능력. 의학, 물리, 생물 등 전문 영역 추론에 활용됩니다.
🗄️
장문 컨텍스트 분석
1M 토큰(약 75만 단어)을 단일 컨텍스트로 처리. 법률 문서, 코드베이스 전체, 학술 논문 묶음 분석에 적합합니다.
