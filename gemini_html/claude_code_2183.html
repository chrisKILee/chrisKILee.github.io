신규 기능

7가지
1
트랜스크립트 검색
Ctrl+O → / → n/N

긴 세션에서 특정 대화를 찾으려면 끝없이 위로 스크롤해야 했습니다. 이제 Ctrl+O 로 트랜스크립트 모드에 진입한 뒤 / 를 누르면 검색창이 활성화됩니다. n / N 으로 매치 간 앞뒤 이동이 가능합니다.

Before
특정 내용 찾으려면 마우스로 수동 스크롤, 시간 낭비
After
Ctrl+O → / → 검색어 입력 → n/N 이동
2
팀별 정책 드롭인 디렉토리
managed-settings.d/

기존에는 managed-settings.json 하나로 전체 정책을 관리해야 했습니다. 이제 managed-settings.d/ 디렉토리에 팀별 JSON 파일을 넣으면 알파벳 순으로 자동 병합됩니다.

Before
팀별 정책 추가할 때마다 단일 JSON 파일 편집 → 충돌 위험
After
각 팀이 자신의 파일만 관리 → 자동 병합

예시 디렉토리 구조:

managed-settings.d/
  ├── 00-base.json          (기본 정책)
  ├── 10-security-team.json (보안팀 정책)
  └── 20-frontend-team.json (프론트엔드팀 정책)
3
플러그인 API 키 안전 저장
macOS Keychain / 보호 자격증명 파일

플러그인의 manifest.userConfig 에서 sensitive: true 로 표시한 설정값은 이제 macOS Keychain 에 암호화 저장됩니다. Windows/Linux 등 다른 플랫폼에서는 OS 보호 자격증명 파일에 저장합니다.

Before
API 키를 평문 설정 파일에 저장하거나 매번 직접 입력
After
플러그인 활성화 시 입력받아 OS 보안 저장소에 자동 보관
4
CwdChanged / FileChanged 훅 이벤트
반응형 환경 관리 (direnv 등)

작업 디렉토리(CwdChanged)나 파일(FileChanged)이 변경될 때 훅이 자동으로 실행됩니다. direnv처럼 디렉토리별로 환경 변수를 자동 로드하는 도구와 연동하기에 최적화되어 있습니다.

CwdChanged 훅 동작 흐름
5
응답 전 중단 시 입력 자동 복원
Interrupt → 입력 복원 → 수정 후 재전송

프롬프트를 전송하고 응답을 기다리다가 실수로 Esc 를 눌러 중단하면, 기존에는 입력했던 내용이 사라졌습니다. 이제 응답이 오기 전에 중단하면 입력이 자동으로 복원되어 바로 수정 후 재전송할 수 있습니다.

6
응답 중에도 /status 즉시 확인
큐 대기 없이 즉시 실행

기존에는 /status 명령이 Claude가 응답을 완료할 때까지 큐에 대기했습니다. 이제 응답이 진행 중인 상태에서도 즉시 실행됩니다. 긴 작업 중에도 현재 상태를 언제든 확인할 수 있습니다.

7
--resume 메모리 및 시작 속도 개선
대용량 세션 재개 최적화

대용량 세션을 --resume 으로 재개할 때 메모리 사용량과 시작 레이턴시가 개선되었습니다. 긴 작업 세션을 반복적으로 이어서 사용하는 경우 체감되는 차이가 있습니다.

버그 수정

3가지 (주요)
🔊
음성 모드 시작 시 1~8초 UI 멈춤
음성 입력이 활성화된 상태로 Claude Code를 시작하면 1~8초간 UI가 완전히 멈추는 문제가 있었습니다. 네이티브 오디오 모듈을 시작 시점에 즉시(eagerly) 로드하는 것이 원인이었으며, 지연 로드(lazy loading) 방식으로 전환하여 해결했습니다.
🖥️
유휴 상태 렌더링 깜빡임
몇 초간 아무 작업도 하지 않으면 화면이 빈 화면으로 순간 깜빡이는 현상이 있었습니다. 유휴 상태 렌더링 로직을 안정화하여 수정했습니다.
⏱️
대용량 파일 diff 무한 행
공통 라인이 거의 없는 매우 큰 파일을 diff할 때 프로그램이 멈추는(hang) 문제가 있었습니다. 이제 5초 타임아웃이 적용되며, 시간 초과 시 안전하게 폴백 처리됩니다.
🛡️

보안 강화

2가지
gitignore 디렉토리 스킬 탐색 제외
.gitignore 에 포함된 node_modules, .env 등의 디렉토리에서 스킬·플러그인이 로드될 수 있는 취약점이 수정되었습니다. 이제 Claude Code는 gitignore로 지정된 디렉토리를 스킬 탐색에서 완전히 제외합니다.
.mcp.json 서버별 승인 대화상자 복원
--mcp-config CLI 플래그가 allowedMcpServers / deniedMcpServers 로 설정된 관리형 정책을 우회할 수 있는 버그가 수정되었습니다. 첫 실행 시 MCP 서버별 승인 대화상자가 항상 올바르게 표시됩니다.
