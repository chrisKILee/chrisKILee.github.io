2
Problem
매번 같은 말, 또 하고 있지 않나요?
Claude에게 뭘 시키려면 항상 "TypeScript strict 모드로 해줘 / 함수형 컴포넌트만 써줘 / ~해요체로 응답해줘" 같은 프롬프트를 세션마다 복사해 붙여넣고 있진 않나요? 사실 이거, 자동화할 수 있어요.
3
Solution
파일 하나면 전부 해결돼요
프로젝트 루트에 CLAUDE.md 하나만 만들어두면 Claude가 대화할 때마다 자동으로 읽어요. 한 번만 적어두면 반복 지시는 끝이에요. # 코드 스타일 / ## 응답 규칙 / ## 프로젝트 정보 섹션으로 구성하면 됩니다.
4
Style
내 코드 규칙, 한 번 적으면 끝
스타일 가이드를 CLAUDE.md에 적어두면 매번 말 안 해도 알아서 지켜줘요. ✅ TypeScript strict 모드 ✅ 함수형 컴포넌트만 사용 ✅ 에러 핸들링 패턴 통일 ✅ Prettier + ESLint 규칙 ✅ ~해요체로 응답
5
Context
환경 설정부터 금지 규칙까지 한 번에
기술 스택(Next.js 14 · Supabase · Turborepo · Vercel · Tailwind CSS)은 물론이고, "하지 말아야 할 것"까지 정해둘 수 있어요. ❌ any 타입 사용 금지 ❌ console.log 남기기 금지 ❌ 자동 커밋 금지 ❌ README 자동 생성 금지
6
Compare
CLAUDE.md 하나로 이렇게 달라져요
똑같은 요청인데 프롬프트 길이가 완전히 달라요. Before: "TS strict 모드로 해줘 / 함수형 컴포넌트만 써줘 / ~해요체로 응답해줘 / 로그인 기능 만들어줘" → After: "로그인 기능 만들어줘" — 나머지는 CLAUDE.md가 알고 있으니까!
7
Start

프로젝트 파일(package.json · tsconfig.json · .eslintrc · next.config.js)을 자동으로 분석해서 CLAUDE.md를 알아서 만들어줘요. /init 명령어 하나로 바로 시작할 수 있어요. → CLAUDE.md created successfully!
