왜 만들었는가

수작업 라이선스 관리의 한계

세아그룹 수십 개 계열사의 Google Workspace 라이선스를 구글 시트 하나로 관리하다 보니 인사발령 때마다 담당자가 직접 시트를 수정해야 했고, 실수·누락이 반복되었습니다.

Before — 기존 방식

구글 시트 수동 관리

  • 인사발령 때마다 담당자가 직접 시트 수정
  • 계열사별 현황 집계를 수작업으로 확인
  • 월말 정산 시 엑셀 취합 후 수동 계산
  • 삭제·변경 이력 추적 불가, 감사 취약
  • 라이선스 잔여 현황을 실시간으로 파악 어려움
After — 이 시스템

DB 기반 자동화 플랫폼

  • 매주 목요일 밤 10시, 인사발령 시트를 자동 읽어 배치 처리
  • 계열사별 사용·잔여 현황을 대시보드에서 실시간 확인
  • 월별 정산 요약을 클릭 한 번으로 조회·다운로드
  • 모든 변경을 이력 테이블에 자동 기록 (감사 추적 가능)
  • 에러 건 별도 관리 및 수기 재처리 지원
주요 기능

5개 탭으로 구성된 관리 화면

대시보드부터 정산 관리까지, 라이선스 운영에 필요한 모든 기능을 하나의 화면에서 제공합니다.
현재 1~3번 기능이 구현 완료되었으며, 4~5번은 개발 진행 중입니다.

구현 완료
🗂️

라이선스 목록

이름·이메일·관리번호로 검색, 사용 상태(사용중/잔여/미사용)별 필터링. 비고 메모 수정 및 신규 라이선스 직접 등록을 지원합니다.

구현 완료
⚙️

배치 처리 현황

구글 시트에서 인사발령(등록/삭제) 데이터를 불러와 대기 목록에 적재. 담당자가 선택 항목을 일괄 Apply하면 이력 테이블에 자동 반영됩니다. 에러 건은 별도 수기 재처리.

구현 완료
🔍

이력 조회

할당·회수·수정·이관 등 모든 변경 이력을 이메일 키워드로 검색. 삭제된 데이터까지 포함한 완전한 감사 추적을 목표로 합니다.

개발 진행 중
💰

정산 관리

월별·계열사별 라이선스 수량과 일할 계산 금액을 자동 산출. 당월 시작·종료 건을 포함한 정산 내역서를 엑셀로 다운로드하는 기능을 개발 중입니다.

시각 증빙 — 실제 동작하는 화면

세아웍스 관리자 포털에 탑재된 GWS 라이선스 관리 화면입니다.
현재 더미 데이터로 테스트 진행 중이며, DB 연결 후 실데이터로 전환될 예정입니다.

대시보드 전체 4,702건 / 사용 4,586건 / 잔여 116건을 KPI 카드로 표시. 계열사별 스탠다드·플러스 사용·잔여 현황을 한눈에 확인.
라이선스 목록 사용자명·이메일·관리번호 검색 및 상태 필터. 계열사별 라이선스 현황을 페이지네이션으로 탐색.
배치 처리 현황 구글 시트에서 불러온 인사발령 데이터 대기열. 월별·회사별 필터, 선택 후 일괄 Apply 처리.
정산 관리 월별 계열사별 라이선스 수량 및 일할 계산 결과. 정산 조회 기능 개발 중.
신규 라이선스 수동 등록 계열사 코드·이메일·등급을 입력해 라이선스를 직접 추가. 이력 테이블에 자동 기록.
세아웍스 포털 통합 기존 세아웍스 관리자 포털 내에 '라이선스 관리' 메뉴로 자연스럽게 탑재.

Frontend

MS-SQL 세아웍스 개발 DB
