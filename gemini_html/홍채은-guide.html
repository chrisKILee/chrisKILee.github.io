문제 정의 · 배경

기존의 어려움

매달 홀딩스 시스템별 ITS 데이터를 항목·월별로 담당자가 직접 수동으로 취합·분류하는 반복 업무가 있었습니다. 1인당 약 60분이 소요되었고, 수작업 특성상 데이터 누락·오입력 등 휴먼에러 발생 위험도 존재했습니다.

자동화로 해결한 방식

GitHub Actions가 매월 3일 오전 8시에 자동으로 실행되어 ITS 시스템에 접속·조회·엑셀 다운로드를 처리합니다. 결과는 Google Drive에 자동 업로드되고, Make.com을 통해 담당자에게 메일로 자동 발송됩니다. 담당자는 결과 확인 후 복사·붙여넣기만 하면 됩니다.

주요 기능

ITS 자동 로그인·조회

Headless Chrome이 ITS 시스템에 자동 접속하여 세아홀딩스 필터로 전월 데이터를 조회합니다.

엑셀 2종 자동 다운로드

요청일자·처리일자 기준으로 각각 전월 데이터를 엑셀 파일로 자동 저장합니다.

Google Drive 자동 업로드

기존 파일을 정리하고 최신 엑셀 2개를 Drive에 자동 업로드합니다.

Make.com 메일 자동 발송

업로드 완료 후 Make.com Webhook으로 시스템 담당자에게 자동으로 메일을 발송합니다.

월별 자동 스케줄 실행

GitHub Actions cron으로 매월 3일 오전 8시(KST)에 사람 개입 없이 자동 실행됩니다.

GitHub 결과 자동 커밋

다운로드된 엑셀 파일을 GitHub 저장소에 자동으로 커밋하여 이력을 보관합니다.

AI 활용 방식 · 기술 스택

개발 방식

ChatGPT 등 AI 도구를 활용한 바이브코딩으로 Python 크롤러를 작성. Make.com 노코드 도구로 메일 자동화 연결.

GitHub Actions (cron) → Selenium (크롤링) → Google Drive API (업로드) → Make.com (메일 발송)
