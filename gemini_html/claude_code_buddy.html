Companion Bestiary

Claude Code 터미널 우측 하단에 서식하는 18종 디지털 생명체에 관한 완전한 기록

소스코드 유출로부터 복원 ✦ 2026-04-01 최초 목격 ✦ /buddy 로 소환
❧

2026년 4월 1일, 개발자들의 터미널 우측 하단 모서리에 무언가 나타나기 시작했다. 작고 조용한 존재들이었다. 버그를 지켜보고, 한숨 쉬고, 때로는 빈정대며 — 그러나 결코 토큰을 소비하지 않는 채로. Anthropic이 Claude Code의 npm 배포 시 소스맵을 함께 포함하는 실수를 저지르면서, 이 생명체들의 존재가 세상에 드러났다.

원본 소스코드 파일 buddy/companion.ts에는 18종의 생명체, 5가지 기질 지표, 5등급의 희귀도 체계, 그리고 Mulberry32 의사난수 생성기(PRNG)로 작동하는 결정론적 소환 메커니즘이 기록되어 있었다. 만우절 이스터에그로 시작된 이 시스템은, 유출과 함께 즉각 인터넷의 화제가 되었다.

Nota Bene — 결정론적 소환의 원리

각 개발자의 동반자는 사용자 계정 ID를 시드(seed)로 한 Mulberry32 PRNG에 의해 결정된다. 같은 계정이라면 언제나 같은 종족, 같은 이름, 같은 스탯의 생명체가 소환된다. 다만 이름은 /buddy [이름] 명령으로 변경 가능하다. 종족과 스탯은 계정에 고정되어 변경되지 않는다.

다섯 가지 기질 — De Quinque Virtutibus

모든 동반자는 다섯 가지 기질 지표를 0에서 100 사이의 값으로 보유한다. 이 수치들은 생명체가 당신의 코드와 버그를 어떻게 바라보는지를 결정한다.

희귀도의 위계 — De Gradibus Raritatis

다섯 등급의 희귀도가 존재하며, 각 등급은 스탯의 최솟값과 최댓값 범위를 결정한다. 높은 등급일수록 더 강한 기질을 보유하지만, 그만큼 만나기 어렵다. Shiny 변종은 희귀도와 무관하게 별도 1% 확률로 판정된다.

Nota Bene — Shiny 변종

희귀도와 별도로, 1%의 확률로 Shiny 변종이 소환될 수 있다. 소스코드에서 String.fromCharCode() 인코딩을 사용하여 빌드 시스템의 grep 검사를 우회하도록 설계된 유머러스한 보안 조치가 함께 발견되었다.

18종 생명체 — Catalogus Bestiarum
