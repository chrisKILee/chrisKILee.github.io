Operation & Strategy

💡 서버 리부팅 불필요 (No-Reboot)

아니오. 운영 중인 서버의 시스템 재시작은 전혀 필요하지 않습니다. 에이전트는 독립적인 바이너리 서비스로 가동됩니다. 설치 후 윈도우 서비스(Services.msc) 등록 및 서비스 '시작'만으로 즉시 데이터 수집이 시작되며 운영 안정성을 보장합니다.

⚙️ 프로그램 개발 불필요 (No-Code)

아니오. 100% 설정(Configuration) 기반 작업입니다. 이미 검증된 바이너리를 활용하며, YAML 또는 River 설정 파일에서 필요한 항목을 true/false로 선택하고 IP 정보를 입력하는 텍스트 편집 작업이 구축의 전부입니다.

🔌 원격 수집 전략 (Remote Pull)

Windows 2003 등 에이전트 설치가 불가능한 서버는 Alloy Gateway에서 원격으로 지표를 당겨오는 WMI(Windows Management Instrumentation) 방식을 사용하여 데이터 가시성을 확보합니다.

📦 에이전트 버전 최적화

Windows 2012+는 최신 8.x 버전을, 2008 R2는 검증된 마지막 안정 버전인 Metricbeat 7.17 (LTS)를 사용하여 구형 OS에 대한 시스템 안정성을 최우선으로 확보합니다.

🖥️ Windows Server 상세 지표 카탈로그

Compute & Memory Resources
  • CPU Performance: User/System Time, Idle Time, Interrupts/sec, DPC Time, Context Switches, Processor Queue Length
  • Memory Metrics: Available/Used Bytes, Committed Limit, Pagefile Usage, Pool Paged/Non-paged, Cache Bytes, Pages/sec
  • System Health: System Uptime, Thread Count, File/Process Handles, Local Time Offset, Paging File %
Storage & Network Services
  • Logical Disk Stats: Free Space %, Bytes Read/Write, Average Latency (Read/Write), Disk IOPS, Transfer Length, Queue Depth
  • Network Analysis: Bytes Sent/Received, Packets/sec, Output Queue Length, Discards/Errors per Interface, Connection Table
  • Services & Apps: Running/Stopped Status, Start Mode, Specific Process CPU/Memory Footprint, IIS Worker Health

💾 Oracle DB 상세 지표 카탈로그

Storage & Instance Health
  • Tablespace Analytics: Total/Used Space %, Auto-extend Status, Max Size limit, Fragmentation, Free MB per Datafile
  • Disk File I/O: Physical Reads/Writes, I/O Time per Datafile, Status (Online/Offline/Recovery), Redo Log Switches
  • Instance Core: Database Status, Archiver Status, Log Sequence, SGA/PGA Allocations, Instance Uptime, Version Info
Performance & Activity
  • Session Tracking: Active/Inactive Sessions, Background Sessions, Session Limit %, Long Running Queries, Blocking Locks
  • Wait Event Profiling: DB File Sequential Read, Log File Sync, System Waits, CPU Time vs Wait Time, Library Cache Contention
  • Efficiency Ratios: Buffer Cache Hit Ratio, Library Cache Hit, Hard/Soft Parse Ratio, Transactions/sec, Rollback Segment usage
