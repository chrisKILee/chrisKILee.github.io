😣 문제 정의 · 배경

❗ 기존의 어려움

  • 🔹 백업일지 작성 — 매일 1시간 수작업 집계
  • 🔹 Veeam 상태 확인 — 콘솔 직접 접속 30분 소요
  • 🔹 서비스 모델 파악 — 스프레드시트 대조 2시간 이상
  • 🔹 이상 발생 인지 지연 — 실시간 모니터링 수단 없음
  • 🔹 용량 산정 — 신규 백업마다 10분 수동 계산

✨ AI로 해결한 방식

  • ✅ 통합 대시보드 — 모든 KPI를 한 화면에서 5분 내 확인
  • ✅ Ansible 로그 자동 파싱 → 백업일지 HTML 자동 생성
  • ✅ Gemini AI 분석 — 일일 현황 자동 리포트 생성
  • ✅ Google Chat 실시간 알림 — 실패/경고 즉시 수신
  • ✅ 용량 계산기 — 클릭 몇 번으로 1분 내 산정

③ 업무 효율성 28/30

백업일지 1시간→5분(92%↓), Veeam 확인 30분→5분(83%↓), 서비스 모델 파악 2시간→5분(96%↓) — 수치 근거 명확하며 실운영 중. 가점 +3점 적용.

④ 아이디어 적절성 23/25

분산된 백업 관리 도구를 단일 플랫폼으로 통합하는 명쾌한 해결 방식. 기존 Docker/Nginx 인프라를 활용한 현실적 접근. AI(Gemini) 활용 범위가 분석 리포트에 집중되어 있어 추가 확장 여지 있음.

⑤ 확산 가능성 19/25

브라우저 + Google OAuth만으로 비개발자 접근 가능. RBAC 4단계로 영업기획팀·고객사까지 권한 분리. Docker 운영 환경 필요로 타 부서 독립 배포에 진입 장벽 존재.

⑥ 조직 목표 연결 17/20

플랫폼인프라팀 부서 목표 "AI 활용 고도화 및 업무 효율화"와 직접 연계. 팀 전체 반복 수작업 제거 + 고객사까지 가시성 제공. 향후 월간 보고서·주간일지 고도화 계획 명시.
