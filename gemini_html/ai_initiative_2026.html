Six Pillars of the Initiative

From hands-on AI tasks to secure infrastructure — each pillar drives adoption at a different layer of the organization.

🤖

AI-WORKER Program

Company-wide AI task challenge. Every employee submits a real work use case, building hands-on AI fluency across all departments.

✨

Gemini for Workspace

Official Google AI integrated across Gmail, Docs, Sheets, and Meet. Opt-out is managed org-wide by the admin — no individual setup required.

🏠

SEAH AI Chat

Internal AI system hosted on-prem. Data stays inside VNTG infrastructure — the recommended tool for sensitive tasks and confidential documents.

🔑

Gemini API Access

Personal API keys for development experiments and prototypes. Issued per-person for usage tracking. For calling AI from code — not a replacement for chat tools.

☁️

Cloud Run Hosting

GCP-powered serverless hosting for approved AI projects. Requires manager sign-off. Costs are attributed to the requesting department.

📚

AI Culture & Learning

Shared knowledge hub, best-practice guides, and peer learning across teams. Use cases are documented and circulated company-wide after each AI-WORKER cycle.

Which Tool Should I Use?

A quick decision guide for choosing the right AI tool for the job.

Situation Recommended Tool Why
General Q&A, drafting, summarizing Gemini (Workspace) Official tool, opt-out auto-applied via org admin
Analyzing confidential docs or internal data SEAH AI Chat On-prem hosted — data never leaves VNTG
Uploading & deep-diving into documents/PDFs NotebookLM Use Workspace account — content not used for training
Calling AI from code (analysis, auto-review) Gemini API Request a personal API key from the infra team
Hosting an approved AI project publicly Cloud Run Requires manager approval; costs go to your department

FAQ

Is my data safe when using Gemini?

When using Gemini through your VNTG Workspace account, the org admin has applied data opt-out settings — your inputs are not used to train Google's models. Always use your Workspace account, not a personal Google account.

What is the AI-WORKER program?

AI-WORKER is VNTG's company-wide initiative where every employee submits one real AI use case from their day-to-day work. Outstanding submissions are reviewed by a committee (led by the CTO) and recognized company-wide.

How do I get a Gemini API key?

Contact the infra team (이동열 매니저) to request a personal API key. Keys are issued per-person for usage tracking. This is for programmatic use (calling AI from code), not for chat.

Can I deploy my AI project on GCP?

Yes, with manager approval (team lead or center head). Cloud Run hosting is available for personal projects. Costs are attributed to your department, so make sure your manager is aligned before requesting.
