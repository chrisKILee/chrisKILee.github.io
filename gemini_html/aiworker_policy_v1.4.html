1. 프로젝트 목표

AI-WORKER Project는 전 직원이 AI에 대한 친밀성을 갖고, 자기 업무의 효율성을 위해 AI를 자신 있게 활용할 수 있는 수준을 목표로 한다.

LEVEL 3 — Workflow Integrator

업무 자동화 사용자

AI 도구를 업무에 적용하여 실질적인 효율화를 달성한 수준.

기존의 수작업 프로세스(예: 주간 보고 데이터 자동 취합, 티켓 자동 분류/요약 등)를 API·자동화 도구와 연결하여 사람의 개입 없이 자동으로 처리되도록 구현할 수 있어야 한다.

LEVEL 4 — Solution Builder

솔루션 제작자

AI를 주도적으로 활용하여 팀·조직 단위 효율화를 이끄는 수준.

단순한 업무 자동화를 넘어, 독립적인 기능을 수행하는 AI 기반 프로토타입/솔루션(예: 사내 기술지원 챗봇 PoC, 데이터 자동 분석 대시보드 등)을 직접 기획하고 구현할 수 있어야 한다.

💡 과제의 평가 레벨이 개인의 역량 레벨과 동일하지 않습니다. 목표 LEVEL 3·4 달성을 통해 AI 활용 자신감을 갖는 것이 핵심입니다.

4. AI 도구 지원 정책

왜 이 도구들인가?

🤖
왜 Claude인가
AI-WORKER 내부 테스트 결과, Claude는 한국어 업무 맥락 이해와 코드 작성·리뷰 영역에서 가장 높은 품질을 보였습니다. 단순한 질의응답을 넘어 복잡한 업무 흐름을 파악하고 맥락에 맞는 결과물을 만들어 내는 능력이 구성원들의 실무 생산성과 직결됐습니다. Claude Code는 실제 프로젝트 코드를 이해하고 자율적으로 작업을 수행하는 에이전트 방식으로, 단순 자동완성 수준을 넘어선 개발 경험을 제공합니다. 또한 테루아가 제공하는 개발 방법론과 템플릿들이 Claude에 최적화되어 있습니다.
⚡
왜 Antigravity인가
처음에는 Cursor를 도입했지만, 개인 계정 기반 구조로 인해 팀 단위 계정 관리가 어렵고, 이를 해결하려면 Team Plan으로 전환해야 하는데 동일 사용량 대비 약 2배의 비용이 발생하는 구조적 문제가 있었습니다. 반면 Antigravity는 프리뷰 기간 동안 대부분의 기능을 무료로 제공하고 있어, 구성원 각자가 개별 계정을 사용하더라도 별도의 비용이 발생하지 않습니다. 관리가 필요한 비용 자체가 없으니 계정 관리 부담도 자연히 사라집니다. Claude 기반의 동일한 AI 품질을 유지하면서 비용 부담 없이 도입할 수 있어, 현 단계에서 가장 합리적인 선택입니다.

운영 원칙

👤 개인별 API Key 발급: 추적·모니터링 목적으로 반드시 개인 Key를 사용합니다.
🔔 한도 및 알림 설정: 각 API Key별 사용 한도(limit) 및 알림 설정. 한도 초과 시 인프라 담당자에게 알림.
📉 사용량 현저히 감소 시: 사용자에게 확인 후 미사용 확인되면 Key Expire 처리.
🏭 상용 프로덕트: 개인 Gemini API가 아닌 Vertex AI 등 별도 솔루션 검토를 권장합니다.

AI API 비용 안내

📌 여기서의 AI API는 개인 프로젝트 코드에서 Gemini API로 AI 분석을 요청할 때 사용하는 API Key입니다.
(예: 데이터를 넘기고 인사이트 요약 작성 요청, 결과물 자동 리뷰 생성 등)
※ SEAH AI Chat(웹 채팅 UI)과는 별개 — 코드에서 직접 AI에게 분석·생성 작업을 요청하는 경우에 해당합니다.
💸 Gemini AI Studio API: 소규모 학습·실험 목적에 적합. 월 사용량에 따라 비용 변동. 개인별 Key를 통해 부서별 사용량을 추적합니다.

운영의 주체

🏢 운영의 주체는 승인 부서입니다. AI-WORKER는 모두가 함께 만들어가는 프로젝트인 만큼, Cloud Run 서비스도 부서 내 누구나 운영할 수 있어야 합니다.
🗑️ 미사용 서비스 종료: 불필요한 비용 발생을 방지하기 위해, 사용하지 않는 서비스는 해당 부서에서 직접 종료 요청을 합니다.
🔄 부서 내 기술 이전 필수: 운영자 퇴사나 조직 변경 시에도 서비스가 단절되지 않도록, 운영 지식은 반드시 부서 내에 공유·이전되어야 합니다.
