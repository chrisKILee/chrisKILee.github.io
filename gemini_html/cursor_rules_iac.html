# .cursor/rules/ 디렉토리 구조

RND-INFRA/
├── AGENTS.md              # AI 에이전트 전역 가이드
└── .cursor/rules/
    ├── README.md          # 전체 사용 가이드
    ├── meta/              # 전역 · 항상 적용 (alwaysApply)
    │   └── global.mdc
    ├── iac/               # Terraform / IaC
    │   └── terraform.mdc
    ├── gcp/               # GCP 리전 · CIDR · 비용
    │   └── gcp.mdc
    ├── argocd/            # ArgoCD App · GitOps 브랜치
    │   └── argocd.mdc
    ├── k8s/               # K8s 구조 · values · 운영
    │   └── k8s.mdc
    └── docs/              # ADR · 아키텍처 인덱스
        └── docs.mdc

# 진화 과정
① .cursorrules  (단일 파일)
        ↓
② AGENTS.md + .cursor/rules/  (.mdc 배치)
        ↓
③ 기술스택별 하위 디렉토리 분리
        ↓
④ globs + alwaysApply 설정 최적화
🌐

meta/ alwaysApply

모든 작업에 항상 적용되는 전역 규칙. 프로젝트 컨텍스트, 커밋 컨벤션, 공통 패턴을 담습니다.

🏗️

iac/ globs: iac/**

Terraform 코딩 규칙. 리소스 네이밍, variables.tf 구조, 모듈 패턴, 상태 관리 가이드.

☁️

gcp/ globs: infra/gcp/**

GCP 리전·CIDR·비용 기준. 아키텍처 문서(@문서 연동)를 참고해 네트워크 코드를 생성합니다.

🚀

argocd/ globs: k8s/argocd/**

ArgoCD Application 구조, GitOps 브랜치 전략, reloader 패턴 등 배포 규칙.

⚙️

k8s/ globs: k8s/**

K8s 디렉토리 구조, 클러스터/values 작성 기준. Observability·Kafka 가이드 포함.

📝

docs/ globs: docs/**

ADR 작성 형식, 아키텍처 문서 인덱스. @문서 멘션 시 AI가 자동으로 참고합니다.

💡 Cursor Rules vs Gemini Gems — 역할 분담

두 도구는 경쟁 관계가 아니라 상호 보완입니다.

  • Gemini Gems (2종) — 브라우저/채팅 단발 조언. 설계 아이디어, 코드 리뷰 질문, 빠른 확인에 활용.
  • Cursor Rules — IDE 안에서 파일 맥락과 함께 일관 적용. 실제 코드 작성 시 규칙이 자동 주입됩니다.
  • Cursor 없이 Gems만 써도 되고, Cursor를 쓰면 Rules까지 함께 적용되어 더 빠르게 작업할 수 있습니다.
🤖 AI 활용 증빙
실제 업무에서 Cursor Agent가 어떻게 동작했는지 두 가지 사례입니다.
1

Terraform 모듈 추가 — @파일 멘션으로 코드 자동 생성

신규 GCP 리소스를 추가할 때 아키텍처 문서와 IaC 규칙을 직접 @로 붙이자, Agent가 변수·리소스 블록을 한 번에 제안했습니다.

@docs/architecture/gcp-network-cidr.md @iac/terraform.mdc

→ Agent가 variables.tf / main.tf 블록 자동 제안
→ 검토 후 PR에 반영
✓ 맥락 재설명 없이 규칙에 맞는 코드가 바로 생성됨. 네이밍·구조 수정 최소화.
2

dev 환경 VPN 구성 — 디렉토리 멘션으로 완전 자동 생성

VPN 신규 구성 시 현재 네트워크 디렉토리를 멘션하자, Agent가 CIDR 문서와 Terraform Rules를 스스로 참고하여 코드와 문서를 모두 생성했습니다.

@infra/gcp/envs/dev/host_project/dev-network

→ Agent가 자동으로 참고:
  docs/architecture/gcp-network-cidr.md
  iac/terraform.mdc

→ vpn.tf + README-VPN.md 생성
✓ 코드 + 문서 동시 생성. 기존 3일 작업이 1일로 단축.

온보딩 표준화

신규 입사자에게 AGENTS.md + .cursor/rules/README.md만 공유하면 첫 Terraform PR까지 스스로 진행할 수 있습니다.

🤝

Gems와 역할 분담

Cursor 없이 Gems만 쓰는 팀원도 ok, Cursor를 쓰면 Rules까지 자동 적용. 도구 선택의 자유를 유지하면서 표준을 공유합니다.
