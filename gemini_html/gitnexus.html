GitNexus

코드베이스 전체를 지식 그래프로 변환하는 서버리스 코드 인텔리전스 엔진. 브라우저만으로 의존성·호출 체인·실행 흐름을 시각화하고 AI 에이전트와 대화하며 코드를 탐색합니다.

📅 2025년 출시 ⭐ 17.5k GitHub Stars GitHub → Web UI →
💡 핵심 가치: 인덱싱 시점에 코드 구조를 사전 계산하여 단일 AI 도구 호출로 완전한 컨텍스트를 제공합니다. 여러 LLM 쿼리 없이 소형 모델도 효과적으로 작동하며 토큰 소비를 대폭 절감합니다.

주요 기능

GitNexus는 GitHub 레포 URL이나 ZIP 파일만으로 코드베이스의 전체 구조를 분석해 지식 그래프로 시각화합니다.

🕸️
지식 그래프 시각화
의존성, 호출 체인, 실행 흐름을 인터랙티브 그래프로 한눈에 확인. Leiden 커뮤니티 감지로 모듈 클러스터링 자동화.
🤖
AI 에이전트 대화
그래프 위에서 AI와 직접 대화하며 코드 탐색. Claude Code와 완전 통합되어 지능형 코드 분석 제공.
🔌
MCP 프로토콜 지원
7개의 MCP 도구로 외부 AI 도구와 연결. 쿼리, 컨텍스트, 영향 분석, 변경 감지, 이름 변경 등 지원.
📚
자동 위키 생성
레포지토리 구조를 분석해 위키를 자동 생성. 새 팀원 온보딩과 문서화 작업 시간을 대폭 단축.
🔍
하이브리드 검색
BM25 + 시맨틱 검색 + 상호 순위 융합(RRF) 조합으로 정확도 높은 코드 검색 및 컨텍스트 추출.
🔒
100% 로컬 처리
서버로 코드가 전송되지 않음. LadybugDB(WASM)로 브라우저 내에서 완전히 로컬 처리. 보안 민감 레포도 안심.

🚀 시작하기

CLI 설치 & 사용법

npx 명령어 하나로 즉시 시작. 패키지 전역 설치 없이도 사용 가능합니다.

빠른 시작 (3분)

  1. 저장소 인덱싱
    분석할 레포 디렉토리에서 실행. Tree-sitter로 AST를 추출하고 지식 그래프를 빌드합니다.
  2. 에디터 MCP 설정
    Claude Code, Cursor, Windsurf 등 지원 에디터에 MCP 서버를 자동으로 등록합니다.
  3. AI와 코드 탐색
    에디터의 AI 어시스턴트가 GitNexus의 7개 MCP 도구를 활용해 코드 전체를 이해하며 답변합니다.
  4. 로컬 UI로 시각화
    gitnexus serve 명령으로 로컬 웹 서버를 실행해 그래프 UI에서 의존성과 호출 체인을 확인합니다.

CLI 명령어

# 1. 현재 디렉토리 레포 인덱싱 npx gitnexus analyze # 2. MCP 에디터 자동 설정 (Claude Code, Cursor 등) gitnexus setup # 3. MCP 서버 직접 시작 gitnexus mcp # 4. 로컬 HTTP 백엔드 실행 (Web UI와 연결) gitnexus serve

7가지 MCP 도구

도구명기능
query자연어로 코드베이스 검색. 관련 코드 컨텍스트 반환.
get_context특정 파일/함수의 전체 컨텍스트 (의존성, 호출처 포함) 반환.
analyze_impact변경 시 영향받는 코드 범위 사전 분석.
detect_changesgit diff 기반으로 변경된 부분의 의존성 체인 탐지.
rename함수/변수 이름 변경 시 모든 참조처를 자동으로 찾아줌.
find_usages특정 심볼이 사용된 모든 위치 추적.
generate_wiki코드 구조 기반 레포지토리 위키 자동 생성.
✅ Claude Code 완전 통합: gitnexus setup 실행 시 Claude Code MCP + skills + hooks가 자동으로 설정됩니다. 가장 높은 수준의 통합을 제공합니다.
🌐 Web UI

브라우저 기반 그래프 탐색

설치 없이 gitnexus.vercel.app에서 즉시 사용. GitHub 레포 URL이나 ZIP 파일만 있으면 됩니다.

Web UI 사용 방법

  1. gitnexus.vercel.app 접속
    브라우저에서 직접 접속. 계정 생성이나 로그인 불필요.
  2. GitHub URL 또는 ZIP 업로드
    공개 레포는 URL 입력만으로 분석 시작. 비공개 레포는 ZIP으로 다운로드 후 업로드.
  3. 지식 그래프 탐색
    파일 간 의존성, 함수 호출 체인, 실행 흐름을 인터랙티브 그래프로 탐색. 노드 클릭으로 상세 정보 확인.
  4. AI 에이전트와 대화
    그래프 UI에서 직접 AI와 대화. "이 함수가 어디서 호출돼?" 같은 자연어 질문으로 코드 탐색.

🔧 MCP 통합

에디터 & AI 도구 연동

Model Context Protocol(MCP)을 통해 Claude Code, Cursor, Windsurf 등 주요 AI 에디터와 완전 통합됩니다.

MCP 설정 방법

# 자동 설정 (권장) — 에디터 자동 감지 gitnexus setup # 수동 MCP 서버 실행 gitnexus mcp # Claude Code에 수동 추가 시 claude mcp add gitnexus -- gitnexus mcp

MCP 통합 활용 예시

Claude Code에서 GitNexus 활용

  • "이 함수를 변경하면 어떤 파일들이 영향을 받아?" → analyze_impact 도구 자동 호출
  • "결제 관련 코드가 어디 있어?" → query 도구로 시맨틱 검색
  • "AuthService가 어디서 사용돼?" → find_usages 도구로 전체 참조 추적
  • "이 레포 전체 구조 설명해줘" → generate_wiki 도구로 자동 위키 생성
  • "UserModel 이름을 Member로 바꾸려면?" → rename 도구로 모든 참조처 파악
🔌 MCP란? Model Context Protocol은 AI 에이전트가 외부 도구와 표준화된 방식으로 통신하는 프로토콜입니다. GitNexus는 이 프로토콜을 통해 AI가 코드베이스의 구조 정보를 정확하게 가져올 수 있게 합니다.

언제 쓰면 좋을까?

새 프로젝트 온보딩부터 레거시 코드 파악, 리팩토링까지 다양한 상황에서 실용적으로 활용할 수 있습니다.

주요 활용 사례

🆕
새 프로젝트 온보딩
처음 투입된 레포의 전체 구조를 빠르게 파악. "이 서비스가 뭘 하는 거야?" 수준의 질문부터 세부 의존성까지 한 번에 이해.
🏚️
레거시 코드 분석
문서가 없는 오래된 코드베이스의 구조를 자동으로 역문서화. 호출 체인 시각화로 변경 영향 범위 파악.
🔁
리팩토링 안전망
함수/클래스 변경 전 영향 범위를 analyze_impact로 사전 확인. 예상치 못한 사이드 이펙트 방지.
🔎
코드 리뷰 보조
PR 변경사항이 코드베이스에 미치는 영향을 자동 분석. 리뷰어가 놓칠 수 있는 간접 의존성까지 탐지.
📖
문서 자동화
generate_wiki로 레포지토리 전체 위키 자동 생성. API 문서, 아키텍처 다이어그램 작성 시간 절약.
🤝
팀 협업
Web UI로 그래프를 팀원과 공유. 특정 모듈의 의존성을 시각적으로 설명하며 기술 부채 논의.

실제 사용 흐름 예시

레거시 Node.js 서비스 분석 시나리오

  • gitnexus.vercel.app에 GitHub URL 입력 → 즉시 그래프 생성
  • 그래프에서 "결제 모듈" 클러스터 클릭 → 관련 파일 목록 확인
  • AI에게 "이 결제 흐름 설명해줘" → 호출 체인 기반 자동 설명
  • "PaymentService를 수정하면 어디가 깨져?" → 영향 범위 즉시 파악
  • generate_wiki로 해당 모듈 문서 자동 생성 → Confluence 업로드
