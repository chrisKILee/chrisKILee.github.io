What is it
AI Website Redesign이란?
Shuffle.dev가 만든 도구로, 기존 웹사이트 URL을 입력하면 여러 AI가 동시에 새 디자인을 생성해 나란히 비교할 수 있다.
💡
핵심 개념 — AI가 전체 작업의 약 80%를 처리하고, Shuffle의 드래그&드롭 에디터로 나머지 20%를 완성하는 방식이다. 디자인 결정을 "AI에게 물어보는" 추상적 과정이 아니라, 실제 시각 결과물을 나란히 놓고 선택하는 형태로 바꿔준다.
🔗
URL만 붙여넣으면 끝
기존 사이트 주소와 "이렇게 바꿔줘"라는 짧은 설명만 입력하면 된다. 디자인 파일이나 코드가 없어도 시작 가능하다.
⚡
4개 AI 동시 생성
Claude, GPT, Gemini, Kimi가 동일한 프롬프트를 받아 독립적으로 해석한다. 각 AI마다 다른 "취향"과 스타일이 나온다.
🖱️
시각적 편집기 연동
마음에 드는 AI 결과물을 선택하면 Shuffle 에디터로 바로 열린다. 드래그&드롭으로 세부 조정 — CSS 없이도 가능하다.
💾
프로덕션 코드 내보내기
Next.js, Laravel, WordPress, HTML/CSS 형식으로 내보내기 가능. 실제 프로젝트에 바로 사용할 수 있는 코드가 나온다.
How to Use
단계별 사용법
처음 써본다면 이 순서대로 따라하면 된다.
1
사이트 URL 입력
shuffle.dev/ai-website-redesign 에 접속해서 바꾸고 싶은 웹사이트 주소를 붙여넣는다. 공개된 URL이면 어떤 사이트든 사용 가능하다.
🔒 로그인이 필요한 사이트나 localhost는 Chrome/Firefox 브라우저 확장 프로그램을 설치하면 된다.
2
프롬프트 작성
어떻게 바꾸고 싶은지 설명한다. Prompt Builder 기능을 쓰면 더 구체적인 프롬프트를 구성하는 데 도움을 받을 수 있다.
💡 구체적일수록 좋다. "모던하게" 보다 "다크 배경에 흰 텍스트, 버튼을 파란색으로, 섹션 간격을 넓게"가 더 좋은 결과를 낸다.
3
4개 결과 나란히 비교
Claude, GPT, Gemini, Kimi 각각의 해석이 side-by-side로 표시된다. 같은 프롬프트를 받아도 결과가 다르기 때문에 실용적인 AI 모델 비교 기준이 된다.
4
마음에 드는 것 선택 후 편집
가장 마음에 드는 디자인을 선택하면 Shuffle 비주얼 에디터로 열린다. 레이아웃, 컴포넌트, 색상, 타이포그래피를 코드 없이 조정한다.
5
코드 내보내기
Next.js, Laravel, WordPress, 또는 순수 HTML/CSS 중 필요한 형식을 선택해서 코드를 다운로드한다. 실제 프로젝트에 바로 사용할 수 있다.
좋은 프롬프트 vs 나쁜 프롬프트
나쁜 프롬프트 예시
모던하게 바꿔줘
예쁘게 만들어줘
더 좋게 해줘
좋은 프롬프트 예시
어두운 배경(#0f0f0f)에 흰색 텍스트. 메인 CTA 버튼은 노란색. 섹션 간격을 현재의 2배로 늘리고, 폰트를 Inter로 통일해줘.
SaaS 스타트업 스타일로. 히어로 섹션 제목을 크게 키우고, 가격표를 눈에 띄게 만들어줘. 소셜 프루프 섹션 추가.
기존 레이아웃은 유지하되 색상만 바꿔줘. 파란색 계열 대신 초록색 계열로. 둥근 버튼, 그림자 없이.
✓
Prompt Builder 활용 — 처음엔 어떻게 써야 할지 막막할 수 있다. Shuffle의 Prompt Builder가 질문을 던지며 프롬프트를 구성해준다. 먼저 이걸 써보는 게 좋다.
AI Models
4개 AI의 특성 비교
같은 프롬프트를 줘도 각 AI마다 결과 스타일이 다르다. 어떤 AI가 어떤 경향이 있는지 알면 더 빠르게 원하는 결과를 찾을 수 있다.
Anthropic
Claude
구조적이고 읽기 쉬운 레이아웃을 선호하는 경향. 콘텐츠 계층을 명확하게 표현하며, 접근성을 고려한 디자인을 잘 만든다.
OpenAI
GPT
트렌디하고 상업적인 느낌의 디자인을 자주 생성. SaaS 랜딩 페이지나 마케팅 사이트 스타일에 강하다.
Google
Gemini
Material Design 영향을 받은 정제된 스타일. 컴포넌트 일관성이 높고 구글의 디자인 언어를 자연스럽게 반영한다.
Moonshot AI
Kimi
동아시아 스타일에서 영향을 받은 독특한 해석을 보여주는 경우가 있다. 다른 AI와 가장 다른 결과가 나올 때가 많다.
💡
각 AI는 같은 URL과 프롬프트를 받아도 서로 다른 "취향"으로 해석한다. 하나만 써보는 것보다 4개를 동시에 비교하는 것이 핵심이다. 어떤 AI가 내 프로젝트에 맞는지 실제 결과물로 판단할 수 있다.

Related Features
Shuffle의 관련 기능들
AI Design Arena
기존 URL이 없어도 된다. 텍스트 프롬프트만으로 여러 AI 모델이 완전히 새로운 웹사이트 디자인을 생성해 비교한다.
DESIGN.md
AI 에이전트가 디자인 결정을 올바르게 내릴 수 있도록 프로젝트의 디자인 시스템을 문서화하는 표준. Cursor, Windsurf 같은 AI 코딩 도구와 연동된다.
Shuffle Visual Editor
AI가 생성한 결과를 드래그&드롭으로 수정하는 에디터. 13,000개 이상의 반응형 UI 컴포넌트를 가져다 쓸 수 있다.
Prompt Builder
효과적인 리디자인 프롬프트 작성을 도와주는 기능. 처음 사용자가 무엇을 어떻게 요청해야 할지 가이드해준다.
Browser Extension
Chrome/Firefox 확장으로 localhost나 로그인이 필요한 내부 사이트도 AI 리디자인 대상으로 사용할 수 있다.

AI 코딩 에디터 Windsurf(Codeium)용 Visual Editor. 코드 에디터 안에서 바로 UI를 시각적으로 편집 가능하다.
