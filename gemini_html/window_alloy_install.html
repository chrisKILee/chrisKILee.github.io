설치 대상 확인

⚠️
Alloy는 Windows 2016 이상만 지원합니다. Windows 2012 이하 버전은 설치 불가합니다.

대상 서버의 서비스 종류에 따라 필요한 모듈이 다릅니다. 서버에서 어떤 서비스가 운영되는지 모를 경우, 아래 PowerShell 스크립트를 실행하여 확인합니다.

PowerShell — 서비스 확인 스크립트 
# [1] 주요 프로세스 확인 (IIS, WAS, DB 5종 전체)
Write-Host "`n[1] 주요 프로세스 확인" -ForegroundColor Cyan
Get-Process | Where-Object { $_.ProcessName -match "sqlservr|oracle|w3wp|java|tomcat|js|postgres|mysqld|mariadbd" } |
  Select-Object ProcessName, Id, @{Name="Mem(MB)";Expression={ [math]::round($_.WorkingSet / 1MB, 2) }} |
  Format-Table -AutoSize

# [2] 주요 포트 확인 (1433, 1521, 8080, 80, 443, 3306, 5432)
Write-Host "[2] 주요 포트 확인" -ForegroundColor Cyan
netstat -ano | Select-String "LISTENING" | Select-String "1433|1521|8080|9404|80 |443 |3306|5432"

# [3] 관련 서비스 확인
Write-Host "`n[3] 관련 서비스 확인" -ForegroundColor Cyan
Get-Service | Where-Object { $_.Name -match "MSSQL|Oracle|W3SVC|Tomcat|postgresql|mysql|mariadb" } |
  Select-Object DisplayName, Status | Format-Table -AutoSize

# [4] 설치 경로 확인 (표준 경로 리스트)
Write-Host "[4] 설치 경로 확인" -ForegroundColor Cyan
$paths = @(
    "C:\inetpub",
    "D:\app\Administrator",
    "D:\DATA\Microsoft SQL Server",
    "D:\eGurkha\manager\tomcat",
    "C:\Program Files\PostgreSQL",
    "C:\Program Files\MySQL"
)
foreach($p in $paths){
    if(Test-Path $p){ Write-Host "[발견] $p" -ForegroundColor Green }
}

Alloy 설치 방법

1

설치 파일 다운로드

Google Drive에서 alloy-installer-windows-amd64.exe.zip을 다운로드합니다.

Google Drive에서 설치 파일 다운로드
2

파일을 대상 서버로 복사

다운로드한 zip 파일을 대상 서버에 Ctrl+C → Ctrl+V로 복사합니다.

3

압축 해제 후 관리자 권한 실행

zip 파일의 압축을 해제하고, alloy-installer-windows-amd64.exe를 관리자 권한으로 실행합니다.

마우스 우클릭 → 관리자 권한으로 실행
4

라이선스 동의

설치 마법사에서 I Agree를 클릭합니다.

5

기본 경로로 Install

설치 경로를 Default(C:\Program Files\GrafanaLabs\Alloy)로 유지하고 Install을 클릭합니다.

6

GrafanaLabs 폴더 확인

C:\Program Files에서 GrafanaLabs 폴더가 생성되었는지 확인합니다.

7

Alloy 폴더 확인

GrafanaLabs 폴더 안에 Alloy 폴더가 있는지 확인합니다.

8

config.alloy 및 DB 설정 파일 다운로드

Drive에서 주 설정 파일인 config.alloy를 다운로드합니다.
해당 서버에서 Database를 사용한다면, 관련 DB 파일도 함께 다운로드합니다.

Drive에서 config.alloy 및 DB 커스텀 파일 다운로드
9

Alloy 폴더에 설정 파일 복사

다운로드한 config.alloy와 DB 커스텀 파일을 Alloy 폴더에 붙여넣습니다.

⚠️
파일을 복사하기 전에 Config.alloy 수정 방법을 먼저 참고하세요. 서버 각각에 맞게 수정이 필요합니다.
10

modules 폴더 생성 및 모듈 파일 복사

Alloy 폴더 안에 modules 폴더를 생성합니다.

Drive에서 해당 서버에 필요한 모듈 파일을 다운로드합니다.

Drive에서 사용할 모듈 파일만 선택하여 다운로드
11

modules 폴더에 모듈 파일 복사

해당 서버에서 사용하는 모듈 파일을 modules 폴더에 붙여넣습니다.

12

Alloy 서비스 시작

services.msc (서비스 관리자)에서 Alloy 서비스를 시작 또는 다시 시작합니다.

13

이벤트 뷰어로 정상 동작 확인

Windows 이벤트 뷰어를 통해 Alloy가 정상적으로 작동하는지 확인합니다.

💡
에러가 발생했다면, 이벤트 내용을 AI에게 물어보면 대부분 해결됩니다.
이벤트 뷰어 → Windows 로그 → 응용 프로그램에서 Alloy 상태 확인

설정 정보 자동 추출 스크립트

설정 파일에 필요한 경로 정보를 아래 PowerShell 스크립트로 자동 추출할 수 있습니다.

PowerShell — Alloy 설정 정보 추출 스크립트 v2.1 
# [설정] 인코딩 설정 (한글 깨짐 방지)
$OutputEncoding = [System.Text.Encoding]::UTF8

Write-Host "===============================================" -ForegroundColor Magenta
Write-Host "   Alloy 설정 정보 추출 스크립트 (v2.1)        " -ForegroundColor Magenta
Write-Host "   실행 후 녹색(Green) 경로를 복사하여 사용하세요." -ForegroundColor Magenta
Write-Host "===============================================" -ForegroundColor Magenta

# [1] IIS - log_path 조사
Write-Host "`n[1] IIS (Web Server)" -ForegroundColor Cyan
if (Get-Module -ListAvailable WebAdministration) {
    Import-Module WebAdministration
    $sites = Get-Website
    if ($sites) {
        $iisLogPath = $sites[0].logFile.directory
        $finalPath = $iisLogPath.Replace("%SystemDrive%", $env:SystemDrive).Replace('\','/')
        Write-Host "log_path = `"$finalPath/*/*.log`"" -ForegroundColor Green
    }
} else { Write-Host "IIS 모듈 없음. 기본값 확인: C:/inetpub/logs/LogFiles/*/*.log" -ForegroundColor Yellow }

# [2] MSSQL - 서비스 경로 기반 로그 및 포트 조사
Write-Host "`n[2] MSSQL (Database)" -ForegroundColor Cyan
$sqlServices = Get-Service "MSSQL*" | Where-Object { $_.Name -notmatch "Launcher|ADHelper|Writer" }
foreach ($svc in $sqlServices) {
    $svcConfig = Get-CimInstance Win32_Service -Filter "Name = '$($svc.Name)'"
    if ($svcConfig.PathName -match '-e"([^"]+)"') {
        $fullLogPath = $Matches[1]; $logDir = Split-Path $fullLogPath -Parent
        Write-Host "발견된 인스턴스: $($svc.Name)" -ForegroundColor Gray
        Write-Host "errorlog_path = `"$($logDir.Replace('\','/'))/ERRORLOG*`"" -ForegroundColor Green
        Write-Host "사용 포트: SELECT local_tcp_port FROM sys.dm_exec_connections WHERE local_tcp_port IS NOT NULL;" -ForegroundColor Yellow
    }
}

# [3] Oracle - SID 및 Alert Log 조사
Write-Host "`n[3] Oracle (Database)" -ForegroundColor Cyan
$oraServices = Get-Service "OracleService*"
foreach ($ora in $oraServices) {
    $sid = $ora.Name.Replace("OracleService","")
    Write-Host "SID 발견: $sid" -ForegroundColor Green
    $oraSvcConfig = Get-CimInstance Win32_Service -Filter "Name = '$($ora.Name)'"
    if ($oraSvcConfig.PathName -match '^(.*)\\bin\\') {
        $oraHome = $Matches[1]
        Write-Host "예상 Alert Log: $($oraHome.Replace('\','/'))/diag/rdbms/$($sid.ToLower())/$sid/trace/alert_$sid.log" -ForegroundColor Yellow
    }
}

# [4] Tomcat - 실행 프로세스 기반 경로 추출
Write-Host "`n[4] Tomcat (WAS)" -ForegroundColor Cyan
$tomcatProc = Get-CimInstance Win32_Process | Where-Object { $_.Name -match "java.exe|tomcat.*.exe" -and $_.CommandLine -match "catalina.home" }
if ($tomcatProc) {
    if ($tomcatProc.CommandLine -match '-Dcatalina.home="?([^"\s]+)"?') {
        $tHome = $Matches[1].TrimEnd('\')
        Write-Host "catalina_log_path = `"$($tHome.Replace('\','/'))/logs/catalina.*.log`"" -ForegroundColor Green
        Write-Host "access_log_path   = `"$($tHome.Replace('\','/'))/logs/localhost_access_log.*.txt`"" -ForegroundColor Green
    }
} else { Write-Host "실행 중인 Tomcat 프로세스 없음" -ForegroundColor Yellow }

# [5] MariaDB / MySQL
Write-Host "`n[5] MariaDB / MySQL (Database)" -ForegroundColor Cyan
$dbServices = Get-Service "MariaDB*", "MySQL*" | Where-Object { $_.Status -eq 'Running' }
foreach ($db in $dbServices) {
    $svcConfig = Get-CimInstance Win32_Service -Filter "Name = '$($db.Name)'"
    if ($svcConfig.PathName -match '--defaults-file="?([^"]+)"?') {
        $iniPath = $Matches[1]
        $iniContent = Get-Content $iniPath -ErrorAction SilentlyContinue
        $logError = ($iniContent | Select-String "^log-error").ToString().Split('=')[1].Trim().Replace('"','')
        if ($logError) { Write-Host "log_error_path = `"$($logError.Replace('\','/'))`"" -ForegroundColor Green }
    } else { Write-Host "서비스($($db.Name))의 설정파일(ini) 수동 확인 필요" -ForegroundColor Yellow }
}

# [6] PostgreSQL
Write-Host "`n[6] PostgreSQL (Database)" -ForegroundColor Cyan
$pgServices = Get-Service "postgresql*" | Where-Object { $_.Status -eq 'Running' }
foreach ($pg in $pgServices) {
    $pgSvcConfig = Get-CimInstance Win32_Service -Filter "Name = '$($pg.Name)'"
    if ($pgSvcConfig.PathName -match '-D\s*"?([^"]+)"?') {
        $pgDataDir = $Matches[1].TrimEnd('\').TrimEnd('"')
        $pgConfPath = Join-Path $pgDataDir "postgresql.conf"
        if (Test-Path $pgConfPath) {
            $logDir = (Get-Content $pgConfPath | Select-String "^log_directory").ToString().Split('=')[1].Trim().Replace("'","")
            $fullLogPath = if ($logDir -notmatch '^[A-Z]:') { Join-Path $pgDataDir $logDir } else { $logDir }
            Write-Host "log_path = `"$($fullLogPath.Replace('\','/'))/*.log`"" -ForegroundColor Green
        }
    }
}

Write-Host "`n===============================================" -ForegroundColor Magenta
Write-Host "   조사가 완료되었습니다.                       " -ForegroundColor Magenta
Write-Host "===============================================" -ForegroundColor Magenta

Tomcat 추가 설정

ℹ️
Tomcat 모니터링을 위해서는 JMX 설정이 필요하며, 서비스 재시작이 필요합니다.
1

C 드라이브에 jmx 폴더 생성

C:\jmx 폴더를 생성합니다.

2

Tomcat 관련 파일 다운로드

Drive에서 Tomcat 관련 파일(tomcat.yml, jmx_prometheus_javaagent-1.5.0.jar)을 다운로드합니다.

3

jmx 폴더에 파일 복사

다운로드한 파일을 C:\jmx 폴더에 붙여넣습니다.

4

Tomcat 서비스 설정 파일 열기

Windows 서비스(services.msc)로 Tomcat이 등록된 경우, Tomcat 설치 경로에서 Tomcat10w.exe를 관리자 권한으로 실행합니다.

5

Java Options에 JMX 설정 추가

Java 탭의 Java Options에 JMX 설정 명령어를 추가합니다. 설정 명령어는 Drive의 tomcat 추출 방법.txt를 참고하세요.

6

Tomcat 서비스 재시작

services.msc에서 Tomcat 서비스를 다시 시작합니다.
