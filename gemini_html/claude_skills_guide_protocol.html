스킬 목록 보기 → 빠른 참조

소개

이 가이드는 ~/.claude/skills/에 설치된 모든 스킬을 문서화합니다. 스킬은 Power Pack (공통 워크플로우 도구)과 커스텀 스킬 (프로젝트·사이트 특화 도구)로 구분됩니다.

스킬을 실행하려면 Claude Code 프롬프트에 /스킬명을 입력하거나, Skill 도구를 통해 호출합니다. 각 스킬은 특정 키워드에도 자동 활성화됩니다.

💡

복잡한 작업은 /plan으로 계획을 먼저 수립하고, 구현 후 /verify → /review → /commit-push 순서로 마무리하는 것을 권장합니다.

사용 팁

컨텍스트 관리 패턴

토큰 80-100k 이전에 컨텍스트를 정리하면 응답 품질이 유지됩니다.

작업 → /compact → 작업 → /compact → 작업
→ /handoff (HANDOFF.md 생성) → /clear → 새 세션

Red-Green-Refactor (TDD)

/tdd 스킬은 Kent Beck의 TDD 원칙을 강제합니다. 구현 전 반드시 실패하는 테스트를 먼저 작성해야 합니다.

⚠️

main/master 브랜치에 직접 push 금지. /commit-push 실행 시 브랜치를 확인합니다.

⚡ Power Pack 스킬

Claude Code Power Pack에 포함된 공통 워크플로우 스킬입니다. 모든 프로젝트에서 사용 가능합니다.

명령어 이름 설명
/plan Plan 복잡한 작업 전 계획 수립. Plan 모드에서 사용.
/spec Spec SPEC 기반 개발 - 심층 인터뷰로 명세서 생성.
/frontend Frontend 빅테크 스타일 UI 개발. 플래닝 → 구현까지.
/tdd TDD 테스트 주도 개발 - 테스트 먼저 작성 후 구현.
/review Review 현재 브랜치의 변경사항 코드 리뷰.
/verify Verify 작업 완료 후 코드 검증 (타입체크, 린트, 테스트, 빌드).
/simplify Simplify 코드 단순화 및 리팩토링.
/build-fix Build Fix TypeScript 및 빌드 에러를 점진적으로 수정.
/handoff Handoff 세션 종료 전 HANDOFF.md 작업 인계 문서 생성.
/compact-guide Compact Guide 컨텍스트 관리 가이드.
/techdebt Techdebt 기술 부채 정리 - 중복 코드, console.log 등 검사.
/security-review Security Review 보안 취약점 분석 및 리뷰.
/nano-banana Nano Banana 이미지 생성 - Gemini CLI 기반.
/dogfood Dogfood 웹 앱을 탐색하고 테스트해 버그, UX 이슈 발견.
