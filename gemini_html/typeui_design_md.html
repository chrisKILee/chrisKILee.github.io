Google Stitch의 "디자인→코드" 흐름에서 빠진 앞단. TypeUI는 어느 웹사이트에서나 클릭 한 번으로 DESIGN.md를 생성합니다. Claude Code, Codex에 바로 물릴 수 있는 형태로.

🧩 Chrome Extension 📄 DESIGN.md 생성 🤖 Claude Code 연동 🖌️ 피그마 없이 일관된 UI
01 배경

디자인→코드 흐름의 빠진 조각

Google이 Stitch에 Design.md를 내놓으면서 "AI에게 디자인 명세를 넘기면 코드로 만들어준다"는 흐름이 자리잡고 있습니다. 그런데 그 앞단이 빠져 있습니다.

"AI한테 넘길 디자인 명세, 누가 만들어주나요?"

— unclejobs.ai AI Threads, 2026-04-17
TypeUI가 채우는 빈칸
웹사이트에서 디자인 시스템을 읽어 AI가 이해할 수 있는 DESIGN.md 파일로 변환합니다. 이 파일 하나로 Claude Code나 Codex는 일관된 UI를 생성할 수 있습니다.
02 핵심 기능

클릭 한 번으로 추출되는 것들

단순히 CSS 값을 나열하는 것이 아닙니다. 페이지에서 280개 요소를 읽어 "맥락까지 담긴" 디자인 명세를 만들어냅니다.

🎨
색상 시스템

주요 색상, 보조 색상, 배경·경계·텍스트 색상을 추출합니다. 단순 hex 코드가 아닌 역할(primary, surface, border 등)과 함께 정리됩니다.

Colors
🔤
타이포그래피

폰트 패밀리, 사이즈 스케일, 굵기, 줄 간격을 읽어냅니다. 제목·본문·레이블 각 역할에 어떤 값이 쓰이는지 계층 구조로 정리합니다.

Typography
📐
간격 & 레이아웃

패딩, 마진, 그리드 컬럼, border-radius, 그림자 등 레이아웃 토큰을 추출합니다. 일관된 컴포넌트 제작에 필요한 수치들입니다.

Spacing
💬
톤 & 매너 (맥락)

"이 페이지는 대시보드형, 개발자 대상" 같은 맥락 분석을 포함합니다. AI가 CSS 값 너머의 의도를 이해할 수 있게 해줍니다.

Context
280개 요소 분석
단순 CSS 파싱이 아닙니다. 페이지 전체 구조를 읽어 어떤 패턴이 반복되는지, 어떤 컴포넌트가 주로 사용되는지 맥락을 함께 정리합니다.
03 사용 방법

3단계로 끝나는 흐름

Chrome 익스텐션 설치 후 어느 웹사이트에서나 클릭 한 번으로 DESIGN.md를 얻고, AI 코딩 도구에 바로 넘깁니다.

1
Chrome 익스텐션 설치
Chrome 웹 스토어에서 "Design.md Style Extractor"를 설치합니다. 아래 링크 섹션에서 바로 이동할 수 있습니다.
2
분석할 웹사이트에서 익스텐션 실행
디자인 레퍼런스로 삼고 싶은 웹사이트를 열고 TypeUI 아이콘을 클릭합니다.
익스텐션이 페이지에서 280개 이상의 요소를 읽어 분석합니다.
3
DESIGN.md를 Claude Code / Codex에 넘기기
생성된 DESIGN.md 파일을 프로젝트 루트에 저장합니다.
Claude Code나 Codex가 이 파일을 참조해 일관된 UI를 생성합니다.
Claude Code 프롬프트 예시 
DESIGN.md를 참고해서 대시보드 컴포넌트를 만들어줘.
색상 토큰과 타이포그래피 스케일을 그대로 따라야 해.
04 활용 케이스

언제 써야 할까

피그마가 없을 때, 빠르게 레퍼런스 디자인을 코드로 옮기고 싶을 때 효과적입니다.

🖼️
피그마 없이 일관된 화면 제작

디자이너 없이 개발자가 직접 UI를 만들어야 할 때, 레퍼런스 사이트의 디자인 시스템을 추출해 일관된 화면을 구성할 수 있습니다.

Solo Dev
🌊
바이브 코딩 / 바이브 디자인

"이 사이트 느낌으로 만들어줘"라는 막연한 요청을 구체적인 명세로 바꿔줍니다. AI가 해석할 수 있는 정확한 값으로 전달됩니다.

Vibe Design
⚡
AI 코딩 도구 연동 가속화

Claude Code, Codex 등 AI 코딩 도구에게 "어떤 디자인으로 만들어야 하는지"를 명확히 전달합니다. 수정 반복 횟수가 줄어듭니다.
