Features

주요 기능

워크플로우 연결부터 AI 분석 리포트까지, CI/CD 파이프라인 전체를 커버합니다.

Feature 01

레포지토리 연결

GitHub URL 하나만 입력하면 브랜치 목록을 자동으로 불러오고 워크플로우 스캔을 즉시 시작합니다.

  • Public 레포: 토큰 없이 바로 분석 가능
  • Private 레포: GitHub PAT(Fine-grained Token)으로 인증
  • 브랜치 선택 후 .github/workflows 자동 스캔
  • PAT 토큰은 메모리에만 유지 — localStorage 저장 없음
GitHub URL 입력 → 브랜치 선택 → 워크플로우 스캔 시작
Feature 02

워크플로우 맵 (브랜치 전체 흐름)

선택한 브랜치의 모든 워크플로우를 Force-directed Graph로 시각화합니다. 명시적 관계와 추론된 관계를 동시에 표현합니다.

  • 노드 = 개별 워크플로우, 엣지 = 실행 의존관계
  • 실선(명시 관계): workflow_run, workflow_call로 직접 연결
  • 점선(추론 흐름): 이름·trigger·branch rule 기반 추론
  • 머지 이전 / 머지 이후 / 수동 필터로 phase별 분류
  • 드래그·줌·팬 인터랙션 지원
Force-directed Graph로 브랜치 전체 워크플로우 관계 시각화
Feature 03

Job DAG & 상세 분석

워크플로우를 선택하면 내부 Job 구조를 DAG(방향 비순환 그래프)로 시각화하고, Step 단위까지 드릴다운할 수 있습니다.

  • 워크플로우 요약: 트리거, 브랜치 조건, Job 수, 최근 실행 이력
  • Job 의존관계를 Level 단위로 시각화
  • Step Flow: 각 Job 내부의 action 사용 흐름을 순서대로 표시
  • 실행 시간 하이라이트 (가장 오래 걸리는 스텝 식별)
  • 최근 10개 실행 이력 표시 (상태·결론·브랜치·이벤트)
Job DAG 시각화 및 Step Flow 드릴다운 패널
Feature 04

CI 리뷰 리포트 & 비주얼 대시보드

브랜치 전체 CI 구조에 대한 종합 분석 리포트를 자동 생성합니다. AI + 휴리스틱 이중 분석으로 신뢰성을 확보합니다.

  • 전체 건강도 점수(0~100) 자동 산출
  • 4개 축 자동 점검: 보안·안정성·성능·유지관리
  • Phase Distribution, Workflow Risk Matrix 시각화
  • 핵심 보강 포인트를 한 줄 요약으로 제공
  • Gemini 장애 시 휴리스틱 폴백으로 무중단 분석
건강도 점수 · Phase Distribution · Workflow Risk Matrix 한눈에 확인
Feature 05

Deep Review & 리포트 내보내기

카테고리별 발견 이슈를 severity 기준으로 정렬하여 보여주고, 결과를 HTML 파일로 내보낼 수 있습니다.

  • Critical: 보안 권한 범위 초과, permissions block 누락 등
  • Warning: 타임아웃 미설정, 캐시 미사용 등 안정성/성능 이슈
  • 각 항목에 YAML 소스 위치(파일:라인) 함께 표시
  • 구체적인 수정 권고 사항 제공
  • 독립 HTML 파일로 다운로드 → 팀 내 공유 및 아카이빙
severity별 이슈 목록 및 YAML 소스 위치 링크
Architecture

시스템 아키텍처

프론트엔드가 GitHub API를 직접 호출하고, AI 분석은 백엔드가 담당하는 2계층 구조입니다.

┌─────────────────────────────────────────────────────┐
│                   사용자 브라우저                     │
│  ┌──────────────────────────────────────────────┐   │
│  │         React + Vite (Frontend)             │   │
│  │  레포 연결 / 워크플로우 맵 / Job DAG             │   │
│  │  CI 리뷰 리포트 / HTML 내보내기                  │   │
│  └───────────┬──────────────────┬───────────────┘   │
│              │ GitHub REST API   │ /api/*            │
│              ▼                   ▼                   │
│       GitHub API           NestJS Backend          │
│  (워크플로우 YAML,         (분석 엔진)               │
│   실행 이력, 브랜치)   ┌──────────────┐             │
│                        │  Gemini AI   │             │
│                        │  + 휴리스틱   │             │
│                        └──────────────┘             │
└─────────────────────────────────────────────────────┘
Step 1
GitHub 데이터 수집
Frontend가 GitHub REST API를 직접 호출하여 워크플로우 YAML, 실행 이력, 브랜치 정보를 가져옵니다. PAT 토큰은 메모리에만 유지됩니다.
Step 2
DAG 생성 및 시각화
클라이언트에서 YAML을 파싱하고 Job DAG를 구성합니다. trigger, branch rule, 이름 패턴 기반으로 워크플로우 관계를 추론합니다.
Step 3
AI 분석 및 리포트
Backend가 Gemini API로 분석을 수행하고, 장애 시 휴리스틱 분석으로 자동 폴백합니다. 결과를 severity 기준으로 정렬하여 반환합니다.
