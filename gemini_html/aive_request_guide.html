01 / STRATEGY AI 도입 전략 How & Where

AI를 적용한 업무 영역과 기술적 접근 방식을 구체적으로 서술합니다. 단순 프롬프트 활용부터 API 연동, MLOps 구축까지 실제 적용 방법을 명시합니다.

02 / ROI 업무 효율성 및 자동화 성과 Automation

기존 수작업 대비 자동화 수준을 정량적으로 제시합니다. 절감된 시간, 처리량 변화, 오류율 감소 등 측정 가능한 성과 지표를 포함합니다.

03 / OPTIMIZATION AI 성능 및 정확도 고도화 Accuracy

환각(Hallucination) 감소 및 정확도 향상을 위해 적용한 기법을 기술합니다. RAG, 프롬프트 체이닝, 파인튜닝 등 구체적 방법론을 상세히 기재합니다. ★ 상위 레벨 핵심 항목

04 / PoC 시각적 증빙 자료 Proof

작동하는 프로토타입 또는 결과물의 스크린샷 URL을 기재합니다. 실제 동작 화면으로 성과를 증명합니다.

05 / SCALABILITY 범용성 및 타 부서 확장성 Expandable

개발된 솔루션이 타 부서 또는 유사 업무 프로세스에 적용 가능한지를 검토합니다. 권한 제약이 있는 경우 팀 내 동료로의 확장성도 유효합니다.

06 / BUSINESS IMPACT 현업 적용 가능성 현업 적용

결과물이 실제 비즈니스 환경에 즉시 투입되어 실효성을 낼 수 있는지 그 가치를 증명합니다. 단순 실험적 결과물이 아닌 현업 운영 가능성을 서술합니다.

Gemini API 키

신청 및 운영 가이드

프로젝트에서 AI API가 필요한 경우 Gemini AI Studio를 통해 개인별 API 키를 발급받습니다. 효율적 비용 운영을 위해 Flash 계열 모델을 우선 사용하는 것을 권장합니다. 본 신청은 개인 또는 부서 프로젝트에 한하며, 상용 서비스는 Vertex AI 검토가 필요합니다.

결재라인 팀장 → 센터장/실장 → CTO
적용 범위 개인 · 부서 프로젝트 한정
API 키 발급 흐름
  1. 구매의뢰서 제출 및 결재
    팀장 → 센터장/실장 → CTO 결재 라인을 통해 구매의뢰서를 제출합니다.
  2. 관리자 프로젝트 명세 확인
    승인 후 담당 관리자가 사용 용도 및 프로젝트 명세를 검토합니다.
  3. 개인 API 키 발급 및 사용량 한도 설정
    Gemini AI Studio에서 개인별 키가 생성되며, 월 사용량 한도(Limit)가 설정됩니다.
  4. 사용량 모니터링 및 키 관리
    개인 키 단위로 사용량이 추적됩니다. 현저히 감소하면 미사용으로 간주하여 키가 만료 처리됩니다.

Cloud Run

서버 자원 신청 가이드

서버 자원이 필요한 경우 Cloud Run을 통해 신청할 수 있습니다. 단, 부서장의 사전 승인이 필요하며 발생 비용은 해당 부서에 귀속됩니다. 서비스 운영의 지속성을 위해 미사용 종료와 부서 내 기술 이전이 의무화됩니다.

결재라인 팀장 → 센터장/실장 (CTO 제외)
비용 귀속 신청 부서
운영 원칙
항목 내용
비용 귀속 Cloud Run 운영으로 발생하는 모든 비용은 신청 부서에 귀속됩니다.
미사용 종료 의무 불필요한 비용 방지를 위해 사용하지 않는 서비스는 해당 부서에서 직접 종료를 요청합니다.
기술 이전 필수 운영자 퇴사 또는 조직 개편 시에도 서비스가 단절되지 않도록 운영 지식을 부서 내에 반드시 공유·이전합니다.
사양 확인 품의 승인 완료 후 플랫폼인프라팀에서 사양 확인 등의 안내 메일을 발송합니다.
