🔌 /claude-api 스킬이란?

Claude Code에 내장된 claude-api 스킬은 Anthropic SDK로 앱을 빌드·디버그·최적화할 때 자동으로 활성화됩니다. 코드에 import anthropic 또는 from @anthropic-ai/sdk가 보이면 트리거됩니다.

스킬이 활성화되면 context7 MCP를 통해 Anthropic 공식 문서를 실시간 조회하고, 최신 모델 ID·프롬프트 캐싱·스트리밍·툴 사용 패턴을 자동으로 코드에 포함시킵니다.

자동 트리거 조건

✓ import anthropic 포함 파일 수정

✓ Claude API / Anthropic SDK에 대한 질문

✓ 캐싱, 스트리밍, 툴 사용, 배치, 파일, 메모리 기능 추가

✓ Opus / Sonnet / Haiku 모델 관련 작업

✗ openai / 다른 제공사 SDK 파일은 SKIP

프롬프트 캐싱이란?

동일한 시스템 프롬프트나 대용량 문서를 반복 전송할 때, Anthropic 서버가 이를 캐시에 저장해둡니다. 이후 요청에서 캐시가 히트되면 입력 비용의 10%(0.1배)만 청구됩니다.

모델 기본 입력 캐시 쓰기(5m) 캐시 읽기
Opus 4.6 $5.00 $6.25 $0.50
Sonnet 4.6 $3.00 $3.75 $0.30
Haiku 4.5 $1.00 $1.25 $0.10

※ 1M 토큰 기준 USD. 1시간 TTL 쓰기: 기본가 × 2배

⚠️ 캐시 무효화 원인

  • • datetime.now() 같은 동적 타임스탬프를 시스템 프롬프트에 삽입
  • • json.dumps() 에 sort_keys=True 미사용 (비결정적 직렬화)
  • • 요청마다 툴 셋 변경 (추가/제거/순서 변경)
  • • 요청 간 모델 전환

Python 코드 예시

# 자동 캐싱 (권장) response = client.messages.create( model="claude-sonnet-4-6", max_tokens=16000, cache_control={"type": "ephemeral"}, system="대용량 시스템 프롬프트...", messages=[{ "role": "user", "content": "핵심 포인트 요약" }] ) # 캐시 히트 확인 usage = response.usage print(usage.cache_creation_input_tokens) # 쓰기 print(usage.cache_read_input_tokens) # 읽기 (90%↓) print(usage.input_tokens) # 미캐시

캐싱 적용 대상

✓ tools 정의 ✓ system 프롬프트 ✓ messages 히스토리 ✓ 이미지 포함 블록

렌더 순서: tools → system → messages

최소 토큰: Sonnet 4.6 = 2,048 / 나머지 = 4,096

스트리밍이란?

Server-Sent Events(SSE) 방식으로 Claude가 토큰을 생성하는 즉시 전달합니다. 실시간 채팅 UI, 긴 보고서 생성, Opus 4.6의 128K 출력 사용 시 필수입니다.

SSE 이벤트 흐름

message_start 메시지 메타데이터
content_block_start 새 블록 시작
content_block_delta 증분 토큰 전달 (반복)
content_block_stop 블록 완료
message_stop 메시지 완료

Python / TypeScript 코드

# Python

# context manager 방식 with client.messages.stream( model="claude-opus-4-6", max_tokens=64000, messages=[...] ) as stream: for text in stream.text_stream: print(text, end="", flush=True) final = stream.get_final_message() print(final.usage.output_tokens)

// TypeScript

const stream = client.messages.stream({ model: "claude-opus-4-6", max_tokens: 64000, messages: [...] }); stream.on("text", (delta) => { process.stdout.write(delta); }); const final = await stream.finalMessage();

파일 편집

# Tool Runner (아젠틱 루프 자동화)

from anthropic import beta_tool @beta_tool def get_weather(location: str) -> str: """날씨 조회 (docstring이 description)""" return f"{location}: 맑음, 22°C" runner = client.beta.messages.tool_runner( model="claude-opus-4-6", max_tokens=16000, tools=[get_weather], messages=[{"role": "user", "content": "서울 날씨?"}] ) for message in runner: print(message)

Adaptive Thinking이란?

Claude 4.6 모델부터 도입된 자동 추론 깊이 조절 기능입니다. 기존 Extended Thinking에서 토큰 예산을 수동으로 지정하던 방식을 Claude가 문제 복잡도에 따라 자동으로 결정하도록 개선했습니다.

구분 Extended (구) Adaptive (신)
설정 budget_tokens: N type: "adaptive"
제어 수동 지정 자동 결정
지원 모든 모델 Opus/Sonnet 4.6만
권장 Deprecated ✓ 권장

Effort 파라미터

"low" 빠른 응답, 서브에이전트·단순 작업
"medium" 비용-품질 균형 (일반 권장)
"high" 기본값, 높은 품질
"max" 최고 품질 (Opus 4.6 전용)

코드 예시

response = client.messages.create( model="claude-opus-4-6", max_tokens=16000, thinking={"type": "adaptive"}, output_config={"effort": "max"}, messages=[{ "role": "user", "content": "이 수학 증명을 풀어주세요..." }] ) # 추론 과정 + 최종 답변 분리 for block in response.content: if block.type == "thinking": print(f"[추론] {block.thinking}") elif block.type == "text": print(f"[답변] {block.text}")

활용 사례

  • • 복잡한 수학·논리 문제 풀이
  • • 멀티스텝 코딩 에이전트
  • • 법률·의학 문서 심층 분석
  • • 연구 논문 비판적 리뷰

멀티턴 대화 관리

Claude API는 Stateless(무상태)입니다. 이전 대화 내용을 messages 배열에 직접 담아 전송해야 컨텍스트가 유지됩니다.

class ConversationManager: def __init__(self, client, model, system=None): self.client = client self.model = model self.system = system self.messages = [] def send(self, user_message: str) -> str: self.messages.append({ "role": "user", "content": user_message }) response = self.client.messages.create( model=self.model, max_tokens=16000, system=self.system, messages=self.messages ) answer = next( b.text for b in response.content if b.type == "text" ) self.messages.append({ "role": "assistant", "content": answer }) return answer

컨텍스트 압축 (Compaction Beta)

200K 컨텍스트 초과 방지. Opus 4.6 / Sonnet 4.6 지원.

response = client.beta.messages.create( betas=["compact-2026-01-12"], model="claude-opus-4-6", max_tokens=16000, messages=messages, context_management={ "edits": [{ "type": "compact_20260112" }] } ) # compaction 블록 포함, 전체 content 보존 필수 messages.append({ "role": "assistant", "content": response.content })

⚠️ Compaction 주의사항

응답의 전체 content 배열을 messages에 보존해야 합니다. compaction 블록을 제거하면 컨텍스트가 손상됩니다.
