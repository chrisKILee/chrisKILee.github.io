Agent Development Kit

Claude Code는
완전한 에이전트 개발 키트

대부분의 개발자는 Layer 1(CLAUDE.md)만 사용합니다. 하지만 Claude Code는 5계층 아키텍처로 구성된 완전한 에이전트 개발 프레임워크입니다. 각 계층이 역할을 나눠 런타임에 프롬프트 엔지니어링이 필요 없는 구조를 만듭니다.

🧠 CLAUDE.md 📚 Skills 🔒 Hooks 🤖 Subagents 📦 Plugins
01 Architecture

5계층 구조

각 계층은 독립적인 역할을 가지며, 아래로 내려갈수록 더 넓은 팀과 공유할 수 있는 기능을 담당합니다.

Layer 1
CLAUDE.md — Memory
에이전트의 헌법 (Constitution)
항상 로드되며 항상 활성화됩니다. 아키텍처 규칙, 네이밍 컨벤션, 테스트 기대치를 정의합니다. 프롬프트를 입력하기 전에 이미 모든 규칙이 적용된 상태입니다. ~/.claude/CLAUDE.md(전역)와 .claude/CLAUDE.md(프로젝트) 두 레벨로 관리합니다.
Memory
Layer 2
SKILLS — Knowledge
온디맨드 컨텍스트
각 SKILL.md는 참조 문서, 스크립트, 템플릿을 하나로 묶습니다. 항상 켜져 있지 않고, 작업이 일치할 때만 자동으로 호출됩니다. 분리된 서브에이전트에서 실행되어 메인 컨텍스트를 깨끗하게 유지합니다.
Knowledge
Layer 3
HOOKS — Guardrails
결정론적 가드레일
AI가 아닙니다. 에이전트를 위한 Git 훅이라고 생각하세요. PreToolUse, PostToolUse, SessionStart, Stop, SubagentStop 이벤트에 반응합니다. 파일 저장 시 자동 린트, 위험 명령 차단, Slack 알림 발송 — 루프에 LLM이 없습니다.
Guardrails
Layer 4
SUBAGENTS — Delegation
독립 에이전트 위임
코드 리뷰어, 테스트 러너, 탐색기 등 각자의 컨텍스트 창, 커스텀 도구, 커스텀 권한을 가진 서브에이전트를 생성합니다. 서브에이전트는 서브에이전트를 생성할 수 없습니다 — 무한 재귀가 없습니다. 메인 컨텍스트를 깨끗하게 유지하며 병렬 실행이 가능합니다.
Delegation
Layer 5
PLUGINS — Distribution
팀 배포 패키지
모든 것(skills/, agents/, hooks/, commands/)을 설치 가능한 패키지로 묶습니다. 에이전트 역량을 위한 npm 패키지라고 생각하세요. 팀 전체에 한 번에 설치할 수 있는 마켓플레이스 구조입니다.
Distribution

03 Comparison

계층별 상세 비교

각 계층의 역할, 작동 방식, 적용 범위를 한눈에 비교합니다.

계층 역할 작동 방식 적용 범위 핵심 특징
Layer 1
CLAUDE.md		 Memory 항상 로드됨 전역 / 프로젝트 에이전트 헌법. 프롬프트 입력 전 규칙 적용
Layer 2
Skills		 Knowledge 온디맨드 자동 호출 작업별 분리된 서브에이전트 실행. 컨텍스트 모듈화
Layer 3
Hooks		 Guardrails 이벤트 기반 결정론적 세션 전체 LLM 없음. Git 훅처럼 동작. 자동 린트·차단
Layer 4
Subagents		 Delegation 스폰(spawn) 후 결과 반환 작업별 독립 컨텍스트. 서브에이전트→서브에이전트 불가
Layer 5
Plugins		 Distribution 패키지 설치 팀 전체 skills+agents+hooks+commands 번들. npm 유사
04 Pipeline

실행 파이프라인

사용자가 명령을 입력하면 5계층이 순서대로 역할을 수행합니다.

핵심 원칙
Five layers. One architecture. Zero prompt engineering at runtime. — Brij Kishore Pandey
Layer 1
규칙 적용
CLAUDE.md가 컨텍스트에 로드되어 기본 동작 규정
Layer 2
전문성 제공
작업에 맞는 Skill이 자동 호출되어 도메인 지식 주입
Layer 3
품질 보증
Hooks가 이벤트를 감지해 린트·차단·알림을 결정론적으로 실행
Layer 4
작업 위임
복잡한 작업을 Subagents에 분산하여 병렬 처리
Layer 5
팀 배포
Plugins으로 전체 역량을 팀에 한 번에 배포
대부분의 개발자는 Layer 1만 사용합니다
CLAUDE.md 작성 → Skills 추가 → Hooks 설정 → Subagents 활용 → Plugins 배포 순서로 점진적으로 확장하세요.
05 Hooks Events

Hooks 이벤트 종류

Layer 3 Hooks는 5가지 이벤트 시점에 반응하여 결정론적으로 동작합니다.

hooks event types 
PreToolUse    → 도구 호출 전   (예: rm -rf 차단)
PostToolUse   → 도구 호출 후   (예: 파일 저장 후 자동 린트)
SessionStart  → 세션 시작 시   (예: 환경 초기화)
Stop          → 세션 종료 시   (예: Slack 알림 발송)
SubagentStop  → 서브에이전트 종료 시 (예: 결과 로깅)
Hooks vs CLAUDE.md 차이
CLAUDE.md는 AI에게 "이렇게 행동하라"고 가르치는 것이고, Hooks는 AI의 행동과 무관하게 강제로 실행되는 결정론적 명령입니다. LLM이 무시할 수 없습니다.
