매주 반복되는 보고서 작업

HR 담당자는 매주 동일한 포맷의 인사 현황 보고서를 수작업으로 만들어야 했습니다. 데이터가 바뀔 뿐, 포맷은 동일한 반복 업무였습니다.

수동 작성 프로세스

  • ERP에서 데이터 추출
  • 엑셀/시트에서 수동 정리
  • 조직도·현황 직접 작성
  • 이메일 직접 작성 및 발송
  • 매주 동일 작업 반복
현재 방식

자동화 프로세스

  • ERP 데이터를 시트에 업로드
  • Apps Script 실행 1회
  • 조직도·분석·발령 자동 생성
  • HTML 이메일 자동 발송
  • 데이터만 바뀌면 완료

주요 기능

자동으로 생성되는 보고서 섹션

스크립트 실행 한 번으로 4개 섹션이 자동 조립되어 이메일로 발송됩니다.

1

계층형 조직도 자동 생성

마스터 데이터에서 부서 계층 구조를 분석하여 HTML 조직도로 시각화합니다. 정렬 순서는 CONST 설정으로 제어합니다.

2

인력 현황 분석

전체 인원수 및 부서별 현황을 집계하고, 과거 데이터와 비교하여 증감 추이를 분석합니다.

3

휴직자 자동 추출

근태 데이터에서 오늘 날짜 기준으로 휴직·출산휴가 중인 직원 목록을 자동 추출하여 테이블로 표시합니다.

4

인사발령 사항 정리

인사발령 시트의 내역을 포맷된 HTML 테이블로 변환하여 보고서에 포함합니다.

5

HTML 이메일 자동 발송

위 4개 섹션을 하나의 보고서로 조립하여 제목에 날짜를 포함한 HTML 이메일로 지정 수신자에게 자동 발송합니다.

AI 활용 방식

Gemini 바이브 코딩으로 구현

Google Gemini에게 원하는 기능을 자연어로 설명하여 Apps Script 코드를 생성하고, 실행 테스트 후 반복적으로 개선하는 바이브 코딩 방식으로 전체 솔루션을 개발했습니다.
