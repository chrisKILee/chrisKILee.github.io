Auto Dream이란?

Auto Dream은 Claude Code의 실험적 메모리 관리 기능입니다. 인간이 수면 중 기억을 통합·정리하듯, Claude가 백그라운드 서브에이전트로 실행되어 쌓인 메모리 파일을 통합·정리·가지치기합니다.

기존 Auto Memory가 "대화 내용을 계속 기록"하는 수집 시스템이라면, Auto Dream은 "기록된 내용을 주기적으로 검토해 핵심만 남기는" 정리 시스템입니다.

🔁

반복작업 감소

중복된 메모리 항목을 자동으로 감지하고 통합해 불필요한 반복을 줄입니다.

불필요한 데이터 정리

오래되거나 더 이상 유효하지 않은 메모리를 자동으로 삭제합니다.

핵심 정보만 남아있어 관련 맥락을 더 빠르게 찾아 응답합니다.

Auto Memory vs Auto Dream

두 기능은 서로 대체재가 아니라 보완 관계입니다. Auto Memory가 수집하고, Auto Dream이 정리합니다.

기존 — Auto Memory

수집형 메모리

  • 매 세션마다 새 정보 수집
  • 대화 내용을 MEMORY.md에 기록
  • 패턴·인사이트를 지속 추가
  • 시간이 지날수록 파일 증가
  • 오래된 정보도 그대로 유지
신규 — Auto Dream

정리형 메모리

  • 24시간 + 5세션 이상 경과 시 실행
  • 기존 메모리를 검토·가지치기
  • 중복 제거, 오래된 정보 삭제
  • 핵심 정보만 남겨 경량화
  • 더 신선한 상태로 재시작
항목 Auto Memory Auto Dream
역할 세션 중 새 정보 수집 기존 메모리 통합·정리
실행 시점 매 세션 주기적 (24시간 + 5세션 이상)
하는 일 패턴·인사이트 기록 중복 제거, 오래된 정보 삭제, 재구성
결과 메모리 파일 증가 메모리 파일 경량화
설정 위치 /memory 설정 /memory → Auto-dream 토글

작동 3단계

Auto Dream은 실행 시 아래 3단계 순서로 메모리를 정리합니다.

Phase 1

Orientation — 현황 파악

현재 메모리 디렉토리와 MEMORY.md를 읽어 전체 메모리 구조와 현재 상태를 파악합니다. 어떤 파일이 있는지, 마지막으로 Dream이 실행된 시점이 언제인지 확인합니다.

Phase 2

Gather Signal — 신호 수집

JSONL 세션 기록에서 사용자 피드백, 반복 패턴, 중요한 결정 사항 등을 탐색합니다. 어떤 정보가 실제로 자주 활용되었는지, 어떤 내용이 오래되어 폐기해도 되는지를 분석합니다.

Phase 3

Consolidation — 통합·정리

수집된 신호를 바탕으로 새 정보를 기존 메모리에 병합하고, 모순·충돌을 해결하며, 더 이상 유효하지 않은 오래된 메모리를 삭제합니다. 이 단계에서만 파일이 실제로 수정됩니다.

🎮

사용법

Auto Dream을 사용하는 방법은 두 가지입니다. 자동 실행과 수동 실행.

1

Auto-dream 토글 켜기

/memory 명령어를 입력하면 메모리 설정 화면이 열립니다. 여기서 Auto-dream 항목을 ON으로 변경합니다.

2

수동으로 Dream 실행하기

/dream 명령어를 입력하거나, 아직 스킬이 없는 경우 다음 문장을 그대로 입력합니다:

Claude Code 채팅창 
run your autodream

터미널 하단에 "dreaming" 표시가 나타나면 정상적으로 실행 중인 것입니다.

3

완료 확인

Dream이 끝난 뒤 /memory를 다시 열면 마지막으로 Dream이 실행된 시점이 표시됩니다. "몇 분 전에 실행됨"과 같은 메시지로 확인할 수 있습니다.

✦

자동 실행 조건: Auto-dream이 켜져 있으면 최소 5세션 경과 + 24시간 이상 지났을 때 자동으로 실행됩니다. 직접 트리거하지 않아도 조건이 충족되면 스스로 동작합니다.

⚠️

/dream 명령어가 "unknown skill"로 나오는 건 정상입니다. 이 경우 "run your autodream"을 직접 입력하면 작동합니다. /dream 스킬이 배포된 사용자는 명령어로 바로 실행 가능합니다.

🛡️

안전장치

Dream은 메모리 파일만 수정하며 소스 코드에는 절대 접근하지 않습니다. 세 가지 안전장치가 내장되어 있습니다.

🔒

읽기 전용 실행

Dream 중에는 소스 코드 수정이 불가능합니다. 메모리 파일만 수정 대상이며, 프로젝트 코드는 건드리지 않습니다.

🔑

Lock File

동일 프로젝트에서 Dream이 동시에 실행되는 것을 방지하는 잠금 파일(lock file) 시스템이 내장되어 있습니다.

⏰

자동 실행 조건

최소 5세션 + 24시간이 경과해야 자동 실행됩니다. 너무 자주 실행되어 방해가 되지 않도록 설계되어 있습니다.

📡
