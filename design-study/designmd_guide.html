design.md 가이드 2026-06-19
🎨 Design Study

AI가 만든 티 안 나게,
design.md로 디자인 잡기

"누가 봐도 AI가 만든 것 같다(Slop)" — 매번 같은 그라디언트, 둥근 카드, 천편일률 산세리프. design.md는 색·타이포·간격·금지사항을 미리 적어둔 마크다운 한 장으로 이 문제를 줄입니다. 마음에 드는 시안의 design.md를 받아 "이대로 적용해줘"라고 시키면 끝.

🔖 design.md 한 장으로 디자인 통일 📌 PPT·강의안·웹 제작 ⚡ Claude Code / Claude.ai
01 개요

design.md가 뭔가요?

AI 코딩 도구(Claude·Cursor·Kiro·Windsurf 등)가 읽는 표준 마크다운 디자인 지침 파일입니다. "디자인을 어떻게 잡아야 할지"를 사람이 한 번 정의해두면, AI가 매번 그 규칙대로 만들어줍니다.

🌀
왜 AI 디자인은 매번 비슷할까

LLM은 프롬프트마다 독립적으로 판단합니다. 저장소에 참고 기준이 없으면 컴포넌트마다 다른 결정이 나오고, "안전한 평균값"으로 수렴해 다 닮아 보입니다.

Problem
📄
한 장의 명세로 고정

색 팔레트(hex), 폰트·자간, 그리드·간격, 형태·그림자·모션, 그리고 "하지 말 것"까지 적어둡니다. AI가 기본값으로 회귀하지 못하게 막는 게 핵심입니다.

Solution
🎯
의도가 담긴 결과물

시안을 직접 고르므로 "이런 느낌으로"라는 의도가 반영됩니다. 양산형 Slop 대신, 일관되고 수정 가능한 산출물이 나옵니다.

Result
02 구조

design.md(디자인 팩)는 무엇으로 이루어지나

design-diversity 저장소 기준으로, 하나의 디자인 팩은 아래 파일들로 구성됩니다. 이 중 prompt.md가 AI에게 그대로 복붙하는 핵심 지시문입니다.

prompt.md에는 무엇이 적혀 있나
디자인 정체성 · 색 팔레트(hex) · 타이포(폰트·크기·굵기·자간) · 레이아웃/그리드(최대폭·브레이크포인트·갭) · 형태/질감(반지름·보더·그림자·모션), 그리고 "하지 말 것" 섹션(순흑 배경·발광 보더·다색 그라디언트 등 AI 기본값 차단).
prompt.md (예: web-velvet-dark-boutique) 
색:    #1a1216(와인-차콜 배경), #ece4e0(오프화이트), #c79a52(골드 강조)
타이포: Cormorant(세리프) + Inter(산세리프)
레이아웃: 벤토 그리드, 12열, 타일 비대칭 배치
모션:  300ms cubic-bezier, 절제된 전환
금지:  순흑 배경 / 발광 보더 / 다색 그라디언트 / 균등 크기 타일
03 워크플로우

실제로 어떻게 쓰나

시안을 고르고 → 그 design.md를 AI에 건네고 → "이대로 만들어줘"라고 하면 됩니다. 많은 사용자가 이렇게 만든 결과물을 초안으로 삼아 Canva에서 최종만 다듬습니다.

PPT 만들 때 핵심 한 줄
"편집 가능한 네이티브 .pptx로 만들어줘"라고 명시하세요. 그래야 PNG 풀블리드(이미지 한 장)가 아니라 파워포인트에서 텍스트·수치·도형을 직접 고칠 수 있는 객체로 생성됩니다.

방법 A — Claude Code (design-pick 스킬)

1
스킬 설치
저장소를 받아 design-pick 스킬을 복사합니다.
bash 
# 전역 설치
cp -r skills/design-pick ~/.claude/skills/

# 프로젝트별 설치
cp -r skills/design-pick YOUR_PROJECT/.claude/skills/
2
느낌 또는 슬러그로 요청
"고급스러운 다크 톤으로 발표자료 만들어줘" → 스킬이 어울리는 팩 2~3개 추천. 또는 /design-pick web-velvet-dark-boutique처럼 슬러그를 직접 지정하면 그 팩의 명세를 그대로 적용합니다.
3
생성
PPT는 편집 가능한 네이티브 .pptx, 웹은 HTML/CSS로 만들어집니다.

방법 B — Claude.ai 채팅 (스킬 없이)

1
prompt.md 전문 복사
카탈로그에서 마음에 드는 팩의 prompt.md 전체를 복사합니다.
2
원본 자료와 함께 붙여넣기
기획서·강의안 스크립트 등 원본 콘텐츠와 prompt.md를 함께 채팅에 붙여넣고 요청합니다.
prompt 
위 디자인 명세 그대로,
편집 가능한 네이티브 .pptx로 발표자료를 만들어줘
(또는 HTML/CSS 웹으로)
3
다운로드 → 최종 다듬기
생성된 .pptx/HTML을 받아 PowerPoint나 Canva에서 최종만 손봅니다.
04 Slop

"AI Slop"과 design.md의 완화 방식

Slop은 AI로 대량 생산된 저품질 콘텐츠를 가리키는 말로, Merriam-Webster가 선정한 2025 올해의 단어이기도 합니다. design.md는 디자인 영역에서 이 "양산·천편일률" 문제를 아래처럼 줄여줍니다.

측면 Slop 문제 design.md의 완화
시각 천편일률 매번 같은 그라디언트·둥근 카드 서로 다른 팩 다수로 선택지 다양화
기본값 회귀 "안전한 평균"으로 수렴 "하지 말 것" 섹션으로 회피점 차단
검증 부재 기준 없는 양산 색 hex·간격 단위·폰트 크기로 검증 가능
편집 불가 PNG 풀블리드 → 수정 못 함 네이티브 객체 강제 → 편집 가능
맥락 무시 의도 없는 결과 팩 선택으로 의도를 명시
균형 잡기
목표는 "Slop이 너무 심하지 않게, 그러나 너무 어렵지도 않게". design.md는 디자인 전문 지식 없이도 일관된 기준을 적용하게 해주는 중간 지점입니다.
