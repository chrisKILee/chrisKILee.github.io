AI 에이전트의 밋밋한 UI를
"좋은 안목"으로 끌어올리는 스킬

Taste Skill은 AI 코딩 에이전트가 만들어내는 평범하고 generic한 프론트엔드("AI slop")를 더 강한 레이아웃·타이포그래피·모션·간격으로 업그레이드하는 휴대용 Agent Skill 프레임워크입니다. SKILL.md 한 장을 에이전트에 끼워 넣는 방식으로, 특정 프레임워크에 종속되지 않습니다.

01 개요

"AI Slop"이란 무엇이고, 왜 문제인가

에이전트에 "랜딩 페이지 만들어줘"라고 하면 대부분 비슷한 결과가 나옵니다. 보라/파랑 그라디언트, 중앙 정렬 히어로, Inter 폰트, 균일한 카드 그리드. 이렇게 어디서 본 듯한 generic한 출력이 AI slop입니다. Taste Skill은 이를 규칙으로 차단합니다.

02 작동 원리

SKILL.md가 끼어드는 위치

Taste Skill은 모델을 바꾸지 않습니다. 코드를 생성하기 직전, 에이전트에게 "이렇게 만들지 말고 이렇게 만들어라"는 디자인 가드레일을 주입합니다.

그림 1 · 브리프 → SKILL.md 주입 → 에이전트 → 결과물. 모델이 아니라 "지시"를 바꾼다.
03 스킬 카탈로그

스킬 13종 — 하나의 스킬, 하나의 역할

04 튜닝

3개의 다이얼 (taste-skill 전용)

taste-skill의 SKILL.md 상단에는 1–10 스케일의 다이얼 3개가 있습니다. 숫자만 바꾸면 같은 스킬로도 전혀 다른 결의 결과물을 얻을 수 있습니다.

DESIGN_VARIANCE

낮음 → 중앙 정렬·깔끔 / 높음 → 비대칭·모던
1 · clean10 · modern
MOTION_INTENSITY
애니메이션 깊이.
낮음 → hover 정도 / 높음 → scroll·magnetic
1 · hover10 · scroll
VISUAL_DENSITY
뷰포트당 정보량.
낮음 → 여유로움 / 높음 → 대시보드급 밀도
1 · spacious10 · dense
💡 어떤 스킬을 쓸까?
안전한 기본값은 taste-skill. GPT/Codex의 엄격한 규칙·모션 강제가 필요하면 gpt-taste. 기존 코드베이스 개선은 redesign-skill. 비주얼 방향이 이미 정해졌다면 soft / minimalist / brutalist. 에이전트가 자꾸 출력을 자른다면 output-skill을 추가하세요.
05 Anti-Slop 규칙

금지하는 것 vs 권장하는 것

Taste Skill의 핵심은 "더 잘하라"가 아니라 "이건 하지 마라"는 명시적 금지 목록입니다. generic한 AI 미학으로 회귀하는 길목을 규칙으로 막습니다.

🚫 금지 (Slop 신호)
  • "creative" 무드에 Inter 단독 사용
  • 보라/파랑 일색의 "AI 미학" 팔레트
  • 무조건 중앙 정렬 히어로 섹션
  • 본문의 em-dash(—) 남용 (v2에서 hard ban)
  • 반쯤 만들고 멈추는 플레이스홀더 주석
✓ 권장 (의도된 디자인)
  • 브리프에서 디자인 언어를 먼저 추론
  • 비대칭·계층이 있는 레이아웃 변화
  • 의미 있는 타이포 페어링과 간격 시스템
  • canonical GSAP 모션 스켈레톤 적용
  • 출력 전 strict pre-flight 체크
⚠️ 참고
Taste Skill과 shadcn/ui는 경쟁 관계가 아니라 함께 쌓아 쓰는 관계입니다. 접근성을 위해 shadcn 컴포넌트를 설치하고, 레이아웃·타이포·모션의 "안목"은 Taste Skill이 담당하는 식으로 병행하는 것이 권장됩니다.
06 설치 & 사용

한 줄로 설치하기

npx skills add CLI가 저장소의 skills/ 폴더를 스캔합니다. 코드 스킬이든 이미지 생성 스킬이든 설치 방법은 동일합니다.

시작 전 확인
Node.js / npx 환경이 필요합니다. CLI 대신 SKILL.md를 프로젝트에 직접 복사하거나 ChatGPT·Codex 대화에 붙여 넣어도 됩니다.
1
전체 스킬 설치
저장소의 모든 스킬(코드 + 이미지)을 한 번에 등록합니다.
bash 
npx skills add https://github.com/Leonxlnx/taste-skill
2
단일 스킬만 설치
install name(폴더명 아님)으로 하나만 고릅니다. v1로 고정하려면 design-taste-frontend-v1.
bash 
npx skills add https://github.com/Leonxlnx/taste-skill \
  --skill "design-taste-frontend"
3
이미지 우선 워크플로우
image-to-code-skill 사용 시 프롬프트에 파이프라인을 명시하면, 레퍼런스 생성 → 분석 → 구현까지 한 흐름으로 진행됩니다.
prompt 
# 프롬프트에 파이프라인을 그대로 적는다
follow the skill: generate images, then analyze, then code
