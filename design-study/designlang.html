designlang(저장소명 design-extract)은 헤드리스 브라우저를 임의의 URL에 붙여 살아있는 DOM에서 디자인 시스템을 읽어냅니다. 단일 실행으로 DTCG 토큰·Tailwind 설정· Figma 변수·모션 토큰·컴포넌트 해부도·브랜드 보이스·붙여넣기용 프롬프트 팩까지 17개 이상의 파일을 한 번에 내보냅니다.

01 / OVERVIEW

페인트가 아니라 아키텍처를 읽는다

대부분의 추출기는 색·폰트 같은 "표면"만 뽑습니다. designlang은 한 발 더 들어가 레이아웃 시스템, 4개 브레이크포인트의 반응형 거동, hover/focus/active 상태, WCAG 대비 점수, 멀티페이지 일관성, 라이브 소스 대비 드리프트까지 읽습니다.

npx designlang https://stripe.com 한 줄이면 충분합니다. 결과물은 ./design-extract-output/ 에 17개 이상 파일로 기록되며, 그대로 LLM·디자인 도구·코드베이스에 투입할 수 있습니다.
측정 축읽어내는 것
레이아웃 시스템그리드 패턴, flex 컨테이너, 컨테이너 너비, gap 값 — 토큰이 아닌 구조
반응형4개 브레이크포인트를 크롤해 무엇이 바뀌는지 보고 --responsive
인터랙션 상태프로그램으로 hover·focus를 발생시켜 델타 캡처 --interactions
모션 언어duration·easing 계열·스프링 감지·스크롤 연동 플래그, feel 지문(springy/smooth/mechanical/mixed)
컴포넌트 해부도variant × size × state 매트릭스를 가진 슬롯 트리를 타입드 .tsx로 출력
브랜드 보이스톤, 대명사 태도, 헤딩 스타일, CTA 동사 인벤토리
WCAG모든 fg/bg 쌍을 채점하고, 통과에 가장 가까운 색을 제안하는 remediation 팔레트

03 / OUTPUTS

한 번 실행 = 17개 이상 파일

모든 실행은 ./design-extract-output/ 에 기록됩니다. 대표 출력물은 다음과 같습니다.

파일내용
*-design-language.md19개 섹션 마크다운 — 어떤 LLM에든 먹여 디자인 재현
*-design-tokens.jsonW3C DTCG 토큰 (primitive + semantic + composite 레이어)
*-tailwind.config.js드롭인 Tailwind 테마
*-shadcn-theme.cssshadcn/ui globals.css 변수
*-figma-variables.jsonFigma Variables import (라이트 + 다크)
*-anatomy.tsx감지된 모든 컴포넌트 + variant의 타입드 React 스텁
*-motion-tokens.jsonduration·easing·spring·스크롤 연동 플래그
*-voice.json브랜드 보이스 — 톤·대명사 태도·CTA 동사
*-prompts/v0·Lovable·Cursor·Claude Artifacts 붙여넣기용 프롬프트
*-mcp.json디스크 기반 MCP 서버 페이로드
*-grade.html / .svg공유 가능한 디자인 리포트 카드 + Shields 스타일 배지v12.1·v12.2
*-remix.<vocab>.htmlbrutalist·swiss·art-deco·cyberpunk·soft-ui·editorial로 리스타일v12.3
멀티플랫폼 — --platforms web,ios,android,flutter,wordpress,all 을 더하면 iOS SwiftUI·Android Compose·Flutter·WordPress 블록 테마 출력이 추가됩니다. --emit-agent-rules 는 Cursor·Claude Code·범용 에이전트 규칙 파일을 생성합니다.

theme-swap--primary <hex> · v12.6

branddesignlang brand <url> · v12.7

pairpair <A> <B> · v12.8

clone / applyclone · apply -d ./app
동작하는 Next.js 스타터 생성 / 프레임워크 자동 감지 후 토큰 주입
drift / lint / visual-diffv9 · CI-ready
라이브 사이트 대비 드리프트 검사 / 토큰 파일 린트 / 두 URL 사이드바이사이드 diff. 실패 시 non-zero exit
