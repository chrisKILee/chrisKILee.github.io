😣 문제 정의 · 배경

기존의 어려움

  • 🔴 며칠 소요 — ERP 다운 → 블룸버그 검색 → 뉴스 취합 → PPT 보고서
  • 🔴 전문성 장벽 — LME 가격·거시지표 정량 분석은 전문 지식 필요
  • 🔴 분석-실행 괴리 — 외부 리포트는 단편적 추세만 전달, 액션 플랜 없음
  • 🔴 정적 대시보드 — 거시경제·뉴스 연계 분석 없음

✨ AI로 해결한 방식

  • ✅ 채팅 한 줄 → 수십 초에 통합 분석·리포트 자동 출력
  • ✅ 자연어 SQL 자동 생성 — 코딩 지식 불필요
  • ✅ CTRM 시뮬레이터 — "현물 N% / 선물 N%" 명확한 구매 가이드
  • ✅ 이중 교차 검증 — 통계 에이전트 + RAG 뉴스 에이전트 협업

③ 업무 효율성 32/35

데이터 수집·가공 시간 90% 이상 절감 명시. 기존 며칠 소요 업무를 수십 초로 단축하는 Full End-to-End 자동화 구현. 실제 실행 가능한 ~9,000줄 코드로 자동화 범위 넓음.

④ 아이디어 적절성 22/25

문제 3가지 명확 정의 (전문성 장벽·분석-실행 괴리·정적 대시보드). LangGraph 다중 에이전트 + CTRM 시뮬레이터 선택이 문제에 정확히 매칭. 실용적으로 구현됨.

⑤ 확산 가능성 18/25

Streamlit 채팅 UI로 비개발자 접근 가능. 재무·영업·물류 확장 계획 구체적. SQLite+ChromaDB 로컬 설치 진입 장벽 존재.

⑥ 조직 목표 연결 13/15

원가 변동성 통제·데이터 기반 의사결정 표준화와 직접 연결. 전사 부서 간 Silo 해소, 데이터 민주화 기여. 팀 전체 수준 영향 명확.

⚡ 주요 기능

🗣️ 자연어 데이터 조회

채팅으로 SQL 자동 생성, 다중 테이블 조인. "니켈·달러인덱스 2024년 보여줘" 한 줄로 통합 DataFrame 반환.

📈 추세 분석

이동평균, 시계열 분해, 다중 선형 회귀, 골든/데드크로스, VECM 공적분 분석. Plotly 인터랙티브 차트.

⚠️ 변동성·VaR 분석

일일 수익률 분포, 볼린저밴드, 95%·99% VaR(예상 최대 손실액) 자동 산출. 조달 예산 리스크 정량화.

🎯 CTRM 시뮬레이터

현물·선물·장기계약 비율을 1,000회 몬테카를로 시뮬레이션. 최적 헷징 비율 자동 도출.

🔔 리스크 모니터링

볼린저밴드·RSI·MACD 실시간 연산. "현재 과매수 → 즉각 매수 중단" 등 명확한 구매 타이밍 가이드.

📰 RAG 뉴스 교차 분석

ChromaDB + DuckDuckGo 이중 검색. 가격 급등락 진짜 원인(파업·정책 변화 등) 자동 분석.
