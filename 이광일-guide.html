해결한 문제

정보보호 업무의 수작업 반복을 AI와 자동화로 대체했습니다.

기존 방식 (Before)

  • 보안 솔루션 DB에서 수동 CSV 다운로드
  • 회사별로 데이터 분리·정제 수작업
  • PPT 보고서 직접 작성 후 품의·배포
  • 보안 규정 문의를 담당자가 직접 응대
  • 악성메일 의심 시 개인 판단에 의존

SECUCENTER 도입 후 (After)

  • 매월 영업일 3일 01시 자동 데이터 수집
  • 웹에서 언제든 최신 보고서 즉시 조회
  • AI 챗봇이 사내 규정 + KISA 기반 자동 응답
  • Gmail 우클릭 → 즉시 악성메일 위험도 판정
  • 5단계 분류 + VirusTotal 검증으로 신뢰도 확보

6대 핵심 체크리스트

AIVE-CONTEST 심사 기준에 맞춰 6가지 관점으로 평가됩니다.

🎯

① AI 도입 전략

Google Gemini 2.5 Flash를 정보보호 Q&A 챗봇과 악성메일 분석에 직접 API 연동. SDD 개발 방법론으로 설계 → 구현. VirusTotal·Gmail API와 멀티시그널 통합.

⚡

② 업무 효율성

월별 수동 데이터 수집·PPT 작성 업무를 Python 스크립트 자동화로 완전 대체. 임직원 반복 보안 문의를 AI 챗봇으로 자동 응대하는 구조 구축.

🔬

③ AI 성능 고도화

BM25 + ILIKE(동의어 31종) + pg_trgm 3단계 RAG 검색. LLM 쿼리 확장으로 검색 품질 향상. Gmail API로 실제 SPF/DKIM 인증 헤더 조회하여 분석 신뢰도 제고.

📸

④ 시각 증빙

GCP Cloud Run + Cloud SQL에 실운영 배포 완료 (infosec.vntgcorp.com). Chrome Extension 설치 패키지 제공. 외부 가이드 페이지 공개.

🌐

⑤ 확장성

세아그룹 + 브이엔티지 계열사 전체 적용. 회사별·페이지별 세분화 권한으로 멀티테넌시 지원. Chrome Extension은 임직원 전체 배포 가능.

💼

⑥ 현업 적용

현재 실운영 중. 수동 보고서 작성 업무 대체 완료. AI 챗봇과 악성메일 분석이 실무에 즉시 투입 가능한 상태로 배포됨.

주요 기능

4가지 핵심 기능이 하나의 포털로 통합됩니다.

🤖

정보보호 AI 챗봇

사내 정책문서를 업로드하면 Gemini가 질문에 맞춤 답변. 세아 내부 규정 / KISA 가이드라인 / 법령 출처를 구분하여 신뢰도 있는 응답 제공.

🛡️

악성메일 AI 분석

Chrome Extension으로 Gmail 우클릭 → 즉시 분석. Gemini + VirusTotal + SPF/DKIM 검증으로 5단계 위험도(매우위험/위험/주의/안전/홍보성) 판정.

📊

운영보고서 자동화

DLP·NAC 데이터를 매월 자동 수집하여 대시보드로 시각화. PDF/Excel 내보내기, 보고서 Publish 상태 관리 기능 포함.

🎯

APT 모의훈련 대시보드

악성메일 모의훈련 결과를 라운드별·회사별·팀별로 차트 시각화. 2회차 이상 트렌드 분석, 4단계 클릭 현황(미열람/메일열람/링크클릭/정보입력) 통계.

AI 활용 방식 및 아키텍처

단순 API 호출을 넘어 멀티시그널 통합과 3단계 RAG 검색을 구현했습니다.

정보보호 챗봇 흐름

사용자 질문 → Gemini 쿼리 확장 → BM25+ILIKE+pg_trgm → Gemini 답변 생성 → 출처 분류 답변

악성메일 분석 흐름

Gmail 우클릭 → Chrome Extension → VirusTotal API + Gmail API → Gemini 판정 → 5단계 위험도

기술 스택

Google Gemini 2.5 Flash VirusTotal API v3 Gmail API NestJS 10 React 18 TypeScript PostgreSQL 15 Prisma 5 Chrome Extension MV3 GCP Cloud Run Docker Python (자동 수집)

성과 및 시각 증빙

GCP Cloud Run에 실운영 배포 완료. 실제 업무에 투입 중입니다.
