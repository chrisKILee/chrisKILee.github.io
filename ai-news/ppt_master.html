02 아키텍처

SVG → DrawingML 변환 파이프라인

PPT Master의 핵심은 SVG를 중간 표현 형식으로 활용한다는 점이다. SVG와 DrawingML은 모두 절대 좌표 기반 2D 벡터 표현이라는 공통 철학을 공유한다.

왜 SVG인가?
DrawingML은 너무 장황해 AI 생성에 부적합하고, HTML/CSS는 절대 좌표 캔버스가 없다. SVG는 DrawingML과 동일한 방언이라 자연스럽게 번역이 가능하다.
형식 PPT Master 선택 이유 비고
SVG ✓ 채택 DrawingML과 동일 철학, AI 생성에 최적 중간 표현 형식으로 사용
DrawingML 직접 생성 ✗ 너무 장황, AI 생성 부적합 최종 출력 형식
HTML/CSS 미사용 절대 좌표 캔버스 없음 문서 표현용
래스터 이미지 폴백만 편집 가능성 상실 SVG 변환 실패 시 자동 폴백

05 설치 & 시작

빠른 시작 가이드

Python 3.10 이상이 설치된 환경에서 아래 단계를 따른다. 전체 설치에 약 10–15분 소요.

사전 요구사항
Python 3.10+ · 인터넷 연결 (AI API 호출) · AI 에디터 중 하나 (Claude Code / Cursor / VS Code Copilot)
1
저장소 클론
GitHub에서 PPT Master를 다운로드합니다.
bash 
git clone https://github.com/hugohe3/ppt-master.git
cd ppt-master
2
의존성 설치
가상환경을 만든 후 패키지를 설치합니다 (macOS/Linux 기준).
bash 
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
3
소스 파일 배치
projects/ 디렉토리에 변환할 파일(PDF, DOCX, Markdown 등)을 넣습니다.
bash 
ppt-master/
├── projects/          ← 여기에 소스 파일 배치
│   └── my_report.pdf
└── exports/           ← 생성된 .pptx 저장됨
4
AI 에디터에서 생성 요청
Claude Code, Cursor, 또는 VS Code Copilot에서 프로젝트 디렉토리를 열고 아래처럼 요청합니다.
prompt (Claude Code) 
projects/my_report.pdf를 "Tech/SaaS" 스타일의
16:9 프레젠테이션으로 변환해줘.
5
결과 확인 및 편집
exports/ 디렉토리에 생성된 .pptx 파일을 PowerPoint 또는 Keynote에서 열어 자유롭게 편집합니다. 생성 시간은 10–20장 기준 약 10–20분.
