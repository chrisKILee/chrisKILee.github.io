Google, Gemini CLI 종료하고
Antigravity CLI로 강제 전환

Google이 약 1년간 운영한 AI 터미널 도구 Gemini CLI를 2026년 6월 18일부로 종료한다. 대체제인 Antigravity CLI는 5월 19일 이미 공개됐으나, 오픈소스에서 독점 소프트웨어로 전환되면서 커뮤니티의 강한 반발을 사고 있다. Google의 전략 핵심은 단일 모델 상호작용에서 멀티에이전트 워크플로우로의 이동이다.

TL;DR · 지금 당장 알아야 할 4가지

  • 종료 대상: 개인, Pro, Ultra 구독자 — 6월 18일 이후 서비스 요청 불가.
  • 예외: Standard·Enterprise 라이선스 보유자는 계속 사용 가능.
  • 대안: Antigravity CLI는 5월 19일부터 모든 사용자에게 공개.
  • 변화: 오픈소스(Apache 2) → 독점 소프트웨어 전환. Python → Go 언어.

Migration Guide

마이그레이션 핵심 포인트

01
6월 18일 전 전환 필수 — 이날 이후 Gemini CLI는 개인·Pro·Ultra 사용자의 서비스 요청을 처리하지 않는다.
02
Antigravity CLI 설치 — 2026년 5월 19일부터 모든 사용자에게 공개됐다. Google 공식 채널에서 설치 방법을 확인하자.
03
Agent Skills · Hooks 이전 가능 — 기존 Gemini CLI의 핵심 기능은 Antigravity로 이전이 지원된다. 단, 초기 기능 패리티가 완전하지 않으므로 전환 후 동작 확인이 필요하다.
04
Enterprise 고객은 예외 — Standard·Enterprise 라이선스 보유자는 기존 Gemini CLI를 계속 사용할 수 있고 최신 모델 접근권도 유지된다.
05
대화 이력 자동 이전 없음 — 기존 대화 기록은 수동으로 백업해야 한다.

⚠ 오픈소스 역전

Gemini CLI는 Apache 2 라이선스로 공개돼 6,000개 이상의 커뮤니티 PR을 받았다. Antigravity로의 전환은 이 오픈소스 기여를 기반으로 독점 제품을 출시한 것이라는 비판이 이어지고 있다. 일부에서는 "Bait-and-Switch" 패턴으로 부르고 있다.

브랜드 혼란

수백만 명이 인지하는 "Gemini" 브랜드를 버리고 생소한 "Antigravity"를 채택한 결정에 대해 마케팅 전략 측면에서 의문을 제기하는 목소리가 많다.

killedbygoogle.com 패턴

경쟁 도구 언급

일부 사용자들은 Gemini CLI 대안으로 Claude Code 등 경쟁 도구를 거론하며, 전환 시점에 도구 선택을 재검토하고 있다는 반응을 보이고 있다.

과금 투명성 우려

가격 체계와 quota 정책이 불명확하다는 지속적인 불만이 있다. 커뮤니티에서는 동일 작업에 이전보다 더 많은 사용량이 소비된다는 보고도 나오고 있다.

Strategic Context

Google AI 도구 전략의 변화

이번 Gemini CLI → Antigravity CLI 전환은 단순한 도구 교체가 아니다. Google이 단일 모델 상호작용에서 멀티에이전트 워크플로우 중심의 플랫폼으로 전략을 전환했다는 공개 신호다.

Antigravity CLI의 핵심 기술적 진보는 Go 기반의 성능 개선과 비동기 서브에이전트 지원이다. 이는 Claude Code, GitHub Copilot 등 경쟁 도구들이 이미 지향하는 방향과 일치하며, AI 터미널 도구 시장의 패러다임이 전환되고 있음을 보여준다.

다만 오픈소스에서 독점 소프트웨어로의 전환, 초기 기능 미완성, 불명확한 가격 정책은 기존 Gemini CLI 사용자와 오픈소스 커뮤니티의 신뢰를 손상시키는 위험 요소로 지적된다. Gemini CLI가 쌓아온 100,000개 이상의 GitHub 스타와 6,000개의 커뮤니티 PR이 이 전환 결정에 가려지는 형국이다.
