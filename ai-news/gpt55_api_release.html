OpenAI, GPT-5.5와 GPT-5.5 Pro를 API에 공개 — GPT-4.5 이후 첫 완전 재학습

2026년 4월 23일 ChatGPT·Codex에 먼저 적용된 GPT-5.5가 이튿날 API로 개방됐다. GPT-4.5 이후 처음으로 아키텍처부터 다시 학습한 모델로, 1M 토큰 컨텍스트·네이티브 멀티모달·MCP 내장이 특징이다. 동시에 가격은 GPT-5.4 대비 2배 인상되어 개발자 커뮤니티 반응이 엇갈리고 있다.

TL;DR · 오늘 꼭 알아야 할 5가지

  • GPT-5.5 모델 ID gpt-5.5, Pro는 gpt-5.5-pro — 오늘부터 API 사용 가능.
  • 컨텍스트 윈도우 1,000,000 토큰 (Pro는 1,050,000) — MRCR 512K-1M 구간 +37pp 개선.
  • API 입력/출력 단가 $5/$30 per 1M — GPT-5.4($2.50/$15) 대비 2배 인상.
  • GPT-5.5 Pro는 캐싱 미지원, Reasoning Token 지원 — 최고 정확도 우선 사용 사례 대상.
  • GPT Image 2(ChatGPT Images 2.0) 동시 출시 — DALL-E 3은 2026년 5월 12일 은퇴.

How to Use

API 사용법 — 모델 ID와 코드 예시

기존 GPT-5.4 호출 코드에서 모델 ID만 교체하면 된다. Responses API(권장)와 Chat Completions API 모두 지원한다.

Python · Chat Completions API
from openai import OpenAI client = OpenAI(api_key="YOUR_API_KEY") response = client.chat.completions.create( model="gpt-5.5", # Pro: "gpt-5.5-pro" messages=[ {"role": "user", "content": "Your prompt here"} ] ) print(response.choices[0].message.content)
Python · Responses API (고급 — Reasoning Effort 지정)
response = client.responses.create( model="gpt-5.5-pro", messages=[ {"role": "user", "content": "Complex reasoning task"} ], reasoning={"effort": "high"} # low / medium / high / xhigh )
프롬프트 캐싱 조건 (GPT-5.5 표준만 해당)
최소 1,024 토큰 이상이어야 캐싱 적용. 캐시 유지 시간 5~10분(비활성), 최대 1시간. 정적 내용(지시사항, 예시)을 프롬프트 앞에, 동적 콘텐츠(사용자 입력)를 뒤에 배치해야 히트율이 높아진다.

용어 사전

Reasoning Token

Prompt Caching
동일한 프롬프트 접두사를 재사용할 때 캐시에서 처리해 비용·속도를 줄이는 기법. 최소 1,024 토큰 필요.
MCP Model Context Protocol
AI 모델이 외부 툴·데이터 소스와 통신하는 표준 프로토콜. GPT-5.5에 빌트인으로 지원된다.
