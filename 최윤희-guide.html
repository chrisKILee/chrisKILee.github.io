😣 문제 정의 · 배경

기존의 어려움

  • 🔹 수십~수백 개의 Jira 이슈 댓글을 매일 수동으로 하나씩 확인
  • 🔹 중요/일반 이슈 구분을 사람이 직접 판단해야 하는 부담
  • 🔹 이슈 수 증가 시 중요 업데이트 누락 위험 증가
  • 🔹 별도 아카이빙 없어 과거 업무 이력 추적 어려움

✨ AI로 해결한 방식

  • ✅ Jira Automation이 정해진 시각에 자동 트리거
  • ✅ Rovo AI 에이전트가 전체 댓글 수집·분류·요약
  • ✅ Confluence에 날짜별 보고서 자동 게시 + 이메일 알림
  • ✅ 담당자는 '작성자'에서 '검토자'로 역할 전환

✅ 평가 체크리스트

① AI 활용 유형

✅ 바이브코딩 ✅ 런타임 AI (Rovo Agent) ✅ 노코드 AI (Jira Automation)

② 자동화 대상

✅ 반복 보고서 취합·정리 ✅ 데이터 수집·분류·가공 내부 문의·요청 처리 ✅ 알림·모니터링 자동화
③ 업무 효율성 19/35

일일·주간 보고 전 과정 완전 자동화. 수동 준비 시간 사실상 0분 달성. 실제 팀 운영 중 (+3점). 정확한 수치 측정은 없으나 체감 절감 효과 명확.

④ 아이디어 적절성 22/25

Jira 댓글이라는 기존 데이터 자산 그대로 활용. 기존 도구 생태계 내 해결로 학습 비용 0. 단계적 확장(일일→주간) 리스크 최소화.

⑤ 확산 가능성 19/25

코드 없는 노코드 구성으로 비개발자 접근성 우수. JQL·프롬프트 수정만으로 타 팀 즉시 적용 가능. Jira 댓글 문화 전제 필요.

⑥ 조직 목표 연결 13/15

팀 전체 보고 체계를 수동→AI 검토 기반으로 전환. Confluence 영구 아카이빙으로 조직 지식 자산화. 전사 재사용 템플릿 완성.

⚡ 주요 기능

📅 일일 자동 보고

  • 🔹 매일 오후 4시 자동 실행
  • 🔹 당일 이슈 댓글 전체 수집
  • 🔹 33시간 버퍼로 누락 방지
  • 🔹 Confluence 날짜별 페이지 자동 생성

📊 주간 구조화 보고

  • 🔹 매주 목요일 오후 1시 자동 실행
  • 🔹 176시간 댓글 자동 수집
  • 🔹 KEY/GENERAL 중요도 분류
  • 🔹 배경→경과→결론 논리 흐름 보고서

🤖 AI 중요도 분류

  • 🔹 6가지 기준으로 자동 분류
  • 🔹 의사결정·리스크·블로커 → KEY
  • 🔹 단순 진행 업데이트 → GENERAL
  • 🔹 3인 이상 댓글 이슈 자동 포착

📬 팀 이메일 알림

  • 🔹 보고서 게시 즉시 팀 전체 자동 발송
  • 🔹 VNTG-users 그룹 일괄 수신
  • 🔹 별도 공유·전달 작업 불필요

🗂️ 히스토리 아카이빙

  • 🔹 Confluence에 날짜별 영구 저장
  • 🔹 전체 텍스트 검색 가능
  • 🔹 인력 변동 시 업무 연속성 확보

🔧 노코드 커스터마이징

  • 🔹 코드 작성 전혀 없음
  • 🔹 JQL 조건 수정만으로 범위 조정
  • 🔹 자연어 프롬프트로 형식 변경
