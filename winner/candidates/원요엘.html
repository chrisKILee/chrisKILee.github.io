😣 문제 정의 · 배경

❗ 기존의 어려움

  • 🔹 AI 자동화 사각지대 — 로우코드(OutSystems) 특성상 백엔드 소스코드 접근 불가 → 일반 AI 코드 리뷰·단위 테스트 도구 활용 불가
  • 🔹 수동 QA 병목 — 기능 1건당 화면 클릭 검증에 평균 180분 소요
  • 🔹 스크립트 파손 반복 — UI 변경마다 Selenium 로케이터 깨짐 → 수정 공수가 자동화 이점을 역전

✨ AI로 해결한 방식

  • ✅ "코드 대신 화면을 본다" — AI가 실제 브라우저 DOM을 직접 분석해 테스트 생성
  • ✅ Self-Healing 디버거 — UI 변경 시 AI가 로케이터를 스스로 수정·재실행 (개발자 개입 0시간)
  • ✅ 다중 에이전트 파이프라인 — Spec Writer → Executor → Debugger → Doc Writer 자동 순환
