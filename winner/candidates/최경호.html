AI-WORKER 인증 과제

V-GROW

VNTG의 R&R(역할과 책임) 데이터를 기반으로 리더-팀원 간 1on1 코칭을 체계화하고, GPT-4o가 면담 전 아젠다 추천부터 면담 후 녹음 자동 분석까지 전주기를 지원하는 사내 코칭 플랫폼

2026. 4. 6 🏅 최종후보

Representative Screen

😣 문제 정의 · 배경

기존의 어려움

  • ✗ 조직장이 면담 내용 수기 작성, 이력 관리 어려움
  • ✗ 전사 현황 파악은 개별 취합 요청 후 수일 소요
  • ✗ 범용 SaaS로 계열사별 독립 평가 프로세스 커버 구조적 한계
  • ✗ 미완료 액션 아이템 수동 추적, 이력 단절

✨ AI로 해결한 방식

  • ✅ GPT-4o 아젠다 자동 추천 — R&R 기반 코칭 질문 생성
  • ✅ 오디오 AI 파이프라인 — Whisper STT + 화자분리 + 요약 자동화
  • ✅ 관리자 대시보드 — 전사 현황 실시간 조회
  • ✅ TMS 연동 — 마스터 데이터 이중관리 원천 차단

✅ 평가 체크리스트

① AI 활용 유형

✅ 바이브코딩 ✅ 런타임 AI 노코드 AI

② 자동화 대상

✅ 반복 보고서 취합 ✅ 데이터 수집·분류 ✅ 알림·모니터링 ✅ 면담 이력 관리
③ 업무 효율성
  • 🎯면담 사전 준비 건당 10~15분 절감, 전사 현황 파악 수일 → 실시간 전환.
  • 💡액션 아이템 이월 · 오디오 분석 완전 자동화 구현.
  • 📊파일럿 배포 상태 가점 반영
④ 아이디어 적절성
  • 🎯TMS 운영 경험 기반 VNTG 특화 기획.
  • 💡외부 SaaS 구조적 한계 인식 후 내부 개발 선택.
  • 📊TMS 연동으로 마스터 데이터 이중관리 차단 설계 명쾌
⑤ 확산 가능성
  • 🎯웹 브라우저 기반, 별도 설치 불필요.
  • 💡역할별 UI 분리로 비개발자 접근 가능.
  • 📊TMS 연동으로 계열사 확장 시 추가 개발 최소화 구조 확보.
  • 🚀무료서버 한계가 현재 진입 장벽
⑥ 조직 목표 연결
  • 🎯R&R 기반 코칭 디지털 전환 직접 연결.
  • 💡AI 개발 방법론 팀 내 공유(2회).
  • 📊전사 실시율·진행현황 데이터 가시화로 경영진 의사결정 지원 구조

⚡ 주요 기능

🤖 AI 아젠다 추천

팀원 R&R + 이전 미팅 요약 기반으로 GPT-4o가 코칭 질문 3~5개를 자동 생성. 매 면담마다 최신화된 질문 제안

🎙️ 오디오 AI 파이프라인

녹음 업로드 → Whisper STT → 화자 분리 → 구간 요약 → 전체 요약 → Action Item 추출 → 리더십 점수까지 완전 자동화

🔁 액션 아이템 자동 이월

이전 면담의 미완료 액션 아이템을 다음 세션 시작 시 자동 이월. 이력 단절 없이 연속성 있는 코칭 가능

📊 리더 대시보드

팀원별 1on1 현황을 신호등 상태(정상/1개월 지남/2개월 초과)로 시각화. 미팅 추이·R&R 진행률 한눈에 확인

🏢 관리자 대시보드

전사 1on1 실시율, 부서별 히트맵, 리더 랭킹, R&R 현황을 실시간 조회. 기존 수일 소요 취합을 즉시 대체

🔗 TMS HR 연동

그룹 인사평가 시스템(TMS)과 연동 인터페이스 구현. 마스터 데이터 이중관리 원천 차단, 계열사 확장 시 추가 개발 최소화

🧠 AI 활용 방식 · 기술 스택

🤖 AI 모델 · 활용

  • 🔹 OpenAI Whisper — 면담 오디오 STT 변환
  • 🔹 GPT-4o — 화자 분리, 구간 요약, 전체 요약, Action Item 추출
  • 🔹 GPT-4o — leader_hints, leadership_score 생성
  • 🔹 GPT-4o — R&R 초안 생성, ALIGN 체크, 구체화 제안
  • 🔹 asyncio.gather — 병렬 처리로 파이프라인 속도 최적화

🛠️ 기술 스택

  • 🔹 Backend — Python 3.11+, FastAPI 0.109, SQLAlchemy 2.0
  • 🔹 Frontend — React 19, TypeScript, Vite, Tailwind CSS v4
  • 🔹 DB — PostgreSQL (Supabase), Alembic 마이그레이션
  • 🔹 Storage — Google Cloud Storage (오디오 파일)
  • 🔹 배포 — Vercel (현재 무료 플랜, 파일럿 단계)

🏗️ 아키텍처 흐름

면담 전: 팀원 R&R + 이전 요약 → GPT-4o → 아젠다 추천
→ 면담 중: 오디오 녹음 → GCS 업로드 → 타임라인 기록
→ 면담 후: BackgroundTask 트리거 → Whisper STT → 화자분리 → 요약·Action Item(병렬) → leader_hints·리더십점수(병렬) → COMPLETED
→ 대시보드: PostgreSQL → 리더/관리자 API → React 차트
