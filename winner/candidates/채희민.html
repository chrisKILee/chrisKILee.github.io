😣 기존의 어려움 · 해결 방식

기존의 어려움

  • 🔴 AI 할루시네이션
    Copilot이 존재하지 않는 테이블·컬럼을 그럴듯하게 만들어 냄
  • 🔄 컨텍스트 스위칭 비용
    IDE ↔ DB 클라이언트를 수시로 오가며 스키마 수동 대조
  • ⏱️ 디버깅 낭비
    잘못 생성된 쿼리·코드를 찾아 수정하는 시간 반복

✨ AI로 해결한 방식

  • 🔌 MCP 서버 직접 개발
    Copilot이 실시간으로 사내 Oracle DB 스키마를 참조
  • 💬 자연어로 DB 질의
    "소형압연 테이블 알려줘" → AI가 즉시 정확한 테이블 목록 반환
  • 🔒 보안 내재화
    SQL Injection 방지 + SELECT 전용 제한으로 안전하게 운영

③ 업무 효율성
  • 🎯AS-IS/TO-BE 흐름이 명확하고 컨텍스트 스위칭 제거 효과 확인됨.
  • 💡구체적 시간 절감 수치 미제시로 감점.

  • 💡설치 진입 장벽(env 설정 등)이 일부 존재.
⑥ 조직 목표 연결
  • 🎯AI 활용 인프라를 팀 단위로 구축해 조직 AI 고도화 방향과 직접 연결됨.

⚡ 주요 기능

🔍 소스코드 검색

함수명·변수명을 .java/.py/.sql 파일에서 즉시 검색. AI가 기존 코드 패턴을 파악해 일관된 코드 생성.

🗃️ DB 객체 검색

"소형압연 테이블" 한글로 질의 → Oracle 테이블명·코멘트 즉시 반환. 한글 업무 키워드 자동 매핑.

▶️ SQL 실행

AI가 작성한 SELECT 쿼리를 즉시 실행하여 결과 확인. 보안상 읽기 전용으로 제한.

🔤 한글 키워드 매핑

소형압연→SPRF, 빌렛정정→SPRW 등 사내 업무 용어를 DB prefix로 자동 변환.

🔒 보안 내재화

SQL Injection 방지(바인드 변수), RCE 차단, SELECT 전용 제한으로 사내 DB 안전하게 연동.

🌐 SSE/stdio 이중 지원

로컬(stdio)과 원격(SSE, 포트 20007) 두 가지 연결 방식 지원. 팀 서버로 배포 가능.

🧠 AI 활용 방식 · 기술 스택

🔌 MCP 아키텍처

  • ① 개발자가 IDE에서 자연어로 질문
  • ↓ MCP 프로토콜
  • ② Oracle MCP Server가 요청 처리
  • ↓ python-oracledb
  • ③ 사내 Oracle DB에서 실시간 조회
  • ↓ JSON 결과 반환
  • ④ Copilot이 정확한 SQL/코드 생성

🛠️ 기술 스택

  • 🐍 Python 3.14 — 서버 런타임
  • ⚡ FastMCP — MCP 서버 프레임워크
  • 🗄️ python-oracledb — Oracle 공식 드라이버
  • 🌐 Starlette — SSE 웹 서버 (내장)
  • 🤖 GitHub Copilot / Cursor — AI IDE

💡 MCP(Model Context Protocol)란?

AI가 외부 데이터·시스템에 동적으로 접근할 수 있게 해주는 최신 표준 프로토콜입니다. 프롬프트에 매번 스키마를 복사·붙여넣기하지 않고, AI가 필요한 순간 자동으로 DB를 조회합니다.
