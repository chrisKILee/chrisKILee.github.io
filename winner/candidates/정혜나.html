IT 서비스 품질지표를 전 계열사 통합 웹 대시보드로 전환, 월 8시간 수작업을 3분으로 단축하고 ITGC 가시성 확보에 직접 기여한 실전 과제

문제 정의 · 배경

기존의 어려움

매월 스프레드시트에서 데이터 수기 취합 → 차트 생성 → 구글슬라이드 수기 입력의 3단계 반복. 계열사 추가 시마다 작업 공수가 선형으로 증가. 총 월 8시간 소모.

AI로 해결한 방식

Google Apps Script 웹앱으로 전 계열사 IT 서비스 품질지표 통합 대시보드 구축. 계열사·월 선택만으로 즉시 지표 조회. 3분으로 단축 (97.8% 절감).
