  • 🔹 보안·라이선스 이슈로 신기술 도입 진입 장벽 높음

  • ✅ bar / line / pie 차트 자동 생성 (Chart.js)

⚡ 주요 기능

🗣️ 자연어 질문 분석

자유로운 한국어로 질문 입력 → Gemini AI가 CSV 데이터를 자동 분석·요약

📊 차트 자동 생성

AI가 데이터 특성에 맞는 bar / line / pie 차트 자동 선택 후 즉시 렌더링

📂 Drive CSV 연동

Google Drive의 CSV 파일을 자동 읽기. 데이터 교체만으로 다양한 분석 가능

💡 예시 질문 버튼

6종 예시 질문 원클릭 입력. 분석 방법을 모르는 비개발자도 즉시 시작 가능

🕐 질문 히스토리

최근 5개 질문 자동 저장. 클릭 한 번으로 이전 질문 재실행

🛡️ 에러 안전 처리

API 실패·파싱 오류 시 화면이 멈추지 않도록 안전한 fallback 응답 제공

🧠 AI 활용 방식 · 기술 스택

🤖 AI 모델

  • 🔹 Gemini 2.0 Flash — 런타임 분석 엔진
  • 🔹 Claude Code — 개발 단계 AI Pair

🛠️ 기술 스택

  • 🔹 Google AppScript (V8) — 서버리스 백엔드
  • 🔹 Chart.js — 인터랙티브 차트
  • 🔹 Google Drive — CSV 데이터 저장소

📡 데이터 흐름

① 자연어 질문 입력 → ② Drive CSV 자동 로드 (최대 2,000행) → ③ JSON 배열 변환 + 프롬프트 구성 → ④ Gemini API 호출 → ⑤ JSON 응답 파싱 (text + chartType + labels + values) → ⑥ Chart.js 차트 렌더링
