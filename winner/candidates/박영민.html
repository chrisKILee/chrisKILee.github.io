😣 문제 정의 · 배경

기존의 어려움

  • 🔴 개발 물량 폭증 — SAP 도입·차세대 MES 준비로 대규모 시스템 개편 필요
  • 🔴 암묵지 의존 — 시스템 지식이 개발자 개인에게 종속, 병목 발생
  • 🔴 설계 문서 부재 — 선 코딩·후 문서화로 설계 문서 확보율 10%에 불과
  • 🔴 야근·외부 인력 의존 — 물량 급증 시 ODC 인력 불가피

✨ AI로 해결한 방식

  • ✅ Ask → Plan → Agent 3단계 방법론 수립 — 개발자는 설계 집중, 구현은 AI 위임
  • ✅ MES SiS Framework MCP 서버 직접 개발 — AI가 도메인 규칙 실시간 참조, 환각 최소화
  • ✅ PDF 13종 교육 가이드 제작 — 팀 내 전파 완료, 타 팀 "따라 하기 쉽다" 피드백

③ 업무 효율성
  • 🎯단위 기능 개발 6시간 → 2시간(67% 단축), 월 처리 건수 15 → 24건(60% 향상).
  • 💡연간 절감 시간 1,152시간(4h/건 × 24건 × 12개월).
  • 📊실제 26년 2~3월 운영 실적으로 검증.

  • 💡MES 도메인 MCP 서버를 직접 개발해 환각을 근본적으로 해결.
  • 📊문제-해결 논리가 매우 명쾌하고 실용적으로 구현됨.
⑤ 확산 가능성
  • 🎯팀 내 교육 완료.
  • 💡타 팀에서 "보고 따라 하기 쉽다" 피드백 확보.
  • 📊Ask→Plan→Agent 방법론은 언어·도메인 무관 범용 적용 가능.
  • 🚀PDF 13종 가이드로 진입 장벽 최소화.
⑥ 조직 목표 연결
  • 🎯2026년 센터 비전 "일하는 방식의 변화" 직접 달성.
  • 💡MES2팀 KPI 50% 직접 부합(운영 문서 자산화·시스템 안정화·역량 고도화).
  • 📊팀 전체 AI 활용 개발 체계 정립.

⚡ 주요 기능

🧠 Ask → Plan → Agent

  • 🔹 Ask: 요구사항 명확화, AI에 컨텍스트 전달
  • 🔹 Plan: AI가 설계 문서 생성 (개발자 검토)
  • 🔹 Agent: AI가 코드 자동 생성·리팩토링

🔌 SiS Framework MCP 서버

  • 🔹 Resources: 3-Tier 아키텍처 문서 AI 실시간 제공
  • 🔹 Tools: 화면 코드로 파일 경로 자동 조회
  • 🔹 Prompts: 시나리오별 표준 가이드 제공

📚 AI 페어 프로그래밍 가이드

  • 🔹 PDF 13종 교육 자료 (설치~고급 전략)
  • 🔹 MES 아키텍처 소개 및 Cursor 연결 방법
  • 🔹 AI 환각(Hallucination) 이해와 대응 전략

🗂️ 화면 파일 경로 자동 조회

화면 코드(예: SPRG700E02) 입력 시 UX/Biz 계층의 Pop, Proc, Tds, Biz, SRD 파일 경로를 자동 반환. 파일 검색 시간 제거.

📐 신규 화면 추가 표준 가이드

조회/등록/수정 화면 유형별로 생성 순서·노드ID·서비스ID 규칙을 MCP Prompt로 표준화. 개발자 실수 방지.

💡 코드 컨벤션 자동 적용

.cursorrules 파일로 SIS Framework 코드 컨벤션을 정의하여 AI가 일관된 스타일로 코드 생성. 리뷰 부담 감소.

🧠 AI 활용 방식 · 기술 스택

AI/IDE 도구

  • 🔹 Cursor AI — Claude 기반 Agent Mode
  • 🔹 MCP (Model Context Protocol)
  • 🔹 Ask → Plan → Agent 방법론

MCP 서버 기술 스택

  • 🔹 TypeScript + Node.js 18+
  • 🔹 @modelcontextprotocol/sdk ^1.27.0
  • 🔹 zod ^3.23.0 (유효성 검증)

🔄 개발 흐름 (Cursor + MCP)

① Ask → ② Plan → ③ Agent → MCP 참조 → MES 코드 생성

MCP 서버가 SIS 3-Tier 아키텍처·규칙을 AI에 실시간 공급 → AI 환각(Hallucination) 최소화 → 일관된 고품질 코드 생성
