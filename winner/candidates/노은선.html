😣 문제 정의 · 배경

기존의 어려움

  • ❗ 경영전략회의 등 대규모 회의 녹취록 정리에 최대 1.5일(12시간) 소요
  • ❗ 일반 STT AI의 사내 전문 용어·고유명사 오인식으로 수기 교정 반복
  • ❗ 녹취(원문)와 요약(회의록) 분리 작업으로 추가 공수 발생
  • ❗ 회의록 담당자 집중 리소스가 Non-core 업무에 묶임

✨ AI로 해결한 방식

  • 🎙️ Gemini 멀티모달 — 별도 STT 엔진 없이 오디오 직접 분석
  • 📖 사내 용어 딕셔너리 주입 — Google Sheets → Gemini 컨텍스트(RAG 유사)
  • ⚙️ n8n End-to-End 자동화 — Drive 업로드 → Docs 저장 전 과정
  • 📄 녹취록·회의록 분리 생성 — 원문·요약 동시 아카이빙

✅ 평가 체크리스트

① AI 활용 유형

✅ 바이브코딩 ✅ 런타임 AI ✅ 노코드 AI

③ 업무 효율성
  • 🔹 녹취록 초안 생성 1.5일 → 3분 (99% 단축)
  • 🔹 연간 약 143시간 절감 (월 1회 대규모 회의 기준)
  • 🔹 사내 용어 오인식 제거 → 수기 교정 공수 대폭 감소
④ 아이디어 적절성
  • 🔹 Knowledge Base 결합 — 단순 프롬프팅 한계 돌파
  • 🔹 Event-driven 아키텍처 — 인간 개입 없는 완전 자동화
  • 🔹 Google Workspace 완결형 — 별도 인프라 불필요
⑤ 확산 가능성
  • 🔹 트리거 경로 + 딕셔너리 교체만으로 타 부서 자체 배포 가능
  • 🔹 Drive 업로드만으로 동작 — 비개발자 진입장벽 없음
  • 🔹 현재 1인 운영 — 타 부서 실사용 실증 필요
⑥ 조직 목표 연결
  • 🔹 전사 AI 기반 업무 효율화 기조와 직접 부합
  • 🔹 Non-core 업무 자동화 → Core 업무 리소스 확보
  • 🔹 원문·요약 아카이빙으로 사내 데이터 자산 축적 기여

⚡ 주요 기능

🎙️ Event-driven 트리거

Google Drive 지정 폴더에 MP3 업로드 시 n8n이 자동 감지 → 워크플로우 즉시 시작

📖 용어 딕셔너리 로드

Google Sheets 사내 용어집 전체 조회 → Python으로 전처리 → Gemini 컨텍스트에 주입

🤖 Gemini 멀티모달 STT

오디오 + 용어 사전 → Gemini Native 오디오 분석 → 원문 녹취록 생성 (별도 STT 엔진 불필요)

✏️ 녹취록 정제 Agent

화자 구분, 구간 분류, 사내 용어 교정 → INDEX 구조(날짜/참여자/요약/전문) 포함 정제

📋 회의록 자동 생성

정제 녹취록 기반 핵심 요약 회의록 생성 → 날짜·참여자 수·내용 요약·요약본 포함

💾 Google Docs 자동 저장

녹취록·회의록을 별도 Docs 파일로 자동 생성 — [파일명]_녹취록, [파일명]_요약 분리 아카이빙

🧠 AI 활용 방식 · 기술 스택

파이프라인 흐름 (End-to-End 자동화)

① Drive 업로드 — MP3 업로드 감지 → n8n 워크플로우 자동 시작
② 용어 주입 — Sheets 딕셔너리 로드 → Python 전처리 → keywords 문자열 생성
③ Gemini STT — 오디오 + keywords → Raw 녹취록 (불확실 단어 괄호 표기)
④ 녹취록 정제 — Gemini Agent → 화자 분리, 구간 분류, 용어 교정
⑤ Docs 저장 — 녹취록·회의록 별도 파일 자동 생성 (2~3분 내 완료)
