⚡ 주요 기능

🕐 월간 자동 스케줄러

매월 1일 07:00 자동 감지 및 실행. 중복 발송 방지 로직 내장. 수동 재전송 버튼도 지원.

🗄️ Oracle DB 자동 쿼리

AOD, LT, LT2 3개 테이블에서 전월 합금철 투입 실적을 자동으로 기간 계산하여 조회.

📊 엑셀 보고서 자동 생성

ClosedXML로 AOD/LT 데이터를 각각 XLSX 파일로 저장. 열 너비 자동 조정 포함.

🤖 Gemini AI 이상치 분석

요구량 vs 실제 투입량 오차를 AI가 공정 특성 고려하여 유연하게 탐지. 원인 추론까지 자동 생성.

📧 Gmail 자동 발송

AI 분석 결과를 본문에, 엑셀 2개를 첨부하여 담당자에게 자동 발송. SMTP SSL 443.

📝 운영 로그 자동 기록

일자별 로그 파일 자동 생성. DB 접속 성공/실패, 실행 단계별 이력 추적 가능.

📸 시각 증빙 자료

이미지를 클릭하면 확대 보기가 가능합니다.
