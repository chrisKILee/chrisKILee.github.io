AI-WORKER 인증 과제

AI 기반 로그 분석 시스템

Zabbix·Grafana·PostgreSQL·NiFi 로그를 통합 관제하고, Google Gemini AI가 장애 원인을 자동 분석하여 60분 걸리던 대응 시간을 5분으로 단축

2026. 4. 8 🏅 최종후보

Representative Screen

😣 문제 정의 · 배경

기존의 어려움

  • 🔴 장애 대응 지연 — 파편화된 로그를 수동으로 교차 분석, 원인 파악에 60분 이상 소요
  • 📋 반복 행정 낭비 — 매월 보고서 수작업에 엔지니어 8시간 소비
  • 👤 숙련도 의존 — 담당자 숙련도에 따라 분석 품질 편차, 부재 시 대응 공백

✨ AI로 해결한 방식

  • 🤖 Gemini AI 자동 분석 — 로그 선택 시 자동으로 원인 분석·조치 권고안 생성
  • 📊 통합 대시보드 — 4개 시스템 로그를 단일 화면에서 조회
  • 📄 보고서 자동 생성 — 기간 지정 후 클릭 한 번으로 PDF 완성

③ 업무 효율성
  • 🎯수치 명확(분석 시간 91%, 보고서 작성 98% 절감).
  • 💡자동 수집 데몬 + AI 분석 + PDF 생성이 소스코드에서 모두 구현 확인.
  • 📊DataForge 서비스에 실제 운영 중.

  • 📊Few-Shot 학습 루프로 AI 품질 누적 향상 구조까지 구현.

  • 🎯DataForge 서비스 전체 운영 인프라로 활용.
  • 💡엔지니어 암묵지를 df_training_data로 자산화.
  • 📊장애 대응 시간 단축 → 서비스 연속성에 직접 기여.

⚡ 주요 기능

🤖 AI 자동 로그 분석

로그 선택 시 Gemini AI가 즉시 원인 분석·조치 권고안 생성. 로그 유형별 전용 프롬프트 적용

📊 통합 대시보드

Zabbix·Grafana·PostgreSQL·NiFi 4개 시스템 로그를 단일 화면에서 실시간 조회. 자동 새로고침(10s/30s/1m)

📄 보고서 자동 생성

기간 지정 → 이벤트 자동 집계 → PDF 보고서 생성. 월 8시간 → 1분으로 단축

🧠 Few-Shot 학습 루프

우수 분석 사례 승인 → 자동 저장 → 이후 AI 분석 시 자동 참조. 사용할수록 품질 향상

🔔 Google Chat 알림

AI 분석 결과를 Google Chat Cards V2 포맷으로 팀 채널 자동 발송

⚙️ 자동 수집 데몬

Zabbix 이벤트(60초), 호스트 인벤토리(300초) 백그라운드 자동 수집. 30일 보존

🧠 AI 활용 방식 · 기술 스택

AI 모델 구성

  • 🔹 Zabbix 분석 — gemini-2.5-flash
  • 🔹 Grafana 분석 — gemini-2.5-flash
  • 🔹 PostgreSQL 분석 — gemini-2.5-flash (DBA 관점)
  • 🔹 NiFi 분석 — gemini-2.5-flash (데이터 엔지니어 관점)
  • 🔹 파일 업로드 분석 — gemini-2.5-flash

💡 Few-Shot 학습 흐름

① AI 분석 → ② 우수 사례 승인 → ③ df_training_data 저장 → ④ 다음 분석 시 프롬프트 컨텍스트 자동 주입
