⚙️ 어드민 모드 사용 가이드

🔑 어드민 모드 진입 · 종료
진입: URL 끝에 #gdedse-adm-2026 추가
종료: URL에서 # 이하 삭제 후 Enter → 일반 뷰로 전환
💡 어드민 모드에서는 상단에 빨간 줄과 ADMIN MODE 뱃지가 표시됩니다.
모든 변경사항은 이 브라우저에 자동 저장됩니다. 별도 저장 버튼이 없습니다.
🔧 상단 버튼
도움말 지금 보고 있는 이 화면을 엽니다.
Reset 브라우저에 저장된 로컬 변경사항을 모두 취소하고, 서버의 site.json으로 원상복구합니다.
Export site.json 현재 설정을 파일로 다운로드합니다. 이 파일을 루트에 덮어쓴 뒤 git commit하면 모든 기기에 영구 적용됩니다.
📁 섹션 컨트롤 (각 섹션 헤더 오른쪽)
접기 / 펴기 섹션 이름 왼쪽의 화살표 버튼입니다. 클릭하면 하위 카테고리가 접히거나 펼쳐집니다. 어드민/일반 모드 모두 동작합니다.
이름 변경 섹션 제목을 수정합니다. 클릭하면 입력창이 열리고, 새 이름을 입력 후 Enter 또는 확인 버튼을 누르면 즉시 반영됩니다.
보이기 / 숨기기 일반 방문자에게 이 섹션을 보여줄지 결정합니다. 숨기면 반투명하게 표시되고 숨김 뱃지가 붙습니다. 어드민 모드에서는 항상 보입니다.
위로 이동 이 섹션을 목록에서 한 칸 위로 올립니다.
아래로 이동 이 섹션을 목록에서 한 칸 아래로 내립니다.
섹션 삭제 이 섹션을 삭제합니다. 안에 있던 카테고리들은 삭제되지 않고 미분류 영역으로 이동됩니다.
🗂 카테고리 컨트롤 (각 카테고리 오른쪽)
드롭
다운
섹션 이동 (드롭다운) 드롭다운에서 원하는 섹션을 선택하면 해당 카테고리가 즉시 이동됩니다. 미분류를 선택하면 어느 섹션에도 속하지 않습니다.
섹션 이동 (드래그앤드랍) 카테고리 카드를 직접 다른 섹션으로 드래그하면 즉시 이동됩니다. 미분류 영역으로도 드래그할 수 있습니다.
카테고리 보이기 / 숨기기 일반 방문자에게 이 카테고리를 보여줄지 결정합니다. 해당 카테고리의 모든 파일 카드가 함께 숨겨집니다.
새 탭에서 목록 열기 해당 카테고리의 파일 목록 페이지를 새 탭으로 엽니다. 파일을 직접 관리할 때 사용합니다.
📄 파일 카드 컨트롤 (카드 하단 오른쪽)
파일 보이기 / 숨기기 일반 방문자에게 개별 파일 카드를 보여줄지 결정합니다. 숨겨진 파일은 어드민 모드에서 반투명하게 표시됩니다. 설정은 site.json에 저장됩니다.
➕ 추가 버튼
카테고리 생성 (각 섹션 하단) 새 카테고리를 만듭니다. 이름과 secretHash를 입력하면 site.json에 추가되고, SPA shell 파일 생성 명령어를 안내합니다.
새 섹션 추가 (맨 아래) 새로운 섹션을 만듭니다. 이름을 입력하면 빈 섹션이 추가됩니다. 이후 카테고리 배정으로 카테고리를 넣으세요.
🗂 미분류 카테고리 영역
어드민 모드에서만 보이는 영역입니다. 어떤 섹션에도 속하지 않은 카테고리들이 여기에 모입니다.
드롭다운으로 섹션을 선택하면 즉시 배정됩니다.
💾 변경사항 저장 흐름
1. 어드민 모드에서 변경
→ 2. 브라우저 localStorage에 자동 저장 (즉시, 새로고침해도 유지)
→ 3. Export site.json 클릭 → 파일 다운로드
→ 4. 다운로드된 파일을 site.json에 덮어쓰기
→ 5. git commit & push → GitHub Pages 배포 (약 30~60초)
⚠️ Export → git commit을 하지 않으면 이 브라우저에서만 변경사항이 유지됩니다.
다른 기기나 브라우저에서는 이전 설정이 보입니다.
