🎯 검토 목적: 릴리즈 전 사용자 관점 문제점 식별

0. 사전 요구사항 확인

Docker 설치 확인

bash
docker --version
docker compose version

두 명령어 모두 정상 출력되면 준비 완료. 하나라도 실패하면 아래 설치 진행.

Docker 설치 (Ubuntu / WSL2)

bash
sudo apt-get update
sudo apt-get install -y ca-certificates curl gnupg lsb-release

sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

docker-compose-plugin이 핵심 — 이게 없으면 docker compose 명령어 사용 불가

sudo 없이 docker 사용 (선택)

bash
sudo usermod -aG docker $USER
# 터미널 재시작 후 적용

pnpm 설치 확인

bash
pnpm --version

1. 레포지토리 클론

bash
git clone git@github.com:VntgCorp/RND-NX.git
cd RND-NX

2. 브랜치 체크아웃

bash
git fetch origin
git checkout feature/chris-nolja

# 확인
git branch --show-current
# feature/chris-nolja

3. 의존성 설치

bash
pnpm install

4. 인프라 환경변수 설정

bash
cd infra/local/docker
cp .env.example .env.local
.env.local
DATABASE_DB=chris-nolja-db          # ← 프로젝트명에 맞게 변경
DATABASE_USER=chris-nolja-user       # ← 프로젝트명에 맞게 변경
DATABASE_PASSWORD=chris-nolja-password

5. 인프라 서버 실행 (DB / Redis / Kafka)

bash
cd infra/local/docker
make all-up       # PostgreSQL + Redis + Kafka 실행
make ps           # 상태 확인

6. NX 앱 개발 서버 실행

bash
cd ../../..   # 레포 루트로
pnpm nx serve chris-nolja-app
# front
pnpm nx serve "chris-nolja/fe-user-client"

로컬 실행 방법

  1. 로컬 DB 시작 
    cd /home/chris/git/RND-NX/projects/chris-nolja
docker compose up -d
    PostgreSQL: localhost:5433, DB: insamaster
  2. 의존성 설치 (최초 1회, 루트에서)
    ⚠️ pnpm 모노레포 — 서브 디렉토리에서 npm install 금지. workspace:* 프로토콜은 pnpm 전용
    cd /home/chris/git/RND-NX
pnpm install
  3. Prisma Client 생성 + 마이그레이션 
    cd projects/chris-nolja/be-api-server
npm run prisma:generate

cd ../db-postgres
npx prisma migrate dev --schema=./src/api-server-db/prisma
  4. 서버 실행 
    # 터미널 1 — BE (port 23000)
cd projects/chris-nolja/be-api-server
npm run start:dev

# 터미널 2 — FE (port 23001)
cd projects/chris-nolja/fe-user-client
npm run dev
