01 개요

여행 앱이 아니라 협업 플랫폼

TREK은 "A self-hosted, real-time collaborative travel planner — with maps, budgets, packing lists, a journal, and AI built in"이라는 한 줄로 스스로를 소개한다. 핵심은 세 가지 축이다.

05 인증 · 보안

계정 체계가 기업급이다

여러 명이 같이 쓰는 협업 도구인 만큼, 인증 체계는 개인용 앱 수준을 넘는다.

🔐
SSO (OIDC)

Google, Apple, Authentik, Keycloak 등 모든 OIDC 프로바이더 연동 가능.

🔢
2FA / TOTP

otplib 기반 TOTP + 백업 코드 지원.

🔑
패스키(WebAuthn)

지문·얼굴·PIN·보안키로 비밀번호 없이 로그인. 관리자가 토글 가능.

06 설치

Docker 한 줄, 30초 시작

README에 실려 있는 설치 명령어 그대로다.

사전 요구사항
리버스 프록시(Nginx/Caddy 등)를 앞단에 둘 경우 WebSocket 업그레이드(/ws) 경로를 반드시 통과시켜야 실시간 동기화가 동작한다.
1
Docker 단일 실행
암호화 키를 생성하고 컨테이너 하나로 바로 띄운다.
bash 
ENCRYPTION_KEY=$(openssl rand -hex 32) docker run -d -p 3000:3000 \
  -e ENCRYPTION_KEY=$ENCRYPTION_KEY \
  -v ./data:/app/data -v ./uploads:/app/uploads mauriceboe/trek
2
Kubernetes(Helm)로 운영 배포
클러스터 환경이라면 공식 Helm 차트를 사용한다.
bash 
helm repo add trek https://mauriceboe.github.io/TREK
helm repo update
helm install trek trek/trek
3
업데이트 & PWA 설치
docker compose pull && docker compose up -d로 갱신. 브라우저에서 "홈 화면에 추가"만으로 앱스토어 없이 PWA 설치 가능.
07 라이선스

AGPL-3.0 — 상용 서비스는 조건부

⚠️ 네트워크 서비스 조항 (AGPL 제13조)
개인·사내 셀프호스트는 자유롭게 사용 가능하다. 단, TREK을 수정해서 제3자에게 네트워크 서비스로 제공할 경우, 수정한 소스코드(Corresponding Source)를 이용자에게 무료로 제공할 기회를 눈에 띄게 안내해야 한다 — 일반적인 오픈소스 라이선스보다 엄격한 조건이다.
