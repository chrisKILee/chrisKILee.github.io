1. 핵심 개념 이해하기

성공적인 자동화를 위해 사용되는 두 가지 핵심 기술의 역할을 이해합니다.

🚀

Google Antigravity

단순한 코드 자동 완성 도구가 아닙니다. Gemini 3 Pro 및 Claude Sonnet 4.5 등 최신 거대언어모델(LLM)을 탑재한 '에이전트 우선(Agent-first) 차세대 통합 개발 환경(IDE)'입니다. AI 에이전트가 터미널과 브라우저를 직접 제어하며 자율적으로 코드를 작성하고 검증합니다. 현재 퍼블릭 프리뷰 기간 동안 개인에게 무료로 제공됩니다.

🔌

MCP (Model Context Protocol)

AI 모델이 외부 도구나 데이터베이스와 안전하게 통신할 수 있게 해주는 오픈 표준 규격(일종의 'AI용 USB-C')입니다. Antigravity가 호스트, AI가 클라이언트라면, Figma MCP 서버는 디자인 데이터를 AI가 이해할 수 있는 코드로 번역해 주는 '다리(Bridge)' 역할을 수행합니다.

⚠️ 2. 요금제에 대한 정확한 팩트 체크

무료 계정으로 이 모든 것이 가능할까요? 기술적으로는 "가능"하지만, 실무적으로는 "불가능"에 가깝습니다.

제한 사항 (Starter 플랜)

Figma 무료 사용자는 원격 MCP 서버 연결은 가능하지만, 월 최대 6회의 도구 호출 권한만 부여됩니다. 화면 하나 변환 시 3~5회가 소모되므로 한 달에 1~2개 화면만 테스트 가능합니다.

권장 사항 (Professional 플랜)

실제 프로젝트 진행을 위해서는 하루 200~600회 호출이 가능한 Professional 플랜($16/월)과 개발 좌석(Dev Seat) 확보가 필수적입니다.

월간 API 도구 호출 한도 비교

* Pro 플랜은 일일 수백 회 호출을 바탕으로 한 월간 추정치입니다.

3. 실전 1단계: Figma 디자인 최적화

AI가 코드를 잘 짜게 하려면, 원본 파일이 구조화되어 있어야 합니다. AI는 그림이 아닌 노드 트리와 속성을 읽습니다.

  • 1
    의미 있는 이름 부여 (Semantic Naming)

    Frame 123 대신 SubmitButton, PricingCardContainer처럼 역할 기반으로 이름을 지어주세요.

  • 2
    오토 레이아웃(Auto Layout) 필수 적용

    오토 레이아웃을 사용해야 AI가 이를 CSS의 Flexbox나 Grid 아키텍처로 정확히 매핑하여 반응형 웹을 구현할 수 있습니다.

  • 3
    디자인 토큰(변수) 사용

    색상이나 간격을 단순 Hex 코드가 아닌 Figma의 Variables로 정의하면, AI가 Tailwind CSS의 테마 설정과 연결된 깔끔한 코드를 작성합니다.

4. 실전 2단계: Antigravity와 Figma 연결하기

진행 전, Figma의 Settings > Security에서 Personal Access Token을 미리 발급받아 복사해 두세요.

  1. Antigravity 에디터 사이드 패널 상단의 ... 아이콘을 클릭하고 "MCP Servers"를 선택해 내장 스토어를 엽니다.
  2. "Figma Dev Mode MCP"를 검색하여 Install을 클릭합니다.
  3. 브라우저 창이 열리면 Figma 계정 접근 권한을 승인(OAuth 인증)합니다.
  4. 연결이 완료되면 #get_design_context 같은 도구가 에이전트 패널에 나타납니다.

데스크톱 앱 제약 등을 우회하고 싶다면 GitHub 별 13,300개 이상을 받은 Framelink MCP 서버를 수동으로 설정할 수 있습니다.

  1. Manage MCP Servers 메뉴에서 View raw config를 눌러 mcp_config.json 파일을 엽니다.
  2. 아래 코드를 붙여넣습니다. (서버 이름에 띄어쓰기 대신 하이픈 사용 필수)
{
  "mcpServers": {
    "Framelink-MCP-for-Figma": {
      "command": "npx",
      "args": [
        "-y",
        "figma-developer-mcp",
        "--figma-api-key=여기에_발급받은_토큰_입력",
        "--stdio"
      ]
    }
  }
}

5. 실전 3단계: AI 에이전트에게 코드 생성 지시

연결이 끝났다면, 대화형 인터페이스를 통해 프롬프트를 입력하고 코드를 뽑아낼 차례입니다.

1

Figma에서 변환하고 싶은 프레임을 선택하고 우클릭하여 "Copy link to selection"을 누릅니다.

2

Antigravity 챗 창에 링크를 붙여넣고, 프레임워크와 아키텍처를 명시하는 '지침 기반 프롬프트'를 입력합니다.

3

에이전트는 자율적으로 노드 정보를 가져오고, React+Tailwind 구조의 200~350줄가량 초안 코드를 반환합니다.

Antigravity Chat

이 Figma 디자인 링크(https://figma.com/...)를 분석해서 Next.js 14 환경에 맞는 React 컴포넌트로 만들어줘. Tailwind CSS를 사용하고, 모든 요소는 하나의 파일에 넣지 말고 src/components/ui 폴더 내에 분리해서 저장해. 버튼에는 클라이언트 측 상호작용을 위해 상단에 'use client'를 선언해 줘.

💡 6. 성공적인 실무 적용을 위한 팁

📝 AGENTS.md 활용

프로젝트 최상위 경로에 .agent 또는 AGENTS.md 파일을 만들고 "우리 팀은 Shadcn UI를 사용한다" 같은 규칙을 적어두세요. AI의 코드 생성 성공률과 일관성이 비약적으로 상승합니다.

🎯 완벽주의 버리기

AI가 생성하는 코드는 훌륭한 "강력한 초안(Strong first draft)"입니다. 정적인 UI 레이아웃은 완벽하게 잡아내지만, 복잡한 상태 관리나 비즈니스 로직 연동은 여전히 개발자의 마무리 손길이 필요함을 기억하세요.
